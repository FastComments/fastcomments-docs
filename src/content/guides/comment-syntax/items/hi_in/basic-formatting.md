FastComments कमेंट लिखने के लिए Markdown और HTML के एक सरल सबसेट का संयोजन उपयोग करता है।

[Markdown सिंटैक्स के लिए एक अच्छा संसाधन यहाँ है](https://www.markdownguide.org/cheat-sheet/)।

अधिकांश सामान्य फ़ॉर्मेटिंग के लिए, आप फ़ॉर्मेटिंग टूलबार का उपयोग करके टेक्स्ट को बोल्ड या इटैलिक करने जैसे काम कर सकते हैं।

कुछ सिंटैक्स उदाहरण हैं:

- बोल्ड:
  - `**bold**`
  - `<b>bold text</b>`
- इटैलिक्स:
  - `*italics*`
  - `<i>italic text</i>`
- स्ट्राइकथ्रू:
  - `~~strikethrough~~`
  - `<strike>strikethrough</strike>`
- कोट्स:
  - `> quote`

ध्यान दें कि Markdown हेडिंग समर्थित नहीं हैं।

लिंक उनके रॉ URL के रूप में लिखे जा सकते हैं, बिना HTML या अन्य सिंटैक्स के, और डिफ़ॉल्ट रूप से लिंक को `target="nofollow noopener"` के साथ एक क्लिक करने योग्य लिंक में बदल दिया जाएगा ताकि स्पैमर्स को हतोत्साहित किया जा सके। कुछ साइटें स्वचालित लिंक निर्माण को अक्षम करने का विकल्प चुन सकती हैं।

क्रमबद्ध सूचियाँ इस तरह लिखी जा सकती हैं:

```
1. One Item.
2. Second Item.
3. Third Item.
```

बुलेटेड सूचियों के लिए भी यही बात है:

```
- Some point.
- Some other point.
```

प्रोग्रामिंग-उन्मुख समुदायों के लिए, कोड को कमेंट एरिया में पेस्ट करके साझा किया जा सकता है, और भाषा का स्वतः पता लगाकर फ़ॉर्मेट किया जाएगा। कोड को `<code></code>` टैग या बैकटिक्स के साथ Markdown कोड फ़ेंस में जोड़ा जा सकता है।
