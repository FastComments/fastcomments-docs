#### 填充自動完成

HashTags 可以透過兩種方式填充。

首先，預設情況下使用者可以輸入 `#` 符號和一些文字——如果已有現有的 hashtags，將會顯示自動完成 UI。

如果使用者輸入新的 hashtag，[除非已停用](/guide-customizations-and-configuration.html#disable-automatic-hashtag-creation)，該 hashtag
將會自動建立並高亮顯示。

第二種方式是手動定義每個 hashtag。這將在本文件中介紹。

#### 使用案例

HashTags 對社群成員導航以尋找相關討論非常有用。它們也可用於標記相關的資訊片段（作為連結），可以透過我們的 API 定義。例如，hashtags 可用於標記：

- 工單系統中的工單。
- CRM 中的文件或頁面。
- 檔案。
