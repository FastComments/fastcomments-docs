#### Remplissage de l'autocomplétion

Les HashTags peuvent être remplis de deux manières.

Premièrement, par défaut, les utilisateurs peuvent saisir le symbole `#` suivi de texte - et si des hashtags existent déjà, une interface d'autocomplétion sera affichée.

Si un utilisateur saisit un nouveau hashtag, [sauf si cette fonctionnalité est désactivée](/guide-customizations-and-configuration.html#disable-automatic-hashtag-creation), le hashtag
sera automatiquement créé et mis en surbrillance.

La seconde manière consiste à définir manuellement chaque hashtag. C'est ce qui est décrit dans ce document.

#### Cas d'utilisation

Les HashTags sont utiles pour permettre aux membres de la communauté de naviguer afin de trouver des discussions pertinentes. Ils sont également utiles pour étiqueter des
informations pertinentes, sous forme de liens, qui peuvent être définis via notre API. Par exemple, les hashtags pourraient être utilisés pour étiqueter :

- Des tickets dans un système de ticketing.
- Des documents ou des pages dans un CRM.
- Des fichiers.
