#### Заполнение автодополнения

Хэштеги могут быть заполнены двумя способами.

Во-первых, по умолчанию пользователи могут ввести символ `#` и некоторый текст — и если существуют существующие хэштеги, будет показан интерфейс автодополнения.

Если пользователь вводит новый хэштег, [если это не отключено](/guide-customizations-and-configuration.html#disable-automatic-hashtag-creation), хэштег
будет автоматически создан и выделен.

Второй способ — вручную определить каждый хэштег. Это описано в данном документе.

#### Варианты использования

Хэштеги полезны для участников сообщества, чтобы ориентироваться и находить релевантные обсуждения. Они также полезны для пометки релевантной
информации в виде ссылок, которые можно определить через наш API. Например, хэштеги можно использовать для пометки:

- Заявок в системе тикетов.
- Документов или страниц в CRM.
- Файлов.
