#### Autovervollständigung befüllen

HashTags können auf zwei Arten befüllt werden.

Erstens können Benutzer standardmäßig das `#`-Symbol und etwas Text eingeben – und wenn bereits vorhandene Hashtags existieren, wird eine Autovervollständigungs-UI angezeigt.

Wenn ein Benutzer einen neuen Hashtag eingibt, [sofern nicht deaktiviert](/guide-customizations-and-configuration.html#disable-automatic-hashtag-creation), wird der Hashtag
automatisch erstellt und hervorgehoben.

Die zweite Möglichkeit ist, jeden Hashtag manuell zu definieren. Dies wird in diesem Dokument behandelt.

#### Anwendungsfälle

HashTags sind nützlich, damit Mitglieder der Community zu relevanten Diskussionen navigieren können. Sie sind auch nützlich, um relevante
Informationen als Links zu kennzeichnen, die über unsere API definiert werden können. Beispielsweise könnten Hashtags verwendet werden, um Folgendes zu kennzeichnen:

- Tickets in einem Ticketing-System.
- Dokumente oder Seiten in einem CRM.
- Dateien.
