FastComments 的 Zapier 应用将您的评论连接到数千个其他应用，无需编写代码。

使用它在有人发表评论时发送 Slack 消息，将每条评论记录到电子表格，创建  
来自表单提交的评论，或将评论者添加到您的 CRM。触发器在事件发生的瞬间触发，  
因为它们基于 webhook 而非轮询，操作调用 FastComments API  
代表您。

本指南假设您已有 FastComments 账户。[您可以在此创建一个。](https://fastcomments.com/auth/tenant-signup?packageId=flex)

本指南涵盖 Zapier 应用的使用。它调用的端点以及请求和响应格式、以及连接背后的 OAuth  
流程，均记录在 [API reference](./guide-api.html) 中。
