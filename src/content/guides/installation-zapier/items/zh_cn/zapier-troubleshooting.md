## 故障排除

**连接时提示 "You do not have permission"。** 当前登录的用户不是该账户的 API 管理员。
请让账户所有者在“用户”页面上授予 API 权限，或以所有者身份进行连接。

**连接标记的站点错误。** 授权页面连接的是您当时登录的账户。请在 Zapier 中断开连接，在 FastComments 控制台中切换账户，然后重新连接。

**事件停止到达。** 请检查控制台中的 Webhooks 页面。如果某个订阅的端点连续失败六天，它会被自动禁用，并显示原因。您可以在那里重新启用它，或者将 Zap 关闭再重新打开。如果订阅完全不存在，说明有人删除了它；将 Zap 关闭再重新打开即可重新创建。

**Zapier 提示账户需要重新连接。** 该连接已从“已连接应用”页面被撤销，批准该连接的用户失去了 API 权限，或者该账户已被删除。请从 Zapier 重新连接。

**操作失败并提示 "does not have write access"。** 该连接在批准时仅授予了只读权限。请重新连接并同时批准两项权限。

**速率限制和额度。** 操作和搜索会消耗您套餐中的 API 额度，并受到与 REST API 相同的速率限制。触发器不消耗额度。当 Zap 达到限制时，Zapier 会在 FastComments 报告的延迟时间后自动重试。

**Domain 下拉列表为空。** 只有在 FastComments 控制台的 Domains 页面上配置了域名后，域名才会显示。将该字段留空即可接收所有域名的事件。
