## Триггеры

Триггеры запускают Zap, когда в FastComments происходит событие. Все три работают мгновенно: FastComments доставляет событие в Zapier через вебхук в момент его возникновения. Никакие запросы к вашему аккаунту не выполняются, и не тратятся кредиты API в ожидании.

| Триггер | Срабатывает когда |
|---------|--------------------|
| New Comment | Комментарий опубликован. По умолчанию срабатывают только одобренные, не являющиеся спамом комментарии. |
| Updated Comment | Комментарий отредактирован, одобрен, проголосован, закреплён, заблокирован или иным образом изменён. |
| Deleted Comment | Комментарий удалён. |

## Параметры

**Domain.** Каждый триггер имеет необязательный фильтр домена, перечисляющий домены, настроенные в вашем аккаунте. Оставьте пустым, чтобы получать события со всех доменов.

**Include Unapproved and Spam Comments.** Только для триггера New Comment. Комментарии, находящиеся в модерации или помеченные как спам, по умолчанию пропускаются. Когда такой комментарий позже одобряется, срабатывает триггер Updated Comment, поэтому Zap, который должен реагировать на каждый комментарий, ставший видимым, использует Updated Comment с фильтром по полю approved.

## Как работает доставка

Включение Zap создаёт подписку на вебхук в вашем аккаунте, видимую на странице Webhooks с источником **API**. Отключение Zap удаляет её. На количество событий, принимаемых Zapier в минуту, действуют собственные ограничения; FastComments повторно пытается доставить неудавшуюся доставку с увеличивающейся задержкой и отключает подписку, которая продолжает сбоить в течение шести дней. Отключённую подписку можно повторно включить со страницы Webhooks, либо просто выключить и снова включить Zap, чтобы создать новую.

Аккаунт может иметь до 50 подписок API. Каждый Zap, использующий триггер FastComments, использует одну.
