## Действия и Поиски

Действия создают данные в FastComments; поиски ищут данные, чтобы последующий шаг мог их использовать. Каждое действие вызывает REST API FastComments и тратит те же кредиты API, что и вызов из вашего собственного кода: один кредит за вызов, если не указано иначе.

## Создать комментарий

Публикует комментарий на странице.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Yes | Идентификатор URL, который использует виджет комментариев на странице. Комментарии группируются по нему. |
| Page URL | Yes | Полный URL страницы, используется в уведомительных письмах. |
| Comment | Yes | Тело комментария в разметке FastComments. |
| Commenter Name | Yes | Имена уникальны для каждого email, поэтому повторное использование имени с другим email приводит к ошибке. |
| Commenter Email | No | Пользователь создаётся для данного email, если он ещё не существует. |
| User ID | No | Идентификатор существующего SSO‑пользователя. Имеет приоритет над именем и email. |
| Parent Comment ID | No | Устанавливается для публикации ответа. |
| Approved, Verified | No | По умолчанию оба значения true. Неодобренные комментарии остаются скрытыми до модерации. |
| Posted At | No | По умолчанию — текущее время. |
| Avatar URL, Page Title, Locale | No | Локаль по умолчанию `en_us`. |
| Show Live In Widget | No | Отправляет комментарий зрителям в реальном времени. Стоит 2 кредита вместо 1. |
| Run Spam Check, Send Emails | No | Отключено по умолчанию. |

## Создать страницу

Создаёт запись страницы до появления на ней комментариев, чтобы её можно было отображать в списках и ограничивать доступ. Принимает идентификатор URL, заголовок, URL и, при желании, идентификаторы групп SSO, которым разрешён просмотр.

## Создать SSO‑пользователя

Создаёт пользователя единого входа (SSO). Принимает ваш собственный идентификатор пользователя, имя пользователя и email, а также необязательные отображаемое имя, метку, аватар, веб‑сайт, идентификаторы групп и флаги уведомлений и конфиденциальности. Административные роли нельзя назначать через Zapier.

## Создать запись в ленте

Создаёт запись в ленте FastComments из HTML‑контента. Требуется идентификатор пользователя‑автора (идентификатор FastComments или SSO); заголовок, теги и один предварительный просмотр ссылки являются необязательными.

## Создать хеш‑тег

Создаёт хеш‑тег, который комментаторы могут использовать, с необязательным URL, на который он ссылается. Теги уникальны в пределах аккаунта, поэтому Zap, который создаёт тег при каждом запуске, должен использовать что‑то уникальное в теге.

## Пометить комментарий

Помечает комментарий для проверки модератором. Требуется идентификатор пользователя, который ставит пометку; подходит идентификатор автора, возвращённый при создании комментария.

## Поиски

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | Комментарий, либо ничего. |
| Find SSO User | Email | SSO‑пользователь, либо ничего. |
| Find Page | URL ID | Страница, либо ничего. |

Поиск, который ничего не находит, не приводит к ошибке Zap. Сочетайте поиск с созданием в режиме «найти или создать» Zapier, чтобы создать страницу или пользователя, если их нет.
