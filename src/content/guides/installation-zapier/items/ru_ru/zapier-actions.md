## Действия и Поиски

Действия создают данные в FastComments; поиски ищут данные, чтобы последующий шаг мог их использовать. Каждое действие вызывает REST API FastComments и тратит те же кредиты API, что и вызов из вашего собственного кода: один кредит за вызов, если не указано иначе.

## Создать комментарий

Публикует комментарий на странице.

| Поле | Обязательно | Примечания |
|------|--------------|------------|
| Идентификатор URL страницы | Да | Идентификатор URL, который использует виджет комментариев на странице. Комментарии группируются по нему. |
| URL страницы | Да | Полный URL страницы, используется в уведомительных письмах. |
| Комментарий | Да | Тело комментария в разметке FastComments. |
| Имя комментатора | Да | Имена уникальны для каждого email, поэтому повторное использование имени с другим email приводит к ошибке. |
| Email комментатора | Нет | Пользователь создаётся для данного email, если он ещё не существует. |
| ID пользователя | Нет | Существующий SSO ID пользователя. Имеет приоритет над именем и email. |
| ID родительского комментария | Нет | Установите, чтобы опубликовать ответ. |
| Одобрено, Проверено | Нет | По умолчанию оба значения true. Неодобренные комментарии остаются скрытыми до модерации. |
| Дата публикации | Нет | По умолчанию — текущий момент. |
| URL аватара, Заголовок страницы, Локаль | Нет | Локаль по умолчанию `en_us`. |
| Показать в реальном времени в виджете | Нет | Отправляет комментарий зрителям в реальном времени. Стоит 2 кредита вместо 1. |
| Запуск проверки спама, Отправка писем | Нет | По умолчанию отключено. |

## Создать страницу

Создаёт запись страницы до появления на ней комментариев, чтобы её можно было перечислять и ограничивать. Принимает идентификатор URL, заголовок, URL и, при желании, идентификаторы групп SSO, которым разрешён доступ.

## Создать SSO‑пользователя

Создаёт пользователя единого входа (SSO). Принимает ваш собственный ID пользователя, имя пользователя и email, а также необязательные отображаемое имя, метку, аватар, веб‑сайт, идентификаторы групп и флаги уведомлений и конфиденциальности. Административные роли нельзя предоставить через Zapier.

## Создать запись в ленте

Создаёт запись в ленте FastComments из HTML‑контента, с необязательным заголовком, автором, тегами и одним предварительным просмотром ссылки.

## Создать хеш‑тег

Создаёт хеш‑тег, который комментаторы могут использовать, с необязательным URL, на который он ссылается.

## Пометить комментарий

Помечает комментарий для проверки модератором. Укажите ID пользователя, который ставит пометку, или оставьте пустым, чтобы пометить от имени интеграции Zapier.

## Поиски

| Поиск | Ввод | Возвращает |
|-------|------|------------|
| Найти комментарий | ID комментария | Комментарий или ничего. |
| Найти SSO‑пользователя | Email | Пользователь SSO или ничего. |
| Найти страницу | ID URL | Страница или ничего. |

Поиск, который ничего не находит, не приводит к ошибке Zap. Сочетайте поиск с созданием в режиме «найти или создать» Zapier, чтобы создать страницу или пользователя, если их нет.
