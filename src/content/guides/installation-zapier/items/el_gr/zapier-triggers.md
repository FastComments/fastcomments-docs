## Ενεργοποιητές

Οι ενεργοποιητές ξεκινούν ένα Zap όταν συμβαίνει κάτι στο FastComments. Και οι τρεις είναι άμεσοι: το FastComments παραδίδει το γεγονός στο Zapier μέσω webhook τη στιγμή που συμβαίνει. Τίποτα δεν ελέγχει (polls) τον λογαριασμό σας και δεν δαπανώνται πιστώσεις API σε αναμονή.

| Ενεργοποιητής | Ενεργοποιείται όταν |
|---------------|----------------------|
| Νέο Σχόλιο | Δημοσιεύεται ένα σχόλιο. Από προεπιλογή μόνο εγκεκριμένα, μη‑spam σχόλια ενεργοποιούν. |
| Ενημερωμένο Σχόλιο | Ένα σχόλιο επεξεργάζεται, εγκρίνεται, ψηφίζεται, καρφιτσωθεί, κλειδώνεται ή αλλιώς τροποποιείται. |
| Διαγραμμένο Σχόλιο | Ένα σχόλιο διαγράφεται. |

Κάθε ενεργοποιητής επιστρέφει το πλήρες σχόλιο: id, URL σελίδας και URL ID, όνομα και email του σχολιαστή, το κείμενο του σχολίου ως markdown και ως HTML, αριθμούς ψήφων, σημαίες έγκρισης και spam, τη γλώσσα, τον τομέα και τυχόν αναφορές. Τα πεδία ταιριάζουν με το payload του webhook που τεκμηριώνεται στην ενότητα Webhooks, Data Structures.

## Επιλογές

**Domain.** Κάθε ενεργοποιητής έχει ένα προαιρετικό φίλτρο τομέα, που παραθέτει τους τομείς που έχουν ρυθμιστεί στον λογαριασμό σας. Αφήστε το κενό για να λαμβάνετε γεγονότα από κάθε τομέα.

**Include Unapproved and Spam Comments.** Μόνο στον ενεργοποιητή Νέο Σχόλιο. Τα σχόλια που κρατούνται για έλεγχο ή επισημαίνονται ως spam παραλείπονται από προεπιλογή. Όταν ένα τέτοιο σχόλιο εγκριθεί αργότερα, ο ενεργοποιητής Ενημερωμένο Σχόλιο ενεργοποιείται για αυτό, έτσι ένα Zap που πρέπει να αντιδρά σε κάθε σχόλιο που γίνεται ορατό χρησιμοποιεί το Ενημερωμένο Σχόλιο με ένα φίλτρο στο πεδίο approved.

## Πώς λειτουργεί η παράδοση

Η ενεργοποίηση ενός Zap δημιουργεί μια συνδρομή webhook στον λογαριασμό σας, ορατή στη σελίδα Webhooks με την πηγή **API**. Η απενεργοποίηση του Zap την αφαιρεί. Οι δικοί περιορισμοί του Zapier ισχύουν για το πόσα γεγονότα δέχεται ανά λεπτό· το FastComments επαναπροσπαθεί μια αποτυχημένη παράδοση, με αυξανόμενη καθυστέρηση, και απενεργοποιεί μια συνδρομή που αποτυγχάνει συνεχώς για έξι ημέρες. Μια απενεργοποιημένη συνδρομή μπορεί να ενεργοποιηθεί ξανά από τη σελίδα Webhooks, ή απλώς απενεργοποιήστε και ενεργοποιήστε ξανά το Zap για να δημιουργήσετε μια νέα.

Ένας λογαριασμός μπορεί να διατηρεί έως 50 συνδρομές API. Κάθε Zap που χρησιμοποιεί έναν ενεργοποιητή FastComments χρησιμοποιεί μία.
