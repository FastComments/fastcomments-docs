Η εφαρμογή FastComments για το Zapier συνδέει τα σχόλιά σας με χιλιάδες άλλες εφαρμογές χωρίς να γράψετε κώδικα.

Χρησιμοποιήστε την για να στέλνετε ένα μήνυμα Slack όταν κάποιος σχολιάζει, να καταγράφετε κάθε σχόλιο σε ένα υπολογιστικό φύλλο, να δημιουργείτε σχόλιο από υποβολή φόρμας ή να προσθέτετε σχολιαστές στο CRM σας. Οι ενεργοποιητές εκτελούνται τη στιγμή που συμβαίνει κάτι, επειδή βασίζονται σε webhooks αντί για polling, και οι ενέργειες καλούν το API του FastComments εκ μέρους σας.

Αυτός ο οδηγός υποθέτει ότι έχετε λογαριασμό FastComments. [Μπορείτε να δημιουργήσετε έναν εδώ.](https://fastcomments.com/auth/tenant-signup?packageId=flex)

Αυτός ο οδηγός καλύπτει τη χρήση της εφαρμογής Zapier. Τα endpoints που καλεί, μαζί με τις μορφές αιτήσεων και απαντήσεων και τη ροή OAuth πίσω από τη σύνδεση, τεκμηριώνονται στην [αναφορά API](./guide-api.html).
