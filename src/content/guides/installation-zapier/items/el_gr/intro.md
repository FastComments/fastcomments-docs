Η εφαρμογή FastComments για Zapier συνδέει τα σχόλιά σας με χιλιάδες άλλες εφαρμογές χωρίς να γράψετε κώδικα.

Χρησιμοποιήστε την για να στέλνετε ένα μήνυμα Slack όταν κάποιος σχολιάζει, να καταγράφετε κάθε σχόλιο σε ένα υπολογιστικό φύλλο, να δημιουργείτε
σχόλιο από υποβολή φόρμας ή να προσθέτετε σχολιαστές στο CRM σας. Οι ενεργοποιητές (triggers) εκτελούνται τη στιγμή που συμβαίνει κάτι,
επειδή βασίζονται σε webhooks αντί για polling, και οι ενέργειες (actions) καλούν το FastComments API εκ
μέρους σας.

Αυτός ο οδηγός υποθέτει ότι έχετε λογαριασμό FastComments. [Μπορείτε να δημιουργήσετε έναν εδώ.](https://fastcomments.com/auth/tenant-signup?packageId=flex)
