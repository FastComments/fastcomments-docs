## Ενέργειες και Αναζητήσεις

Οι ενέργειες δημιουργούν δεδομένα στο FastComments· οι αναζητήσεις εντοπίζουν δεδομένα ώστε ένα μεταγενέστερο βήμα να μπορεί να τα χρησιμοποιήσει. Κάθε ενέργεια καλεί το FastComments REST API και καταναλώνει τα ίδια API credits που θα κόστιζε η κλήση από τον δικό σας κώδικα: ένα credit ανά κλήση, εκτός εάν αναφέρεται διαφορετικά.

## Δημιουργία Σχολίου

Αναρτά ένα σχόλιο σε μια σελίδα.

| Πεδία | Απαιτείται | Σημειώσεις |
|-------|------------|------------|
| Page URL ID | Ναι | Το URL ID που χρησιμοποιεί το widget σχολίων στη σελίδα. Τα σχόλια ομαδοποιούνται με βάση αυτό. |
| Page URL | Ναι | Το πλήρες URL της σελίδας, χρησιμοποιείται στα email ειδοποιήσεων. |
| Comment | Ναι | Το σώμα του σχολίου σε FastComments markdown. |
| Commenter Name | Ναι | Τα ονόματα είναι μοναδικά ανά email, οπότε η επαναχρησιμοποίηση ονόματος με διαφορετικό email αποτυγχάνει. |
| Commenter Email | Όχι | Δημιουργείται χρήστης για το email όταν δεν υπάρχει ακόμη. |
| User ID | Όχι | Ένα υπάρχον SSO user id. Πρωταρχικό έναντι του ονόματος και του email. |
| Parent Comment ID | Όχι | Ορίζεται για να δημοσιευτεί μια απάντηση. |
| Approved, Verified | Όχι | Και τα δύο προεπιλογή είναι true. Τα μη εγκεκριμένα σχόλια παραμένουν κρυμμένα μέχρι τη διαχείριση. |
| Posted At | Όχι | Προεπιλογή είναι η τρέχουσα ώρα. |
| Avatar URL, Page Title, Locale | Όχι | Το Locale προεπιλογή είναι `en_us`. |
| Show Live In Widget | Όχι | Σπρώχνει το σχόλιο στους θεατές σε πραγματικό χρόνο. Κόστος 2 credits αντί για 1. |
| Run Spam Check, Send Emails | Όχι | Απενεργοποιημένο προεπιλογή. |

## Δημιουργία ή Ενημέρωση Σελίδας

Δημιουργεί μια εγγραφή σελίδας πριν υπάρξει οποιοδήποτε σχόλιο, ώστε να μπορεί να εμφανιστεί και να περιοριστεί. Δέχεται το URL ID, τον τίτλο, το URL και προαιρετικά τα SSO group ids που επιτρέπεται να δουν τη σελίδα. Εάν υπάρχει ήδη σελίδα με αυτό το URL ID, ενημερώνεται με τα παρεχόμενα πεδία, ώστε ένα Zap να μπορεί να εκτελείται επανειλημμένα για την ίδια σελίδα.

## Δημιουργία ή Ενημέρωση Χρήστη SSO

Δημιουργεί έναν χρήστη single sign-on. Δέχεται το δικό σας user id, όνομα χρήστη και email, καθώς και προαιρετικά εμφανιζόμενο όνομα, ετικέτα εμφάνισης, avatar, ιστοσελίδα, group ids, και σημαίες ειδοποιήσεων και απορρήτου. Εάν υπάρχει ήδη χρήστης με αυτό το id, ενημερώνεται αντί για δημιουργία. Οι διοικητικοί ρόλοι δεν μπορούν να χορηγηθούν από το Zapier.

## Δημιουργία Δημοσίευσης Ροής

Δημιουργεί μια δημοσίευση σε ροή FastComments από περιεχόμενο HTML. Το author user id είναι υποχρεωτικό (FastComments ή SSO user id); ο τίτλος, οι ετικέτες και μια προεπισκόπηση συνδέσμου είναι προαιρετικά.

## Δημιουργία ή Ενημέρωση Hash Tag

Δημιουργεί ένα hashtag που μπορούν να χρησιμοποιήσουν οι σχολιαστές, με προαιρετικό URL στο οποίο οδηγεί. Εάν το hashtag υπάρχει ήδη, ενημερώνεται αντί για δημιουργία.

## Σήμανση Σχολίου

Σημαδεύει ένα σχόλιο για έλεγχο από συντονιστή. Το id του χρήστη που κάνει τη σήμανση είναι υποχρεωτικό· το author id που επιστρέφεται από τη Δημιουργία Σχολίου λειτουργεί.

## Αναζητήσεις

| Αναζήτηση | Είσοδος | Επιστρέφει |
|----------|--------|------------|
| Find Comment | Comment ID | Το σχόλιο, ή τίποτα. |
| Find SSO User | Email | Ο χρήστης SSO, ή τίποτα. |
| Find Page | URL ID | Η σελίδα, ή τίποτα. |

Μια αναζήτηση που δεν βρίσκει τίποτα δεν αποτυγχάνει το Zap. Τα Find SSO User και Find Page προσφέρουν την επιλογή του Zapier «create if it doesn't exist», η οποία εκτελεί τη δημιουργία όταν δεν βρεθεί αποτέλεσμα.
