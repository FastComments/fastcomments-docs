## Δράσεις και Αναζητήσεις

Οι δράσεις δημιουργούν δεδομένα στο FastComments· οι αναζητήσεις αναζητούν δεδομένα ώστε ένα μεταγενέστερο βήμα να μπορεί να τα χρησιμοποιήσει. Κάθε δράση καλεί το FastComments REST API και ξοδεύει τα ίδια API credits που θα κόστιζε η κλήση από τον δικό σας κώδικα: ένα credit ανά κλήση εκτός εάν σημειωθεί διαφορετικά.

## Δημιουργία Σχολίου

Δημοσιεύει ένα σχόλιο σε μια σελίδα.

| Πεδίο | Απαιτείται | Σημειώσεις |
|-------|------------|------------|
| ID URL Σελίδας | Ναι | Το ID URL που χρησιμοποιεί το widget σχολίων στη σελίδα. Τα σχόλια ομαδοποιούνται με βάση αυτό. |
| URL Σελίδας | Ναι | Το πλήρες URL της σελίδας, χρησιμοποιείται σε email ειδοποιήσεων. |
| Σχόλιο | Ναι | Το σώμα του σχολίου σε FastComments markdown. |
| Όνομα Σχολιαστή | Ναι | Τα ονόματα είναι μοναδικά ανά email, έτσι η επαναχρησιμοποίηση ενός ονόματος με διαφορετικό email αποτυγχάνει. |
| Email Σχολιαστή | Όχι | Δημιουργείται χρήστης για το email όταν δεν υπάρχει ακόμη. |
| ID Χρήστη | Όχι | Ένα υπάρχον SSO ID χρήστη. Πρωταρχικό έναντι του ονόματος και του email. |
| ID Γονικού Σχολίου | Όχι | Ορίστε για να δημοσιεύσετε απάντηση. |
| Εγκεκριμένο, Επαληθευμένο | Όχι | Και τα δύο προεπιλεγμένα σε true. Τα μη εγκεκριμένα σχόλια παραμένουν κρυμμένα μέχρι να διαχειριστούν. |
| Δημοσιεύτηκε Στις | Όχι | Προεπιλογή η τρέχουσα ώρα. |
| URL Avatar, Τίτλος Σελίδας, Τοπική Ρύθμιση | Όχι | Η τοπική ρύθμιση προεπιλογή είναι `en_us`. |
| Εμφάνιση Ζωντανά Στο Widget | Όχι | Σπρώχνει το σχόλιο στους θεατές σε πραγματικό χρόνο. Κοστίζει 2 credits αντί για 1. |
| Εκτέλεση Ελέγχου Spam, Αποστολή Emails | Όχι | Απενεργοποιημένο από προεπιλογή. |

## Δημιουργία Σελίδας

Δημιουργεί μια εγγραφή σελίδας πριν υπάρξει οποιοδήποτε σχόλιο σε αυτήν, ώστε να μπορεί να καταγραφεί και να περιοριστεί. Δέχεται το ID URL, τον τίτλο, το URL και προαιρετικά τα SSO group ids που επιτρέπεται να δουν τη σελίδα.

## Δημιουργία Χρήστη SSO

Δημιουργεί έναν χρήστη single sign-on. Δέχεται το δικό σας ID χρήστη, όνομα χρήστη και email, καθώς και προαιρετικά όνομα εμφάνισης, ετικέτα εμφάνισης, avatar, ιστοσελίδα, group ids, και σημαίες ειδοποιήσεων και απορρήτου. Οι διαχειριστικοί ρόλοι δεν μπορούν να χορηγηθούν από το Zapier.

## Δημιουργία Ανάρτησης Feed

Δημιουργεί μια ανάρτηση σε ένα feed του FastComments από περιεχόμενο HTML, με προαιρετικό τίτλο, συγγραφέα, ετικέτες και μια προεπισκόπηση συνδέσμου.

## Δημιουργία Hash Tag

Δημιουργεί ένα hashtag που μπορούν να χρησιμοποιήσουν οι σχολιαστές, με προαιρετικό URL στο οποίο οδηγεί.

## Σημείωση Σχολίου

Σημαδεύει ένα σχόλιο για έλεγχο του συντονιστή. Παρέχετε το id του χρήστη που κάνει τη σήμανση, ή αφήστε το κενό για να σημαδέψετε ως η ενσωμάτωση Zapier.

## Αναζητήσεις

| Αναζήτηση | Είσοδος | Επιστρέφει |
|----------|---------|------------|
| Εύρεση Σχολίου | ID Σχολίου | Το σχόλιο, ή τίποτα. |
| Εύρεση Χρήστη SSO | Email | Ο χρήστης SSO, ή τίποτα. |
| Εύρεση Σελίδας | ID URL | Η σελίδα, ή τίποτα. |

Μια αναζήτηση που δεν βρίσκει τίποτα δεν αποτυγχάνει το Zap. Συνδυάστε μια αναζήτηση με δημιουργία στη λειτουργία "find or create" του Zapier για να δημιουργήσετε τη σελίδα ή τον χρήστη όταν λείπουν.
