## Ενέργειες και Αναζητήσεις

Οι ενέργειες δημιουργούν δεδομένα στο FastComments· οι αναζητήσεις αναζητούν δεδομένα ώστε ένα μεταγενέπειο βήμα να τα χρησιμοποιήσει. Κάθε ενέργεια καλεί το FastComments REST API και καταναλώνει τα ίδια API credits που θα κόστιζε η κλήση από τον κώδικά σας: ένα credit ανά κλήση εκτός εάν σημειωθεί διαφορετικά.

## Δημιουργία Σχολίου

Αναρτά ένα σχόλιο σε μια σελίδα.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Ναι | Το URL ID που χρησιμοποιεί το widget σχολίων στη σελίδα. Τα σχόλια ομαδοποιούνται με βάση αυτό. |
| Page URL | Ναι | Η πλήρης διεύθυνση URL της σελίδας, χρησιμοποιείται στα email ειδοποιήσεων. |
| Comment | Ναι | Το σώμα του σχολίου σε FastComments markdown. |
| Commenter Name | Ναι | Τα ονόματα είναι μοναδικά ανά email, έτσι η επαναχρησιμοποίηση ονόματος με διαφορετικό email αποτυγχάνει. |
| Commenter Email | Όχι | Ένας χρήστης δημιουργείται για το email όταν δεν υπάρχει ακόμη. |
| User ID | Όχι | Ένα υπάρχον SSO user id. Πρωταρχικό έναντι του ονόματος και του email. |
| Parent Comment ID | Όχι | Ορίστε για να δημοσιεύσετε μια απάντηση. |
| Approved, Verified | Όχι | Και τα δύο προεπιλογή είναι true. Τα μη εγκεκριμένα σχόλια παραμένουν κρυμμένα μέχρι τη διαχείριση. |
| Posted At | Όχι | Προεπιλογή είναι τώρα. |
| Avatar URL, Page Title, Locale | Όχι | Η Locale προεπιλογή είναι `en_us`. |
| Show Live In Widget | Όχι | Σπρώχνει το σχόλιο στους θεατές σε πραγματικό χρόνο. Κόστος 2 credits αντί για 1. |
| Run Spam Check, Send Emails | Όχι | Απενεργοποιημένο από προεπιλογή. |

## Δημιουργία Σελίδας

Δημιουργεί μια εγγραφή σελίδας πριν υπάρξει οποιοδήποτε σχόλιο σε αυτήν, ώστε να μπορεί να καταγραφεί και να περιοριστεί. Δέχεται το URL ID, τον τίτλο, το URL, και προαιρετικά τα SSO group ids που επιτρέπεται να δουν τη σελίδα.

## Δημιουργία SSO Χρήστη

Δημιουργεί έναν χρήστη single sign-on. Δέχεται το δικό σας user id, όνομα χρήστη και email, καθώς και προαιρετικά όνομα εμφάνισης, ετικέτα εμφάνισης, avatar, ιστοσελίδα, group ids, και σημαίες ειδοποιήσεων και ιδιωτικότητας. Οι διαχειριστικοί ρόλοι δεν μπορούν να χορηγηθούν από το Zapier.

## Δημιουργία Ανάρτησης Feed

Δημιουργεί μια ανάρτηση σε ένα FastComments feed από περιεχόμενο HTML. Το user id του δημιουργού είναι απαιτούμενο (ένα FastComments ή SSO user id); ο τίτλος, οι ετικέτες και μια προεπισκόπηση συνδέσμου είναι προαιρετικά.

## Δημιουργία Hash Tag

Δημιουργεί ένα hashtag που μπορούν να χρησιμοποιήσουν οι σχολιαστές, με προαιρετικό URL στον οποίο συνδέεται. Τα tags είναι μοναδικά ανά λογαριασμό, έτσι ένα Zap που δημιουργεί ένα σε κάθε εκτέλεση χρειάζεται κάτι μοναδικό στο tag.

## Σήμανση Σχολίου

Σημαδεύει ένα σχόλιο για έλεγχο από συντονιστή. Το id του χρήστη που κάνει τη σήμανση είναι απαιτούμενο· το author id που επιστρέφεται από τη Δημιουργία Σχολίου λειτουργεί.

## Αναζητήσεις

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | Το σχόλιο, ή τίποτα. |
| Find SSO User | Email | Ο SSO χρήστης, ή τίποτα. |
| Find Page | URL ID | Η σελίδα, ή τίποτα. |

Μια αναζήτηση που δεν βρίσκει τίποτα δεν αποτυγχάνει το Zap. Συνδυάστε μια αναζήτηση με δημιουργία στη λειτουργία "find or create" του Zapier για να δημιουργήσετε τη σελίδα ή τον χρήστη όταν λείπουν.
