## 連接您的帳戶

1. 在 Zapier 中，將 FastComments 步驟加入 Zap,或在 Zapier App Directory 中開啟 FastComments 應用程式頁面。
2. 選擇 **Sign in to FastComments**。Zapier 會先詢問您的地區：除非您的帳戶是在歐盟地區(`eu.fastcomments.com`)建立的，否則請選擇 **United States**。
3. 會開啟一個 FastComments 視窗。如果您尚未登入，請先登入。
4. 檢視同意頁面。它會顯示 Zapier 應用程式、將被連接的帳戶，以及所請求的權限(讀取與寫入)。選擇 **Approve**。
5. Zapier 會儲存此連接，並以您的網站名稱與使用者名稱標記它。

此連接使用 OAuth。不會將任何 API 金鑰複製到 Zapier 中，且 Zapier 持有的權杖僅適用於您核准的帳戶。

## 誰可以連接

核准連接的人必須是 FastComments 帳戶上的 **API admin**。帳戶擁有者具備此權限；其他團隊成員可以在 Users 頁面上被授予此權限。沒有此權限的人會看到「您沒有權限」的頁面，而不是同意表單。

## 連接正確的網站

同意頁面會連接您目前登入的帳戶。如果您管理多個帳戶，請在核准前從帳戶切換器切換到正確的帳戶，或使用同意頁面上的 **switch account** 連結。Zapier 中的連接標籤會顯示網站名稱，因此錯誤的選擇很容易被發現。

## 檢視與撤銷存取權

每個連接都會顯示在 FastComments 儀表板的 **Connected Apps** 下方，並顯示其所持有的權限以及最後使用時間。在那裡撤銷連接會立即中斷 Zapier;任何使用該連接的 Zap 都會停止，直到重新連接為止。您也可以在 Zapier 端的 **My Apps** 下方移除該連接。
