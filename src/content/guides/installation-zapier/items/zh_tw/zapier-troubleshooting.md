## 疑難排解

**連線時出現「You do not have permission」。** 目前登入的使用者不是該帳戶的 API 管理員。
請帳戶擁有者在「Users」頁面授予 API 權限，或以擁有者身分連線。

**連線標示的網站錯誤。** 同意頁面連線的是您當時登入的帳戶。請在 Zapier 中斷連線，在 FastComments 儀表板中切換帳戶，然後重新連線。

**事件停止送達。** 請檢查儀表板中的「Webhooks」頁面。若某個訂閱的端點連續失敗六天，系統會自動將其停用並顯示原因。您可以在該處重新啟用，或將 Zap 關閉再開啟。如果訂閱完全消失，表示有人將其刪除；將 Zap 關閉再開啟即可重新建立。

**Zapier 顯示帳戶需要重新連線。** 連線已從「Connected Apps」頁面被撤銷、核准連線的使用者失去了 API 權限，或帳戶已被刪除。請從 Zapier 重新連線。

**動作失敗並顯示「does not have write access」。** 連線當時僅以唯讀權限核准。請重新連線並核准兩項權限。

**速率限制與點數。** 動作與搜尋會消耗您方案中的 API 點數，並受到與 REST API 相同的速率限制。觸發器則不消耗任何點數。當 Zap 達到限制時，Zapier 會在 FastComments 回報的延遲時間後重試。

**「Domain」下拉選單是空的。** 網域只有在 FastComments 儀表板的「Domains」頁面中設定後才會顯示。將該欄位留空即可接收所有網域的事件。
