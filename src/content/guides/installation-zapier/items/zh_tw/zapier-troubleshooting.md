## 疑難排解

**「You do not have permission」在連線時。** 已登入的使用者不是此帳號的 API 管理員。請帳號擁有者在 Users 頁面授予 API 權限，或以擁有者身分連線。

**連線被標記為錯誤的網站。** 同意頁面會連接您當時已登入的帳號。於 Zapier 中斷開連線，於 FastComments 控制台切換帳號，然後重新連線。

**事件停止到達。** 請檢查控制台中的 Webhooks 頁面。若訂閱的端點連續六天失敗，系統會自動停用並顯示原因。於該處重新啟用，或將 Zap 關閉再開啟。若訂閱完全消失，表示有人刪除它；關閉再開啟 Zap 會重新建立它。

**Zapier 表示需要重新連接帳號。** 連線已在 Connected Apps 頁面被撤銷，或批准連線的使用者失去 API 權限，亦或帳號被刪除。請在 Zapier 中重新連接。

**動作失敗，顯示「does not have write access」。** 連線僅獲得唯讀權限。重新連接並批准讀寫兩項權限。

**速率限制與點數。** 行動與搜尋會消耗您方案中的 API 點數，且受限於與 REST API 相同的速率限制。觸發器不消耗點數。若 Zap 遭遇限制，Zapier 會在 FastComments 回報的延遲時間後重新嘗試。

**「Domain」下拉選單為空。** 當在 FastComments 控制台的 Domains 頁面設定完畢後，域名即會出現在下拉選單。若將此欄位留空，將接收所有域名的事件。
