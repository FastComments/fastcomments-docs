## 작업 및 검색

작업은 FastComments에 데이터를 생성하고, 검색은 데이터를 조회하여 이후 단계에서 사용할 수 있게 합니다. 각 작업은 FastComments REST API를 호출하며, 호출에 필요한 API 크레딧을 귀하의 코드와 동일하게 사용합니다: 별도 언급이 없는 한 호출당 1 크레딧이 소모됩니다.

## 댓글 생성

페이지에 댓글을 게시합니다.

| 필드 | 필수 | 비고 |
|-------|----------|-------|
| Page URL ID | 예 | 댓글 위젯이 페이지에서 사용하는 URL ID입니다. 댓글은 이 ID로 그룹화됩니다. |
| Page URL | 예 | 전체 페이지 URL이며, 알림 이메일에 사용됩니다. |
| Comment | 예 | FastComments 마크다운 형식의 댓글 본문입니다. |
| Commenter Name | 예 | 이름은 이메일당 고유하므로, 다른 이메일로 같은 이름을 재사용하면 실패합니다. |
| Commenter Email | 아니오 | 해당 이메일이 아직 존재하지 않을 경우 사용자가 생성됩니다. |
| User ID | 아니오 | 기존 SSO 사용자 ID입니다. 이름 및 이메일보다 우선합니다. |
| Parent Comment ID | 아니오 | 답글을 게시하려면 설정합니다. |
| Approved, Verified | 아니오 | 두 항목 모두 기본값은 true입니다. 승인되지 않은 댓글은 검토될 때까지 숨겨집니다. |
| Posted At | 아니오 | 기본값은 현재 시각입니다. |
| Avatar URL, Page Title, Locale | 아니오 | 로케일은 기본값이 `en_us`입니다. |
| Show Live In Widget | 아니오 | 댓글을 실시간으로 시청자에게 푸시합니다. 1크레딧 대신 2크레딧이 소모됩니다. |
| Run Spam Check, Send Emails | 아니오 | 기본값은 비활성화입니다. |

## 페이지 생성

댓글이 존재하기 전에 페이지 레코드를 생성하여 목록에 표시하고 제한할 수 있게 합니다. URL ID, 제목, URL을 입력받으며, 선택적으로 해당 페이지를 볼 수 있는 SSO 그룹 ID를 지정할 수 있습니다.

## SSO 사용자 생성

싱글 사인온 사용자를 생성합니다. 자체 사용자 ID, 사용자명 및 이메일을 입력받으며, 선택적으로 표시 이름, 표시 라벨, 아바타, 웹사이트, 그룹 ID, 알림 및 개인정보 플래그를 지정할 수 있습니다. 관리 역할은 Zapier를 통해 부여할 수 없습니다.

## 피드 포스트 생성

HTML 콘텐츠를 기반으로 FastComments 피드에 포스트를 생성합니다. 선택적으로 제목, 작성자, 태그 및 하나의 링크 미리보기를 지정할 수 있습니다.

## 해시 태그 생성

댓글 작성자가 사용할 수 있는 해시 태그를 생성합니다. 선택적으로 해당 해시 태그가 연결될 URL을 지정할 수 있습니다.

## 댓글 플래그 지정

댓글을 검토를 위해 플래그 지정합니다. 플래그를 지정하는 사용자의 ID를 제공하거나, 비워두면 Zapier 통합으로 플래그가 지정됩니다.

## 검색

| 검색 | 입력 | 반환 |
|--------|-------|---------|
| 댓글 찾기 | 댓글 ID | 댓글이 있으면 반환하고, 없으면 아무것도 반환하지 않습니다. |
| SSO 사용자 찾기 | 이메일 | SSO 사용자가 있으면 반환하고, 없으면 아무것도 반환하지 않습니다. |
| 페이지 찾기 | URL ID | 페이지가 있으면 반환하고, 없으면 아무것도 반환하지 않습니다. |

검색 결과가 없더라도 Zap이 실패하지 않습니다. Zapier의 "찾기 또는 생성" 모드에서 검색과 생성을 결합하면, 해당 페이지나 사용자가 없을 경우 자동으로 생성할 수 있습니다.
