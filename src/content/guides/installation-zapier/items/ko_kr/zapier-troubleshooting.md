## 문제 해결

**연결 시 "You do not have permission"** 라는 메시지가 표시됩니다. 로그인한 사용자가 계정의 API 관리자 권한이 없습니다.  
계정 소유자에게 사용자 페이지에서 API 권한을 부여하도록 요청하거나 소유자 계정으로 연결하십시오.

**연결이 잘못된 사이트로 표시됩니다.** 동의 페이지는 당시 로그인한  
계정을 연결합니다. Zapier에서 연결을 끊고, FastComments 대시보드에서 계정을 전환한 뒤 다시 연결하십시오.

**이벤트가 도착하지 않습니다.** 대시보드의 Webhooks 페이지를 확인하십시오. 엔드포인트가  
6일 동안 계속 실패한 구독은 자동으로 비활성화되며 이유가 표시됩니다. 해당 페이지에서 다시 활성화하거나 Zap을 끄고  
다시 켜십시오. 구독이 완전히 사라진 경우, 누군가 삭제한 것입니다; Zap을 끄고 다시 켜면 구독이 재생성됩니다.

**Zapier에서 계정을 다시 연결해야 한다고 표시됩니다.** 연결이 Connected Apps  
페이지에서 취소되었거나, 승인한 사용자가 API 권한을 잃었거나, 계정이 삭제되었습니다. Zapier에서 다시 연결하십시오.

**작업이 "does not have write access" 오류로 실패합니다.** 연결이 읽기 전용  
권한으로 승인되었습니다. 다시 연결하고 두 권한 모두 승인하십시오.

**속도 제한 및 크레딧.** 작업 및 검색은 플랜의 API 크레딧을 사용하며 REST API와 동일한  
속도 제한을 적용받습니다. 트리거는 크레딧을 사용하지 않습니다. 제한에 걸린 Zap은  
FastComments가 보고하는 지연 후 Zapier에 의해 재시도됩니다.

**Domain 드롭다운이 비어 있습니다.** 도메인은 FastComments 대시보드의 Domains 페이지에서  
설정된 후에 나타납니다. 모든 도메인에 대한 이벤트를 받으려면 필드를 비워 두십시오.
