## 문제 해결

**연결 시 "You do not have permission" 오류가 발생합니다.** 로그인한 사용자가 해당 계정의 API 관리자가 아닙니다.
계정 소유자에게 Users 페이지에서 API 권한을 부여해 달라고 요청하거나, 소유자 계정으로 연결하세요.

**연결이 잘못된 사이트로 표시됩니다.** 동의 페이지는 연결 당시 로그인되어 있던 계정을 연결합니다. Zapier에서 연결을 해제하고, FastComments 대시보드에서 계정을 전환한 후 다시 연결하세요.

**이벤트가 더 이상 도착하지 않습니다.** 대시보드의 Webhooks 페이지를 확인하세요. 엔드포인트가 6일 동안 계속 실패한 구독은 자동으로 비활성화되며 그 이유가 표시됩니다. 해당 페이지에서 다시 활성화하거나, Zap을 끄고 다시 켜세요. 구독이 완전히 사라진 경우 누군가 삭제한 것이므로, Zap을 끄고 다시 켜면 구독이 다시 생성됩니다.

**Zapier에서 계정을 다시 연결해야 한다고 표시됩니다.** Connected Apps 페이지에서 연결이 취소되었거나, 승인한 사용자가 API 권한을 잃었거나, 계정이 삭제되었을 수 있습니다. Zapier에서 다시 연결하세요.

**액션이 "does not have write access" 오류로 실패합니다.** 연결이 읽기 전용 권한으로 승인되었습니다. 다시 연결하여 두 권한을 모두 승인하세요.

**속도 제한 및 크레딧.** 액션과 검색은 플랜의 API 크레딧을 사용하며 REST API와 동일한 속도 제한이 적용됩니다. 트리거는 크레딧을 사용하지 않습니다. 제한에 도달한 Zap은 FastComments가 보고한 지연 시간 이후 Zapier가 재시도합니다.

**Domain 드롭다운이 비어 있습니다.** 도메인은 FastComments 대시보드의 Domains 페이지에서 구성된 후에 표시됩니다. 모든 도메인에 대한 이벤트를 받으려면 해당 필드를 비워 두세요.
