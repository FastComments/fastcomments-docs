## アクションと検索

アクションは FastComments にデータを作成します。検索はデータを検索し、後続のステップで使用できるようにします。各アクションは FastComments の REST API を呼び出し、呼び出しにかかる API クレジットを自分のコードと同様に消費します：特に記載がない限り、呼び出しごとに 1 クレジットです。

## コメント作成

ページにコメントを投稿します。

| フィールド | 必須 | 備考 |
|-------|----------|-------|
| Page URL ID | はい | コメントウィジェットがページで使用する URL ID です。コメントはこれでグループ化されます。 |
| Page URL | はい | 通知メールで使用されるフルページ URL です。 |
| Comment | はい | FastComments のマークダウン形式のコメント本文です。 |
| Commenter Name | はい | 名前はメールごとに一意であるため、別のメールで同じ名前を使用すると失敗します。 |
| Commenter Email | いいえ | まだ存在しないメールの場合、ユーザーが作成されます。 |
| User ID | いいえ | 既存の SSO ユーザー ID です。名前とメールより優先されます。 |
| Parent Comment ID | いいえ | 返信を投稿する際に設定します。 |
| Approved, Verified | いいえ | 両方ともデフォルトで true です。未承認のコメントはモデレーションされるまで非表示のままです。 |
| Posted At | いいえ | デフォルトは現在時刻です。 |
| Avatar URL, Page Title, Locale | いいえ | ロケールのデフォルトは `en_us` です。 |
| Show Live In Widget | いいえ | コメントをリアルタイムで閲覧者にプッシュします。クレジットは 1 ではなく 2 が必要です。 |
| Run Spam Check, Send Emails | いいえ | デフォルトでオフです。 |

## ページ作成

コメントが存在する前にページレコードを作成し、一覧表示や制限ができるようにします。URL ID、タイトル、URL、そしてオプションで閲覧を許可する SSO グループ ID を受け取ります。

## SSO ユーザー作成

シングルサインオンユーザーを作成します。独自のユーザー ID、ユーザー名、メールアドレスに加えて、オプションで表示名、表示ラベル、アバター、ウェブサイト、グループ ID、通知およびプライバシーフラグを受け取ります。管理者ロールは Zapier から付与できません。

## フィード投稿作成

HTML コンテンツから FastComments フィードに投稿を作成します。著者のユーザー ID が必須です（FastComments または SSO ユーザー ID）。タイトル、タグ、リンクプレビューはオプションです。

## ハッシュタグ作成

コメント投稿者が使用できるハッシュタグを作成します。オプションでリンク先の URL を指定できます。タグはアカウントごとに一意であるため、毎回実行される Zap が作成する場合はタグに一意なものが必要です。

## コメントフラグ付け

コメントにモデレーターのレビュー用フラグを付けます。フラグを付けるユーザーの ID が必須です；Create Comment で返される著者 ID が使用できます。

## 検索

| 検索 | 入力 | 戻り値 |
|--------|-------|---------|
| コメント検索 | コメント ID | コメントが返されます。見つからなければ何も返りません。 |
| SSO ユーザー検索 | メール | SSO ユーザーが返されます。見つからなければ何も返りません。 |
| ページ検索 | URL ID | ページが返されます。見つからなければ何も返りません。 |

検索で何も見つからない場合でも Zap は失敗しません。Zapier の「検索または作成」モードで検索と作成を組み合わせると、ページやユーザーが存在しないときに自動で作成できます。
