## アクションと検索

アクションは FastComments にデータを作成し、検索はデータを検索して後続のステップで使用できるようにします。各アクションは FastComments の REST API を呼び出し、呼び出しにかかる API クレジットを自分のコードと同様に消費します：特に記載がない限り、呼び出しごとに 1 クレジットです。

## コメントの作成

ページにコメントを投稿します。

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Yes | コメントウィジェットがページで使用する URL ID です。コメントはこの ID でグループ化されます。 |
| Page URL | Yes | 通知メールで使用されるページのフル URL です。 |
| Comment | Yes | FastComments のマークダウン形式のコメント本文です。 |
| Commenter Name | Yes | 名前はメールアドレスごとに一意であるため、異なるメールアドレスで同じ名前を使用すると失敗します。 |
| Commenter Email | No | まだ存在しないメールアドレスの場合、ユーザーが作成されます。 |
| User ID | No | 既存の SSO ユーザー ID です。名前とメールアドレスよりも優先されます。 |
| Parent Comment ID | No | 返信を投稿する場合に設定します。 |
| Approved, Verified | No | どちらもデフォルトで true です。未承認のコメントはモデレーションされるまで非表示のままです。 |
| Posted At | No | デフォルトは現在時刻です。 |
| Avatar URL, Page Title, Locale | No | ロケールはデフォルトで `en_us` です。 |
| Show Live In Widget | No | コメントをリアルタイムで閲覧者にプッシュします。クレジットは 1 ではなく 2 が必要です。 |
| Run Spam Check, Send Emails | No | デフォルトではオフです。 |

## ページの作成または更新

コメントが存在する前にページレコードを作成し、一覧表示やアクセス制限ができるようにします。URL ID、タイトル、URL、そしてオプションで閲覧を許可する SSO グループ ID を受け取ります。その URL ID のページが既に存在する場合、指定されたフィールドで更新されるため、同じページに対して Zap を繰り返し実行できます。

## SSO ユーザーの作成または更新

シングルサインオンユーザーを作成します。独自のユーザー ID、ユーザー名、メールアドレスに加えて、オプションで表示名、表示ラベル、アバター、ウェブサイト、グループ ID、通知およびプライバシーフラグを受け取ります。その ID のユーザーが既に存在する場合は更新されます。管理者ロールは Zapier から付与できません。

## フィード投稿の作成

HTML コンテンツから FastComments フィードに投稿を作成します。著者のユーザー ID が必須です（FastComments または SSO ユーザー ID）。タイトル、タグ、リンクプレビューはオプションです。

## ハッシュタグの作成または更新

コメント投稿者が使用できるハッシュタグを作成し、オプションでリンク先の URL を設定できます。タグが既に存在する場合は更新されます。

## コメントのフラグ付け

コメントにモデレーターのレビュー用フラグを付けます。フラグを付けるユーザーの ID が必須です；Create Comment で返される著者 ID が使用できます。

## 検索

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | コメント、または何も返りません。 |
| Find SSO User | Email | SSO ユーザー、または何も返りません。 |
| Find Page | URL ID | ページ、または何も返りません。 |

検索で何も見つからない場合でも Zap は失敗しません。Find SSO User と Find Page は Zapier の「存在しない場合は作成」オプションを提供し、何も見つからなかったときに対応する作成アクションを実行します。
