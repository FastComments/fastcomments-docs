FastComments の Zapier アプリは、コードを書かずにコメントを何千もの他のアプリと連携させます。

誰かがコメントしたときに Slack メッセージを投稿したり、すべてのコメントをスプレッドシートに記録したり、フォーム送信からコメントを作成したり、またはコメント投稿者を CRM に追加したりできます。トリガーは何かが起きた瞬間に発火します。これはポーリングではなく Webhook によって裏付けられているためで、アクションは FastComments API をあなたに代わって呼び出します。

このガイドは FastComments アカウントをお持ちであることを前提としています。[ここでアカウントを作成できます。](https://fastcomments.com/auth/tenant-signup?packageId=flex)

このガイドでは Zapier アプリの使用方法を説明します。呼び出されるエンドポイントやリクエスト・レスポンス形式、接続の背後にある OAuth フローは、[API リファレンス](./guide-api.html) に記載されています。
