O aplicativo FastComments para Zapier conecta seus comentários a milhares de outros aplicativos sem escrever código.

Use-o para publicar uma mensagem no Slack quando alguém comentar, registrar cada comentário em uma planilha, criar um  
comentário a partir de uma submissão de formulário, ou adicionar comentaristas ao seu CRM. Os gatilhos disparam no momento em que algo acontece,  
pois são baseados em webhooks em vez de polling, e as ações chamam a API do FastComments em seu  
nome.

Este guia assume que você tem uma conta FastComments. [Você pode criar uma aqui.](https://fastcomments.com/auth/tenant-signup?packageId=flex)
