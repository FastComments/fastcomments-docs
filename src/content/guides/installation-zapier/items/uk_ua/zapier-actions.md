## Дії та пошуки

Дії створюють дані у FastComments; пошуки шукають дані, щоб пізніший крок міг їх використати. Кожна дія викликає REST API FastComments і витрачає ті ж API‑кредити, які б коштувала виклик з вашого коду: один кредит за виклик, якщо не зазначено інше.

## Створити коментар

Публікує коментар на сторінці.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Yes | Ідентифікатор URL, який використовується віджетом коментарів на сторінці. Коментарі групуються за цим ідентифікатором. |
| Page URL | Yes | Повний URL сторінки, використовується у сповіщеннях електронною поштою. |
| Comment | Yes | Тіло коментаря у форматі FastComments markdown. |
| Commenter Name | Yes | Імена унікальні для кожного електронного листа, тому повторне використання імені з іншим електронним листом призводить до помилки. |
| Commenter Email | No | Користувач створюється для електронного листа, якщо він ще не існує. |
| User ID | No | Існуючий ідентифікатор SSO користувача. Має пріоритет над іменем та електронною поштою. |
| Parent Comment ID | No | Встановити, щоб опублікувати відповідь. |
| Approved, Verified | No | Обидва за замовчуванням true. Не затверджені коментарі залишаються прихованими до модерації. |
| Posted At | No | За замовчуванням — поточний час. |
| Avatar URL, Page Title, Locale | No | Locale за замовчуванням `en_us`. |
| Show Live In Widget | No | Відправляє коментар глядачам у реальному часі. Вартість 2 кредити замість 1. |
| Run Spam Check, Send Emails | No | Вимкнено за замовчуванням. |

## Створити сторінку

Створює запис сторінки до того, як на ній з'являться коментарі, щоб її можна було перелічити та обмежити. Приймає ідентифікатор URL, назву, URL та, за бажанням, ідентифікатори груп SSO, яким дозволено її переглядати.

## Створити SSO користувача

Створює користувача єдиного входу (SSO). Приймає ваш власний ідентифікатор користувача, ім'я користувача та електронну пошту, а також необов'язкові відображуване ім'я, мітку, аватар, веб‑сайт, ідентифікатори груп та прапорці сповіщень і конфіденційності. Адміністративні ролі не можна надати через Zapier.

## Створити запис у стрічці

Створює запис у стрічці FastComments з HTML‑вмісту, з необов'язковою назвою, автором, тегами та попереднім переглядом одного посилання.

## Створити хештег

Створює хештег, яким можуть користуватися коментатори, з необов'язковим URL, на який він посилається.

## Позначити коментар

Позначає коментар для перегляду модератором. Вкажіть ідентифікатор користувача, який виконує позначення, або залиште порожнім, щоб позначити від імені інтеграції Zapier.

## Пошуки

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | Коментар, або нічого. |
| Find SSO User | Email | SSO користувач, або нічого. |
| Find Page | URL ID | Сторінка, або нічого. |

Пошук, який нічого не знаходить, не призводить до помилки Zap. Поєднайте пошук зі створенням у режимі Zapier «знайти або створити», щоб створити сторінку або користувача, якщо їх немає.
