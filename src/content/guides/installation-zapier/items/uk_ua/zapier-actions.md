## Дії та пошуки

Дії створюють дані у FastComments; пошуки шукають дані, щоб наступний крок міг їх використати. Кожна дія викликає
REST API FastComments і витрачає ту саму кількість API-кредитів, яку коштував би виклик з вашого власного коду: один
кредит за виклик, якщо не вказано інше.

## Створити коментар

Публікує коментар на сторінці.

| Поле | Обов'язково | Примітки |
|-------|----------|-------|
| Page URL ID | Так | URL ID, який віджет коментарів використовує на сторінці. Коментарі групуються за ним. |
| Page URL | Так | Повна URL-адреса сторінки, використовується в листах сповіщень. |
| Comment | Так | Текст коментаря у markdown FastComments. |
| Commenter Name | Так | Імена унікальні для кожної електронної пошти, тому повторне використання імені з іншою електронною поштою завершиться помилкою. |
| Commenter Email | Ні | Для електронної пошти створюється користувач, якщо її ще не існує. |
| User ID | Ні | Ідентифікатор наявного SSO-користувача. Має пріоритет над ім'ям та електронною поштою. |
| Parent Comment ID | Ні | Встановіть, щоб опублікувати відповідь. |
| Approved, Verified | Ні | Обидва за замовчуванням true. Неухвалені коментарі залишаються прихованими до модерації. |
| Posted At | Ні | За замовчуванням — зараз. |
| Avatar URL, Page Title, Locale | Ні | Locale за замовчуванням `en_us`. |
| Show Live In Widget | Ні | Надсилає коментар глядачам у реальному часі. Коштує 2 кредити замість 1. |
| Run Spam Check, Send Emails | Ні | За замовчуванням вимкнено. |

## Створити або оновити сторінку

Створює запис сторінки до появи на ній будь-яких коментарів, щоб її можна було перелічити та обмежити. Приймає URL ID,
заголовок, URL та, за бажанням, ідентифікатори SSO-груп, яким дозволено її бачити. Якщо сторінка з таким URL ID вже існує, вона
оновлюється наданими полями, тому Zap може запускатися для однієї й тієї ж сторінки повторно.

## Створити або оновити SSO-користувача

Створює користувача єдиного входу. Приймає ваш власний ідентифікатор користувача, ім'я користувача та електронну пошту, а також необов'язкове відображуване ім'я,
відображувану мітку, аватар, вебсайт, ідентифікатори груп та прапорці сповіщень і приватності. Якщо користувач з таким ідентифікатором вже
існує, він оновлюється. Адміністративні ролі не можуть бути надані через Zapier.

## Створити публікацію у стрічці

Створює публікацію у стрічці FastComments з HTML-контенту. Ідентифікатор користувача-автора є обов'язковим (ідентифікатор користувача FastComments або
SSO); заголовок, теги та один попередній перегляд посилання є необов'язковими.

## Створити або оновити хеш-тег

Створює хеш-тег, який коментатори можуть використовувати, з необов'язковою URL-адресою, на яку він посилається. Якщо тег уже існує, він
оновлюється.

## Позначити коментар

Позначає коментар для перевірки модератором. Потрібен ідентифікатор користувача, який позначає; підходить ідентифікатор автора,
повернутий дією Create Comment.

## Пошуки

| Пошук | Вхідні дані | Повертає |
|--------|-------|---------|
| Find Comment | Comment ID | Коментар або нічого. |
| Find SSO User | Email | SSO-користувача або нічого. |
| Find Page | URL ID | Сторінку або нічого. |

Пошук, який нічого не знаходить, не призводить до збою Zap. Find SSO User та Find Page пропонують опцію Zapier «створити, якщо не
існує», яка запускає відповідну дію створення, коли нічого не знайдено.
