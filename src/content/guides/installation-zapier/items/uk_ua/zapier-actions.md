## Actions and Searches

Дії створюють дані у FastComments; пошуки шукають дані, щоб пізніший крок міг їх використати. Кожна дія викликає REST API FastComments і витрачає ті ж API‑кредити, які б коштували виклик у вашому коді: один кредит за виклик, якщо не зазначено інше.

## Create Comment

Posts a comment on a page.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Yes | Ідентифікатор URL, який використовується віджетом коментарів на сторінці. Коментарі групуються за цим ідентифікатором. |
| Page URL | Yes | Повний URL сторінки, використовується у сповіщеннях електронною поштою. |
| Comment | Yes | Тіло коментаря у форматі FastComments markdown. |
| Commenter Name | Yes | Імена унікальні для кожного електронного листа, тому повторне використання імені з іншим email не вдається. |
| Commenter Email | No | Користувач створюється для цього email, якщо він ще не існує. |
| User ID | No | Існуючий ідентифікатор SSO‑користувача. Має пріоритет над ім'ям та email. |
| Parent Comment ID | No | Встановіть, щоб опублікувати відповідь. |
| Approved, Verified | No | Обидва за замовчуванням true. Не затверджені коментарі залишаються прихованими до модерації. |
| Posted At | No | За замовчуванням — поточний час. |
| Avatar URL, Page Title, Locale | No | Локаль за замовчуванням `en_us`. |
| Show Live In Widget | No | Надсилає коментар глядачам у реальному часі. Вартує 2 кредити замість 1. |
| Run Spam Check, Send Emails | No | Вимкнено за замовчуванням. |

## Create or Update Page

Створює запис сторінки до появи будь‑якого коментаря, щоб її можна було відображати у списках та обмежувати доступ. Приймає ідентифікатор URL, назву, URL та, за потреби, ідентифікатори SSO‑груп, яким дозволено її переглядати. Якщо сторінка з таким ідентифікатором URL вже існує, вона оновлюється переданими полями, тому Zap може виконуватись для однієї й тієї ж сторінки кілька разів.

## Create or Update SSO User

Створює користувача єдиного входу (SSO). Приймає ваш власний ідентифікатор користувача, ім'я користувача та email, а також необов’язкові відображуване ім'я, мітку, аватар, веб‑сайт, ідентифікатори груп та прапорці сповіщень і конфіденційності. Якщо користувач з таким ідентифікатором вже існує, він оновлюється. Адміністративні ролі не можна надати через Zapier.

## Create Feed Post

Створює запис у стрічці FastComments з HTML‑вмісту. Ідентифікатор користувача‑автора обов’язковий (ідентифікатор FastComments або SSO); назва, теги та один попередній перегляд посилання — необов’язкові.

## Create or Update Hash Tag

Створює хештег, яким можуть користуватися коментатори, з необов’язковим URL, на який він посилається. Якщо хештег вже існує, він оновлюється.

## Flag Comment

Позначає коментар для перегляду модератором. Потрібен ідентифікатор користувача, який ставить прапорець; підходить ідентифікатор автора, який повертається у Create Comment.

## Searches

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | Коментар або нічого. |
| Find SSO User | Email | SSO‑користувач або нічого. |
| Find Page | URL ID | Сторінка або нічого. |

Пошук, який нічого не знаходить, не призводить до помилки Zap. Find SSO User та Find Page пропонують опцію Zapier «створити, якщо не існує», яка виконує відповідне створення, коли нічого не знайдено.
