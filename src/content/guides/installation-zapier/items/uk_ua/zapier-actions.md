## Дії та Пошуки

Дії створюють дані у FastComments; пошуки шукають дані, щоб пізніший крок міг їх використати. Кожна дія викликає FastComments REST API і витрачає ту ж кількість кредитів API, яку б коштував виклик у вашому коді: один кредит за виклик, якщо не зазначено інше.

## Створити Коментар

Публікує коментар на сторінці.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Так | Ідентифікатор URL, який використовується віджетом коментарів на сторінці. Коментарі групуються за цим ідентифікатором. |
| Page URL | Так | Повний URL сторінки, використовується у сповіщеннях електронною поштою. |
| Comment | Так | Тіло коментаря у форматі FastComments markdown. |
| Commenter Name | Так | Імена унікальні для кожного електронного листа, тому повторне використання імені з іншим електронним листом призведе до помилки. |
| Commenter Email | Ні | Користувач створюється для електронного листа, якщо він ще не існує. |
| User ID | Ні | Ідентифікатор існуючого SSO користувача. Має пріоритет над іменем та електронною поштою. |
| Parent Comment ID | Ні | Встановити, щоб опублікувати відповідь. |
| Approved, Verified | Ні | Обидва за замовчуванням true. Не затверджені коментарі залишаються прихованими до модерації. |
| Posted At | Ні | За замовчуванням — поточний час. |
| Avatar URL, Page Title, Locale | Ні | Локаль за замовчуванням `en_us`. |
| Show Live In Widget | Ні | Надсилає коментар глядачам у реальному часі. Вартість 2 кредити замість 1. |
| Run Spam Check, Send Emails | Ні | Вимкнено за замовчуванням. |

## Створити Сторінку

Створює запис сторінки перед тим, як на ній з’явиться будь‑який коментар, щоб її можна було перелічити та обмежити. Приймає ідентифікатор URL, назву, URL та, за потреби, ідентифікатори SSO‑груп, яким дозволено її перегляд.

## Створити SSO Користувача

Створює користувача єдиного входу (single sign‑on). Приймає ваш власний ідентифікатор користувача, ім’я користувача та електронну пошту, а також необов’язкові відображуване ім’я, мітку, аватар, веб‑сайт, ідентифікатори груп та прапорці сповіщень і конфіденційності. Адміністративні ролі не можна надати через Zapier.

## Створити Публікацію у Стрічці

Створює публікацію у стрічці FastComments з HTML‑вмісту. Ідентифікатор користувача‑автора обов’язковий (FastComments або SSO‑ідентифікатор); назва, теги та один попередній перегляд посилання — необов’язкові.

## Створити Хештег

Створює хештег, яким можуть користуватися коментатори, з необов’язковим URL, на який він посилається. Теги унікальні в межах облікового запису, тому Zap, який створює їх при кожному запуску, потребує чогось унікального в тегу.

## Позначити Коментар

Позначає коментар для перегляду модератором. Потрібен ідентифікатор користувача, який виконує позначення; підходить ідентифікатор автора, який повертає «Create Comment».

## Пошуки

| Пошук | Вхід | Повертає |
|--------|-------|---------|
| Find Comment | Comment ID | Коментар, або нічого. |
| Find SSO User | Email | SSO користувач, або нічого. |
| Find Page | URL ID | Сторінка, або нічого. |

Пошук, який нічого не знаходить, не призводить до помилки Zap. Поєднайте пошук із створенням у режимі Zapier «find or create», щоб створити сторінку або користувача, коли їх немає.
