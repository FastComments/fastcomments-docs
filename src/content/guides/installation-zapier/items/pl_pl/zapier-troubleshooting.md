## Rozwiązywanie problemów

**"Nie masz uprawnień" podczas łączenia.** Zalogowany użytkownik nie jest administratorem API na koncie.  
Poproś właściciela konta o przyznanie uprawnień API na stronie Użytkownicy lub połącz się jako właściciel.

**Połączenie jest oznaczone niewłaściwą witryną.** Strona zgody łączy się z kontem, na które byłeś zalogowany  
w tym momencie. Odłącz w Zapier, przełącz konta w panelu FastComments, a następnie połącz ponownie.

**Zdarzenia przestały przychodzić.** Sprawdź stronę Webhooków w panelu. Subskrypcja, której punkt końcowy nie działał  
przez sześć dni, jest automatycznie wyłączana i wyświetla przyczynę. Włącz ją ponownie tam, lub wyłącz i włącz Zap  
ponownie. Jeśli subskrypcja całkowicie zniknęła, ktoś ją usunął; wyłączenie i włączenie Zapa odtworzy ją.

**Zapier informuje, że konto wymaga ponownego połączenia.** Połączenie zostało odwołane na stronie Połączonych aplikacji,  
użytkownik, który je zatwierdził, stracił uprawnienia API lub konto zostało usunięte. Połącz ponownie z Zapier.

**Działanie nie powiodło się z komunikatem "brak uprawnień do zapisu".** Połączenie zostało zatwierdzone z uprawnieniami tylko do odczytu  
Połącz ponownie i zatwierdź oba uprawnienia.

**Limity szybkości i kredyty.** Działania i wyszukiwania zużywają kredyty API z Twojego planu i podlegają tym  
samym limitom szybkości co REST API. Wyzwalacze nie zużywają kredytów. Zap, który napotka limit, jest ponawiany przez Zapier  
po opóźnieniu zgłoszonym przez FastComments.

**Lista rozwijana Domen jest pusta.** Domeny pojawiają się po ich skonfigurowaniu na stronie Domen w  
panelu FastComments. Pozostaw pole puste, aby otrzymywać zdarzenia dla każdej domeny.
