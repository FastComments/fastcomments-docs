## Действия и Търсения

Действията създават данни във FastComments; търсенията извличат данни, за да може следваща стъпка да ги използва. Всяко действие извиква FastComments REST API и използва същите API кредити, които би струвало извикването от вашия собствен код: един кредит за извикване, освен ако не е посочено друго.

## Създаване на Коментар

Публикува коментар на страница.

| Поле | Задължително | Бележки |
|-------|----------|-------|
| Page URL ID | Да | URL идентификаторът, който използва уиджетът за коментари на страницата. Коментарите се групират по него. |
| Page URL | Да | Пълният URL на страницата, използван в имейл известия. |
| Comment | Да | Тялото на коментара във FastComments markdown. |
| Commenter Name | Да | Имената са уникални за всеки имейл, затова повторното използване на име с различен имейл не успява. |
| Commenter Email | Не | Потребител се създава за имейла, ако все още не съществува. |
| User ID | Не | Съществуващ SSO потребителски ID. Има предимство пред името и имейла. |
| Parent Comment ID | Не | Задайте, за да публикувате отговор. |
| Approved, Verified | Не | И двете по подразбиране са true. Неодобрени коментари остават скрити, докато не бъдат модерирани. |
| Posted At | Не | По подразбиране е текущото време. |
| Avatar URL, Page Title, Locale | Не | Локалът по подразбиране е `en_us`. |
| Show Live In Widget | Не | Изпраща коментара към зрителите в реално време. Стои 2 кредита вместо 1. |
| Run Spam Check, Send Emails | Не | Изключено по подразбиране. |

## Създаване на Страница

Създава запис за страница преди да има коментари върху нея, за да може да бъде изброена и ограничена. Приема URL ID, заглавие, URL и по желание SSO групови ID, които имат право да я виждат.

## Създаване на SSO Потребител

Създава потребител за единично влизане (single sign-on). Приема ваш собствен потребителски ID, потребителско име и имейл, плюс по желание име за показване, етикет за показване, аватар, уебсайт, групови ID и флагове за известия и поверителност. Административни роли не могат да се предоставят от Zapier.

## Създаване на Публикация във Фийд

Създава публикация във FastComments фийд от HTML съдържание. Авторският потребителски ID е задължителен (a FastComments or SSO user id); заглавието, етикетите и едно предварително преглеждане на връзка са по желание.

## Създаване на Хаш Таг

Създава хаш таг, който коментаторите могат да използват, с по желание URL, към който води. Таговете са уникални за всеки акаунт, затова Zap, който създава такъв при всяко изпълнение, се нуждае от нещо уникално в тага.

## Маркиране на Коментар

Маркира коментар за преглед от модератор. ID на потребителя, който маркира, е задължително; ID на автора, върнато от Създаване на Коментар, работи.

## Търсения

| Търсене | Вход | Връща |
|--------|-------|---------|
| Намери Коментар | Comment ID | Коментарът, или нищо. |
| Намери SSO Потребител | Email | SSO потребителят, или нищо. |
| Намери Страница | URL ID | Страницата, или нищо. |

Търсене, което не намира нищо, не проваля Zap. Комбинирайте търсене със създаване в режим „find or create“ на Zapier, за да създадете страницата или потребителя, ако липсва.
