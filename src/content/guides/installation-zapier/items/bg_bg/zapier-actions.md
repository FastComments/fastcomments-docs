## Действия и Търсения

Действията създават данни във FastComments; търсенията извличат данни, за да може по‑късен етап да ги използва. Всяко действие извиква FastComments REST API и използва същите API кредити, които би струвало извикването от вашия собствен код: един кредит за извикване, освен ако не е посочено друго.

## Създаване на Коментар

Публикува коментар на страница.

| Поле | Задължително | Бележки |
|------|--------------|---------|
| Page URL ID | Да | URL идентификаторът, който уиджетът за коментари използва на страницата. Коментарите се групират по него. |
| Page URL | Да | Пълният URL на страницата, използван в имейл известия. |
| Comment | Да | Тялото на коментара във FastComments markdown. |
| Commenter Name | Да | Имената са уникални за всеки имейл, затова повторното използване на име с различен имейл се проваля. |
| Commenter Email | Не | Потребител се създава за имейла, ако все още не съществува. |
| User ID | Не | Съществуващ SSO потребителски идентификатор. Има предимство пред името и имейла. |
| Parent Comment ID | Не | Задайте, за да публикувате отговор. |
| Approved, Verified | Не | И двете по подразбиране са true. Неодобрени коментари остават скрити, докато не бъдат модерирани. |
| Posted At | Не | По подразбиране е текущото време. |
| Avatar URL, Page Title, Locale | Не | Локалът по подразбиране е `en_us`. |
| Show Live In Widget | Не | Изпраща коментара към зрителите в реално време. Стои 2 кредита вместо 1. |
| Run Spam Check, Send Emails | Не | Изключено по подразбиране. |

## Създаване на Страница

Създава запис за страница преди да има коментари върху нея, за да може да бъде изброена и ограничена. Приема URL ID, заглавие, URL и по избор SSO групови идентификатори, които имат достъп до нея.

## Създаване на SSO Потребител

Създава потребител за единично влизане (single sign-on). Приема ваш собствен потребителски идентификатор, потребителско име и имейл, плюс по избор име за показване, етикет за показване, аватар, уебсайт, групови идентификатори и флагове за известия и поверителност. Административни роли не могат да бъдат предоставени от Zapier.

## Създаване на Feed Публикация

Създава публикация във FastComments feed от HTML съдържание, с по избор заглавие, автор, тагове и един преглед на връзка.

## Създаване на Хаш Таг

Създава хаш таг, който коментаторите могат да използват, с по избор URL, към който води.

## Маркиране на Коментар

Маркира коментар за преглед от модератор. Предоставете идентификатора на потребителя, който маркира, или оставете празно, за да маркирате като Zapier интеграцията.

## Търсения

| Търсене | Вход | Връща |
|---------|------|-------|
| Find Comment | Comment ID | Коментарът, или нищо. |
| Find SSO User | Email | SSO потребителят, или нищо. |
| Find Page | URL ID | Страницата, или нищо. |

Търсене, което не намира нищо, не проваля Zap. Комбинирайте търсене със създаване в режим „find or create“ на Zapier, за да създадете страницата или потребителя, ако липсва.
