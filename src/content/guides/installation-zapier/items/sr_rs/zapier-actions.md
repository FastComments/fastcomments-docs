## Радње и Претраге

Радње креирају податке у FastComments; претраге траже податке како би их каснији корак могао користити. Свака радња позива FastComments REST API и троши исте API кредите колико би позив коштао из вашег кода: један кредит по позиву осим ако је другачије наведено.

## Креирање Коментара

Објављује коментар на страници.

| Поље | Обавезно | Белешке |
|-------|----------|-------|
| Page URL ID | Yes | URL ID који користи виџет за коментаре на страници. Коментари се групишу према њему. |
| Page URL | Yes | Пуна URL адреса странице, користи се у обавештајним имејловима. |
| Comment | Yes | Тело коментара у FastComments markdown-у. |
| Commenter Name | Yes | Имена су јединствена по имејлу, па поновна употреба имена са другим имејлом не успева. |
| Commenter Email | No | Корисник се креира за имејл ако још не постоји. |
| User ID | No | Постојећи SSO кориснички ID. Има предност над именом и имејлом. |
| Parent Comment ID | No | Подесите за објављивање одговора. |
| Approved, Verified | No | Оба подразумевано су true. Неодобрене коментаре остају скривени док се не модерирају. |
| Posted At | No | Подразумевано је тренутно време. |
| Avatar URL, Page Title, Locale | No | Локализација подразумевано је `en_us`. |
| Show Live In Widget | No | Гурка коментар гледаоцима у реалном времену. Коштује 2 кредита уместо 1. |
| Run Spam Check, Send Emails | No | Подразумевано искључено. |

## Креирање или Ажурирање Странице

Креира запис странице пре него што на њој постоји било какав коментар, тако да може бити листана и ограничена. Прихвата URL ID, наслов, URL, и по избору SSO групне ID‑ове који су овлашћени да виде страницу. Ако страница са тим URL ID‑ом већ постоји, она се ажурира наведеним пољима, тако да Zap може више пута да се изврши за исту страницу.

## Креирање или Ажурирање SSO Корисника

Креира корисника за једнократну пријаву (single sign‑on). Прихвата ваш сопствени кориснички ID, корисничко име и имејл, као и по избору име за приказ, ознаку за приказ, аватар, вебсајт, групне ID‑ове, и заставице за обавештења и приватност. Ако корисник са тим ID‑ом већ постоји, он се уместо тога ажурира. Административне улоге не могу бити додељене из Zapier‑а.

## Креирање Објаве у Фиду

Креира објаву у FastComments фиду из HTML садржаја. ID аутора је обавезан (FastComments или SSO кориснички ID); наслов, ознаке и један преглед линка су по избору.

## Креирање или Ажурирање Хеш Тагова

Креира хеш таг који коментатори могу користити, са по избору URL‑ом на који води. Ако таг већ постоји, он се уместо тога ажурира.

## Означавање Коментара

Означава коментар за преглед модератора. ID корисника који означава је обавезан; ID аутора који се враћа из Креирања Коментара је исправан.

## Претраге

| Претрага | Улаз | Враћа |
|--------|-------|---------|
| Find Comment | Comment ID | Коментар, или ништа. |
| Find SSO User | Email | SSO корисник, или ништа. |
| Find Page | URL ID | Страница, или ништа. |

Претрага која не пронађе ништа не доводи до грешке у Zap‑у. Претраге Find SSO User и Find Page нуде Zapier‑ову опцију „креирај ако не постоји“, која покреће одговарајуће креирање када се ништа не пронађе.
