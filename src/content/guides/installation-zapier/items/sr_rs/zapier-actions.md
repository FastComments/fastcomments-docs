## Радње и Претраге

Радње креирају податке у FastComments; претраге траже податке тако да их каснији корак може користити. Свака радња позива FastComments REST API и троши исте API кредите колико би позив коштао из вашег кода: један кредит по позиву осим ако је наведено другачије.

## Креирање Коментара

Објављује коментар на страници.

| Поље | Обавезно | Белешке |
|-------|----------|-------|
| ID URL-а странице | Да | ID URL-а који користи widget за коментаре на страници. Коментари се групишу према њему. |
| URL странице | Да | Пуни URL странице, користи се у обавештајним имејловима. |
| Коментар | Да | Тело коментара у FastComments markdown-у. |
| Име коментатора | Да | Имена су јединствена по имејлу, па поновно коришћење имена са другим имејлом не успева. |
| Имејл коментатора | Не | Корисник се креира за имејл ако још не постоји. |
| ID корисника | Не | Постојећи SSO ID корисника. Има предност над именом и имејлом. |
| ID родитељског коментара | Не | Подесите за објављивање одговора. |
| Одобрено, Верификовано | Не | Оба подразумевано су true. Неодобрени коментари остају скривени док се не модерирају. |
| Објављено у | Не | Подразумевано је тренутно време. |
| URL аватара, Наслов странице, Локал | Не | Локал подразумевано је `en_us`. |
| Прикажи уживо у widget-у | Не | Гурка коментар гледаоцима у реалном времену. Коштује 2 кредита уместо 1. |
| Покрени проверу спама, Пошаљи имејлове | Не | Подразумевано искључено. |

## Креирање Странице

Креира запис странице пре него што постоји било какав коментар на њој, тако да може бити листана и ограничена. Потребни су ID URL-а, наслов, URL, и по избору SSO ID група којима је дозвољено да виде страницу.

## Креирање SSO Корисника

Креира корисника за једнократну пријаву (single sign-on). Потребни су ваш сопствени ID корисника, корисничко име и имејл, као и по избору име за приказ, ознака за приказ, аватар, вебсајт, ID група, и заставице за обавештења и приватност. Административне улоге не могу бити додељене из Zapier-а.

## Креирање Поставке у Фиду

Креира поставку у FastComments фиду из HTML садржаја, са по избору насловом, аутором, ознакама и једним прегледом линка.

## Креирање Хеш Тагова

Креира хеш таг који коментатори могу користити, са по избору URL-ом на који води.

## Означавање Коментара

Означава коментар за преглед модератора. Наведите ID корисника који означава, или оставите празно да означите као Zapier интеграција.

## Претраге

| Претрага | Улаз | Враћа |
|--------|-------|---------|
| Пронађи коментар | ID коментара | Коментар, или ништа. |
| Пронађи SSO корисника | Имејл | SSO корисник, или ништа. |
| Пронађи страницу | ID URL-а | Страница, или ништа. |

Претрага која не пронађе ништа не доводи до грешке у Zap-у. Комбинујте претрагу са креирањем у режиму "нађи или креирај" у Zapier-у да бисте креирали страницу или корисника када недостаје.
