## Радње и Претраге

Радње креирају податке у FastComments; претраге траже податке тако да их каснији корак може користити. Свака радња позива FastComments REST API и троши исте API кредите колико би позив коштао из вашег кода: један кредит по позиву осим ако је другачије наведено.

## Креирање Коментара

Објављује коментар на страници.

| Поље | Обавезно | Белешке |
|------|----------|---------|
| ID URL-а странице | Да | ID URL-а који користи виџет за коментаре на страници. Коментари се групишу према њему. |
| URL странице | Да | Пун URL странице, који се користи у обавештајним имејловима. |
| Коментар | Да | Тело коментара у FastComments markdown-у. |
| Име коментатора | Да | Имена су јединствена по имејлу, па поновно коришћење имена са другим имејлом не успева. |
| Имејл коментатора | Не | Корисник се креира за имејл ако још не постоји. |
| ID корисника | Не | Постојећи SSO ID корисника. Има предност над именом и имејлом. |
| ID родитељског коментара | Не | Подесите за објављивање одговора. |
| Одобрен, Верификован | Не | Оба подразумевано су true. Неодобрени коментари остају скривени док се не модерирају. |
| Објављено у | Не | Подразумевано је тренутно време. |
| URL аватара, Наслов странице, Локал | Не | Локал подразумева `en_us`. |
| Прикажи уживо у виџету | Не | Гурка коментар гледаоцима у реалном времену. Коштује 2 кредита уместо 1. |
| Покрени проверу спама, Пошаљи имејлове | Не | Подразумевано искључено. |

## Креирање Странице

Креира запис странице пре него што на њој постоји било какав коментар, тако да може бити листана и ограничена. Узима ID URL-а, наслов, URL, и по потреби SSO групне ID‑је који су овлашћени да је виде страницу.

## Креирање SSO Корисника

Креира корисника за једнократну пријаву (single sign‑on). Узима ваш сопствени ID корисника, корисничко име и имејл, као и опционално име за приказ, ознаку за приказ, аватар, вебсајт, групне ID‑је, и заставице за обавештења и приватност. Административне улоге не могу бити додељене из Zapier‑а.

## Креирање Објаве у Фиду

Креира објаву у FastComments фиду из HTML садржаја. ID корисника аутора је обавезан (FastComments или SSO ID корисника); наслов, ознаке и један преглед линка су опционални.

## Креирање Хеш Тагова

Креира хеш таг који коментатори могу користити, са опционалним URL‑ом на који води. Тагови су јединствени по налогу, па Zap који их креира при сваком покретању треба да има нешто јединствено у тагу.

## Означи Коментар

Означава коментар за преглед модератора. ID корисника који означава је обавезан; ID аутора који се враћа из Креирања Коментара функционише.

## Претраге

| Претрага | Улаз | Враћа |
|----------|------|-------|
| Пронађи коментар | ID коментара | Коментар, или ништа. |
| Пронађи SSO корисника | Имејл | SSO корисник, или ништа. |
| Пронађи страницу | ID URL-а | Страница, или ништа. |

Претрага која не пронађе ништа не доводи до грешке у Zap‑у. Комбинујте претрагу са креирањем у „find or create“ режиму Zapier‑а да бисте креирали страницу или корисника када недостаје.
