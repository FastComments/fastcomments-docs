## פתרון בעיות

**"אין לך הרשאה" בעת החיבור.** המשתמש המחובר אינו מנהל API בחשבון.  
בקש מבעל החשבון להעניק הרשאת API בדף המשתמשים, או התחבר כבעל החשבון.

**החיבור מתויג עם האתר הלא נכון.** דף ההסכמה מחבר את החשבון שבו היית מחובר באותו רגע. נתק ב‑Zapier, החלף חשבונות בלוח הבקרה של FastComments, והתחבר שוב.

**האירועים הפסיקו להגיע.** בדוק את דף ה‑Webhooks בלוח הבקרה. מנוי שהקצה שלו נכשל במשך שישה ימים מושבת אוטומטית ומציג את הסיבה. הפעל אותו מחדש שם, או כבה והפעל את ה‑Zap שוב. אם המנוי חסר לחלוטין, מישהו מחק אותו; כיבוי והפעלה של ה‑Zap יוצרים אותו מחדש.

**Zapier אומר שהחשבון צריך להתחבר מחדש.** החיבור בוטל מדף האפליקציות המחוברות, המשתמש שאישר אותו איבד את הרשאת ה‑API, או שהחשבון נמחק. התחבר מחדש מ‑Zapier.

**פעולה נכשלה עם "אין גישה לכתיבה".** החיבור אושר עם הרשאת קריאה בלבד. התחבר מחדש ואשר את שתי ההרשאות.

**מגבלות קצב וקרדיטים.** פעולות וחיפושים משתמשים בקרדיטי API מהתוכנית שלך והם כפופים לאותן מגבלות קצב כמו ה‑REST API. טריגרים אינם משתמשים בקרדיטים. Zap שמגיע למגבלה יופעל מחדש על ידי Zapier לאחר העיכוב שמדווח על ידי FastComments.

**תפריט הנפתחת של הדומיין ריק.** דומיינים מופיעים לאחר שהם מוגדרים בדף הדומיינים בלוח הבקרה של FastComments. השאר את השדה ריק כדי לקבל אירועים מכל דומיין.
