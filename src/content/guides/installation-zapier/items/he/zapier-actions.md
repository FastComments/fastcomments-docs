## פעולות וחיפושים

פעולות יוצרות נתונים ב‑FastComments; חיפושים מחפשים נתונים כך ששלב מאוחר יותר יכול להשתמש בהם. כל פעולה קוראת ל‑FastComments REST API ומבזבזת את אותם קרדיטי API שהקריאה הייתה עולה מהקוד שלך: קרדיט אחד לכל קריאה אלא אם צוין אחרת.

## יצירת תגובה

מפרסמת תגובה בעמוד.

| שדה | נדרש | הערות |
|-------|----------|-------|
| Page URL ID | כן | מזהה ה‑URL שהווידג'ט של התגובה משתמש בו בעמוד. תגובות מקובצות לפי מזהה זה. |
| Page URL | כן | כתובת ה‑URL המלאה של העמוד, משמשת במיילי ההודעות. |
| Comment | כן | גוף התגובה בפורמט Markdown של FastComments. |
| Commenter Name | כן | השם הוא ייחודי לכל אימייל, ולכן שימוש חוזר בשם עם אימייל שונה נכשל. |
| Commenter Email | לא | משתמש נוצר עבור האימייל אם הוא עדיין לא קיים. |
| User ID | לא | מזהה משתמש SSO קיים. מקבל עדיפות על פני שם ואימייל. |
| Parent Comment ID | לא | הגדרה לפרסום תגובה. |
| Approved, Verified | לא | שניהם מוגדרים כברירת מחדל ל‑true. תגובות שלא אושרו נשארות מוסתרות עד למודרציה. |
| Posted At | לא | ברירת מחדל היא עכשיו. |
| Avatar URL, Page Title, Locale | לא | Locale ברירת מחדל היא `en_us`. |
| Show Live In Widget | לא | דוחף את התגובה לצופים בזמן אמת. עולה 2 קרדיטים במקום 1. |
| Run Spam Check, Send Emails | לא | כבוי כברירת מחדל. |

## יצירת או עדכון דף

יוצר רשומת דף לפני שיש תגובה כלשהי עליו, כך שניתן לרשום אותו ולהגביל אותו. מקבל את מזהה ה‑URL, הכותרת, ה‑URL, ובאופן אופציונלי את מזהי קבוצות ה‑SSO המורשים לצפות בו. אם דף עם מזהה URL זה כבר קיים, הוא מתעדכן עם השדות שניתנו, כך ש‑Zap יכול לרוץ על אותו דף באופן חוזר.

## יצירת או עדכון משתמש SSO

יוצר משתמש Single Sign-On. מקבל את מזהה המשתמש שלך, שם משתמש ואימייל, בנוסף לשם תצוגה, תווית תצוגה, אווטר, אתר אינטרנט, מזהי קבוצות, ודגלי התראות ופרטיות. אם משתמש עם מזהה זה כבר קיים, הוא מתעדכן במקום זאת. תפקידים מנהליים אינם ניתנים למתן דרך Zapier.

## יצירת פוסט בפיד

יוצר פוסט בפיד של FastComments מתוכן HTML. מזהה משתמש המחבר נדרש (מזהה משתמש FastComments או SSO); כותרת, תגיות וקישור תצוגה מקדימה אחד הם אופציונליים.

## יצירת או עדכון תגית Hash

יוצר תגית hash שהמשתמשים יכולים להשתמש בה, עם URL אופציונלי שאליו היא מקשרת. אם התגית כבר קיימת, היא מתעדכנת במקום זאת.

## סימון תגובה

מסמן תגובה לבחינת מודרטור. מזהה המשתמש המבצע את הסימון נדרש; מזהה המחבר שמוחזר על ידי יצירת תגובה עובד.

## חיפושים

| חיפוש | קלט | מחזיר |
|--------|-------|---------|
| Find Comment | Comment ID | התגובה, או כלום. |
| Find SSO User | Email | משתמש ה‑SSO, או כלום. |
| Find Page | URL ID | הדף, או כלום. |

חיפוש שמחזיר תוצאה ריקה אינו גורם לכישלון של ה‑Zap. Find SSO User ו‑Find Page מציעים את אפשרות Zapier "create if it doesn't exist" (צור אם אינו קיים), שמריצה את יצירת ההתאמה כאשר לא נמצא דבר.
