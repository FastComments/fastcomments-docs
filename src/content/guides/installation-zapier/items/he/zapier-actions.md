## פעולות וחיפושים

פעולות יוצרות נתונים ב‑FastComments; חיפושים מחפשים נתונים כך שצעד מאוחר יותר יוכל להשתמש בהם. כל פעולה קוראת ל‑FastComments REST API ומבזבזת את אותן נקודות API שהקריאה הייתה עולה מהקוד שלך: נקודה אחת לכל קריאה אלא אם צוין אחרת.

## יצירת תגובה

מפרסמת תגובה בעמוד.

| שדה | נדרש | הערות |
|-------|----------|-------|
| Page URL ID | כן | מזהה ה‑URL שהווידג'ט של התגובה משתמש בו בעמוד. תגובות מקובצות לפי מזהה זה. |
| Page URL | כן | כתובת ה‑URL המלאה של העמוד, משמשת במיילים של התראות. |
| Comment | כן | גוף התגובה במרקאפ של FastComments. |
| Commenter Name | כן | שמות הם ייחודיים לכל אימייל, ולכן שימוש בשם עם אימייל שונה ייכשל. |
| Commenter Email | לא | משתמש נוצר עבור האימייל כאשר הוא עדיין לא קיים. |
| User ID | לא | מזהה משתמש SSO קיים. מקבל עדיפות על שם האימייל. |
| Parent Comment ID | לא | קובע פרסום תגובה כהמשך. |
| Approved, Verified | לא | שני הערכים ברירת מחדל הם true. תגובות שלא אושרו נשארות מוסתרות עד למודרציה. |
| Posted At | לא | ברירת מחדל היא עכשיו. |
| Avatar URL, Page Title, Locale | לא | Locale ברירת מחדל היא `en_us`. |
| Show Live In Widget | לא | דוחף את התגובה לצופים בזמן אמת. עולה 2 נקודות במקום 1. |
| Run Spam Check, Send Emails | לא | כבוי כברירת מחדל. |

## יצירת עמוד

יוצר רשומת עמוד לפני שיש תגובה עליו, כך שניתן לרשום אותו ולהגביל גישה. מקבל את מזהה ה‑URL, הכותרת, ה‑URL, ובאופן אופציונלי את מזהי קבוצות SSO המורשות לראות אותו.

## יצירת משתמש SSO

יוצר משתמש כניסה חד-פעמית (SSO). מקבל את מזהה המשתמש שלך, שם משתמש ואימייל, בנוסף לשם תצוגה, תווית תצוגה, אווטר, אתר אינטרנט, מזהי קבוצות, ודגלי התראות ופרטיות. לא ניתן להקצות תפקידים מנהליים דרך Zapier.

## יצירת פוסט בפיד

יוצר פוסט בפיד של FastComments מתוכן HTML. מזהה משתמש המחבר נדרש (מזהה משתמש FastComments או SSO); כותרת, תגיות וקישור תצוגה מקדים הם אופציונליים.

## יצירת תגית האש

יוצר תגית האש שהמגיבים יכולים להשתמש בה, עם URL אופציונלי שהיא מקשרת אליו. תגיות הן ייחודיות לכל חשבון, ולכן זאפ שיוצר אחת בכל ריצה צריך משהו ייחודי בתגית.

## סימון תגובה

מסמן תגובה לסקירת מודרטור. מזהה המשתמש המבצע את הסימון נדרש; מזהה המחבר המוחזר מ‑Create Comment עובד.

## חיפושים

| חיפוש | קלט | מחזיר |
|--------|-------|---------|
| Find Comment | Comment ID | התגובה, או כלום. |
| Find SSO User | Email | משתמש SSO, או כלום. |
| Find Page | URL ID | העמוד, או כלום. |

חיפוש שלא מוצא דבר אינו גורם לכישלון ב‑Zap. ניתן לשלב חיפוש עם יצירה במצב "find or create" של Zapier כדי ליצור את העמוד או המשתמש כאשר הוא חסר.
