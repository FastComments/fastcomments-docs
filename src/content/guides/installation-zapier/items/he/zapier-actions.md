## פעולות וחיפושים

פעולות יוצרות נתונים ב-FastComments; חיפושים מחפשים נתונים כך שלב מאוחר יותר יכול להשתמש בהם. כל פעולה קוראת ל-REST API של FastComments ומוציא את אותה כמות קרדיטים שהקריאה הייתה עולה בקוד שלך: קרדיט אחד לכל קריאה אלא אם צוין אחרת.

## יצירת תגובה

מפרסמת תגובה על דף.

| Field | Required | Notes |
|-------|----------|-------|
| Page URL ID | Yes | מזהה ה-URL שהווידג'ט של התגובה משתמש בו בדף. תגובות מקובצות לפי מזהה זה. |
| Page URL | Yes | כתובת ה-URL המלאה של הדף, משמשת במיילי התראה. |
| Comment | Yes | גוף התגובה בפורמט markdown של FastComments. |
| Commenter Name | Yes | שמות הם ייחודיים לכל אימייל, ולכן שימוש חוזר בשם עם אימייל שונה נכשל. |
| Commenter Email | No | משתמש נוצר עבור האימייל אם הוא עדיין לא קיים. |
| User ID | No | מזהה משתמש SSO קיים. מקבל עדיפות על פני השם והאימייל. |
| Parent Comment ID | No | הגדרה לפרסום תגובה. |
| Approved, Verified | No | שניהם ברירת מחדל true. תגובות שלא אושרו נשארות מוסתרות עד למודרציה. |
| Posted At | No | ברירת מחדל היא עכשיו. |
| Avatar URL, Page Title, Locale | No | הגדרת שפה ברירת מחדל היא `en_us`. |
| Show Live In Widget | No | דוחפת את התגובה לצופים בזמן אמת. עולה 2 קרדיטים במקום 1. |
| Run Spam Check, Send Emails | No | כבוי כברירת מחדל. |

## יצירת דף

יוצרת רשומת דף לפני שיש תגובה כלשהי עליו, כך שניתן לרשום אותו ולהגביל אותו. מקבלת את מזהה ה-URL, הכותרת, ה-URL, ובאופן אופציונלי את מזהי קבוצות ה-SSO המורשים לראות אותו.

## יצירת משתמש SSO

יוצרת משתמש יחיד (single sign-on). מקבלת את מזהה המשתמש שלך, שם משתמש ואימייל, בנוסף לשם תצוגה, תווית תצוגה, אווטר, אתר אינטרנט, מזהי קבוצות, ודגלי התראה ופרטיות. לא ניתן להקצות תפקידים מנהליים דרך Zapier.

## יצירת פוסט בפיד

יוצרת פוסט בפיד של FastComments מתוכן HTML, עם כותרת אופציונלית, מחבר, תגיות, ותצוגה מקדימה של קישור אחד.

## יצירת תגית

יוצרת תגית hash שהמגיבים יכולים להשתמש בה, עם URL אופציונלי שהיא מקשרת אליו.

## סימון תגובה

מסמנת תגובה לבחינת מודרטור. ספק את המזהה של המשתמש שמבצע את הסימון, או השאר ריק כדי לסמן בשם אינטגרציית Zapier.

## חיפושים

| Search | Input | Returns |
|--------|-------|---------|
| Find Comment | Comment ID | התגובה, או כלום. |
| Find SSO User | Email | המשתמש SSO, או כלום. |
| Find Page | URL ID | הדף, או כלום. |

חיפוש שלא מוצא דבר אינו גורם לכישלון של ה-Zap. ניתן לשלב חיפוש עם יצירה במצב "find or create" של Zapier כדי ליצור את הדף או המשתמש כאשר הוא חסר.
