## טריגרים

טריגרים מתחילים Zap כאשר משהו קורה ב‑FastComments. כל השלושה מיידיים: FastComments מעביר את
האירוע ל‑Zapier דרך webhook ברגע שהוא מתרחש. שום דבר אינו סורק את החשבון שלך ולא מתבזבזים קרדיטים של API
בהמתנה.

| טריגר | מתרחש כאשר |
|---------|-----------|
| New Comment | תגובה מתפרסמת. כברירת מחדל רק תגובות מאושרות, שאינן ספאם מופעלות. |
| Updated Comment | תגובה נערכת, מאושרת, מקבלת הצבעה, מוצמדת, ננעלת, או שונה בדרך אחרת. |
| Deleted Comment | תגובה נמחקת. |

כל טריגר מחזיר את כל התגובה: מזהה, כתובת URL של העמוד ומזהה URL, שם המגיב והדוא"ל, טקסט התגובה כ‑markdown וכ‑HTML, ספירות הצבעות, דגלי אישור וספאם, השפה, הדומיין, וכל אזכורים. השדות תואמים את מטען ה‑webhook המתועד תחת Webhooks, Data Structures.

## אפשרויות

**Domain.** לכל טריגר יש מסנן דומיין אופציונלי, המפרט את הדומיינים שהוגדרו בחשבון שלך. השאר ריק כדי לקבל אירועים מכל דומיין.

**Include Unapproved and Spam Comments.** רק בטריגר New Comment. תגובות שמוחזקות למודרציה או מסומנות כספאם מדולגות כברירת מחדל. כאשר תגובה כזו מאושרת מאוחר יותר, טריגר Updated Comment מתרחש עבורה, ולכן Zap שצריך להגיב לכל תגובה שמופיעה משתמש ב‑Updated Comment עם מסנן על השדה approved.

## איך המסירה עובדת

הפעלת Zap יוצרת מנוי webhook בחשבון שלך, הנראה בדף Webhooks עם המקור **API**. כיבוי ה‑Zap מסיר אותו. המגבלות של Zapier חלות על מספר האירועים שהיא מקבלת לדקה; FastComments מנסה שוב מסירה שנכשלה, עם עיכוב מתגבר, ומנטרל מנוי שממשיך להיכשל במשך שישה ימים. ניתן להפעיל מחדש מנוי מנוטרל מדף Webhooks, או פשוט לכבות ולהדליק את ה‑Zap שוב כדי ליצור מנוי חדש.

חשבון יכול להכיל עד 50 מנויים של API. כל Zap שמשתמש בטריגר של FastComments משתמש באחד.
