## ट्रिगर्स

ट्रिगर्स तब एक Zap शुरू करते हैं जब FastComments में कुछ होता है। तीनों तुरंत काम करते हैं: जिस क्षण घटना घटित होती है, FastComments उसे webhook के माध्यम से Zapier तक पहुँचा देता है। आपके खाते को कुछ भी poll नहीं किया जाता और इंतज़ार में कोई API क्रेडिट खर्च नहीं होता।

| ट्रिगर | कब सक्रिय होता है |
|---------|-----------|
| New Comment | जब एक टिप्पणी पोस्ट की जाती है। डिफ़ॉल्ट रूप से केवल स्वीकृत, गैर-स्पैम टिप्पणियाँ ही ट्रिगर करती हैं। |
| Updated Comment | जब एक टिप्पणी संपादित, स्वीकृत, वोट, पिन, लॉक की जाती है या अन्यथा बदली जाती है। |
| Deleted Comment | जब एक टिप्पणी हटा दी जाती है। |

प्रत्येक ट्रिगर पूरी टिप्पणी लौटाता है: id, page URL और URL ID, टिप्पणीकर्ता का नाम और ईमेल, markdown और HTML रूप में टिप्पणी का पाठ, वोट की संख्या, approval और spam फ़्लैग, locale, domain, और सभी mentions। फ़ील्ड Webhooks, Data Structures के अंतर्गत प्रलेखित webhook payload से मेल खाते हैं।

## विकल्प

**Domain.** प्रत्येक ट्रिगर में एक वैकल्पिक domain फ़िल्टर होता है, जो आपके खाते पर कॉन्फ़िगर किए गए domains की सूची दिखाता है। हर domain से घटनाएँ प्राप्त करने के लिए इसे खाली छोड़ दें।

**Include Unapproved and Spam Comments.** केवल New Comment ट्रिगर पर। मॉडरेशन के लिए रोकी गई या स्पैम चिह्नित टिप्पणियाँ डिफ़ॉल्ट रूप से छोड़ दी जाती हैं। जब ऐसी टिप्पणी बाद में स्वीकृत होती है, तो उसके लिए Updated Comment ट्रिगर सक्रिय होता है, इसलिए एक ऐसा Zap जो हर दृश्यमान होने वाली टिप्पणी पर प्रतिक्रिया देना चाहता है, वह approved फ़ील्ड पर फ़िल्टर के साथ Updated Comment का उपयोग करता है।

## डिलीवरी कैसे काम करती है

एक Zap चालू करने से आपके खाते पर एक webhook सदस्यता बनती है, जो Webhooks पेज पर स्रोत **API** के साथ दिखाई देती है। Zap बंद करने से यह हट जाती है। Zapier की अपनी सीमाएँ लागू होती हैं कि वह प्रति मिनट कितनी घटनाएँ स्वीकार करता है; FastComments विफल डिलीवरी को बढ़ते अंतराल के साथ फिर से प्रयास करता है, और छह दिनों तक लगातार विफल होने वाली सदस्यता को अक्षम कर देता है। अक्षम सदस्यता को Webhooks पेज से दोबारा सक्षम किया जा सकता है, या बस Zap को बंद करके दोबारा चालू करें ताकि एक नई सदस्यता बन जाए।

एक खाते में अधिकतम 50 API सदस्यताएँ हो सकती हैं। FastComments ट्रिगर का उपयोग करने वाला प्रत्येक Zap एक का उपयोग करता है।
