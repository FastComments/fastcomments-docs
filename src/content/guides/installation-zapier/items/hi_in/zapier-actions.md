## एक्शन और सर्च

एक्शन FastComments में डेटा बनाते हैं; सर्च डेटा खोजते हैं ताकि बाद का स्टेप उसका उपयोग कर सके। प्रत्येक एक्शन FastComments REST API को कॉल करता है और वही API क्रेडिट खर्च करता है जो आपके अपने कोड से कॉल करने पर लगते: प्रति कॉल एक क्रेडिट, जब तक अन्यथा उल्लेख न हो।

## Create Comment

किसी पेज पर कमेंट पोस्ट करता है।

| फ़ील्ड | आवश्यक | नोट्स |
|-------|----------|-------|
| Page URL ID | हाँ | वह URL ID जिसका उपयोग कमेंट विजेट पेज पर करता है। कमेंट इसी के आधार पर समूहित होते हैं। |
| Page URL | हाँ | पूरा पेज URL, जो नोटिफिकेशन ईमेल में उपयोग होता है। |
| Comment | हाँ | FastComments मार्कडाउन में कमेंट का मुख्य भाग। |
| Commenter Name | हाँ | नाम प्रति ईमेल अद्वितीय होते हैं, इसलिए उसी नाम का दूसरे ईमेल के साथ उपयोग विफल हो जाता है। |
| Commenter Email | नहीं | यदि ईमेल अभी मौजूद नहीं है तो उसके लिए एक यूज़र बनाया जाता है। |
| User ID | नहीं | किसी मौजूदा SSO यूज़र की id। यह नाम और ईमेल पर प्राथमिकता रखती है। |
| Parent Comment ID | नहीं | रिप्लाई पोस्ट करने के लिए सेट करें। |
| Approved, Verified | नहीं | दोनों का डिफ़ॉल्ट true है। अनअप्रूव्ड कमेंट मॉडरेशन तक छिपे रहते हैं। |
| Posted At | नहीं | डिफ़ॉल्ट रूप से अभी का समय। |
| Avatar URL, Page Title, Locale | नहीं | Locale का डिफ़ॉल्ट `en_us` है। |
| Show Live In Widget | नहीं | कमेंट को दर्शकों तक रीयल टाइम में पुश करता है। 1 के बजाय 2 क्रेडिट लगते हैं। |
| Run Spam Check, Send Emails | नहीं | डिफ़ॉल्ट रूप से बंद। |

## Create or Update Page

किसी पेज पर कोई कमेंट होने से पहले उसका पेज रिकॉर्ड बनाता है, ताकि उसे लिस्ट और प्रतिबंधित किया जा सके। यह URL ID, शीर्षक, URL, और वैकल्पिक रूप से उन SSO ग्रुप ids को लेता है जो उसे देख सकते हैं। यदि उस URL ID वाला पेज पहले से मौजूद है, तो उसे दिए गए फ़ील्ड्स से अपडेट कर दिया जाता है, इसलिए एक Zap उसी पेज के लिए बार-बार चल सकता है।

## Create or Update SSO User

एक सिंगल साइन-ऑन यूज़र बनाता है। यह आपकी अपनी user id, username और email लेता है, साथ ही वैकल्पिक display name, display label, avatar, website, group ids, और नोटिफिकेशन तथा प्राइवेसी फ़्लैग। यदि उस id वाला यूज़र पहले से मौजूद है, तो उसे अपडेट कर दिया जाता है। प्रशासनिक भूमिकाएँ Zapier से नहीं दी जा सकतीं।

## Create Feed Post

HTML कंटेंट से FastComments फ़ीड में एक पोस्ट बनाता है। लेखक की user id आवश्यक है (FastComments या SSO user id); शीर्षक, टैग, और एक लिंक प्रीव्यू वैकल्पिक हैं।

## Create or Update Hash Tag

एक हैश टैग बनाता है जिसका उपयोग कमेंटर्स कर सकते हैं, जिसमें वैकल्पिक रूप से एक URL हो सकता है जिससे वह लिंक हो। यदि टैग पहले से मौजूद है, तो उसे अपडेट कर दिया जाता है।

## Flag Comment

मॉडरेटर समीक्षा के लिए एक कमेंट फ़्लैग करता है। फ़्लैग करने वाले यूज़र की id आवश्यक है; Create Comment द्वारा लौटाई गई author id काम करती है।

## सर्च

| सर्च | इनपुट | रिटर्न करता है |
|--------|-------|---------|
| Find Comment | Comment ID | कमेंट, या कुछ नहीं। |
| Find SSO User | Email | SSO यूज़र, या कुछ नहीं। |
| Find Page | URL ID | पेज, या कुछ नहीं। |

कोई सर्च जो कुछ नहीं ढूँढता, वह Zap को विफल नहीं करता। Find SSO User और Find Page Zapier का "create if it doesn't exist" विकल्प प्रदान करते हैं, जो कुछ न मिलने पर संबंधित create एक्शन चलाता है।
