## समस्या निवारण

**कनेक्ट करते समय "You do not have permission" त्रुटि।** साइन-इन किया गया उपयोगकर्ता खाते पर API एडमिन नहीं है।
खाते के स्वामी से Users पेज पर API अनुमति देने का अनुरोध करें, या स्वामी के रूप में कनेक्ट करें।

**कनेक्शन गलत साइट के साथ लेबल किया गया है।** सहमति पेज उस खाते को कनेक्ट करता है जिसमें आप उस समय
साइन-इन थे। Zapier में डिस्कनेक्ट करें, FastComments डैशबोर्ड में खाता बदलें, और फिर से कनेक्ट करें।

**इवेंट आना बंद हो गए।** डैशबोर्ड में Webhooks पेज जांचें। जिस सब्सक्रिप्शन का एंडपॉइंट छह दिनों तक
लगातार विफल रहा, वह स्वचालित रूप से अक्षम कर दी जाती है और कारण दिखाती है। वहां से इसे पुनः सक्षम करें,
या Zap को बंद करके दोबारा चालू करें। यदि सब्सक्रिप्शन पूरी तरह गायब है, तो किसी ने इसे डिलीट कर दिया है;
Zap को बंद करके दोबारा चालू करने से यह फिर से बन जाती है।

**Zapier कहता है कि खाते को दोबारा कनेक्ट करने की आवश्यकता है।** कनेक्शन Connected Apps
पेज से रद्द कर दिया गया था, जिस उपयोगकर्ता ने इसे स्वीकृत किया था उसने API अनुमति खो दी, या खाता डिलीट कर दिया गया था। Zapier से दोबारा कनेक्ट करें।

**कोई एक्शन "does not have write access" के साथ विफल होता है।** कनेक्शन केवल-पढ़ने (read-only)
की अनुमति के साथ स्वीकृत किया गया था। दोबारा कनेक्ट करें और दोनों अनुमतियां स्वीकार करें।

**रेट लिमिट और क्रेडिट।** एक्शन और खोजें आपकी प्लान के API क्रेडिट खर्च करते हैं और REST API के समान
रेट लिमिट के अधीन होते हैं। ट्रिगर कोई क्रेडिट खर्च नहीं करते। जो Zap किसी सीमा में अटक जाता है, उसे Zapier
FastComments द्वारा बताई गई देरी के बाद पुनः प्रयास करता है।

**Domain ड्रॉपडाउन खाली है।** डोमेन तब दिखाई देते हैं जब वे FastComments डैशबोर्ड के Domains पेज पर
कॉन्फ़िगर किए जाते हैं। हर डोमेन के लिए इवेंट प्राप्त करने के लिए फ़ील्ड खाली छोड़ दें।
