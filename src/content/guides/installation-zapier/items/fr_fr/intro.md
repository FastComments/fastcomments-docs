L'application FastComments pour Zapier connecte vos commentaires à des milliers d'autres applications sans écrire de code.

Utilisez‑la pour publier un message Slack lorsqu'une personne commente, consigner chaque commentaire dans une feuille de calcul, créer un
commentaire à partir d'une soumission de formulaire, ou ajouter les commentateurs à votre CRM. Les déclencheurs s'activent dès qu'un événement se produit,
car ils sont basés sur des webhooks plutôt que sur du polling, et les actions appellent l'API FastComments en votre
nom.

Ce guide suppose que vous avez un compte FastComments. [Vous pouvez en créer un ici.](https://fastcomments.com/auth/tenant-signup?packageId=flex)
