該外掛支援三種 SSO 模式，用於將 Moodle 使用者帳號與 FastComments 整合。

#### 安全 SSO（建議）

使用者資料會在伺服器端使用您的 API Secret 透過 HMAC-SHA256 進行簽署。這是最安全的選項，建議在正式環境中使用。

使用安全 SSO 時：

- 使用者名稱、電子郵件與頭像會安全地傳遞給 FastComments。
- Moodle 網站管理員會自動同步為 FastComments 審核員。
- 使用者無法冒充其他帳號。
- 需要在外掛設定中配置 **API Secret**。

#### 簡單 SSO

使用者資料（名稱、電子郵件、頭像）會在用戶端傳送，且不帶加密簽章。由於不需要 API Secret，設定較為簡單，但因使用者資料不會在伺服器端驗證，安全性較低。

#### 無

不進行 SSO 整合。使用者以匿名方式留言，或必須另外登入 FastComments。若您不希望將 Moodle 使用者帳號與留言連結，請使用此選項。
