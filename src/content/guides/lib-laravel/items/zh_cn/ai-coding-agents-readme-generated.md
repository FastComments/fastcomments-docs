[![skills.sh](https://skills.sh/b/fastcomments/skills)](https://skills.sh/fastcomments/skills)

为您的编码代理提供 FastComments 所需的上下文——小部件、配置、安全单点登录、REST API 和 SDK：

```bash
npx skills add fastcomments/skills
```

兼容 Claude Code、Codex、Cursor、Copilot、Gemini，以及所有其他由 [skills CLI](https://github.com/vercel-labs/skills) 支持的代理。
