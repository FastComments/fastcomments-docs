[![skills.sh](https://skills.sh/b/fastcomments/skills)](https://skills.sh/fastcomments/skills)

コーディングエージェントに必要な FastComments のコンテキストを提供します - ウィジェット、構成、Secure SSO、REST API、そして SDK です：

```bash
npx skills add fastcomments/skills
```

Claude Code、Codex、Cursor、Copilot、Gemini、そして [skills CLI](https://github.com/vercel-labs/skills) がサポートするすべてのエージェントで動作します。
