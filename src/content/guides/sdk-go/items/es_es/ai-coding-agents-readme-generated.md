[![skills.sh](https://skills.sh/b/fastcomments/skills)](https://skills.sh/fastcomments/skills)

Proporcione a su agente de codificación el contexto de FastComments que necesita: widgets, configuración, SSO seguro, la API REST y los SDK:

```bash
npx skills add fastcomments/skills
```

Funciona con Claude Code, Codex, Cursor, Copilot, Gemini y cualquier otro agente que soporte la [skills CLI](https://github.com/vercel-labs/skills).
