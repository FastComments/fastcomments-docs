### ब्रॉडकास्ट आईडी (Broadcast Ids)

आप देखेंगे कि कुछ API कॉल में `broadcastId` पास करना अपेक्षित है। जब आपको इवेंट्स प्राप्त होते हैं, तो आपको यह ID वापस मिलेगी, ताकि आप जान सकें कि यदि आप क्लाइंट पर ऑप्टिमिस्टिक रूप से बदलाव लागू करने की योजना बना रहे हैं (जो आप शायद करना चाहेंगे क्योंकि यह सबसे बेहतर अनुभव देता है) तो उस इवेंट को अनदेखा करें। यहाँ एक UUID पास करें। यह ID इतनी अद्वितीय होनी चाहिए कि वह एक ब्राउज़र सेशन में दो बार न आए।
