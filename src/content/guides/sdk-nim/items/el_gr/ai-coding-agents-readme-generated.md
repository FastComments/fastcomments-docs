Δώστε στον κώδικα πράκτορα το πλαίσιο FastComments που χρειάζεται - widgets, ρυθμίσεις, Secure SSO, το REST API και τα SDKs:

```bash
npx skills add fastcomments/skills
```

Λειτουργεί με Claude Code, Codex, Cursor, Copilot, Gemini και κάθε άλλο πράκτορα που υποστηρίζει το [skills CLI](https://github.com/vercel-labs/skills) υποστηρίζει.
