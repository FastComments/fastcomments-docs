### ब्रॉडकास्ट आईडी

आप देखेंगे कि कुछ API कॉल में `broadcastId` पास करना अपेक्षित है। जब आप इवेंट प्राप्त करते हैं, तो आपको यह आईडी वापस मिलेगी, ताकि यदि आप क्लाइंट पर ऑप्टिमिस्टिक रूप से बदलाव लागू करने की योजना बनाते हैं (जो आप शायद करना चाहेंगे क्योंकि यह सबसे अच्छा अनुभव प्रदान करता है), तो आप उस इवेंट को अनदेखा कर सकें। यहाँ एक UUID पास करें। यह आईडी इतनी अद्वितीय होनी चाहिए कि वह एक ब्राउज़र सत्र में दो बार न आए।
