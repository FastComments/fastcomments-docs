SDK FastComments надає три API-клієнти:

### PublicAPI - Методи, безпечні для клієнта

`PublicAPI` містить методи, які безпечно викликати з клієнтського коду (застосунків iOS/macOS). Ці методи:
- Не потребують API-ключа
- Можуть використовувати SSO-токени для автентифікації
- Мають обмеження частоти запитів на користувача/пристрій
- Підходять для застосунків, орієнтованих на кінцевих користувачів

**Приклад використання**: Отримання та створення коментарів у вашому застосунку iOS

### DefaultAPI - Серверні методи

`DefaultAPI` містить автентифіковані методи, які потребують API-ключа. Ці методи:
- Потребують вашого API-ключа FastComments
- Повинні викликатися ЛИШЕ з серверного коду
- Надають повний доступ до ваших даних FastComments
- Мають обмеження частоти запитів на орендаря (tenant)

**Приклад використання**: Адміністративні операції, масове експортування даних, керування користувачами

### ModerationAPI - Методи панелі модератора

`ModerationAPI` надає розширений набір API для швидкої модерізації в реальному часі. Кожен метод `ModerationAPI` приймає параметр `sso` і може автентифікуватися через SSO або сесійний cookie FastComments.com.

**Приклад використання**: Створення досвіду модерації для модераторів вашої спільноти

**ВАЖЛИВО**: Ніколи не викривайте свій API-ключ у клієнтському коді. API-ключі слід використовувати лише на сервері.
