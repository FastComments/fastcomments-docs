FastComments SDK надає два типи API-ендпоінтів:

### PublicAPI - Безпечні для клієнта ендпоінти

`PublicAPI` містить ендпоінти, які безпечно викликати з клієнтського коду (застосунків iOS/macOS). Ці ендпоінти:
- Не потребують API-ключа
- Можуть використовувати SSO-токени для автентифікації
- Мають обмеження частоти запитів на користувача/пристрій
- Підходять для застосунків, орієнтованих на кінцевих користувачів

**Приклад використання**: Отримання та створення коментарів у вашому застосунку iOS

### DefaultAPI - Серверні ендпоінти

`DefaultAPI` містить автентифіковані ендпоінти, які потребують API-ключа. Ці ендпоінти:
- Вимагають ваш API-ключ FastComments
- Повинні викликатися ЛИШЕ з серверного коду
- Надають повний доступ до ваших даних FastComments
- Мають обмеження частоти запитів на орендаря (tenant)

**Приклад використання**: Адміністративні операції, масовий експорт даних, інструменти модерації

**ВАЖЛИВО**: Ніколи не викривайте ваш API-ключ у клієнтському коді. API-ключі слід використовувати лише на сервері.
