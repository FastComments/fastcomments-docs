Iscrive un URL a un evento di commento (sottoscrizione REST hook). Iscrivere nuovamente lo stesso URL allo stesso evento e dominio restituisce l'iscrizione esistente. Le consegne sono firmate con HMAC, consulta la guida sui webhook; l'intestazione legacy `token` non viene mai inviata alle iscrizioni API.

## Parametri

| Nome | Tipo | Posizione | Obbligatorio | Descrizione |
|------|------|-----------|--------------|-------------|
| tenantId | string | query | Sì |  |
