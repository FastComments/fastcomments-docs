将批量任务加入队列，把评论、页面及相关记录从一个 urlId 或 domain 迁移到另一个。
"urlId" 迁移仅匹配完全相同的 urlId。"domain" 迁移会在每个 urlId 和 url 中查找并替换该值。
轮询 GET /api/v1/batch-jobs/{batchJobId}：任务完成后会包含每次迁移的结果和一个 undoId。
