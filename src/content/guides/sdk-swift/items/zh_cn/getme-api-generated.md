Identifies the credential in use: the tenant it belongs to and, for OAuth tokens, the user who authorized it.  
标识正在使用的凭证：它所属的租户，以及对于 OAuth 令牌，授权该令牌的用户。

Integrations use this to test a connection and label it.  
集成使用此信息来测试连接并对其进行标记。
