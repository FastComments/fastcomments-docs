FastComments SDK предоставляет два типа API-эндпоинтов:

### PublicAPI - Безопасные для клиента эндпоинты

`PublicAPI` содержит эндпоинты, которые безопасно вызывать из клиентского кода (приложения iOS/macOS). Эти эндпоинты:
- Не требуют API-ключа
- Могут использовать SSO-токены для аутентификации
- Имеют ограничение частоты запросов на пользователя/устройство
- Подходят для приложений, ориентированных на конечных пользователей

**Пример использования**: Получение и создание комментариев в вашем iOS-приложении

### DefaultAPI - Серверные эндпоинты

`DefaultAPI` содержит аутентифицированные эндпоинты, требующие API-ключа. Эти эндпоинты:
- Требуют ваш API-ключ FastComments
- Должны вызываться ТОЛЬКО из серверного кода
- Предоставляют полный доступ к вашим данным FastComments
- Имеют ограничение частоты запросов на тенанта

**Пример использования**: Административные операции, массовый экспорт данных, инструменты модерации

**ВАЖНО**: Никогда не раскрывайте свой API-ключ в клиентском коде. API-ключи должны использоваться только на сервере.
