Переводит указанные комментарии в локаль виджета. Доступно только когда соответствующее правило настройки виджета имеет параметр Перевод комментариев, установленный в Автоматический или Ручной.

## Параметры

| Имя | Тип | Расположение | Обязательно | Описание |
|------|------|----------|----------|-------------|
| tenantId | string | path | Yes |  |
| urlId | string | query | Yes |  |
| sso | string | query | No |  |
| locale | string | query | No |  |

## Ответ

Возвращает: [`CommentTranslationsResponse`](https://github.com/FastComments/fastcomments-swift/blob/main/client/FastCommentsSwift/Models/CommentTranslationsResponse.swift)
