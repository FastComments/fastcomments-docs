FastComments SDK предоставляет три API-клиента:

### PublicAPI - Методы, безопасные для клиента

`PublicAPI` содержит методы, которые безопасно вызывать из клиентского кода (приложения iOS/macOS). Эти методы:
- Не требуют API-ключа
- Могут использовать SSO-токены для аутентификации
- Ограничены по частоте запросов для каждого пользователя/устройства
- Подходят для приложений, ориентированных на конечных пользователей

**Пример использования**: Получение и создание комментариев в вашем iOS-приложении

### DefaultAPI - Серверные методы

`DefaultAPI` содержит аутентифицированные методы, требующие API-ключа. Эти методы:
- Требуют ваш FastComments API-ключ
- Должны вызываться ТОЛЬКО из серверного кода
- Предоставляют полный доступ к вашим данным FastComments
- Ограничены по частоте запросов для каждого арендатора (tenant)

**Пример использования**: Административные операции, массовый экспорт данных, управление пользователями

### ModerationAPI - Методы панели модератора

`ModerationAPI` предоставляет обширный набор быстрых API для модерации в реальном времени. Каждый метод `ModerationAPI` принимает параметр `sso` и может аутентифицироваться через SSO или сессионный cookie FastComments.com.

**Пример использования**: Создание опыта модерации для модераторов вашего сообщества

**ВАЖНО**: Никогда не раскрывайте свой API-ключ в клиентском коде. API-ключи должны использоваться только на стороне сервера.
