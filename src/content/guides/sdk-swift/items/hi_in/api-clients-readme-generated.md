FastComments SDK तीन API क्लाइंट प्रदान करता है:

### PublicAPI - क्लाइंट-सुरक्षित मेथड्स

`PublicAPI` में ऐसे मेथड्स शामिल हैं जिन्हें क्लाइंट-साइड कोड (iOS/macOS ऐप्स) से कॉल करना सुरक्षित है। ये मेथड्स:
- API की की आवश्यकता नहीं रखते
- प्रमाणीकरण के लिए SSO टोकन का उपयोग कर सकते हैं
- प्रति उपयोगकर्ता/डिवाइस रेट-लिमिटेड होते हैं
- अंतिम उपयोगकर्ता-केंद्रित एप्लिकेशन के लिए उपयुक्त होते हैं

**उदाहरण उपयोग का मामला**: अपने iOS ऐप में कमेंट्स प्राप्त करना और बनाना

### DefaultAPI - सर्वर-साइड मेथड्स

`DefaultAPI` में प्रमाणित मेथड्स शामिल हैं जिन्हें API की की आवश्यकता होती है। ये मेथड्स:
- आपकी FastComments API की की आवश्यकता रखते हैं
- केवल सर्वर-साइड कोड से ही कॉल किए जाने चाहिए
- आपके FastComments डेटा तक पूर्ण पहुँच प्रदान करते हैं
- प्रति टेनेंट रेट-लिमिटेड होते हैं

**उदाहरण उपयोग का मामला**: प्रशासनिक कार्य, बल्क डेटा एक्सपोर्ट, उपयोगकर्ता प्रबंधन

### ModerationAPI - मॉडरेटर डैशबोर्ड मेथड्स

`ModerationAPI` लाइव और तेज़ मॉडरेशन APIs का एक विस्तृत सूट प्रदान करता है। हर `ModerationAPI` मेथड एक `sso` पैरामीटर स्वीकार करता है और SSO या FastComments.com सेशन कुकी के माध्यम से प्रमाणित हो सकता है।

**उदाहरण उपयोग का मामला**: अपने समुदाय के मॉडरेटर्स के लिए एक मॉडरेशन अनुभव बनाना

**महत्वपूर्ण**: कभी भी अपनी API की को क्लाइंट-साइड कोड में एक्सपोज़ न करें। API कीज़ का उपयोग केवल सर्वर-साइड पर ही किया जाना चाहिए।
