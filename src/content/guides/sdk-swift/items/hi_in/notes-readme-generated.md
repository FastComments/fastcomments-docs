### ब्रॉडकास्ट IDs

आप देखेंगे कि कुछ API कॉल्स में `broadcastId` पास करना अपेक्षित है। जब आप इवेंट्स प्राप्त करते हैं, तो आपको यह ID वापस मिलेगी, ताकि यदि आप क्लाइंट पर बदलावों को optimistically लागू करने की योजना बनाते हैं (जो आप शायद करना चाहेंगे क्योंकि यह सबसे अच्छा अनुभव देता है), तो आप उस इवेंट को अनदेखा कर सकें। यहाँ एक UUID पास करें। यह ID इतनी अद्वितीय होनी चाहिए कि एक सेशन में दो बार न आए।

```swift
let broadcastId = UUID().uuidString
```
