### 401 अनधिकृत त्रुटियाँ

यदि आपको प्रमाणित API का उपयोग करते समय 401 त्रुटियाँ मिल रही हैं:

1. **अपनी API कुंजी जाँचें**: सुनिश्चित करें कि आप अपने FastComments डैशबोर्ड से सही API कुंजी का उपयोग कर रहे हैं
2. **टेनेंट ID सत्यापित करें**: सुनिश्चित करें कि टेनेंट ID आपके खाते से मेल खाती है
3. **API कुंजी प्रारूप**: API कुंजी को साझा कॉन्फ़िगरेशन पर `x-api-key` हेडर के रूप में सेट किया जाना चाहिए:

```swift
FastCommentsSwiftAPIConfiguration.shared.customHeaders["x-api-key"] = "YOUR_API_KEY"
```

4. **गलत API का उपयोग**: प्रमाणित कॉल के लिए सुनिश्चित करें कि आप `DefaultAPI` (न कि `PublicAPI`) का उपयोग कर रहे हैं

### SSO टोकन समस्याएँ

यदि SSO टोकन काम नहीं कर रहे हैं:

1. **प्रोडक्शन के लिए सुरक्षित मोड का उपयोग करें**: प्रोडक्शन के लिए हमेशा अपनी API कुंजी के साथ `FastCommentsSSO.createSecure()` का उपयोग करें
2. **केवल सर्वर-साइड**: अपने सर्वर पर सुरक्षित SSO टोकन जनरेट करें, अपनी API कुंजी कभी क्लाइंट्स को न दिखाएँ
3. **उपयोगकर्ता डेटा जाँचें**: सुनिश्चित करें कि सभी आवश्यक फ़ील्ड (id, email, username) प्रदान की गई हैं
4. **टोकन समाप्ति**: सुरक्षित SSO टोकन में टाइमस्टैम्प होता है और वे समाप्त हो सकते हैं। आवश्यकतानुसार नए टोकन जनरेट करें।

### SSL/TLS त्रुटियाँ

यदि आप SSL/TLS त्रुटियों का सामना करते हैं:

1. सुनिश्चित करें कि आपके ऐप की Info.plist fastcomments.com से HTTPS कनेक्शन की अनुमति देती है
2. जाँचें कि आप ऐसे App Transport Security अपवादों का उपयोग नहीं कर रहे हैं जो कनेक्शन को अवरुद्ध कर सकते हैं
