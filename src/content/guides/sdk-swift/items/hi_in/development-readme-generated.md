### क्लाइंट को पुनः जनरेट करना

नवीनतम OpenAPI स्पेसिफिकेशन से API क्लाइंट को पुनः जनरेट करने के लिए:

1. सुनिश्चित करें कि FastComments सर्वर `http://localhost:3001` पर लोकल रूप से चल रहा है
2. अपडेट स्क्रिप्ट चलाएँ:

```bash
./update.sh
```

यह करेगा:
- नवीनतम OpenAPI स्पेक डाउनलोड करना
- Swift क्लाइंट कोड जनरेट करना (client/docs में API दस्तावेज़ीकरण के साथ)
- सब कुछ काम कर रहा है यह सत्यापित करने के लिए पैकेज बिल्ड करना
