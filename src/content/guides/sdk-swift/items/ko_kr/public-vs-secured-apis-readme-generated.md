FastComments SDK는 두 가지 유형의 API 엔드포인트를 제공합니다:

### PublicAPI - 클라이언트 안전 엔드포인트

`PublicAPI`는 클라이언트 측 코드(iOS/macOS 앱)에서 호출해도 안전한 엔드포인트를 포함합니다. 이 엔드포인트들은:
- API 키가 필요하지 않습니다
- 인증을 위해 SSO 토큰을 사용할 수 있습니다
- 사용자/기기별로 요청 속도가 제한됩니다
- 최종 사용자 대상 애플리케이션에 적합합니다

**사용 사례 예시**: iOS 앱에서 댓글 가져오기 및 작성하기

### DefaultAPI - 서버 측 엔드포인트

`DefaultAPI`는 API 키가 필요한 인증된 엔드포인트를 포함합니다. 이 엔드포인트들은:
- FastComments API 키가 필요합니다
- 서버 측 코드에서만 호출해야 합니다
- FastComments 데이터에 대한 전체 접근 권한을 제공합니다
- 테넌트별로 요청 속도가 제한됩니다

**사용 사례 예시**: 관리 작업, 대량 데이터 내보내기, 모더레이션 도구

**중요**: 클라이언트 측 코드에 API 키를 노출하지 마세요. API 키는 서버 측에서만 사용해야 합니다.
