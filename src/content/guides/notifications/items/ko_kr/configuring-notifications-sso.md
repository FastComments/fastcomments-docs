SSO의 경우 알림과 관련하여 다음 설정을 고려해야 합니다:

- 사용자가 알림을 수신 동의했는지 여부.
  - `SSOUser` 객체에서 `optedInNotifications` 플래그를 `true` 또는 `false`로 설정하여 수행됩니다.
  - API를 통해 설정할 수 있습니다.
  - 또한, 페이로드에서 이 플래그에 값을 전달하면 사용자가 댓글 스레드를 로드할 때 자동으로 업데이트됩니다.
- 사용자가 **구독** 알림을 수신 동의했는지 여부.
  - `SSOUser` 객체에서 `optedInSubscriptionNotifications` 플래그를 `true` 또는 `false`로 설정하여 수행됩니다.
  - API를 통해 설정할 수 있습니다.
  - 또한, 페이로드에서 이 플래그에 값을 전달하면 사용자가 댓글 스레드를 로드할 때 자동으로 업데이트됩니다.
- 사용자가 페이지 구독 알림을 얼마나 자주 수신하는지.
  - SSO 사용자는 FastComments.com에 로그인하여 이를 변경할 수 없으므로, 페이지 구독으로 많은 이메일(일주일 내 20통 이상)이 발송되면 최대 일주일에 한 번 링크가 포함된 이메일을 보냅니다.
  - 링크를 열면 각 페이지 구독의 빈도(매분, 매시간 또는 매일)를 변경하거나 페이지 구독을 취소할 수 있는 페이지가 열립니다.
  - 링크는 30일 동안 유효합니다.
- 이메일 주소 정의.
  - 값이 없으면 이메일 기반 알림을 보낼 수 없습니다.
- 이메일에서 구독 취소 링크를 비활성화할지 여부.
  - `Tenant` 객체의 `disableUnsubscribeLinks` 플래그를 통해 수행됩니다.
  - API를 통해 설정할 수 있습니다.
- 사용자 지정 구독 취소 링크를 사용할지 여부.
  - `DomainConfig` 객체의 `footerUnsubscribeURL` 속성을 통해 수행됩니다.
  - API를 통해 설정할 수 있습니다.
  - 또한 동일한 객체의 `emailHeaders`를 통해 관련 구독 취소 헤더를 설정하는 것도 고려할 수 있습니다.
