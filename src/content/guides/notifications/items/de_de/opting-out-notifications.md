Benachrichtigungen können auf mehrere Arten abbestellt werden. Wenn Ihr Konto von FastComments.com verwaltet wird und nicht über SSO, können Sie Ihre
Benachrichtigungen über die [Benachrichtigungseinstellungen-Seite](https://fastcomments.com/auth/my-account/edit-notifications) konfigurieren.

Hier können Sie Benachrichtigungen für Kommentarantworten und Erwähnungen konfigurieren, die Benachrichtigungsfrequenz (jede Minute, stündlich oder täglich), die Frequenz von Abo-Benachrichtigungen (jede Minute, stündlich oder täglich) sowie Benachrichtigungen im Allgemeinen einstellen. Wenn Sie ein Website-Administrator oder
Moderator sind, haben Sie zusätzlich eine separate Einstellung **Admin-Benachrichtigungsfrequenz**, die steuert, wie oft Sie E-Mails über neue Kommentare auf Ihrer Website erhalten (standardmäßig stündlich), sowie die Möglichkeit, die Frequenz der Digest-E-Mail zu konfigurieren.

Wenn ein Seitenabonnement Ihnen viele E-Mails sendet, senden wir Ihnen höchstens einmal pro Woche eine E-Mail mit der Frage, ob Sie diese Frequenz weiterhin wünschen. Der Link in dieser E-Mail führt Sie zur Benachrichtigungseinstellungen-Seite, um sie zu ändern. Für Benutzer, die über SSO verwaltet werden, öffnet der Link eine Seite, auf der sie die Frequenz jedes ihrer Seitenabonnements ändern oder ein Seitenabonnement kündigen können, ohne ein FastComments.com-Konto.

Zusätzlich enthält jede E-Mail einen Opt-out-Link. Für Benachrichtigungen zu Kommentarantworten enthält die E-Mail einen Link, um **Benachrichtigungen für diesen Kommentar abzubestellen**.

Benachrichtigungen enthalten außerdem einen Abmeldelink zum Deaktivieren sowie die entsprechenden E-Mail-Header.

Abmeldelinks in E-Mails können auf Anfrage für einen bestimmten Tenant entfernt werden. Zusätzlich kann der Link für SSO- oder Whitelabel-Integrationen angepasst werden.
