對於 SSO，通知有以下需要考慮的配置：

- 使用者是否已選擇加入通知。
  - 這是透過在 `SSOUser` 物件中將 `optedInNotifications` 旗標設定為 `true` 或 `false` 來完成。
  - 這可以透過 API 設定。
  - 此外，如果您在 payload 中為此旗標傳遞值，當使用者載入留言串時它會自動更新。
- 使用者是否已選擇加入**訂閱**通知。
  - 這是透過在 `SSOUser` 物件中將 `optedInSubscriptionNotifications` 旗標設定為 `true` 或 `false` 來完成。
  - 這可以透過 API 設定。
  - 此外，如果您在 payload 中為此旗標傳遞值，當使用者載入留言串時它會自動更新。
- 使用者接收頁面訂閱通知的頻率。
  - SSO 使用者無法登入 FastComments.com 來更改此設定，因此當頁面訂閱發送大量電子郵件給他們時（一週內 20 封或更多），我們會向他們發送一個連結，每週最多一次。
  - 該連結會開啟一個頁面，他們可以在其中更改每個頁面訂閱的頻率（每分鐘、每小時或每天），或取消訂閱某個頁面。
  - 該連結有效期為 30 天。
- 定義他們的電子郵件。
  - 如果未提供，我們無法發送基於電子郵件的通知。
- 是否停用電子郵件中的取消訂閱連結。
  - 這是透過 `Tenant` 物件中的 `disableUnsubscribeLinks` 旗標來完成。
  - 這可以透過 API 設定。
- 是否使用自訂的取消訂閱連結。
  - 這是透過 `DomainConfig` 物件上的 `footerUnsubscribeURL` 屬性來完成。
  - 這可以透過 API 設定。
  - 您可能還需要考慮在同一物件中透過 `emailHeaders` 設定相關的取消訂閱標頭。
