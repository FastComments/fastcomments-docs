SSO の場合、通知に関して以下の設定を考慮する必要があります:

- ユーザーが通知をオプトインしているかどうか。
  - これは、`SSOUser` オブジェクトの `optedInNotifications` フラグを `true` または `false` に設定することで行います。
  - これは API 経由で設定できます。
  - また、ペイロードでこのフラグの値を渡すと、ユーザーがコメントスレッドを読み込んだ際に自動的に更新されます。
- ユーザーが**サブスクリプション**通知をオプトインしているかどうか。
  - これは、`SSOUser` オブジェクトの `optedInSubscriptionNotifications` フラグを `true` または `false` に設定することで行います。
  - これは API 経由で設定できます。
  - また、ペイロードでこのフラグの値を渡すと、ユーザーがコメントスレッドを読み込んだ際に自動的に更新されます。
- ユーザーがページサブスクリプションの通知を受け取る頻度。
  - SSO ユーザーは FastComments.com にログインしてこれを変更できないため、ページサブスクリプションから大量のメールが送信される場合(1週間に20件以上)、週に最大1回、リンクを記載したメールを送信します。
  - このリンクを開くと、各ページサブスクリプションの頻度を変更する(毎分、毎時、または毎日)か、ページから購読解除できるページが表示されます。
  - リンクの有効期間は30日です。
- メールアドレスの定義。
  - 設定されていない場合、メールベースの通知を送信できません。
- メール内の購読解除リンクを無効にするかどうか。
  - これは、`Tenant` オブジェクトの `disableUnsubscribeLinks` フラグで行います。
  - これは API 経由で設定できます。
- カスタム購読解除リンクを使用するかどうか。
  - これは、`DomainConfig` オブジェクトの `footerUnsubscribeURL` プロパティで行います。
  - これは API 経由で設定できます。
  - また、同じオブジェクトの `emailHeaders` で関連する購読解除ヘッダーを設定することも検討するとよいでしょう。
