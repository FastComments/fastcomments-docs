对于 SSO，通知方面需要考虑以下配置：

- 用户是否已选择接收通知。
  - 通过在 `SSOUser` 对象中将 `optedInNotifications` 标志设置为 `true` 或 `false` 来实现。
  - 可以通过 API 进行设置。
  - 此外，如果在载荷中为该标志传递了值，当用户加载评论线程时会自动更新。
- 用户是否已选择接收**订阅**通知。
  - 通过在 `SSOUser` 对象中将 `optedInSubscriptionNotifications` 标志设置为 `true` 或 `false` 来实现。
  - 可以通过 API 进行设置。
  - 此外，如果在载荷中为该标志传递了值，当用户加载评论线程时会自动更新。
- 用户接收页面订阅通知的频率。
  - SSO 用户无法登录 FastComments.com 来更改此设置，因此当页面订阅向他们发送大量邮件（一周内 20 封或更多）时，我们会向他们发送一个链接的邮件，每周最多一次。
  - 该链接会打开一个页面，他们可以在其中更改每个页面订阅的频率（每分钟、每小时或每天），或取消订阅某个页面。
  - 该链接有效期为 30 天。
- 定义用户的电子邮件。
  - 如果未提供，我们将无法发送基于电子邮件的通知。
- 是否禁用电子邮件中的取消订阅链接。
  - 通过 `Tenant` 对象中的 `disableUnsubscribeLinks` 标志来实现。
  - 可以通过 API 进行设置。
- 是否使用自定义的取消订阅链接。
  - 通过 `DomainConfig` 对象上的 `footerUnsubscribeURL` 属性来实现。
  - 可以通过 API 进行设置。
  - 您可能还需要考虑在同一对象中通过 `emailHeaders` 设置相关的取消订阅邮件头。
