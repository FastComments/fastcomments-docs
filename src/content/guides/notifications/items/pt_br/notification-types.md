Existem alguns tipos de notificações e meios pelos quais o FastComments envia notificações:

- Imediatas via e-mail.
  - Notificações de resposta a comentários e menções são enviadas a cada minuto.
- Imediatas via aplicativo.
  - Elas são exibidas sob o ícone do sino de notificações.
- Em lote via e-mail.
  - As notificações de assinatura de página podem ser configuradas por assinatura para enviar a cada minuto, como um resumo horário ou como um resumo diário. Se não houver nada para enviar ao usuário nesse período, não enviamos um e-mail.
  - Se uma assinatura que não está no resumo diário enviar a um usuário 20 ou mais e-mails dentro de uma semana, enviamos a ele um e-mail de confirmação perguntando se ainda deseja essa frequência, com um link para mudar para notificações diárias. Isso é enviado no máximo uma vez por semana, e as notificações continuam sendo enviadas como antes até que ele altere a frequência.
  - As notificações de resposta a enquetes são enviadas ao autor da enquete como um e-mail diário.
- Programadas via e-mail.
  - Exemplos incluem o Resumo da Comunidade (Community Digest Summary), que pode ser enviado diariamente, semanalmente ou mensalmente (ou desativado).
