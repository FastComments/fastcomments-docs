यह SDK इष्टतम संगतता सुनिश्चित करने और रनटाइम त्रुटियों को रोकने के लिए **dual entry points** का उपयोग करता है:

- **`fastcomments-sdk/browser`** - नेटिव `fetch` के साथ ब्राउज़र-सुरक्षित संस्करण
- **`fastcomments-sdk/server`** - SGO समर्थन के साथ पूर्ण Node.js संस्करण
- **`fastcomments-sdk`** (डिफ़ॉल्ट) - केवल टाइप्स, कहीं भी इम्पोर्ट करने के लिए सुरक्षित
