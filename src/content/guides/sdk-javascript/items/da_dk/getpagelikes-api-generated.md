Like-tælling for en side, eventuelt med de brugere, der har liket den.

## Parametre

| Navn | Type | Påkrævet | Beskrivelse |
|------|------|----------|-------------|
| tenantId | string | Ja |  |
| urlId | string | Ja |  |
| includeUserInfo | PageReactIncludeUserInfo | Nej |  |

## Svar

Returnerer: [`GetPageLikesAPIResponse`](https://github.com/FastComments/fastcomments-sdk-js/blob/main/src/generated/src/models/GetPageLikesAPIResponse.ts)

const tenantId: string = 'a1b2c3d4e5f6';
const urlId: string = 'https://mysite.com/blog/best-coffee-2024';

// Basiskald med påkrævede parametre
const likesResponse: GetPageLikesAPIResponse = await getPageLikes(tenantId, urlId);

// Inkluder brugerinfo for hvert like

  console.log(`${like.name} liked this page on ${like.date}`);
});
