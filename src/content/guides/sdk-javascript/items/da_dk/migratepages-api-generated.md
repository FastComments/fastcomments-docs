Sætter et batch-job i kø, der flytter kommentarer, sider og relaterede poster fra én urlId eller domæne til en anden.
"urlId"-migrationer matcher kun den præcise urlId. "domain"-migrationer finder/erstatter værdien i hver urlId og url.
Poll GET /api/v1/batch-jobs/{batchJobId}: når den er færdig, indeholder den resultater pr. migration og et undoId.

## Parametre

| Navn | Type | Påkrævet | Beskrivelse |
|------|------|----------|-------------|
| tenantId | string | Ja |  |
| migrateAPIPagesData | MigrateAPIPagesData | Ja |  |

## Svar

Returnerer: [`QueuePageMigrationJobAPIResponse`](https://github.com/FastComments/fastcomments-sdk-js/blob/main/src/generated/src/models/QueuePageMigrationJobAPIResponse.ts)

const migrations: PageMigration[] = [

    ]
  }
];

const migrateAPIPagesData: MigrateAPIPagesData = {
  source: 'disqus',
  dryRun: false,
  pages: migrations

const response: QueuePageMigrationJobAPIResponse = await migratePages(tenantId, migrateAPIPagesData);

if (response.status === 'success') {
  console.log(`Queued migration job: ${response.jobId} for ${migrateAPIPagesData.pages.length} pages`);
}
