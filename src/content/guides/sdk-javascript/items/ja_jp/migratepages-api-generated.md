ある urlId またはドメインから別の urlId またはドメインへ、コメント、ページ、および関連レコードを移動するバッチジョブをキューに入れます。
"urlId" の移行は完全に一致する urlId のみを対象とします。"domain" の移行は、すべての urlId と url 内の値を検索/置換します。
GET /api/v1/batch-jobs/{batchJobId} をポーリングしてください。完了すると、移行ごとの結果と undoId が含まれます。

## パラメータ

| 名前 | 型 | 必須 | 説明 |
|------|------|----------|-------------|
| tenantId | string | はい |  |
| migrateAPIPagesData | MigrateAPIPagesData | はい |  |

## レスポンス

戻り値: [`QueuePageMigrationJobAPIResponse`](https://github.com/FastComments/fastcomments-sdk-js/blob/main/src/generated/src/models/QueuePageMigrationJobAPIResponse.ts)

const tenantId: string = 'abc123def456';

const migrations: PageMigration[] = [
  {

    title: 'The Complete Guide to React Hooks',

      { id: 'c-102', author: 'dev_mike', message: 'Very helpful, bookmarked this one.', date: '2024-01-16T14:47:00Z' }
    ]
  }
];

const migrateAPIPagesData: MigrateAPIPagesData = {
  source: 'disqus',
  dryRun: false,
  pages: migrations
};

const response: QueuePageMigrationJobAPIResponse = await migratePages(tenantId, migrateAPIPagesData);

if (response.status === 'success') {
  console.log(`Queued migration job: ${response.jobId} for ${migrateAPIPagesData.pages.length} pages`);
}
