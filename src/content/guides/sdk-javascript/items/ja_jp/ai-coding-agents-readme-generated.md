[![skills.sh](https://skills.sh/b/fastcomments/skills)](https://skills.sh/fastcomments/skills)

FastComments のコンテキスト（ウィジェット、設定、Secure SSO、REST API、SDK）をコーディングエージェントに提供します:

```bash
npx skills add fastcomments/skills
```

Claude Code、Codex、Cursor、Copilot、Gemini、そして [skills CLI] がサポートする他のすべてのエージェントでも動作します。
