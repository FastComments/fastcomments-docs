Recuento de "me gusta" de una página, opcionalmente con los usuarios que le dieron "me gusta".

## Parámetros

| Nombre | Tipo | Requerido | Descripción |
|------|------|----------|-------------|
| tenantId | string | Sí |  |
| urlId | string | Sí |  |
| includeUserInfo | PageReactIncludeUserInfo | No |  |

## Respuesta

Devuelve: [`GetPageLikesAPIResponse`](https://github.com/FastComments/fastcomments-sdk-js/blob/main/src/generated/src/models/GetPageLikesAPIResponse.ts)

const tenantId: string = 'a1b2c3d4e5f6';
const urlId: string = 'https://mysite.com/blog/best-coffee-2024';

// Llamada básica con los parámetros requeridos
const likesResponse: GetPageLikesAPIResponse = await getPageLikes(tenantId, urlId);
console.log(`Page has ${likesResponse.pageLikes.length} likes`);

// Incluir la información del usuario para cada "me gusta"

  console.log(`${like.name} liked this page on ${like.date}`);
});
