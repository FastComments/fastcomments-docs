`demo` テナントを切り替えた後、ウィジェットが認証エラーで読み込みを拒否することがあります。これは、FastComments がそのドメインであなたのアカウントの使用を許可すべきことを認識していないためです。

[こちらからアカウントにサイトを追加してください。](https://fastcomments.com/auth/my-account/configure-domains)

Val Town はここで注目に値します。というのも、1つの val が複数のホスト名で到達可能になることがあるからです:

- すべての HTTP val には長いデフォルトのエンドポイント `<org>--<id>.web.val.run` があります。
- カスタムサブドメインを取得すると `<name>.val.run` が追加されます。
- [カスタムドメイン](https://docs.val.town/vals/http/custom-domains/) を設定すると3つ目が追加されます。
- ブランチにはそれぞれ固有の URL があります。

ウィジェットを実際に配信するホスト名をすべて追加してください。セットアップ後にサブドメインを取得した場合もそれを追加してください。そうしないと、ウィジェットは古い URL では動作しますが、新しい URL では失敗します。
