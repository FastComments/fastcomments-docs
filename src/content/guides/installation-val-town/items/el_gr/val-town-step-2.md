`tenantId: "demo"` είναι ένα κοινό δημόσιο sandbox. Λειτουργεί χωρίς εγγραφή, γι' αυτό τα παραδείγματα το χρησιμοποιούν, αλλά όλοι οι άλλοι που δοκιμάζουν το FastComments γράφουν στα ίδια νήματα και οποιοσδήποτε μπορεί να τα συντονίσει. Αλλάξτε το πριν δημοσιεύσετε οτιδήποτε σας ενδιαφέρει.

Το tenant ID σας βρίσκεται στη [σελίδα μυστικού API](https://fastcomments.com/auth/my-account/api-secret).

Ένα tenant ID είναι δημόσιο και ανήκει στον κώδικα του προγράμματος περιήγησης. Ένα μυστικό API δεν είναι, και τίποτα σε αυτή τη σελίδα δεν χρειάζεται ένα.

## Διαβάστε το από μεταβλητή περιβάλλοντος

Τα vals του Val Town είναι δημόσια στην δωρεάν έκδοση, έτσι η πηγή τους είναι αναγνώσιμη από όλους. Κρατήστε οτιδήποτε ευαίσθητο σε μεταβλητές περιβάλλοντος, διαβάζοντας με `Deno.env.get`:

[inline-code-attrs-start title = 'config.ts'; type='javascript' inline-code-attrs-end]
[inline-code-start]
export const TENANT_ID = Deno.env.get("FASTCOMMENTS_TENANT_ID") ?? "demo";

// Μόνο λογαριασμοί που δημιουργήθηκαν στο eu.fastcomments.com ορίζουν αυτό σε "eu".
export const REGION = Deno.env.get("FASTCOMMENTS_REGION") ?? "";

export const CDN = REGION === "eu"
  ? "https://cdn-eu.fastcomments.com"
  : "https://cdn.fastcomments.com";
[inline-code-end]

Αυτό έχει μεγαλύτερη σημασία από το συνηθισμένο στο Val Town για έναν δεύτερο λόγο: **η επανασύνθεση ενός val αντιγράφει τα κλειδιά των μεταβλητών περιβάλλοντος, αλλά όχι τις τιμές τους.** Ένα μυστικό που διατηρείται σε μεταβλητή περιβάλλοντος δεν ακολουθεί το val σας σε λογαριασμό κάποιου άλλου. Ένα μυστικό γραμμένο σε αρχείο το κάνει.

Η επιστροφή στην τιμή `"demo"` διατηρεί το val λειτουργικό για όποιον το επανασυνθέσει πριν ορίσει το δικό του tenant.

## EU λογαριασμοί

Ένας λογαριασμός, τα δεδομένα του και τα κλειδιά του ζουν σε μία περιοχή. Αν ο δικός σας δημιουργήθηκε στο `eu.fastcomments.com`, κάθε ρύθμιση widget χρειάζεται επίσης `region: "eu"`, και τα scripts φορτώνουν από `cdn-eu.fastcomments.com`. Διαφορετικά αφήστε και τα δύο όπως είναι.
