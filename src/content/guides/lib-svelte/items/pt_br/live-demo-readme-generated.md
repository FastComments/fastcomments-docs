Experimente cada widget ao vivo em <https://fastcomments.com/commenting-system-for-svelte/>.

Um conjunto de widgets Svelte e wrappers para FastComments. `src/routes` contém exemplos executáveis - basta executar:

    npm install
    npm run dev

Então você pode ver todos os widgets e editá-los - por exemplo, inserir seu próprio ID de tenant ou experimentar diferentes configurações.

TypeScript foi usado para que você possa inspecionar os objetos de configuração de cada widget e ver quais opções eles aceitam.
