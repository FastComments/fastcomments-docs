Попробуйте каждый виджет вживую по адресу <https://fastcomments.com/commenting-system-for-svelte/>.

Набор виджетов Svelte и обёрток для FastComments. `src/routes` содержит исполняемые примеры - просто запустите:

    npm install
    npm run dev

Затем вы сможете увидеть все виджеты и отредактировать их - например, добавить свой tenant id или попробовать другую конфигурацию.

Для этого используется TypeScript, чтобы вы могли просматривать объекты конфигурации каждого виджета и видеть, какие параметры они принимают.
