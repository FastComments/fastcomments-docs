Prøv alle widgets live på <https://fastcomments.com/commenting-system-for-svelte/>.

Et sæt af Svelte-widgets og wrappers til FastComments. `src/routes` indeholder kørbare eksempler - kør blot:

    npm install
    npm run dev

Derefter kan du se alle widgets og redigere dem - for eksempel for at indsætte din egen tenant-id eller prøve en anden konfiguration.

TypeScript er blevet brugt, så du kan inspicere konfigurationsobjekterne for hver widget for at se, hvilke muligheder de har.
