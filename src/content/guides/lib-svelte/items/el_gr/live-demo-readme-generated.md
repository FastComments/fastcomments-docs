Δοκιμάστε κάθε widget ζωντανά στο <https://fastcomments.com/commenting-system-for-svelte/>.

Ένα σύνολο από Svelte widgets και wrappers για το FastComments. `src/routes` περιέχει εκτελέσιμα παραδείγματα - απλώς τρέξτε:

    npm install
    npm run dev

Στη συνέχεια μπορείτε να δείτε όλα τα widgets και να τα επεξεργαστείτε - για παράδειγμα για να εισάγετε το δικό σας tenant id ή να δοκιμάσετε διαφορετική διαμόρφωση.

Χρησιμοποιήθηκε TypeScript ώστε να μπορείτε να εξετάσετε τα αντικείμενα config για κάθε widget και να δείτε ποιες επιλογές δέχονται.
