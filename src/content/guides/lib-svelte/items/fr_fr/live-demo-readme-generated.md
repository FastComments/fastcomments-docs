Essayez chaque widget en direct sur <https://fastcomments.com/commenting-system-for-svelte/>.

Un ensemble de widgets Svelte et d’enveloppes pour FastComments. `src/routes` contient des exemples exécutables – il suffit de lancer :

    npm install
    npm run dev

Ensuite, vous pouvez voir tous les widgets et les modifier – par exemple pour insérer votre propre identifiant de locataire ou essayer une configuration différente.

TypeScript a été utilisé afin que vous puissiez inspecter les objets de configuration de chaque widget pour voir quelles options ils acceptent.
