Prova ogni widget in diretta su <https://fastcomments.com/commenting-system-for-svelte/>.

Un set di widget Svelte e wrapper per FastComments. `src/routes` contiene esempi eseguibili - basta eseguire:

    npm install
    npm run dev

Poi puoi vedere tutti i widget e modificarli - ad esempio per inserire il tuo ID tenant o provare una configurazione diversa.

È stato usato TypeScript in modo da poter ispezionare gli oggetti di configurazione per ogni widget e vedere quali opzioni accettano.
