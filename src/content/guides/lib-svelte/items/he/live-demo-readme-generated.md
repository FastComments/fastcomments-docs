נסו כל וידג'ט באופן חי בכתובת <https://fastcomments.com/commenting-system-for-svelte/>.  

קבוצה של וידג'טים של Svelte ועוטפים ל‑FastComments. `src/routes` מכילה דוגמאות ניתנות להרצה – פשוט הריצו:

    npm install
    npm run dev

לאחר מכן תוכלו לראות את כל הווידג'טים ולערוך אותם – לדוגמה כדי להכניס את מזהה השוכר שלכם או לנסות תצורה שונה.  

השתמשו ב‑TypeScript כדי שתוכלו לבדוק את אובייקטי התצורה של כל וידג'ט ולראות אילו אפשרויות הם מקבלים.
