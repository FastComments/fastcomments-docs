Isprobajte svaki widget uživo na <https://fastcomments.com/commenting-system-for-svelte/>.

Skup Svelte widgeta i omotača za FastComments. `src/routes` sadrži pokretljive primjere – jednostavno pokrenite:

    npm install
    npm run dev

Zatim možete vidjeti sve widgete i uređivati ih – na primjer da unesete svoj tenant id ili isprobate različitu konfiguraciju.

TypeScript je korišten kako biste mogli pregledati objekte konfiguracije za svaki widget i vidjeti koje opcije prihvaćaju.
