Спробуйте кожен віджет у реальному часі за адресою <https://fastcomments.com/commenting-system-for-svelte/>.  

Набір віджетів Svelte та обгорток для FastComments. `src/routes` містить готові до запуску приклади — просто запустіть:

    npm install
    npm run dev

Після цього ви можете переглянути всі віджети та редагувати їх — наприклад, ввести свій tenant id або спробувати іншу конфігурацію.

Для цього використано TypeScript, щоб ви могли переглянути об’єкти конфігурації кожного віджета і побачити, які параметри вони приймають.
