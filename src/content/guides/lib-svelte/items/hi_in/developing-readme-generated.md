`npm install` (या `pnpm install` या `yarn`) के साथ डिपेंडेंसीज़ इंस्टॉल करने के बाद, एक डेवलपमेंट सर्वर शुरू करें:

```bash
npm run dev

# या सर्वर शुरू करें और ऐप को नए ब्राउज़र टैब में खोलें
npm run dev -- --open
```

`src/lib` के अंदर की सब चीज़ लाइब्रेरी का हिस्सा है, और `src/routes` के अंदर की सब चीज़ शोकेस है।
