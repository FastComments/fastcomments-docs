FastComments के लिए Svelte विजेट और रैपर्स का एक सेट। `src/routes` में चलाने योग्य उदाहरण हैं - बस चलाएँ:

    npm install
    npm run dev

फिर आप सभी विजेट देख सकते हैं और उन्हें संपादित कर सकते हैं - उदाहरण के लिए अपनी tenant id डालने या अलग-अलग कॉन्फ़िगरेशन आज़माने के लिए।

TypeScript का उपयोग इसलिए किया गया है ताकि आप प्रत्येक विजेट के config ऑब्जेक्ट की जाँच कर सकें और देख सकें कि वे कौन से विकल्प लेते हैं।
