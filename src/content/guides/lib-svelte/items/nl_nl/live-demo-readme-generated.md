Probeer elke widget live op <https://fastcomments.com/commenting-system-for-svelte/>.

Een set Svelte-widgets en wrappers voor FastComments. `src/routes` bevat uitvoerbare voorbeelden - voer simpelweg uit:

    npm install
    npm run dev

Vervolgens kun je alle widgets zien en bewerken - bijvoorbeeld om je eigen tenant-id in te voeren of verschillende configuraties uit te proberen.

TypeScript is gebruikt zodat je de configuratie‑objecten voor elke widget kunt inspecteren om te zien welke opties ze accepteren.
