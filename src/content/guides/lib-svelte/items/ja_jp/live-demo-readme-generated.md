すべてのウィジェットをライブで試すには、<https://fastcomments.com/commenting-system-for-svelte/> にアクセスしてください。

FastComments 用の Svelte ウィジェットとラッパーのセットです。`src/routes` には実行可能なサンプルが含まれており、次のコマンドを実行するだけです:

    npm install
    npm run dev

これで、すべてのウィジェットを確認し、編集できます。たとえば、独自のテナント ID を設定したり、さまざまな構成を試したりできます。

各ウィジェットの設定オブジェクトを確認できるように、TypeScript が使用されています。
