With FastComments we can easily add live commenting to any Webflow site.

There are two ways to do it. The **FastComments App** (recommended) lets you drop widgets onto your pages and CMS Collection Templates from inside the Webflow Designer - start with **Install the FastComments App**. If you'd rather paste the embed code yourself, the **Manual Installation** steps cover that.

Both work for a simple static site and for a dynamic one built with Webflow Collections.

Note that this tutorial requires a FastComments account. It's recommended that you sign up first and then come back here. [You can create an account here.](https://fastcomments.com/auth/tenant-signup?packageId=flex)
