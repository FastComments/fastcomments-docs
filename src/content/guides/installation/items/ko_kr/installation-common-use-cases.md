### 실시간 댓글 바로 표시

댓글 위젯은 기본적으로 실시간이며, 그러나 실시간 댓글은 페이지 내용이 움직이는 것을 방지하기 위해 "새 댓글 N개 표시" 버튼 아래에 나타납니다.

일부 경우에는 버튼을 클릭하지 않고도 새 댓글을 바로 표시하는 것이 바람직합니다.

이 경우 `showLiveRightAway` 플래그를 활성화하면 되며, 해당 플래그에 대한 문서는 [여기](/guide-customizations-and-configuration.html#show-live-right-away)에서 확인할 수 있습니다.

### 익명 댓글 허용 (이메일 요구 안 함)

기본적으로 FastComments는 사용자가 댓글을 달 때 이메일을 남기도록 요구합니다.

이를 비활성화할 수 있으며, [설명은 여기](/guide-customizations-and-configuration.html#allow-anon)에서 확인하세요.

또한 방문자가 사용자 이름을 선택하는 번거로움을 없애기 위해 FastComments는 [방문자마다 하나씩 생성](/guide-customizations-and-configuration.html#auto-generate-username)할 수 있습니다.

### 사용자 정의 스타일링

많은 고객이 댓글 위젯에 자체 스타일을 적용합니다. 문서는 [여기](/guide-customizations-and-configuration.html#custom-css)에서 확인할 수 있습니다.

### 여러 도메인에서 동일한 댓글 표시

여러 사이트에서 동일한 댓글을 표시하는 것은 FastComments가 기본적으로 지원하는 기능입니다.  
다음에서 확인하세요
[이 주제에 대한 문서](/guide-multiple-sites.html#sharing-comments-across-domains).

### 현재 페이지 변경

FastComments는 SPA와 복잡한 애플리케이션을 지원합니다. 현재 페이지를 변경하는 것은 간단하며, [여기](/guide-customizations-and-configuration.html#switching-comment-threads)에서 다루고 있습니다.
