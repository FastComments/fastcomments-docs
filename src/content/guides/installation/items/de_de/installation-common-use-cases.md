### Live-Kommentare sofort anzeigen

Das Kommentar-Widget ist standardmäßig live, jedoch werden Live-Kommentare unter einem „Show N New Comments“-Button angezeigt, um zu verhindern, dass sich der Seiteninhalt verschiebt.

In einigen Fällen ist es dennoch wünschenswert, die neuen Kommentare sofort anzuzeigen, ohne einen Button klicken zu müssen.

In diesem Fall sollten Sie das Flag `showLiveRightAway` aktivieren, dessen Dokumentation Sie [hier](/guide-customizations-and-configuration.html#show-live-right-away) finden.

### Erlauben anonymer Kommentare (keine E‑Mail erforderlich)

Standardmäßig verlangt FastComments, dass der Benutzer beim Kommentieren eine E‑Mail-Adresse angibt.

Dies kann deaktiviert werden, die Anleitung finden Sie [hier](/guide-customizations-and-configuration.html#allow-anon).

Um Besucher auch von der Wahl eines Benutzernamens zu entlasten, kann FastComments [für jeden Besucher einen generieren](/guide-customizations-and-configuration.html#auto-generate-username).

### Benutzerdefiniertes Styling

Viele unserer Kunden wenden ihr eigenes Styling auf das Kommentar-Widget an. Die Dokumentation finden Sie [hier](/guide-customizations-and-configuration.html#custom-css).

### Die gleichen Kommentare auf mehreren Domains anzeigen

Die gleichen Kommentare auf mehreren Websites anzuzeigen, wird von FastComments standardmäßig unterstützt. Siehe unsere [Dokumentation zu diesem Thema](/guide-multiple-sites.html#sharing-comments-across-domains).

### Ändern der aktuellen Seite

FastComments unterstützt SPAs und komplexe Anwendungen. Das Ändern der aktuellen Seite ist einfach und wird [hier](/guide-customizations-and-configuration.html#switching-comment-threads) behandelt.
