### 立即顯示即時評論

評論小工具預設為即時模式，但即時評論會顯示在「顯示 N 條新評論」按鈕下，以防止頁面內容移動。

在某些情況下，仍希望立即顯示新評論，而不必點擊按鈕。

此時，您需要啟用 `showLiveRightAway` 旗標，相關文件可在[此處](/guide-customizations-and-configuration.html#show-live-right-away)取得。

### 允許匿名評論（不需要電子郵件）

預設情況下，FastComments 要求使用者在評論時留下電子郵件。

此設定可被停用，相關說明請見[此處](/guide-customizations-and-configuration.html#allow-anon)。

若也想免除訪客自行選擇使用者名稱，FastComments 可以為每位訪客[自動產生使用者名稱](/guide-customizations-and-configuration.html#auto-generate-username)。

### 自訂樣式

許多客戶會為評論小工具套用自訂樣式。相關文件可在[此處](/guide-customizations-and-configuration.html#custom-css)取得。

### 在多個網域上顯示相同的評論

在多個網站上顯示相同的評論是 FastComments 內建支援的功能。請參閱[此處](/guide-multiple-sites.html#sharing-comments-across-domains)的文件說明。

### 變更當前頁面

FastComments 支援 SPA 與複雜的應用程式。變更當前頁面相當簡單，相關說明請見[此處](/guide-customizations-and-configuration.html#switching-comment-threads)。
