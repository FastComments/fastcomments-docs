### Showing Live Comments Right Away

Το widget σχολίων είναι ζωντανό από προεπιλογή, ωστόσο τα ζωντανά σχόλια εμφανίζονται κάτω από ένα κουμπί «Show N New Comments» για να αποτραπεί η μετακίνηση του περιεχομένου της σελίδας.

Σε ορισμένες περιπτώσεις, εξακολουθεί να είναι επιθυμητό να εμφανίζονται τα νέα σχόλια άμεσα, χωρίς να χρειάζεται να κάνετε κλικ σε κουμπί.

Σε αυτήν την περίπτωση, θέλετε να ενεργοποιήσετε τη σημαία `showLiveRightAway`, για την οποία μπορείτε να βρείτε τεκμηρίωση [εδώ](/guide-customizations-and-configuration.html#show-live-right-away).

### Allowing Anonymous Commenting (Not Requiring Email)

Από προεπιλογή, το FastComments απαιτεί από τον χρήστη να αφήσει ένα email όταν σχολιάζει.

Αυτό μπορεί να απενεργοποιηθεί, [οι οδηγίες είναι εδώ](/guide-customizations-and-configuration.html#allow-anon).

### Custom Styling

Πολλοί από τους πελάτες μας εφαρμόζουν το δικό τους στυλ στο widget σχολίων. Μπορείτε να βρείτε την τεκμηρίωση [εδώ](/guide-customizations-and-configuration.html#custom-css).

### Showing The Same Comments on Multiple Domains

Η εμφάνιση των ίδιων σχολίων σε πολλαπλές ιστοσελίδες είναι κάτι που το FastComments υποστηρίζει έτοιμο. Δείτε την [τεκμηρίωση για αυτό το θέμα](/guide-multiple-sites.html#sharing-comments-across-domains).

### Changing The Current Page

Το FastComments υποστηρίζει SPAs και σύνθετες εφαρμογές. Η αλλαγή της τρέχουσας σελίδας είναι εύκολη και καλύπτεται [εδώ](/guide-customizations-and-configuration.html#switching-comment-threads).
