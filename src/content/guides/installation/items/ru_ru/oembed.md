Хотите добавить комментарии на свои страницы Notion, Google Sites или Nimbus Notes? Мы вам поможем.

### Notion

Чтобы добавить комментарии к документам Notion, [посмотрите обучающее видео здесь](https://blog.fastcomments.com/(10-05-2021)-adding-commenting-to-notion-pages.html).

### Google Sites

Google Sites также поддерживается, и процесс аналогичен.

1. [Создайте беседу для встраивания.](https://fastcomments.com/create)
2. При редактировании вашего сайта Google перейдите в `Insert` -> `Embed`. Выберите `By URL`.
3. Вставьте URL из шага 1.
4. Нажмите `Insert`. Готово!

### Nimbus Note

Добавление комментариев в реальном времени в Nimbus Note также поддерживается, и процесс аналогичен Notion.

1. [Создайте беседу для встраивания.](https://fastcomments.com/create)
2. При редактировании заметки добавьте блок встраивания.
3. Используйте URL из шага 1 в качестве URL для встраивания.
4. Готово!
