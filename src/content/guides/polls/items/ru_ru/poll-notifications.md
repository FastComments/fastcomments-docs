Автор опроса получает уведомления по мере поступления ответов:

- **В приложении**: уведомление под значком колокольчика, когда в опросе появляется новый ответ. Когда многие люди голосуют, они группируются в одно уведомление.
- **Электронная почта**: ежедневное письмо автору опроса, когда их опрос получает новые ответы в течение дня.

Только первый голос человека считается новым ответом. Изменение голоса не отправляет уведомление, и авторы не получают уведомления о своих собственных голосах.

Уведомления учитывают конфиденциальность опроса. Для анонимных опросов они показывают только количество новых ответов. Имена голосующих включаются для публичных опросов и для опросов, видимых администраторам, когда автор является администратором или модератором.

Электронное письмо содержит ссылку для отключения уведомлений для этого опроса. Его содержание можно изменить с помощью шаблона **Poll Response Notification**, см. [Шаблоны электронной почты](/guide-email-templates.html).
