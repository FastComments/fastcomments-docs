Για να ψηφίσετε, κάντε κλικ σε μια επιλογή. Τα αποτελέσματα εμφανίζονται αμέσως, και η δημοσκόπηση δείχνει πόσες απαντήσεις έχει μέχρι τώρα.

Κάθε άτομο λαμβάνει μία ψήφο ανά δημοσκόπηση. Όσο η δημοσκόπηση είναι ανοιχτή, ένας ψηφοφόρος μπορεί να κάνει κλικ στο **Αλλαγή ψήφου** για να επιλέξει διαφορετική επιλογή.

Τα αποτελέσματα ενημερώνονται ζωντανά. Όταν οποιοσδήποτε στη σελίδα ψηφίσει, οι μετρήσεις και οι γραμμές ενημερώνονται για όλους που βλέπουν τη δημοσκόπηση, χωρίς ανανέωση της σελίδας.

Εκτός εάν η δημοσκόπηση απαιτεί ψήφο για να δει κανείς τα αποτελέσματα, οι θεατές μπορούν να κάνουν κλικ στο **Εμφάνιση αποτελεσμάτων** για να δουν τις τρέχουσες μετρήσεις πριν ψηφίσουν.
