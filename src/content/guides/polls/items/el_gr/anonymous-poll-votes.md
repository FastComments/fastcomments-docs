Από προεπιλογή, μόνο οι συνδεδεμένοι χρήστες μπορούν να ψηφίσουν σε δημοσκοπήσεις. Οι επισκέπτες που δεν είναι συνδεδεμένοι βλέπουν μια προτροπή **Συνδεθείτε για να ψηφίσετε** αντί για τα κουμπιά ψήφου.

Επιλέξτε **Allow Anonymous Poll Votes** για να επιτρέψετε σε οποιονδήποτε να ψηφίσει χωρίς λογαριασμό.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.enable-polls']; selector = '.allow-anonymous-poll-votes'; alt='Η επιλογή Επιτρέψτε ανώνυμες ψήφους σε δημοσκοπήσεις κάτω από το Enable Polls'; title='Επιτρέψτε ανώνυμες ψήφους σε δημοσκοπήσεις' app-screenshot-end]

Για να διατηρηθεί η δικαιοσύνη των αποτελεσμάτων, οι ανώνυμες ψήφοι σε μια δημοσκόπηση περιορίζονται σε τρεις ανά διεύθυνση IP ανά ώρα.

Αυτό είναι ξεχωριστό από το [Allow Anonymous Voting](/guide-customizations-and-configuration.html#allow-anon-votes), το οποίο ελέγχει τις ψήφους θετικό/αρνητικό σε σχόλια.
