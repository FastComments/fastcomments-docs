Sobald Umfragen aktiviert sind, steuert die Einstellung **Who Can Create Polls** darüber, wer den Umfrage‑Button in der Kommentar‑Symbolleiste sieht:

- **Admins/Moderators Only** (die Standardeinstellung): Nur die Administratoren und Moderatoren Ihrer Website können einer Kommentar eine Umfrage hinzufügen.
- **Everyone**: Jeder Kommentator kann seiner Kommentar eine Umfrage hinzufügen.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.enable-polls']; selector = '.poll-creation'; alt='Das Dropdown „Who Can Create Polls“ ist auf Admins/Moderators Only eingestellt'; title='Wer kann Umfragen erstellen' app-screenshot-end]

Diese Einstellung steuert nur, wer Umfragen erstellen kann. Wer abstimmen darf, wird separat festgelegt; siehe den nächsten Abschnitt.
