投票を記録するか、既存の投票を別の選択肢に移動します。投票者は各投票につき最大1票しか持てないため、同じ投票者に対して再度呼び出すと、投票が追加されるのではなく、既存の投票が移動されます。

この操作はサイトの投票設定に従います。投票がログインユーザーのみに制限されている場合、anonUserId だけの投票は拒否され、匿名投票は投票ごとに IP アドレス単位でレート制限されます。
