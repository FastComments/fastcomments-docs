1つの投票の集計の背後にある個別の投票を、古い順に表示します。

投票はコメントに属するため、投票は常に1つの投票(ポール)ずつ読み取ります - commentId が必須です。これにより、すべてのクエリがコレクションが既に持っているインデックスを使用します。

投票のプライバシー設定に従います: 匿名投票の投票内容は読み取ることができません(poll-anonymous)。ここでも、id による取得でも同様です。
