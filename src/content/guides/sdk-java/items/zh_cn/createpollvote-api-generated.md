在投票中记录一次投票，或将现有投票移动到不同的选项。每位投票者在每个投票中最多只有一票，因此对同一投票者再次调用此接口会移动其投票，而不是新增一票。

此操作遵循站点的投票设置：如果投票设置为仅限已登录用户，则仅使用 anonUserId 的投票将被拒绝，并且匿名投票会按 IP 按投票进行速率限制。
