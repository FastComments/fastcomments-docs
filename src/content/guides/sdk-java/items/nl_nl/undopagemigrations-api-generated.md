Queues een batch‑taak die elke migratie van één *migrate‑pages*‑taak ongedaan maakt, beginnend met de nieuwste. Beschikbaar gedurende 90 dagen.  
Records die zijn gewijzigd sinds de migratie blijven onaangeroerd, zodat een latere bewerking nooit wordt overschreven.  
Poll **GET /api/v1/batch-jobs/{batchJobId}** voor de aantallen hersteld/overgeslagen.
