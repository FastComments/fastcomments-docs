Identifies the credential in use: the tenant it belongs to and, for OAuth tokens, the user who authorized it.  
Ідентифікує використані облікові дані: орендар, до якого вони належать, та, для токенів OAuth, користувача, який їх авторизував.  

Integrations use this to test a connection and label it.  
Інтеграції використовують це для тестування з’єднання та його позначення.
