Прикріпіть опитування до коментаря або встановіть повний стан опитування, яке вже існує.

Варіанти зіставляються за id: варіант, надісланий з id існуючого варіанту, зберігає свої голоси (і отримує нову мітку та позицію), варіант без id додається, а наявні варіанти, відсутні у списку, видаляються разом із поданими за них голосами.

Якщо не залишити жодного існуючого id варіанта в опитуванні, яке має голоси, усі вони будуть видалені, тому для цього потрібен replaceVotes=true.
