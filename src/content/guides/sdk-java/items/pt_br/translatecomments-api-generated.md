Translada os comentários fornecidos para o idioma do widget. Disponível apenas quando a regra de personalização do widget correspondente tem a Tradução de Comentários definida como Automática ou Manual.

## Parâmetros

| Nome | Tipo | Localização | Obrigatório | Descrição |
|------|------|-------------|-------------|-----------|
| tenantId | string | path | Sim |  |
| urlId | string | query | Sim |  |
| sso | string | query | Não |  |
| locale | string | query | Não |  |

## Resposta

Retorna: [`CommentTranslationsResponse`](https://github.com/FastComments/fastcomments-java/blob/main/client/src/main/java/com/fastcomments/model/CommentTranslationsResponse.java)
