एक urlId या डोमेन से दूसरे में कमेंट्स, पेज और संबंधित रिकॉर्ड्स को स्थानांतरित करने वाली बैच जॉब को कतार (queue) में रखता है।
"urlId" माइग्रेशन केवल सटीक urlId से मेल खाते हैं। "domain" माइग्रेशन हर urlId और url के भीतर मान को खोजने/बदलने (find/replace) का काम करते हैं।
GET /api/v1/batch-jobs/{batchJobId} को पोल करें: जैसे ही यह पूरा होता है, इसमें प्रति-माइग्रेशन परिणाम और एक undoId होता है।
