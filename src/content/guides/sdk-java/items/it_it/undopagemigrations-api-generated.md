Accoda un lavoro batch che annulla ogni migrazione da un lavoro migrate‑pages, dal più recente al più vecchio. Disponibile per 90 giorni.  
I record modificati dopo la migrazione vengono lasciati invariati, così una modifica successiva non viene mai sovrascritta.  
Esegui il polling **GET** `/api/v1/batch-jobs/{batchJobId}` per ottenere i conteggi di ripristinati/ignorati.
