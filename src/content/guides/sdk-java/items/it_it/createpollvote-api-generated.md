Registra un voto su un sondaggio, o sposta uno esistente su un'opzione diversa. Un elettore può avere al massimo un voto per sondaggio, quindi chiamare nuovamente questo endpoint per lo stesso elettore sposta il suo voto invece di aggiungerne uno.

Questo rispetta le impostazioni del sondaggio del sito: se il voto è impostato solo per utenti autenticati, un voto con solo anonUserId viene rifiutato, e i voti anonimi sono limitati per IP per sondaggio.
