單一投票背後的個別票數記錄，由舊到新排列。

投票屬於某則留言，因此票數一次只能讀取一個投票 - commentId 為必填。這可確保每個查詢都使用集合既有的索引。

遵守投票的隱私設定：匿名投票的票數無法被讀取（poll-anonymous），無論是透過此端點或依 id 查詢。
