Dołącz ankietę do komentarza lub ustaw pełny stan ankiety, którą już posiada.

Opcje są dopasowywane według identyfikatora: opcja wysłana z identyfikatorem istniejącej opcji zachowuje swoje głosy (i przyjmuje nową etykietę oraz pozycję), opcja wysłana bez identyfikatora jest dodawana, a istniejące opcje pominięte na liście są usuwane wraz z oddanymi na nie głosami.

Brak istniejących identyfikatorów opcji w ankiecie, która ma głosy, usuwa wszystkie z nich, dlatego należy użyć replaceVotes=true.

## Parametry

| Nazwa | Typ | Lokalizacja | Wymagane | Opis |
|------|------|-------------|----------|------|
| tenantId | string | query | Tak |  |
| commentId | string | path | Tak |  |
| replaceVotes | boolean | query | Nie |  |
