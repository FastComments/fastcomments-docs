Adjunte una encuesta a un comentario, o establezca el estado completo de la encuesta que ya tiene.

Las opciones se emparejan por id: una opción enviada con el id de una opción existente conserva sus votos (y toma la nueva etiqueta y posición), una opción enviada sin id se agrega, y las opciones existentes que se omiten de la lista se eliminan junto con los votos emitidos sobre ellas.

Mantener ningún id de opción existente en una encuesta que tiene votos elimina todas ellas, por lo que se necesita replaceVotes=true.

| replaceVotes | boolean | query | No |  |
