### डार्क मोड सपोर्ट

### डायनामिक डार्क मोड

यदि आपकी साइट का डार्क मोड body एलिमेंट में `.dark` क्लास जोड़कर नियंत्रित होता है, तो Collab Chat UI इसे बिना री-इनिशियलाइज़ेशन के स्वतः ही सम्मानित करेगा। विजेट की स्टाइल्स इस क्लास की उपस्थिति के प्रति प्रतिक्रिया देने के लिए डिज़ाइन की गई हैं।

[inline-code-attrs-start title = 'डार्क मोड CSS उदाहरण'; type = 'css'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
/* आपकी डार्क मोड CSS */
body.dark {
    background: #1a1a1a;
    color: #ffffff;
}
[inline-code-end]

### CSS के साथ कस्टम स्टाइलिंग

आप CSS का उपयोग करके हाइलाइट्स, चैट विंडोज़ और अन्य एलिमेंट्स की उपस्थिति को कस्टमाइज़ कर सकते हैं। विजेट विशिष्ट क्लासेस जोड़ता है जिन्हें आप अपनी स्टाइलशीट में टारगेट कर सकते हैं।

टेक्स्ट हाइलाइट्स FastComments कमेंट बबल स्टाइलिंग सिस्टम का उपयोग करते हैं, इसलिए स्टैंडर्ड कमेंटिंग विजेट पर आपके द्वारा लागू की गई कोई भी कस्टमाइज़ेशन Collab Chat को भी प्रभावित करेगी।

### टॉप बार कस्टमाइज़ेशन

टॉप बार ऑनलाइन उपयोगकर्ताओं की संख्या और चर्चाओं की संख्या दिखाता है। आप `topBarTarget` के रूप में एक कस्टम एलिमेंट प्रदान करके इसकी स्थिति को कस्टमाइज़ कर सकते हैं:

[inline-code-attrs-start title = 'कस्टम टॉप बार स्थान'; type = 'javascript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
FastCommentsCollabChat(element, {
    tenantId: 'demo',
    topBarTarget: document.getElementById('my-custom-header')
});
[inline-code-end]

या इसे `null` सेट करके पूरी तरह अक्षम करें:

[inline-code-attrs-start title = 'टॉप बार अक्षम करें'; type = 'javascript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
FastCommentsCollabChat(element, {
    tenantId: 'demo',
    topBarTarget: null
});
[inline-code-end]

### मोबाइल व्यवहार

768px से कम चौड़ाई वाली स्क्रीन पर, Collab Chat स्वतः ही मोबाइल-अनुकूलित लेआउट पर स्विच हो जाता है। चैट विंडोज़ टेक्स्ट के बगल में फ्लोटिंग होने के बजाय फुलस्क्रीन दिखाई देती हैं, और अधिक तुरंत इंटरैक्शन के लिए सिलेक्शन डिले हटा दिया जाता है।

यह व्यवहार इन-बिल्ट है और इसके लिए किसी कॉन्फ़िगरेशन की आवश्यकता नहीं है। विजेट स्क्रीन का आकार स्वतः पहचानता है और तदनुसार समायोजित करता है।

### चैट विंडो की उपस्थिति

चैट विंडोज़ डेस्कटॉप पर 410px चौड़ी होती हैं और हाइलाइट किए गए टेक्स्ट की ओर इशारा करने वाला 16px का तीर होता है। विंडोज़ उपलब्ध व्यूपोर्ट स्पेस के आधार पर स्वतः स्थिति निर्धारित करती हैं, जिसमें `to-right`, `to-left`, `to-top`, और `to-bottom` जैसी पोज़िशनिंग क्लासेस का उपयोग होता है।

आप इन विंडोज़ के रंग, फ़ॉन्ट, स्पेसिंग या अन्य विज़ुअल गुणों को समायोजित करने के लिए कस्टम CSS जोड़ सकते हैं। चैट विंडोज़ स्टैंडर्ड FastComments विजेट के समान कंपोनेंट संरचना का उपयोग करती हैं, इसलिए वे आपके द्वारा लागू की गई किसी भी ग्लोबल कस्टमाइज़ेशन को विरासत में लेती हैं।

### लोकलाइज़ेशन

Collab Chat स्टैंडर्ड FastComments विजेट के समान सभी लोकलाइज़ेशन विकल्पों का समर्थन करता है। विभिन्न भाषाओं में UI टेक्स्ट दिखाने के लिए `locale` विकल्प सेट करें:

[inline-code-attrs-start title = 'लोकेल सेट करें'; type = 'javascript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
FastCommentsCollabChat(element, {
    tenantId: 'demo',
    locale: 'es'  // स्पेनिश
});
[inline-code-end]

FastComments दर्जनों भाषाओं का समर्थन करता है। लोकेल सेटिंग प्रॉम्प्ट्स, बटन और प्लेसहोल्डर टेक्स्ट सहित सभी UI टेक्स्ट को प्रभावित करती है।

### विरासत में मिले कस्टमाइज़ेशन विकल्प

चूंकि Collab Chat स्टैंडर्ड कमेंटिंग विजेट का विस्तार करता है, यह बेस विजेट से सभी कस्टमाइज़ेशन विकल्प विरासत में लेता है। इसमें कस्टम CSS क्लासेस, कस्टम अनुवाद, अवतार कस्टमाइज़ेशन, दिनांक फ़ॉर्मेटिंग और बहुत कुछ शामिल है।

उपलब्ध कस्टमाइज़ेशन विकल्पों की पूरी सूची के लिए मुख्य FastComments कस्टमाइज़ेशन दस्तावेज़ीकरण देखें।

### कस्टम फ़ॉन्ट्स के साथ कार्य करना

यदि आपकी साइट कस्टम फ़ॉन्ट्स का उपयोग करती है, तो Collab Chat UI आपके पेज की CSS से उन फ़ॉन्ट्स को विरासत में लेगा। यदि आप चाहते हैं कि फ्लोटिंग चैट विंडो वही फ़ॉन्ट्स उपयोग करे, तो आपको एक विजेट कस्टमाइज़ेशन रूल बनाना पड़ सकता है और उस रूल की कस्टम CSS में फ़ॉन्ट्स को `@import` करना पड़ सकता है।
