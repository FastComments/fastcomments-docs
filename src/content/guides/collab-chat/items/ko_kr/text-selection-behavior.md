### 텍스트 선택 작동 방식

사용자가 Collab Chat 컨테이너 내에서 텍스트를 선택하면, 위젯이 해당 선택을 캡처하여 토론을 시작할 수 있도록 합니다. 선택 범위는 단일 단어만큼 작을 수도 있고, 서로 다른 요소에 걸친 여러 문단만큼 클 수도 있습니다.

### 선택 지연

데스크톱 기기에서는 사용자가 텍스트를 선택한 후 토론 프롬프트가 나타나기까지 3.5초의 지연이 있습니다. 이는 사용자가 단순히 복사하거나 읽기 위해 텍스트를 강조할 때 UI가 깜빡이는 것을 방지합니다. 모바일 기기에서는 터치 스크린에서 텍스트 선택이 더 신중하게 이루어지기 때문에 프롬프트가 즉시 나타납니다.


### 고유 대화 ID

각 대화에는 페이지 URL, DOM 요소 경로, 직렬화된 텍스트 범위를 결합한 고유한 `urlId`가 부여됩니다. 이를 통해 각 텍스트 선택이 나중에 다시 찾을 수 있는 별개의 대화를 생성합니다.

설정에서 사용자 지정 `urlId`를 제공하면, 요소 경로 및 텍스트 범위와 결합되어 최종 식별자가 생성됩니다.

### 시각적 하이라이트

특정 텍스트 선택에 대한 토론이 존재하는 경우, 해당 텍스트에 시각적 하이라이트가 표시됩니다. 하이라이트는 배경색을 사용하여 구현되며, 마우스를 올리거나 관련 채팅 창이 열려 있을 때 나타납니다.

하이라이팅 시스템은 선택된 텍스트를 스타일을 지정할 수 있는 특수 요소로 감싸는 방식으로 작동합니다. 이 접근 방식은 기본 HTML 구조가 복잡하더라도 하이라이트가 정확하게 유지되도록 보장합니다.

### 채팅 창 위치 지정

사용자가 하이라이트를 클릭하거나 새 주석을 생성하면, 선택된 텍스트 근처에 채팅 창이 나타납니다. 위젯은 사용 가능한 뷰포트 공간을 기반으로 이 창의 최적 위치를 자동으로 계산합니다.

위치 지정 시스템은 `to-right`, `to-left`, `to-top`, `to-bottom`과 같은 CSS 클래스를 사용하여 채팅 창이 하이라이트에서 어느 방향으로 확장되어야 하는지 나타냅니다. 모바일 기기(너비 768px 미만 화면)에서는 사용성을 위해 채팅 창이 항상 전체 화면으로 나타납니다.

### 채팅 창 크기

채팅 창은 데스크톱에서 너비가 410px이며, 20px 간격과 강조된 텍스트를 가리키는 16px 시각 화살표가 있습니다. 이러한 크기는 일관된 동작을 보장하기 위해 고정되어 있지만, CSS로 모양을 사용자 지정할 수 있습니다.

### 요소 간 선택

사용자는 여러 HTML 요소에 걸친 텍스트를 선택할 수 있습니다. 예를 들어 한 문단의 중간부터 다른 문단의 시작 부분까지 강조하는 경우입니다. 범위 직렬화 시스템이 이를 올바르게 처리하며, 요소 경계를 넘어서도 선택된 모든 텍스트를 하이라이트합니다.

### 브라우저 호환성

텍스트 선택 시스템은 모든 최신 브라우저에서 지원되는 표준 `window.getSelection()` API를 사용합니다. 구버전 Internet Explorer의 경우 호환성을 위해 `document.selection`으로 대체(fallback)합니다.

### 선택 영역 유지

텍스트 선택에 대한 대화가 생성되면, 페이지가 다시 로드되더라도 해당 주석은 유지됩니다. 직렬화된 범위와 DOM 경로를 통해 위젯은 사용자가 페이지로 돌아왔을 때 정확히 동일한 위치에 하이라이트를 복원할 수 있습니다.

이는 페이지 콘텐츠가 안정적으로 유지되는 한 신뢰할 수 있게 작동합니다. 텍스트 콘텐츠를 변경하거나 HTML 구조를 재구성하면 기존 주석이 텍스트와 더 이상 올바르게 정렬되지 않을 수 있습니다. 따라서 활성 주석이 있는 페이지에서는 주요 콘텐츠 변경을 피하거나, 콘텐츠 변경이 필요한 경우 주석 마이그레이션을 고려하는 것이 좋습니다.
