### Ενημερώσεις σε Πραγματικό Χρόνο

Το Image Chat χρησιμοποιεί συνδέσεις WebSocket για να συγχρονίζει όλες τις συνομιλίες σε πραγματικό χρόνο μεταξύ όλων των συνδεδεμένων χρηστών. Όταν κάποιος δημιουργεί ένα νέο marker, προσθέτει ένα σχόλιο ή διαγράφει μια συζήτηση, όλοι οι άλλοι χρήστες που βλέπουν την ίδια εικόνα βλέπουν την ενημέρωση αμέσως, χωρίς ανανέωση.

### Πώς Λειτουργεί ο Συγχρονισμός WebSocket

Όταν αρχικοποιείτε το Image Chat, το widget δημιουργεί μια σύνδεση WebSocket με τους διακομιστές FastComments. Αυτή η σύνδεση παραμένει ανοιχτή για όλη τη διάρκεια της συνεδρίας του χρήστη και ακούει για ενημερώσεις που σχετίζονται με την τρέχουσα εικόνα.

Το σύστημα WebSocket χρησιμοποιεί τρεις τύπους μηνυμάτων μετάδοσης για το Image Chat. Το γεγονός `new-image-chat` ενεργοποιείται όταν κάποιος δημιουργεί ένα νέο marker στην εικόνα. Το γεγονός `image-chat-updated` ενεργοποιείται όταν κάποιος ενημερώνει μια υπάρχουσα συνομιλία. Το γεγονός `deleted-image-chat` ενεργοποιείται όταν κάποιος διαγράφει ένα marker.

### Σύστημα Broadcast ID

Για να αποφευχθούν εφέ ηχούς, όπου οι χρήστες βλέπουν τις δικές τους ενέργειες να μεταδίδονται πίσω σε αυτούς, κάθε ενημέρωση περιλαμβάνει ένα μοναδικό `broadcastId`. Όταν ένας χρήστης δημιουργεί ή ενημερώνει ένα marker, ο client του δημιουργεί ένα UUID για αυτή τη λειτουργία. Όταν το WebSocket μεταδίδει την ενημέρωση πίσω σε όλους τους clients, ο client που προέρχεται η ενημέρωση την αγνοεί επειδή ταιριάζει με το δικό του `broadcastId`.

Αυτό εξασφαλίζει ομαλή αλληλεπίδραση, όπου οι χρήστες βλέπουν τις αλλαγές τους αμέσως στο UI χωρίς να περιμένουν τη μετάβαση μέσω του διακομιστή, ενώ ταυτόχρονα εξασφαλίζεται ότι όλοι οι άλλοι χρήστες λαμβάνουν την ενημέρωση.

### Ανθεκτικότητα Σύνδεσης

Εάν η σύνδεση WebSocket πέσει λόγω προβλημάτων δικτύου ή συντήρησης διακομιστή, το widget προσπαθεί αυτόματα να επανασυνδεθεί. Κατά τη διάρκεια της περιόδου επανασύνδεσης, οι χρήστες μπορούν ακόμα να αλληλεπιδρούν με υπάρχοντα markers, αλλά δεν θα βλέπουν ενημερώσεις σε πραγματικό χρόνο από άλλους χρήστες μέχρι να επανιδρυθεί η σύνδεση.

Μόλις επανασυνδεθεί, το widget επανασυγχρονίζεται για να διασφαλίσει ότι δεν χάθηκαν ενημερώσεις. Αυτό συμβαίνει διαφανώς, χωρίς να απαιτείται παρέμβαση του χρήστη.

### Ζητήματα Εύρους Ζώνης

Τα μηνύματα WebSocket είναι ελαφριά και περιέχουν μόνο τις απαραίτητες πληροφορίες για τον συγχρονισμό της κατάστασης. Η δημιουργία ενός νέου marker χρησιμοποιεί συνήθως λιγότερο από 1KB εύρους ζώνης. Το σύστημα περιλαμβάνει επίσης έξυπνη ομαδοποίηση για τη μείωση της συχνότητας μηνυμάτων κατά τις περιόδους υψηλής δραστηριότητας.

Οι μετρήσεις χρήσης σας στον πίνακα ελέγχου FastComments παρακολουθούν το `pubSubMessageCount` και το `pubSubBandwidth`, ώστε να μπορείτε να παρακολουθείτε τη δραστηριότητα συγχρονισμού σε πραγματικό χρόνο στις ιστοσελίδες σας.

### Συγχρονισμός μεταξύ Καρτελών

Εάν ένας χρήστης έχει ανοιχτή την ίδια σελίδα σε πολλές καρτέλες του browser, οι ενημερώσεις σε μία καρτέλα εμφανίζονται αμέσως στις άλλες καρτέλες. Αυτό λειτουργεί μέσω του ίδιου μηχανισμού συγχρονισμού WebSocket και δεν απαιτεί πρόσθετη διαμόρφωση.

Οι χρήστες μπορούν να έχουν την ιστοσελίδα σας ανοιχτή σε πολλές συσκευές ταυτόχρονα, και όλες θα παραμένουν συγχρονισμένες. Ένα marker που δημιουργείται σε έναν επιτραπέζιο υπολογιστή εμφανίζεται αμέσως στο tablet του χρήστη, εάν και οι δύο συσκευές βλέπουν την ίδια εικόνα.

### Ασφάλεια

Τα μηνύματα WebSocket μεταδίδονται μέσω ασφαλών συνδέσεων (WSS) και περιλαμβάνουν επικύρωση tenant για να διασφαλιστεί ότι οι χρήστες λαμβάνουν ενημερώσεις μόνο για συνομιλίες που είναι εξουσιοδοτημένοι να βλέπουν. Ο διακομιστής επικυρώνει όλες τις λειτουργίες πριν τις μεταδώσει, για να αποτραπεί μη εξουσιοδοτημένη πρόσβαση ή χειραγώγηση.

### Συμπεριφορά Εκτός Σύνδεσης

Όταν οι χρήστες είναι εντελώς εκτός σύνδεσης, μπορούν ακόμα να βλέπουν υπάρχοντα markers, αλλά δεν μπορούν να δημιουργήσουν νέα ή να δουν ενημερώσεις από άλλους. Το widget ανιχνεύει την κατάσταση εκτός σύνδεσης και εμφανίζει κατάλληλο μήνυμα.

Εάν ένας χρήστης προσπαθήσει να δημιουργήσει ένα marker ενώ είναι εκτός σύνδεσης και στη συνέχεια επανέλθει σε σύνδεση, η λειτουργία θα αποτύχει αντί να μπει σε ουρά, εξασφαλίζοντας τη συνέπεια των δεδομένων. Οι χρήστες πρέπει να επαναλάβουν τη λειτουργία μόλις αποκατασταθεί η σύνδεσή τους.

### Επίδραση στην Απόδοση

Η σύνδεση WebSocket έχει ελάχιστη επίδραση στην απόδοση. Η σύνδεση παραμένει αδρανής όταν δεν συμβαίνουν ενημερώσεις και επεξεργάζεται μηνύματα μόνο όταν υπάρχει δραστηριότητα. Σε μια τυπική εικόνα με μέτρια δραστηριότητα markers, το WebSocket χρησιμοποιεί λιγότερο CPU από την ίδια την απεικόνιση της εικόνας.

Για σελίδες με εκατοντάδες ταυτόχρονους χρήστες και υψηλή δραστηριότητα δημιουργίας markers, το σύστημα κλιμακώνεται οριζόντια για να διατηρήσει την απόδοση χωρίς να επηρεάζει τις μεμονωμένες συνδέσεις των clients.

### Συνεργατικές Περιπτώσεις Χρήσης

Ο συγχρονισμός σε πραγματικό χρόνο καθιστά το Image Chat ιδιαίτερα ισχυρό για συνεργατικές ροές εργασίας. Οι ομάδες σχεδίασης μπορούν να εξετάσουν μαζί mockups, με όλους να βλέπουν την τοποθέτηση markers σε πραγματικό χρόνο. Οι ομάδες εξυπηρέτησης πελατών μπορούν να σχολιάσουν συνεργατικά screenshots για τον εντοπισμό προβλημάτων. Εκπαιδευτικές ομάδες μπορούν να συζητήσουν διαγράμματα, με όλους τους συμμετέχοντες να βλέπουν τα markers του ενός του άλλου καθώς δημιουργούνται.

Η άμεση ανατροφοδότηση δημιουργεί μια πιο ελκυστική και παραγωγική συνεργατική εμπειρία σε σύγκριση με τα παραδοσιακά συστήματα σχολίων, όπου οι χρήστες πρέπει να κάνουν ανανέωση για να δουν τις ενημερώσεις.
