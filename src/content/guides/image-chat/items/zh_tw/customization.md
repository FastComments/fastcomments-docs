### 深色模式支援

Image Chat 內建深色模式支援。當您在設定中設定 `hasDarkBackground: true` 時,聊天視窗和 UI 元素會自動調整以適應深色背景。

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    hasDarkBackground: true
});
```

深色模式樣式適用於聊天視窗、標記方塊以及所有互動元素。如果您的網站有深色模式切換功能,您可以在模式變更時重新初始化小工具,或使用下方描述的 body class 方法。

### 動態深色模式

如果您的網站深色模式是透過在 body 元素上加入 `.dark` class 來控制,Image Chat UI 會自動遵循此設定,無需重新初始化。小工具的樣式設計為會回應此 class 的存在。

```css
/* 您的深色模式 CSS */
body.dark {
    background: #1a1a1a;
    color: #ffffff;
}
```

### 使用 CSS 自訂樣式

您可以使用 CSS 自訂標記、聊天視窗和其他元素的外觀。小工具會加入特定的 class,您可以在樣式表中針對這些 class 進行設定。

聊天方塊和視窗使用 FastComments 的留言氣泡樣式系統,因此您對標準留言小工具所做的任何自訂也會影響 Image Chat。

### 聊天方塊尺寸

`chatSquarePercentage` 選項控制可點擊標記的大小。預設值為圖片寬度的 5%:

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    chatSquarePercentage: 7  // 更大、更明顯的方塊
});
```

較小的數值會產生更融入圖片的細緻標記。較大的數值會讓標記更醒目且更容易點擊,尤其是在行動裝置上或為了無障礙用途。

### 行動裝置行為

在寬度低於 768px 的螢幕上,Image Chat 會自動切換為針對行動裝置最佳化的版面配置。聊天視窗會以全螢幕顯示,而不是浮動在標記旁邊,在小螢幕上提供更好的使用體驗。

標記會保持在圖片上其響應式位置並維持可見。使用者可以點擊任何標記來開啟全螢幕聊天介面。此行為是內建的,不需要任何設定。

### 聊天視窗外觀

聊天視窗在桌面上寬度為 300px,並帶有指向標記的 16px 箭頭。視窗會根據可用的視窗空間自動定位,使用 `to-right`、`to-left`、`to-top` 和 `to-bottom` 等定位 class。

您可以加入自訂 CSS 來調整這些視窗的顏色、字型、間距或其他視覺屬性。聊天視窗使用與標準 FastComments 小工具相同的元件結構,因此會繼承您已套用的任何全域自訂設定。

### 延遲初始化

聊天視窗會在桌面使用者滑鼠懸停時初始化,或在建立時立即初始化。這透過僅在使用者實際與標記互動時才渲染聊天介面,來減少初始載入的負擔。

延遲初始化是透明進行的。使用者不會察覺任何延遲,但如果圖片上有許多標記,瀏覽器就不需要渲染數十個隱藏的聊天視窗。

### 本地化

Image Chat 支援與標準 FastComments 小工具相同的所有本地化選項。設定 `locale` 選項即可顯示不同語言的 UI 文字:

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    locale: 'fr'  // 法文
});
```

FastComments 支援數十種語言。locale 設定會影響所有 UI 文字,包括提示訊息、按鈕和佔位文字。

### 繼承的自訂選項

由於 Image Chat 擴充了標準留言小工具,因此它繼承了基礎小工具的所有自訂選項。這包括自訂 CSS class、自訂翻譯、頭像自訂、日期格式設定等等。

請參閱 FastComments 主要自訂文件,以取得可用自訂選項的完整清單。

### 使用自訂字型

如果您的網站使用自訂字型,Image Chat UI 會從您頁面的 CSS 繼承這些字型。聊天視窗在您頁面的 DOM 內渲染,並遵循您現有的字型排版設定。

為獲得最佳效果,請確保在初始化 Image Chat 之前已載入您的自訂字型,或接受在字型載入期間可能會出現短暫的無樣式文字閃爍。

### 標記視覺設計

方形標記具有細緻的視覺設計,使其引人注意而不會干擾圖片。如果您想要不同的視覺效果,可以使用 CSS 自訂其外觀。

標記包含懸停狀態,當使用者將滑鼠移到其上時會提供回饋。在觸控裝置上,點擊互動會透過開啟聊天視窗提供即時回饋。
