### डार्क मोड सपोर्ट

Image Chat में बिल्ट-इन डार्क मोड सपोर्ट शामिल है। जब आप अपनी कॉन्फ़िगरेशन में `hasDarkBackground: true` सेट करते हैं, तो चैट विंडो और UI एलिमेंट्स स्वचालित रूप से डार्क बैकग्राउंड पर अच्छी तरह काम करने के लिए एडजस्ट हो जाते हैं।

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    hasDarkBackground: true
});
```

डार्क मोड स्टाइलिंग चैट विंडो, मार्कर स्क्वायर और सभी इंटरैक्टिव एलिमेंट्स पर लागू होती है। यदि आपकी साइट में डार्क मोड टॉगल है, तो आप मोड बदलने पर विजेट को फिर से इनिशियलाइज़ कर सकते हैं, या नीचे वर्णित body क्लास अप्रोच का उपयोग कर सकते हैं।

### डायनामिक डार्क मोड

यदि आपकी साइट का डार्क मोड body एलिमेंट में `.dark` क्लास जोड़कर नियंत्रित होता है, तो Image Chat UI स्वचालित रूप से इसका सम्मान करेगा, बिना फिर से इनिशियलाइज़ेशन की आवश्यकता के। विजेट की स्टाइल्स इस क्लास की उपस्थिति के प्रति प्रतिक्रिया देने के लिए डिज़ाइन की गई हैं।

```css
/* आपकी डार्क मोड CSS */
body.dark {
    background: #1a1a1a;
    color: #ffffff;
}
```

### CSS के साथ कस्टम स्टाइलिंग

आप CSS का उपयोग करके मार्कर, चैट विंडो और अन्य एलिमेंट्स की उपस्थिति को कस्टमाइज़ कर सकते हैं। विजेट विशिष्ट क्लासेस जोड़ता है जिन्हें आप अपनी स्टाइलशीट में टारगेट कर सकते हैं।

चैट स्क्वायर और विंडो FastComments कमेंट बबल स्टाइलिंग सिस्टम का उपयोग करते हैं, इसलिए स्टैंडर्ड कमेंटिंग विजेट पर आपके द्वारा लागू की गई कोई भी कस्टमाइज़ेशन Image Chat को भी प्रभावित करेगी।

### चैट स्क्वायर साइज़िंग

`chatSquarePercentage` विकल्प क्लिक करने योग्य मार्कर के आकार को नियंत्रित करता है। डिफ़ॉल्ट इमेज चौड़ाई का 5% है:

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    chatSquarePercentage: 7  // बड़े, अधिक दिखाई देने वाले स्क्वायर
});
```

छोटे मान अधिक सूक्ष्म मार्कर बनाते हैं जो इमेज में मिल जाते हैं। बड़े मान मार्कर को अधिक प्रमुख और क्लिक करने में आसान बनाते हैं, विशेष रूप से मोबाइल डिवाइस पर या एक्सेसिबिलिटी उद्देश्यों के लिए।

### मोबाइल व्यवहार

768px से कम चौड़ाई वाली स्क्रीन पर, Image Chat स्वचालित रूप से मोबाइल-ऑप्टिमाइज़्ड लेआउट पर स्विच हो जाता है। चैट विंडो मार्कर के पास फ्लोटिंग होने के बजाय फुलस्क्रीन दिखाई देती हैं, जिससे छोटी स्क्रीन पर बेहतर उपयोगिता मिलती है।

मार्कर इमेज पर अपनी रिस्पॉन्सिव स्थितियों पर दिखाई देते रहते हैं। उपयोगकर्ता फुलस्क्रीन चैट इंटरफ़ेस खोलने के लिए किसी भी मार्कर पर टैप कर सकते हैं। यह व्यवहार बिल्ट-इन है और इसके लिए किसी कॉन्फ़िगरेशन की आवश्यकता नहीं है।

### चैट विंडो की उपस्थिति

चैट विंडो डेस्कटॉप पर 300px चौड़ी होती हैं और मार्कर की ओर इशारा करते हुए 16px का तीर होता है। विंडो उपलब्ध व्यूपोर्ट स्पेस के आधार पर स्वचालित रूप से खुद को पोज़िशन करती हैं, `to-right`, `to-left`, `to-top`, और `to-bottom` जैसी पोज़िशनिंग क्लासेस का उपयोग करते हुए।

आप इन विंडो के रंग, फ़ॉन्ट, स्पेसिंग या अन्य विज़ुअल गुणों को समायोजित करने के लिए कस्टम CSS जोड़ सकते हैं। चैट विंडो स्टैंडर्ड FastComments विजेट के समान कंपोनेंट संरचना का उपयोग करती हैं, इसलिए वे आपके द्वारा लागू की गई किसी भी ग्लोबल कस्टमाइज़ेशन को इनहेरिट करती हैं।

### लेज़ी इनिशियलाइज़ेशन

चैट विंडो डेस्कटॉप उपयोगकर्ताओं के लिए होवर पर या बनाए जाने पर तुरंत इनिशियलाइज़ होती हैं। यह चैट इंटरफ़ेस को केवल तब रेंडर करके प्रारंभिक लोड ओवरहेड को कम करता है जब उपयोगकर्ता वास्तव में किसी मार्कर के साथ इंटरैक्ट करते हैं।

लेज़ी इनिशियलाइज़ेशन पारदर्शी रूप से होता है। उपयोगकर्ताओं को कोई देरी नहीं दिखती, लेकिन यदि आपके पास एक इमेज पर कई मार्कर हैं तो ब्राउज़र को दर्जनों छिपी हुई चैट विंडो रेंडर करने की आवश्यकता नहीं होती।

### लोकलाइज़ेशन

Image Chat स्टैंडर्ड FastComments विजेट के समान सभी लोकलाइज़ेशन विकल्पों का समर्थन करता है। विभिन्न भाषाओं में UI टेक्स्ट प्रदर्शित करने के लिए `locale` विकल्प सेट करें:

```javascript
FastCommentsImageChat(imageElement, {
    tenantId: 'demo',
    locale: 'fr'  // फ्रेंच
});
```

FastComments दर्जनों भाषाओं का समर्थन करता है। लोकेल सेटिंग प्रॉम्प्ट्स, बटन और प्लेसहोल्डर टेक्स्ट सहित सभी UI टेक्स्ट को प्रभावित करती है।

### इनहेरिटेड कस्टमाइज़ेशन विकल्प

चूंकि Image Chat स्टैंडर्ड कमेंटिंग विजेट का विस्तार करता है, यह बेस विजेट से सभी कस्टमाइज़ेशन विकल्प इनहेरिट करता है। इसमें कस्टम CSS क्लासेस, कस्टम अनुवाद, अवतार कस्टमाइज़ेशन, दिनांक फ़ॉर्मेटिंग और बहुत कुछ शामिल है।

उपलब्ध कस्टमाइज़ेशन विकल्पों की पूरी सूची के लिए मुख्य FastComments कस्टमाइज़ेशन दस्तावेज़ देखें।

### कस्टम फ़ॉन्ट के साथ काम करना

यदि आपकी साइट कस्टम फ़ॉन्ट का उपयोग करती है, तो Image Chat UI आपके पेज की CSS से उन फ़ॉन्ट को इनहेरिट करेगा। चैट विंडो आपके पेज के DOM के अंदर रेंडर होती हैं और आपकी मौजूदा टाइपोग्राफी सेटिंग्स का सम्मान करती हैं।

सर्वोत्तम परिणामों के लिए, Image Chat इनिशियलाइज़ करने से पहले सुनिश्चित करें कि आपके कस्टम फ़ॉन्ट लोड हो चुके हैं, या स्वीकार करें कि फ़ॉन्ट लोड होते समय अनस्टाइल्ड टेक्स्ट की एक संक्षिप्त झलक दिख सकती है।

### मार्कर विज़ुअल डिज़ाइन

स्क्वायर मार्कर में एक सूक्ष्म विज़ुअल डिज़ाइन होता है जो इमेज को अधिक प्रभावित किए बिना उन्हें ध्यान देने योग्य बनाता है। यदि आप कोई अलग विज़ुअल ट्रीटमेंट चाहते हैं तो आप CSS के साथ उनकी उपस्थिति को कस्टमाइज़ कर सकते हैं।

मार्कर में होवर स्टेट शामिल हैं जो उपयोगकर्ताओं के माउस को उन पर ले जाने पर फीडबैक प्रदान करते हैं। टच डिवाइस पर, टैप इंटरैक्शन चैट विंडो खोलकर तुरंत फीडबैक प्रदान करता है।
