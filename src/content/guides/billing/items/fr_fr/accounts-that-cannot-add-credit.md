Le crédit concerne les comptes que FastComments facture directement via Stripe. Le bouton `Manage Credits` n'est pas affiché pour :

- Les comptes facturés en externe, par exemple par facture en dehors du tableau de bord, ou les sous-comptes dont la facturation est gérée par un compte parent.
- Les comptes installés via le Shopify App Store, qui sont facturés via Shopify.
- Les comptes installés via le BigCommerce App Marketplace, qui sont facturés via BigCommerce.

Pour ces comptes, le paiement est géré sur la plateforme qui vous facture, et il n'y a aucun solde sur FastComments à recharger.

### Incompatibilité de devise

Votre solde de crédit est détenu dans une seule devise, celle dans laquelle votre compte a déjà été facturé. Si la devise de facturation dans `Invoice Settings` a été modifiée pour une devise différente, la page Crédits explique cette incompatibilité et ne vous permet pas d'ajouter de crédit tant que les devises ne correspondent pas. Rétablissez la devise de facturation dans `Invoice Settings`, ou [contactez le support](https://fastcomments.com/auth/my-account/help) pour changer de devise.
