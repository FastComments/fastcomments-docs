Guthaben ist Geld, das auf Ihrem FastComments-Konto in Ihrer Abrechnungswährung gehalten wird. Es wird automatisch mit Ihren zukünftigen Rechnungen verrechnet, einschließlich Abonnementverlängerungen und Flex-Nutzung, bevor Ihre Karte belastet wird.

Guthaben ist eine Vorauszahlung, kein Rabatt oder Punktesystem. Das Hinzufügen von `$50` Guthaben bedeutet, dass Ihre nächsten `$50` Rechnungen aus diesem Guthaben statt mit Ihrer Karte bezahlt werden. Der Saldo wird als Guthaben auf Ihrem Konto bei Stripe, unserem Zahlungsabwickler, gehalten und bleibt auf Ihrem Konto, bis eine Rechnung es verwendet.

Einige Gründe, ein Guthaben vorzuhalten:

- Bezahlen Sie eine Periode im Voraus, zum Beispiel wenn eine Finanzabteilung eine größere Zahlung einer monatlichen Kartenbelastung vorzieht.
- Halten Sie einen Puffer auf einem Flex-Plan, damit ein geschäftiger Monat abgedeckt ist, bevor die Rechnung kommt.
- Zahlen Sie einmal mit einer Karte und lassen Sie Verlängerungen dann vom Saldo abgebucht werden.

### Wo Sie es finden

Öffnen Sie [My Account -> Billing Info](https://fastcomments.com/auth/my-account/billing-info) und klicken Sie auf `Manage Credits`, neben `View Invoices` und `Invoice Settings`. Dies öffnet die `Credits`-Seite, die Ihren aktuellen `Credit balance`, das `Add credit`-Formular und Ihre `Past top-ups` anzeigt.

Sobald Sie einen Saldo haben, zeigt die `Billing Info`-Seite auch eine Zeile `Credit balance` an, damit Sie ihn sehen können, ohne die Credits-Seite zu öffnen.

### Wer Guthaben hinzufügen kann

Nur der `Account Owner` oder ein Benutzer mit der `Billing Admin`-Berechtigung kann Guthaben hinzufügen, dieselben Benutzer, die den Plan oder die Zahlungsmethode ändern können. Andere Administratoren sehen die Schaltfläche `Manage Credits` nicht. Siehe [Who Can Manage Billing](#who-can-manage-billing).
