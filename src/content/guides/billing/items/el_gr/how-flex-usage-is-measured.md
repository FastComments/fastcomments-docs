Ένα τιμολόγιο Flex είναι μια λίστα γραμμών χρέωσης, μία ανά είδος χρήσης, καθεμία που δείχνει την ποσότητα και τη χρέωση, για παράδειγμα `213,000 Page Loads. ($1.00 per 100,000 Page Loads)`. Οι χρεώσεις βρίσκονται στη [σελίδα τιμολόγησης](https://fastcomments.com/traffic-pricing) και στη σελίδα [Πληροφορίες Χρέωσης](https://fastcomments.com/auth/my-account/billing-info). Αυτή η ενότητα εξηγεί τι σημαίνει κάθε ποσότητα.

### Μετράται μέσα στον μήνα

Αυτά επανέρχονται στο μηδέν κάθε μήνα και μετρώνται από την πρώτη έως την τελευταία ημέρα του ημερολογιακού μήνα (UTC):

- **Page Loads**: ο αριθμός των φορών που φορτώθηκε ένα widget σχολίων ή feed στις σελίδες σας. Κάθε φόρτωση του widget σχολίων μετράει, ανεξάρτητα από το πόσες σχολιαστικές συζητήσεις εμφανίζει. Δεν υπάρχει χρέωση ανά νήμα σχολίων ή ανά σελίδα.
- **API Credits**: κλήσεις στο REST API με το API key σας.
- **Small Widgets Credits**: φορτώσεις των μικρών widgets, όπως μετρητές σχολίων και σήματα.
- **LLM Tokens**: tokens που χρησιμοποιούνται από τα [AI Agents](/guide-ai-agents.html) και άλλες λειτουργίες LLM.

### Μετράται στο τέλος του μήνα

Αυτά είναι ένα στιγμιότυπο που λαμβάνεται κατά τη δημιουργία του τιμολογίου:

- **Comments Stored**: ο συνολικός αριθμός σχολίων στον λογαριασμό σας, όχι μόνο όσων προστέθηκαν αυτόν τον μήνα. Η διαγραφή σχολίων τον μειώνει, με εξαίρεση ότι ένα διαγραμμένο σχόλιο με απαντήσεις διατηρείται ως placeholder ώστε οι απαντήσεις να εξακολουθούν να έχουν νόημα.
- **SSO Users**: ο συνολικός αριθμός χρηστών SSO που έχει δημιουργήσει ο ιστότοπός σας, συμπεριλαμβανομένων ατόμων που σχολίασαν μία φορά πριν από πολύ καιρό. Αν αυτό είναι το μεγαλύτερο μέρος του λογαριασμού σας, ρωτήστε την υποστήριξη για χρέωση ανά μηνιαίους ενεργούς χρήστες, όπου μετράνε μόνο οι χρήστες που συνδέθηκαν μέσα στον μήνα.
- **Moderators**, **Admins**, **SSO Moderators**, και **SSO Admins**: θέσεις χρήσεων, που καλύπτονται στην ενότητα [Θέσεις Διαχειριστών και Συντονιστών](#admin-and-moderator-seats). Ο πρώτος διαχειριστής είναι δωρεάν.
- **Domains**: οι ιστότοποι στον λογαριασμό σας. Ο πρώτος ιστότοπος είναι δωρεάν και κάθε επιπλέον χρεώνεται ανά μήνα, για όσο διάστημα βρίσκεται στον λογαριασμό. Ένα subdomain μετράει μόνο αν το προσθέσετε ως ξεχωριστό ιστότοπο· ένα ενιαίο top-level domain καλύπτει τα subdomains του. Δείτε [Πολλαπλοί Ιστότοποι](/guide-multiple-sites.html#domain-limits).
- **Managed Tenants**: υπο-λογαριασμοί που διαχειρίζεται αυτός ο λογαριασμός, αν υπάρχουν, μαζί με τη δική τους χρήση ως ξεχωριστές γραμμές.

### Ελάχιστο ποσό

Αν οι γραμμές αθροίζονται σε λιγότερο από το ελάχιστο ποσό του Flex, το τιμολόγιο συμπληρώνεται έως το ελάχιστο. Ένας μικρός ιστότοπος με έναν διαχειριστή και ένα domain πληρώνει μόνο το ελάχιστο.

### Προεπισκόπηση του τιμολογίου

Η σελίδα [Αναλυτικά Χρέωσης](https://fastcomments.com/auth/my-account/analytics/billing) εμφανίζει κάθε γραμμή του επόμενου τιμολογίου με τα σημερινά νούμερα, ώστε να μην υπάρχουν εκπλήξεις. Οι μετρήσεις page loads, API και μικρών widgets μπορεί να υστερούν έως ένα λεπτό· τα υπόλοιπα είναι σε πραγματικό χρόνο.

### Άλλα νομίσματα

Η χρήση Flex τιμολογείται σε δολάρια ΗΠΑ. Αν το νόμισμα του τιμολογίου σας είναι άλλο, κάθε γραμμή μετατρέπεται με τη συναλλαγματική ισοτιμία της ημέρας δημιουργίας του τιμολογίου, οπότε η ίδια χρήση μπορεί να κοστίζει ελαφρώς διαφορετικά ποσά από μήνα σε μήνα. Δείτε [Νομίσματα](#currencies).
