За да видите всички уиджети и потоци, работещи локално срещу публичния `demo` наемател, клонирайте репото и изпълнете:

```bash
npm install
npm run build
cd examples/example-showcase
npm install
npm run dev
```

Примерите се свързват с библиотеката чрез `file:../..`, така че стъпката `npm run build` в корена е необходима еднократно, за да се създаде `dist/`.

Всеки уиджет/поток има собствен изглед в `examples/example-showcase/src/views/`, който можете директно да копирате във вашето собствено React приложение.
