Щоб побачити кожен віджет і потік, що працюють локально проти публічного орендаря `demo`, клонувати репозиторій і запустити:

```bash
npm install
npm run build
cd examples/example-showcase
npm install
npm run dev
```

Приклади посилаються на бібліотеку через `file:../..`, тому крок `npm run build` у корені потрібен один раз, щоб створити `dist/`.

Кожен віджет/потік має власний вигляд у `examples/example-showcase/src/views/`, який ви можете скопіювати безпосередньо у свою React‑аплікацію.
