Да бисте видели сваки виџет и ток који се извршава локално против јавног `demo` тенанта, клонирајте репозиторијум и покрените:

```bash
npm install
npm run build
cd examples/example-showcase
npm install
npm run dev
```

Примери се повезују са библиотеком преко `file:../..`, тако да је коришњени корак `npm run build` потребан једном да би се произвидео `dist/`.

Сваки виџет/ток има свој приказ унутар `examples/example-showcase/src/views/` који можете директно копирати у вашу сопствену React апликацију.
