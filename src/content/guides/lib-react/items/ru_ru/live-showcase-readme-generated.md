Чтобы увидеть каждый виджет и поток, работающие локально против публичного арендатора `demo`, клонируйте репозиторий и выполните:

```bash
npm install
npm run build
cd examples/example-showcase
npm install
npm run dev
```

Примеры подключаются к библиотеке через `file:../..`, поэтому шаг `npm run build` в корне необходимо выполнить один раз, чтобы создать `dist/`.

Каждый виджет/поток имеет собственный представление в `examples/example-showcase/src/views/`, которое вы можете скопировать напрямую в своё приложение React.
