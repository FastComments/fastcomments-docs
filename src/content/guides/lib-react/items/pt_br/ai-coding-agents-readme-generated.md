Dê ao seu agente de codificação o contexto do FastComments que ele precisa - widgets, configuração, Secure SSO, a REST API e os SDKs:

```bash
npx skills add fastcomments/skills
```

Funciona com Claude Code, Codex, Cursor, Copilot, Gemini e todos os outros agentes que o [skills CLI](https://github.com/vercel-labs/skills) suporta.
