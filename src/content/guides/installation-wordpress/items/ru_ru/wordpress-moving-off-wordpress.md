Если вы переносите свой сайт с WordPress и хотите использовать FastComments на новом сайте, плагин WordPress не требуется. Экспортируйте свои комментарии из WordPress, затем загрузите файл на [странице импорта](https://fastcomments.com/auth/my-account/manage-data/import) в панели управления FastComments.

Мы поддерживаем два формата экспорта WordPress.

### WordPress XML (Рекомендуется)

Это файл, созданный встроенным экспортером WordPress, поэтому дополнительный плагин не требуется.

1. В админке WordPress перейдите к `Tools -> Export`.
2. Выберите `All content` и нажмите `Download Export File`.
3. На [странице импорта](https://fastcomments.com/auth/my-account/manage-data/import) FastComments выберите `WordPress (.xml)` и загрузите файл.

Каждый комментарий привязан к URL записи, в которой он был оставлен, и этот URL уже присутствует в файле.

Импорт сохраняет имя автора, электронную почту и веб‑сайт, дату, содержание, ветвление ответов и статус одобрения комментария. Аватары комментаторов импортируются из Gravatar. Голосования не входят в этот формат.

### WordPress CSV

Это файл из [плагина WordPress Comments Import & Export от WebToffee](https://wordpress.org/plugins/comments-import-export-woocommerce/).

1. Установите плагин в админке WordPress и экспортируйте свои комментарии в формате CSV.
2. Замените каждое значение `comment_post_ID` на URL записи.
3. На [странице импорта](https://fastcomments.com/auth/my-account/manage-data/import) FastComments выберите `WordPress (.csv)` и загрузите файл.

Каждый комментарий привязан к столбцу `comment_post_ID`. WordPress заполняет этот столбец ID записи, а на вашем новом сайте нет ID записей WordPress, поэтому шаг 2 заменяет его на URL.

Импорт сохраняет имя автора, электронную почту и веб‑сайт, дату, содержание, ветвление ответов и статус одобрения комментария. Аватары комментаторов импортируются из Gravatar. Также сохраняется флаг спама WordPress и лайки/дизлайки wpDiscuz, если они присутствуют в файле.

### Сопоставление комментариев с вашими новыми страницами

Если ваш новый сайт сохраняет те же URL, что и сайт на WordPress, комментарии появятся на соответствующих страницах без дополнительной настройки.

Если домен меняется, запустите [инструмент миграции домена](/guide-migrations.html#migrating-domains) после импорта. Если меняются отдельные URL страниц, вы можете [мигрировать каждую страницу](/guide-migrations.html#migrating-pages) со старого URL на новый.

Для массовой миграции страниц, например, удаления домена из значения, которое вы передаёте в поле [urlId](/guide-customizations-and-configuration.html#url-id) виджета комментариев, [откройте тикет в поддержку](https://fastcomments.com/auth/my-account/help), и мы займёмся этим за вас.

### Перед переключением

Вы можете выполнять импорт сколько угодно раз. Повторный импорт того же файла [не создаёт дубликаты](/guide-migrations.html#importing-data), поэтому можно импортировать один раз для тестирования нового сайта, а затем снова импортировать последние комментарии непосредственно перед переключением.

Для файлов экспорта размером более 1 ГБ [обратитесь в поддержку](https://fastcomments.com/auth/my-account/help).

Чтобы добавить FastComments на ваш новый сайт, см. [руководство по установке](/guide-installation.html).
