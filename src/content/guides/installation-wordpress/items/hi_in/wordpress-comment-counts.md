FastComments WordPress प्लगइन डिफ़ॉल्ट WordPress काउंट मैकेनिज़्म को FastComments द्वारा प्रदान की गई एक प्रणाली से बदल देगा। जब कमेंट काउंट दिखाने के लिए पोस्ट की एक सूची हो, तो हम प्रत्येक पेज लोड पर एक एसिंक्रोनस रिक्वेस्ट करेंगे। यदि उपयोगकर्ता ने JavaScript अक्षम कर रखा है, तो यह डिफ़ॉल्ट WordPress काउंट पर वापस आ जाएगा ताकि कार्यक्षमता में कोई कमी न हो।
