הסקרים פועלים באותו אופן כמו בווידג'ט האינטרנט, ומופעלים מאותן הגדרות ווידג'ט בלוח הבקרה של FastComments שלך: `pollCreation` (מי יכול לצרף סקר: מושבת, מנהלים ומנחים, או כולם) ו-`pollVoting` (משתמשים מחוברים או כל אחד).

- תגובות עם סקר מציגות אותו מתחת לטקסט שלהן. הקוראים מצביעים על ידי הקשה על אפשרות, יכולים להציג או להסתיר תוצאות לפני ההצבעה, ויכולים לשנות את הצבעתם. הספירות מתעדכנות בזמן אמת ככל שאחרים מצביעים.
- סקרים יכולים להיסגר בתאריך מסוים, להסתיר תוצאות עד שמצביעים, ולהפוך את המצביעים לגלויים למנהלים או לכולם ("הצג מי הצביע").
- כאשר הצופה רשאי ליצור סקרים, שדה הקלט של התגובות ב-`FastCommentsView` מציג כפתור סקר שפותח את בונה הסקרים. סקר מפורסם יחד עם תגובה, ולכן נדרש טקסט תגובה. שדה הקלט של הצ'אט החי משאיר את הכפתור החוצה, בדיוק כמו בצ'אט החי באינטרנט.

הצבעה דורשת משתמש מחובר, ולכן יש להשתמש ב-[SSO](#authentication-sso-readme-generated). השרת מקשר הצבעה אנונימית לעוגיית סשן, שלקוח ה-API אינו שומר, ולכן כאשר `pollVoting` מוגדר לכל אחד, צופה ללא משתמש SSO יראה "התחבר כדי להצביע". סקרים שמסתירים תוצאות עד להצבעה אינם מקבלים עדכוני ספירה בזמן אמת; מצביעים אלה יראו מספרים חדשים בטעינה הבאה שלהם.

כדי לפרסם סקר מממשק המשתמש שלך, העבירו `CommentPollInput` ל-`postComment`:

```swift
let draft = PollDraft(question: "Where should we eat?", options: ["Tacos", "Ramen"], closesDays: 1)
if draft.validate() == nil {
    try await sdk.postComment(text: "Lunch vote", poll: draft.toInput())
}
```

`sdk.votePoll(commentId:optionId:)` ו-`sdk.getPollVoters(commentId:page:search:)` מכסים הצבעה ואת רשימת המצביעים. צבעי הסקר מפורטים תחת [צבעי סקר](#theming-readme-generated).
