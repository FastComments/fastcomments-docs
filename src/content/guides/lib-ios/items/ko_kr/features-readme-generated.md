- 중첩된 답글과 페이지네이션이 있는 스레드형 댓글 트리
- 게시물 작성, 반응, 미디어 첨부가 가능한 소셜 피드
- 자동 스크롤과 날짜 구분선이 있는 라이브 채팅 모드
- WebSocket을 통한 실시간 업데이트 (새 댓글, 투표, 접속 상태)
- Single Sign-On (테스트용 Simple SSO, 프로덕션용 Secure SSO)
- 굵게, 기울임, 코드, @멘션을 지원하는 리치 텍스트 편집
- 구성 가능한 스타일의 투표 (위/아래 화살표 또는 하트)
- 실시간 결과가 표시되는 댓글 내 투표
- 조치 기능: 신고, 고정, 잠금, 차단
- 프리셋과 완전한 사용자 정의를 지원하는 포괄적인 테마 설정
- 댓글 및 피드 게시물 작성을 위한 사용자 정의 툴바 버튼
- 이미지 업로드
- EU 리전 지원
- 사용자 접속 상태 (온라인/오프라인 표시)
- 태그 기반 피드 필터링
