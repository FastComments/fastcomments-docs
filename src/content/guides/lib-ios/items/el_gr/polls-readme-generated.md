Οι δημοσκοπήσεις λειτουργούν όπως στο web widget και ενεργοποιούνται από τις ίδιες ρυθμίσεις του widget στον πίνακα ελέγχου FastComments: `pollCreation` (ποιοι μπορούν να επισυνάψουν δημοσκόπηση: απενεργοποιημένο, διαχειριστές και συντονιστές, ή όλοι) και `pollVoting` (συνδεδεμένοι χρήστες ή οποιοσδήποτε).

- Τα σχόλια με δημοσκόπηση την εμφανίζουν κάτω από το κείμενό τους. Οι αναγνώστες ψηφίζουν πατώντας μια επιλογή, μπορούν να δουν ή να κρύψουν τα αποτελέσματα πριν ψηφίσουν, και μπορούν να αλλάξουν την ψήφο τους. Οι μετρήσεις ενημερώνονται ζωντανά καθώς ψηφίζουν άλλοι.
- Οι δημοσκοπήσεις μπορούν να κλείσουν σε μια ημερομηνία, να κρύβουν τα αποτελέσματα μέχρι να ψηφίσετε, και να κάνουν τους ψηφοφόρους ορατούς στους διαχειριστές ή σε όλους ("Δείτε ποιοι ψήφισαν").
- Όταν ο θεατής μπορεί να δημιουργήσει δημοσκοπήσεις, το πεδίο εισαγωγής σχολίων του `FastCommentsView` εμφανίζει ένα κουμπί δημοσκόπησης που ανοίγει τον δημιουργό δημοσκοπήσεων. Μια δημοσκόπηση δημοσιεύεται μαζί με ένα σχόλιο, οπότε το κείμενο του σχολίου είναι υποχρεωτικό. Το πεδίο εισαγωγής της ζωντανής συνομιλίας παραλείπει το κουμπί, όπως στο web live chat.

Η ψηφοφορία απαιτεί συνδεδεμένο χρήστη, οπότε χρησιμοποιήστε [SSO](#authentication-sso-readme-generated). Ο διακομιστής συνδέει μια ανώνυμη ψήφο με ένα session cookie, το οποίο ο API client δεν διατηρεί, οπότε με το `pollVoting` ρυθμισμένο σε οποιονδήποτε, ένας θεατής χωρίς χρήστη SSO βλέπει "Συνδεθείτε για να ψηφίσετε". Οι δημοσκοπήσεις που κρύβουν τα αποτελέσματα μέχρι να ψηφίσετε δεν λαμβάνουν ζωντανές ενημερώσεις μετρήσεων· αυτοί οι ψηφοφόροι βλέπουν νέους αριθμούς στο επόμενο φορτώματά τους.

Για να δημοσιεύσετε μια δημοσκόπηση από το δικό σας UI, περάστε ένα `CommentPollInput` στο `postComment`:

```swift
let draft = PollDraft(question: "Where should we eat?", options: ["Tacos", "Ramen"], closesDays: 1)
if draft.validate() == nil {
    try await sdk.postComment(text: "Lunch vote", poll: draft.toInput())
}
```

Τα `sdk.votePoll(commentId:optionId:)` και `sdk.getPollVoters(commentId:page:search:)` καλύπτουν την ψηφοφορία και τη λίστα ψηφοφόρων. Τα χρώματα των δημοσκοπήσεων αναφέρονται στην ενότητα [Poll Colors](#theming-readme-generated).
