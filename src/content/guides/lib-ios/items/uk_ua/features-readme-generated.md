- Режим живого чату з автопрокруткою та роздільниками дат

- Опитування в коментарях із результатами в реальному часі
- Дії модератора: скарга, закріплення, блокування, бан

- Підтримка регіону ЄС
- Присутність користувачів (індикатори онлайн/офлайн)
- Фільтрація стрічки за тегами
