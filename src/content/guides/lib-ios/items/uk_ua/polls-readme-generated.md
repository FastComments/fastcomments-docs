Опитування працюють так само, як у веб-віджеті, і вмикаються з тих самих налаштувань віджета у вашій панелі FastComments: `pollCreation` (хто може додавати опитування: вимкнено, адміністратори та модератори, або всі) і `pollVoting` (авторизовані користувачі або будь-хто).

- Коментарі з опитуванням показують його під текстом. Читачі голосують, торкаючись варіанта, можуть показати або приховати результати перед голосуванням і можуть змінити свій голос. Підрахунки оновлюються в реальному часі, коли голосують інші.
- Опитування можуть закриватися за датою, приховувати результати до голосування та робити вибір виборців видимим для адміністраторів або для всіх («Побачити, хто голосував»).
- Коли глядач може створювати опитування, поле введення коментаря у `FastCommentsView` показує кнопку опитування, яка відкриває конструктор опитувань. Опитування публікується разом із коментарем, тому текст коментаря є обов'язковим. Поле введення живого чату не показує цю кнопку, як і веб-версія живого чату.

Для голосування потрібен авторизований користувач, тому використовуйте [SSO](#authentication-sso-readme-generated). Сервер прив'язує анонімний голос до cookie сесії, який API-клієнт не зберігає, тому з `pollVoting`, установленим на «будь-хто», глядач без користувача SSO побачить «Увійдіть, щоб проголосувати». Опитування, що приховують результати до голосування, не отримують оновлень підрахунку в реальному часі; такі виборці побачать нові числа під час наступного завантаження.

Щоб опублікувати опитування з власного інтерфейсу, передайте `CommentPollInput` до `postComment`:

```swift
let draft = PollDraft(question: "Where should we eat?", options: ["Tacos", "Ramen"], closesDays: 1)
if draft.validate() == nil {
    try await sdk.postComment(text: "Lunch vote", poll: draft.toInput())
}
```

`sdk.votePoll(commentId:optionId:)` і `sdk.getPollVoters(commentId:page:search:)` охоплюють голосування та список виборців. Кольори опитувань наведено в розділі [Кольори опитувань](#theming-readme-generated).
