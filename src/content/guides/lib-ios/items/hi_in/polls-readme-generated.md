पोल वेब विजेट की तरह ही काम करते हैं, और आपके FastComments डैशबोर्ड में उसी विजेट सेटिंग्स से चालू होते हैं: `pollCreation` (कौन पोल जोड़ सकता है: अक्षम, एडमिन और मॉडरेटर, या सभी) और `pollVoting` (लॉग इन किए उपयोगकर्ता या कोई भी)।

- पोल वाले कमेंट उसे अपने टेक्स्ट के नीचे दिखाते हैं। पाठक किसी विकल्प पर टैप करके वोट करते हैं, वोट करने से पहले परिणाम दिखा या छिपा सकते हैं, और अपना वोट बदल सकते हैं। जैसे ही अन्य लोग वोट करते हैं, गिनती लाइव अपडेट होती है।
- पोल किसी तारीख पर बंद हो सकते हैं, वोट करने तक परिणाम छिपा सकते हैं, और वोटर्स को एडमिन या सभी को दिखा सकते हैं ("See who voted")।
- जब दर्शक पोल बना सकते हैं, तो `FastCommentsView` के कमेंट इनपुट में एक पोल बटन दिखता है जो पोल बिल्डर खोलता है। पोल एक कमेंट के साथ पोस्ट होता है, इसलिए कमेंट टेक्स्ट आवश्यक है। लाइव चैट इनपुट बटन को छोड़ देता है, जैसा वेब लाइव चैट में होता है।

वोटिंग के लिए लॉग इन उपयोगकर्ता चाहिए, इसलिए [SSO](#authentication-sso-readme-generated) का उपयोग करें। सर्वर एक गुमनाम वोट को सेशन कुकी से जोड़ता है, जिसे API क्लाइंट सहेजता नहीं है, इसलिए `pollVoting` को कोई भी पर सेट करने पर, बिना SSO उपयोगकर्ता वाला दर्शक "Log in to vote" देखता है। वोट करने तक परिणाम छिपाने वाले पोल को लाइव गिनती अपडेट नहीं मिलते; ऐसे वोटर्स को नए नंबर अगली लोड पर दिखते हैं।

अपने UI से पोल पोस्ट करने के लिए, `postComment` को एक `CommentPollInput` पास करें:

```swift
let draft = PollDraft(question: "Where should we eat?", options: ["Tacos", "Ramen"], closesDays: 1)
if draft.validate() == nil {
    try await sdk.postComment(text: "Lunch vote", poll: draft.toInput())
}
```

`sdk.votePoll(commentId:optionId:)` और `sdk.getPollVoters(commentId:page:search:)` वोटिंग और वोटर सूची को कवर करते हैं। पोल रंग [Poll Colors](#poll-colors-readme-generated) के अंतर्गत सूचीबद्ध हैं।
