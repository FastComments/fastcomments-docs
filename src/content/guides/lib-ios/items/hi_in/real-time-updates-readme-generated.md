`sdk.load()` को कॉल करने के बाद, SDK कॉन्फ़िगर किए गए `urlId` के लिए स्वचालित रूप से WebSocket इवेंट्स की सदस्यता ले लेता है। निम्नलिखित इवेंट्स हैंडल किए जाते हैं:

- नई टिप्पणियाँ, संपादन और डिलीशन
- वोट (नए और हटाए गए)
- पिन, लॉक, फ्लैग और ब्लॉक स्थिति में परिवर्तन
- यूज़र प्रेज़ेंस (जॉइन/लीव)
- थ्रेड खुलना/बंद होना
- बैज पुरस्कार
- सर्वर कॉन्फ़िगरेशन अपडेट

### लाइव डिस्प्ले को नियंत्रित करना

डिफ़ॉल्ट रूप से, अन्य उपयोगकर्ताओं की नई टिप्पणियाँ तुरंत दिखाई देती हैं:

```swift
sdk.showLiveRightAway = true   // Default: show instantly
```

नई टिप्पणियों को एक "N नई टिप्पणियाँ" बटन के पीछे बफर करने के लिए इसे `false` सेट करें, जिससे उपयोगकर्ता चुन सके कि उन्हें कब दिखाना है:

```swift
sdk.showLiveRightAway = false
```

### यूज़र प्रेज़ेंस

जब सर्वर प्रेज़ेंस ट्रैकिंग सक्षम करता है, तो ऑनलाइन/ऑफलाइन संकेतक स्वचालित रूप से उपयोगकर्ता अवतारों पर दिखाई देते हैं। क्लाइंट पर किसी अतिरिक्त कॉन्फ़िगरेशन की आवश्यकता नहीं है।
