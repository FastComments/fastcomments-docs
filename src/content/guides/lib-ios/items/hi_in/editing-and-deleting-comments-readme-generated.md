### संपादित करें

```swift
try await sdk.editComment(commentId: commentId, newText: "Updated text")
```

सर्वर HTML को फिर से रेंडर करता है। स्थानीय कमेंट स्वचालित रूप से अपडेट हो जाता है।

### हटाएं

```swift
try await sdk.deleteComment(commentId: commentId)
```

किसी कमेंट को हटाने पर उसके डिसेंडेंट्स भी स्थानीय ट्री से हटा दिए जाते हैं।

दोनों क्रियाएँ UI में कमेंट कॉन्टेक्स्ट मेनू के माध्यम से उपलब्ध होती हैं, जब वर्तमान उपयोगकर्ता कमेंट लेखक (या साइट एडमिन) हो।
