FastComments पर हम अपने एक्सटेंशन स्वयं लिखते हैं, उसी API का उपयोग करके। आप इन एक्सटेंशन का अनमिनिफाइड कोड निम्नलिखित एंडपॉइंट्स पर देख सकते हैं:

#### डार्क मोड

डार्क मोड एक्सटेंशन शर्त के अनुसार लोड होता है जब एक "dark" पेज पहचाना जाता है। यह एक्सटेंशन केवल कमेंट विजेट में कुछ CSS जोड़ता है। इस तरह हमें डार्क मोड CSS तब लोड नहीं करना पड़ता जब उसकी आवश्यकता नहीं होती।

https://fastcomments.com/js/comment-ui/extensions/comment-ui.dark.extension.js

#### मॉडरेशन

जब वर्तमान उपयोगकर्ता एक मॉडरेटर होता है, तो हम मॉडरेशन एक्सटेंशन का उपयोग करते हैं।

यह क्लिक-आधारित इवेंट लिसनर जोड़ने, API अनुरोध करने, और कमेंट मेनू तथा कमेंट एरिया में जोड़ने के लिए एक अच्छा उदाहरण है।

https://fastcomments.com/js/comment-ui/extensions/comment-ui.moderation.extension.js

#### लाइव चैट

लाइव चैट एक्सटेंशन (अन्य कॉन्फ़िगरेशन और स्टाइलिंग के संयोजन में) कमेंट विजेट को एक लाइव चैट कंपोनेंट में बदल देता है।

https://fastcomments.com/js/comment-ui/extensions/live-chat.extension.js
