Το SDK παρέχει πολλές επιλογές διαμόρφωσης μέσω της κλάσης `CommentWidgetConfig`:

| Επιλογή | Περιγραφή |
|--------|-------------|
| `tenantId` | Το ID του λογαριασμού σας στο FastComments |
| `urlId` | ID που αντιπροσωπεύει την τρέχουσα σελίδα |
| `sso` | SSO token για αυθεντικοποίηση |
| `allowAnon` | Επιτρέπει ανώνυμα σχόλια |
| `voteStyle` | Στυλ ψηφοφορίας UpDown ή Heart |
| `hideAvatars` | Αποκρύπτει τα avatar των χρηστών |
| `hasDarkBackground` | Υποδηλώνει σκοτεινή λειτουργία |
| `customCSS` | Προσαρμοσμένα στυλ CSS |
| `enableInfiniteScrolling` | Ενεργοποιεί την σελιδοποίηση με ατελείωτη κύλιση |
| `readonly` | Απενεργοποιεί τα σχόλια αλλά εμφανίζει τα υπάρχοντα σχόλια |
| `disableVoting` | Απενεργοποιεί τη λειτουργία ψηφοφορίας |
| `disableLiveCommenting` | Απενεργοποιεί τις ενημερώσεις σε πραγματικό χρόνο |
| `pollCreation` | Ποιοι μπορούν να επισυνάψουν ψηφοφορία σε σχόλιο: `NUMBER_0` απενεργοποιημένο, `NUMBER_1` διαχειριστές και συντονιστές, `NUMBER_2` όλοι |
| `pollVoting` | Ποιοι μπορούν να ψηφίσουν σε ψηφοφορίες: `NUMBER_0` συνδεδεμένοι χρήστες, `NUMBER_1` οποιοσδήποτε |
