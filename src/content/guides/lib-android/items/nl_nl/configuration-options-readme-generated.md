De SDK biedt veel configuratieopties via de `CommentWidgetConfig` klasse:

| Optie | Beschrijving |
|--------|-------------|
| `tenantId` | Je FastComments account ID |
| `urlId` | ID die de huidige pagina vertegenwoordigt |
| `sso` | SSO token voor authenticatie |
| `allowAnon` | Anoniem reageren toestaan |
| `voteStyle` | UpDown of Heart stemstijl |
| `hideAvatars` | Gebruikersavatars verbergen |
| `hasDarkBackground` | Geeft donkere modus aan |
| `customCSS` | Aangepaste CSS stijlen |
| `enableInfiniteScrolling` | Oneindig scrollen paginering inschakelen |
| `readonly` | Reageren uitschakelen maar reacties tonen |
| `disableVoting` | Stemfunctionaliteit uitschakelen |
| `disableLiveCommenting` | Realtime updates uitschakelen |
| `pollCreation` | Wie een poll aan een reactie kan koppelen: `NUMBER_0` uitgeschakeld, `NUMBER_1` admins en moderators, `NUMBER_2` iedereen |
| `pollVoting` | Wie op polls kan stemmen: `NUMBER_0` ingelogde gebruikers, `NUMBER_1` iedereen |
