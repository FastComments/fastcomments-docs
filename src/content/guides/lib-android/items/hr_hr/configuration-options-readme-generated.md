SDK pruža brojne opcije konfiguracije kroz klasu `CommentWidgetConfig`:

| Opcija | Opis |
|--------|-------------|
| `tenantId` | ID vašeg FastComments računa |
| `urlId` | ID koji predstavlja trenutnu stranicu |
| `sso` | SSO token za autentifikaciju |
| `allowAnon` | Dopušta anonimno komentiranje |
| `voteStyle` | Stil glasovanja UpDown ili Heart |
| `hideAvatars` | Sakriva avatare korisnika |
| `hasDarkBackground` | Označava tamni način rada |
| `customCSS` | Prilagođeni CSS stilovi |
| `enableInfiniteScrolling` | Omogućuje paginaciju s beskonačnim pomicanjem |
| `readonly` | Onemogućuje komentiranje, ali prikazuje komentare |
| `disableVoting` | Onemogućuje funkcionalnost glasovanja |
| `disableLiveCommenting` | Onemogućuje ažuriranja u stvarnom vremenu |
| `pollCreation` | Tko može priložiti anketu komentaru: `NUMBER_0` onemogućeno, `NUMBER_1` administratori i moderatori, `NUMBER_2` svi |
| `pollVoting` | Tko može glasovati u anketama: `NUMBER_0` prijavljeni korisnici, `NUMBER_1` itko |
