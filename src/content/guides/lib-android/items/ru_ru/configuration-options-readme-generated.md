SDK предоставляет множество параметров конфигурации через класс `CommentWidgetConfig`:

| Параметр | Описание |
|--------|-------------|
| `tenantId` | ID вашего аккаунта FastComments |
| `urlId` | ID, представляющий текущую страницу |
| `sso` | SSO-токен для аутентификации |
| `allowAnon` | Разрешить анонимные комментарии |
| `voteStyle` | Стиль голосования: UpDown или Heart |
| `hideAvatars` | Скрыть аватары пользователей |
| `hasDarkBackground` | Указывает на тёмный режим |
| `customCSS` | Пользовательские CSS-стили |
| `enableInfiniteScrolling` | Включить пагинацию с бесконечной прокруткой |
| `readonly` | Отключить комментирование, но показывать комментарии |
| `disableVoting` | Отключить функцию голосования |
| `disableLiveCommenting` | Отключить обновления в реальном времени |
| `pollCreation` | Кто может прикреплять опрос к комментарию: `NUMBER_0` отключено, `NUMBER_1` администраторы и модераторы, `NUMBER_2` все |
| `pollVoting` | Кто может голосовать в опросах: `NUMBER_0` вошедшие пользователи, `NUMBER_1` кто угодно |
