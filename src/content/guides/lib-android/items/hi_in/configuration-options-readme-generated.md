SDK `CommentWidgetConfig` क्लास के माध्यम से कई कॉन्फ़िगरेशन विकल्प प्रदान करता है:

| विकल्प | विवरण |
|--------|-------------|
| `tenantId` | आपकी FastComments खाता ID |
| `urlId` | वर्तमान पृष्ठ का प्रतिनिधित्व करने वाली ID |
| `sso` | प्रमाणीकरण के लिए SSO टोकन |
| `allowAnon` | गुमनाम टिप्पणी की अनुमति दें |
| `voteStyle` | UpDown या Heart वोटिंग शैली |
| `hideAvatars` | उपयोगकर्ता अवतार छिपाएँ |
| `hasDarkBackground` | डार्क मोड का संकेत देता है |
| `customCSS` | कस्टम CSS स्टाइल |
| `enableInfiniteScrolling` | इनफिनिट स्क्रॉल पेजिनेशन सक्षम करें |
| `readonly` | टिप्पणी अक्षम करें लेकिन टिप्पणियाँ दिखाएँ |
| `disableVoting` | वोटिंग कार्यक्षमता अक्षम करें |
| `disableLiveCommenting` | रीयल-टाइम अपडेट अक्षम करें |
