Das SDK bietet viele Konfigurationsoptionen über die `CommentWidgetConfig`-Klasse:

| Option | Beschreibung |
|--------|-------------|
| `tenantId` | Ihre FastComments-Konto-ID |
| `urlId` | ID, die die aktuelle Seite repräsentiert |
| `sso` | SSO-Token zur Authentifizierung |
| `allowAnon` | Anonymes Kommentieren erlauben |
| `voteStyle` | UpDown- oder Heart-Abstilstil |
| `hideAvatars` | Benutzer-Avatare ausblenden |
| `hasDarkBackground` | Zeigt den Dunkelmodus an |
| `customCSS` | Benutzerdefinierte CSS-Stile |
| `enableInfiniteScrolling` | Endlos-Scroll-Paginierung aktivieren |
| `readonly` | Kommentieren deaktivieren, aber Kommentare anzeigen |
| `disableVoting` | Abstimmungsfunktion deaktivieren |
| `disableLiveCommenting` | Echtzeit-Updates deaktivieren |
| `pollCreation` | Wer eine Umfrage an einen Kommentar anhängen kann: `NUMBER_0` deaktiviert, `NUMBER_1` Admins und Moderatoren, `NUMBER_2` alle |
| `pollVoting` | Wer über Umfragen abstimmen kann: `NUMBER_0` angemeldete Benutzer, `NUMBER_1` alle |
