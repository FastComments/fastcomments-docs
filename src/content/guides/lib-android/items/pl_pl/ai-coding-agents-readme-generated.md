Daj swojemu agentowi programistycznemu kontekst FastComments, którego potrzebuje – widgety, konfigurację, Secure SSO, REST API i SDK:

```bash
npx skills add fastcomments/skills
```

Działa z Claude Code, Codex, Cursor, Copilot, Gemini oraz każdym innym agentem obsługiwanym przez [skills CLI](https://github.com/vercel-labs/skills).
