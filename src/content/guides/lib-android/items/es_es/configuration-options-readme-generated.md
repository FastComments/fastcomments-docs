El SDK ofrece muchas opciones de configuración a través de la clase `CommentWidgetConfig`:

| Opción | Descripción |
|--------|-------------|
| `tenantId` | El ID de tu cuenta de FastComments |
| `urlId` | ID que representa la página actual |
| `sso` | Token SSO para autenticación |
| `allowAnon` | Permitir comentarios anónimos |
| `voteStyle` | Estilo de votación UpDown o Heart |
| `hideAvatars` | Ocultar los avatares de los usuarios |
| `hasDarkBackground` | Indica modo oscuro |
| `customCSS` | Estilos CSS personalizados |
| `enableInfiniteScrolling` | Habilitar paginación con scroll infinito |
| `readonly` | Deshabilitar comentarios pero mostrar los comentarios existentes |
| `disableVoting` | Deshabilitar la funcionalidad de votación |
| `disableLiveCommenting` | Deshabilitar las actualizaciones en tiempo real |
| `pollCreation` | Quién puede adjuntar una encuesta a un comentario: `NUMBER_0` deshabilitado, `NUMBER_1` administradores y moderadores, `NUMBER_2` todos |
| `pollVoting` | Quién puede votar en las encuestas: `NUMBER_0` usuarios conectados, `NUMBER_1` cualquiera |
