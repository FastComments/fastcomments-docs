SDK ponuja številne možnosti konfiguracije prek razreda `CommentWidgetConfig`:

| Možnost | Opis |
|--------|-------------|
| `tenantId` | ID vašega FastComments računa |
| `urlId` | ID, ki predstavlja trenutno stran |
| `sso` | SSO žeton za avtentikacijo |
| `allowAnon` | Dovoli anonimno komentiranje |
| `voteStyle` | Slog glasovanja UpDown ali Heart |
| `hideAvatars` | Skrij avatarje uporabnikov |
| `hasDarkBackground` | Označuje temni način |
| `customCSS` | Slogi CSS po meri |
| `enableInfiniteScrolling` | Omogoči paginacijo z neskončnim pomikanjem |
| `readonly` | Onemogoči komentiranje, vendar prikaži komentarje |
| `disableVoting` | Onemogoči funkcionalnost glasovanja |
| `disableLiveCommenting` | Onemogoči posodobitve v realnem času |
| `pollCreation` | Kdo lahko priloži anketo komentarju: `NUMBER_0` onemogočeno, `NUMBER_1` skrbniki in moderatorji, `NUMBER_2` vsi |
| `pollVoting` | Kdo lahko glasuje o anketah: `NUMBER_0` prijavljeni uporabniki, `NUMBER_1` kdorkoli |
