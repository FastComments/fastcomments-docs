ה-SDK מספק אפשרויות תצורה רבות באמצעות המחלקה `CommentWidgetConfig`:

| אפשרות | תיאור |
|--------|-------------|
| `tenantId` | מזהה החשבון שלך ב-FastComments |
| `urlId` | מזהה המייצג את הדף הנוכחי |
| `sso` | אסימון SSO לאימות |
| `allowAnon` | אפשרות לתגובות אנונימיות |
| `voteStyle` | סגנון הצבעה UpDown או Heart |
| `hideAvatars` | הסתרת אווטארים של משתמשים |
| `hasDarkBackground` | מציין מצב כהה |
| `customCSS` | סגנונות CSS מותאמים אישית |
| `enableInfiniteScrolling` | הפעלת עימוד בגלילה אינסופית |
| `readonly` | השבתת תגובות אך הצגת תגובות קיימות |
| `disableVoting` | השבתת פונקציונליות ההצבעה |
| `disableLiveCommenting` | השבתת עדכונים בזמן אמת |
| `pollCreation` | מי יכול לצרף סקר לתגובה: `NUMBER_0` מושבת, `NUMBER_1` מנהלים ומפקחים, `NUMBER_2` כולם |
| `pollVoting` | מי יכול להצביע בסקרים: `NUMBER_0` משתמשים מחוברים, `NUMBER_1` כל אחד |
