SDK надає багато параметрів конфігурації через клас `CommentWidgetConfig`:

| Параметр | Опис |
|--------|-------------|
| `tenantId` | ID вашого облікового запису FastComments |
| `urlId` | ID, що представляє поточну сторінку |
| `sso` | SSO-токен для автентифікації |
| `allowAnon` | Дозволити анонімне коментування |
| `voteStyle` | Стиль голосування UpDown або Heart |
| `hideAvatars` | Приховати аватари користувачів |
| `hasDarkBackground` | Вказує на темний режим |
| `customCSS` | Власні стилі CSS |
| `enableInfiniteScrolling` | Увімкнути пагінацію з нескінченним прокручуванням |
| `readonly` | Вимкнути коментування, але показувати коментарі |
| `disableVoting` | Вимкнути функціональність голосування |
| `disableLiveCommenting` | Вимкнути оновлення в реальному часі |
| `pollCreation` | Хто може додавати опитування до коментаря: `NUMBER_0` вимкнено, `NUMBER_1` адміністратори та модератори, `NUMBER_2` усі |
| `pollVoting` | Хто може голосувати в опитуваннях: `NUMBER_0` авторизовані користувачі, `NUMBER_1` будь-хто |
