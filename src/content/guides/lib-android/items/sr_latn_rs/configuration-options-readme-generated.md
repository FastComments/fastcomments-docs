SDK pruža mnoge opcije konfiguracije kroz `CommentWidgetConfig` klasu:

| Opcija | Opis |
|--------|-------------|
| `tenantId` | ID vašeg FastComments naloga |
| `urlId` | ID koji predstavlja trenutnu stranicu |
| `sso` | SSO token za autentifikaciju |
| `allowAnon` | Dozvoli anonimno komentarisanje |
| `voteStyle` | Stil glasanja UpDown ili Heart |
| `hideAvatars` | Sakrij avatire korisnika |
| `hasDarkBackground` | Označava tamni režim |
| `customCSS` | Prilagođeni CSS stilovi |
| `enableInfiniteScrolling` | Omogući paginaciju beskonačnim skrolovanjem |
| `readonly` | Onemogući komentarisanje, ali prikaži komentare |
| `disableVoting` | Onemogući funkcionalnost glasanja |
| `disableLiveCommenting` | Onemogući ažuriranja u realnom vremenu |
| `pollCreation` | Ko može da prikači anketu uz komentar: `NUMBER_0` onemogućeno, `NUMBER_1` administratori i moderatori, `NUMBER_2` svi |
| `pollVoting` | Ko može da glasa u anketama: `NUMBER_0` prijavljeni korisnici, `NUMBER_1` bilo ko |
