SDK'en giver mange konfigurationsmuligheder gennem `CommentWidgetConfig`-klassen:

| Option | Beskrivelse |
|--------|-------------|
| `tenantId` | Dit FastComments-konto-ID |
| `urlId` | ID, der repræsenterer den aktuelle side |
| `sso` | SSO-token til autentificering |
| `allowAnon` | Tillad anonym kommentering |
| `voteStyle` | UpDown- eller Heart-stemmetype |
| `hideAvatars` | Skjul brugeravatarer |
| `hasDarkBackground` | Angiver mørk tilstand |
| `customCSS` | Brugerdefinerede CSS-stile |
| `enableInfiniteScrolling` | Aktiver uendelig rulning (paginering) |
| `readonly` | Deaktivér kommentering, men vis kommentarer |
| `disableVoting` | Deaktivér stemefunktion |
| `disableLiveCommenting` | Deaktivér opdateringer i realtid |
| `pollCreation` | Hvem kan vedhæfte en afstemning til en kommentar: `NUMBER_0` deaktiveret, `NUMBER_1` administratorer og moderatorer, `NUMBER_2` alle |
| `pollVoting` | Hvem kan stemme på afstemninger: `NUMBER_0` loggede brugere, `NUMBER_1` alle |
