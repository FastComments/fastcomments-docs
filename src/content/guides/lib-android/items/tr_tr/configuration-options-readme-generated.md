SDK, `CommentWidgetConfig` sınıfı aracılığıyla birçok yapılandırma seçeneği sunar:

| Seçenek | Açıklama |
|--------|-------------|
| `tenantId` | FastComments hesap kimliğiniz |
| `urlId` | Geçerli sayfayı temsil eden kimlik |
| `sso` | Kimlik doğrulama için SSO token'ı |
| `allowAnon` | Anonim yorum yapmaya izin ver |
| `voteStyle` | UpDown veya Heart oylama stili |
| `hideAvatars` | Kullanıcı avatarlarını gizle |
| `hasDarkBackground` | Karanlık modu belirtir |
| `customCSS` | Özel CSS stilleri |
| `enableInfiniteScrolling` | Sonsuz kaydırma sayfalandırmasını etkinleştir |
| `readonly` | Yorum yapmayı devre dışı bırak ancak yorumları göster |
| `disableVoting` | Oylama işlevini devre dışı bırak |
| `disableLiveCommenting` | Gerçek zamanlı güncellemeleri devre dışı bırak |
| `pollCreation` | Kim bir ankete yorum ekleyebilir: `NUMBER_0` devre dışı, `NUMBER_1` yöneticiler ve moderatörler, `NUMBER_2` herkes |
| `pollVoting` | Kim anketlerde oy verebilir: `NUMBER_0` giriş yapmış kullanıcılar, `NUMBER_1` herkes |
