O SDK fornece muitas opções de configuração através da classe `CommentWidgetConfig`:

| Opção | Descrição |
|--------|-------------|
| `tenantId` | ID da sua conta FastComments |
| `urlId` | ID representando a página atual |
| `sso` | Token SSO para autenticação |
| `allowAnon` | Permitir comentários anônimos |
| `voteStyle` | Estilo de votação UpDown ou Heart |
| `hideAvatars` | Ocultar avatares dos usuários |
| `hasDarkBackground` | Indica modo escuro |
| `customCSS` | Estilos CSS personalizados |
| `enableInfiniteScrolling` | Ativar paginação com rolagem infinita |
| `readonly` | Desabilitar comentários, mas exibir os comentários |
| `disableVoting` | Desabilitar a funcionalidade de votação |
| `disableLiveCommenting` | Desabilitar atualizações em tempo real |
| `pollCreation` | Quem pode anexar uma enquete a um comentário: `NUMBER_0` desabilitado, `NUMBER_1` administradores e moderadores, `NUMBER_2` todos |
| `pollVoting` | Quem pode votar em enquetes: `NUMBER_0` usuários autenticados, `NUMBER_1` qualquer pessoa |
