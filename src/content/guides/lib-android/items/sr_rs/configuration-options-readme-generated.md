SDK пружа многе конфигурационе опције кроз класу `CommentWidgetConfig`:

| Опција | Опис |
|--------|-------------|
| `tenantId` | ID вашег FastComments налога |
| `urlId` | ID који представља тренутну страницу |
| `sso` | SSO токен за аутентификацију |
| `allowAnon` | Дозвољава анонимно коментарисање |
| `voteStyle` | Стил гласања UpDown или Heart |
| `hideAvatars` | Сакрива аватаре корисника |
| `hasDarkBackground` | Означава тамни режим |
| `customCSS` | Прилагођени CSS стилови |
| `enableInfiniteScrolling` | Омогућава пагинацију са бесконачним померањем |
| `readonly` | Онемогућава коментарисање, али приказује коментаре |
| `disableVoting` | Онемогућава функцију гласања |
| `disableLiveCommenting` | Онемогућава ажурирања у реалном времену |
| `pollCreation` | Ко може да прикачи анкету на коментар: `NUMBER_0` онемогућено, `NUMBER_1` администратори и модератори, `NUMBER_2` сви |
| `pollVoting` | Ко може да гласа у анкетама: `NUMBER_0` пријављени корисници, `NUMBER_1` свако |
