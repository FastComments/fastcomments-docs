SDK-ът предоставя много опции за конфигурация чрез класа `CommentWidgetConfig`:

| Опция | Описание |
|--------|-------------|
| `tenantId` | ID на вашия FastComments акаунт |
| `urlId` | ID, представляващо текущата страница |
| `sso` | SSO токен за автентикация |
| `allowAnon` | Разрешава анонимно коментиране |
| `voteStyle` | Стил на гласуване UpDown или Heart |
| `hideAvatars` | Скрива аватарите на потребителите |
| `hasDarkBackground` | Указва тъмен режим |
| `customCSS` | Персонализирани CSS стилове |
| `enableInfiniteScrolling` | Активира пагинация с безкрайно скролиране |
| `readonly` | Забранява коментирането, но показва коментарите |
| `disableVoting` | Изключва функцията за гласуване |
| `disableLiveCommenting` | Изключва обновленията в реално време |
| `pollCreation` | Кой може да прикачи анкета към коментар: `NUMBER_0` изключено, `NUMBER_1` администратори и модератори, `NUMBER_2` всички |
| `pollVoting` | Кой може да гласува в анкети: `NUMBER_0` влезли потребители, `NUMBER_1` всеки |
