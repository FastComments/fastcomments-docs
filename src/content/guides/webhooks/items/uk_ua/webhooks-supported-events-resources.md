FastComments підтримує вебхуки лише для ресурсу Comment.

Ми підтримуємо вебхуки для створення коментаря, його видалення та оновлення.

Кожен з цих випадків розглядається як окрема подія в нашій системі, і тому має різну семантику
та структуру для подій вебхука.

Будь‑яка кількість кінцевих точок може підписатися на одну й ту ж подію: один вебхук на домен можна налаштувати в
панелі управління, а подальші підписки можна створити через API (див. Управління вебхуками через API).
