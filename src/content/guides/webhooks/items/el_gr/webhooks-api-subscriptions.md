Webhooks μπορούν επίσης να διαχειρίζονται μέσω του REST API. Έτσι οι ενσωματώσεις όπως το Zapier εγγράφονται σε συμβάντα σχολίων χωρίς να αγγίζουν τον πίνακα ελέγχου, και ακολουθεί το πρότυπο REST Hooks: εγγραφή, λήψη συμβάντων, διαγραφή εγγραφής.

API subscriptions ζουν παράλληλα με τα webhooks που έχουν ρυθμιστεί στον πίνακα ελέγχου. Ένα συμβάν σχολίου παραδίδεται στο webhook του πίνακα ελέγχου για το domain του και σε κάθε συνδρομή API που ταιριάζει, καθεμία ως δική της παράδοση. Δεν υπάρχει περιορισμός ενός συνδρομητή ανά συμβάν.

## Έλεγχος ταυτότητας

Κάθε αίτηση χρειάζεται το API Key σας στην κεφαλίδα `x-api-key` (ή στην παράμετρο ερωτήματος `API_KEY`) και το tenant ID σας στην παράμετρο ερωτήματος `tenantId`. Και τα δύο εμφανίζονται στη σελίδα API Secret στον πίνακα ελέγχου.

## Εγγραφή

```
POST https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
x-api-key: YOUR_API_KEY
Content-Type: application/json

{
    "url": "https://hooks.zapier.com/hooks/catch/123/abc",
    "event": "comment-created"
}
```

| Πεδίο | Απαιτείται | Περιγραφή |
|-------|------------|------------|
| `url` | Ναι | Ένα απόλυτο http ή https URL. |
| `event` | Ναι | `comment-created`, `comment-updated` ή `comment-deleted`. |
| `domain` | Όχι | Ένα domain από τη ρύθμιση λογαριασμού σας. Προεπιλογή είναι `*`, που λαμβάνει συμβάντα για κάθε domain. |
| `method` | Όχι | `POST` (προεπιλογή), `PUT` ή `DELETE`. |

Η απάντηση περιέχει τη συνδρομή:

```json
{
    "status": "success",
    "webhook": {
        "id": "66f1c4c1e7a2b3d4f5a6b7c8",
        "url": "https://hooks.zapier.com/hooks/catch/123/abc",
        "event": "comment-created",
        "domain": "*",
        "method": "POST",
        "source": "api",
        "enabled": true,
        "createdAt": "2026-09-08T12:00:00.000Z"
    }
}
```

Η εγγραφή του ίδιου URL στο ίδιο συμβάν και domain ξανά επιστρέφει την υπάρχουσα συνδρομή αντί να δημιουργήσει διπλότυπο, ώστε ένας πελάτης να μπορεί να επαναπροσπαθήσει με ασφάλεια. Κάθε tenant μπορεί να έχει έως 50 συνδρομές API.

## Λίστα

```
GET https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
```

Επιστρέφει κάθε webhook για το tenant, συμπεριλαμβανομένων αυτών που διαχειρίζονται στον πίνακα ελέγχου (`"source": "dashboard"`). Φιλτράρετε με `event`, `domain` ή `source`.

## Κατάργηση εγγραφής

```
DELETE https://fastcomments.com/api/v1/webhooks/SUBSCRIPTION_ID?tenantId=YOUR_TENANT_ID
```

Η διαγραφή μιας συνδρομής απορρίπτει επίσης τυχόν συμβάντα που είναι ακόμη στην ουρά της. Μόνο οι συνδρομές που δημιουργήθηκαν μέσω του API μπορούν να διαγραφούν με αυτόν τον τρόπο. Τα webhooks του πίνακα ελέγχου επεξεργάζονται στη σελίδα Webhooks.

## Φορτία δεδομένων και υπογραφή

Οι παραδόσεις χρησιμοποιούν το ίδιο φορτίο δεδομένων με τα webhooks του πίνακα ελέγχου (δείτε Δομές Δεδομένων) και υπογράφονται με το ίδιο σχήμα HMAC (δείτε Ασφάλεια & API Tokens). Οι συνδρομές API δεν λαμβάνουν ποτέ την παλιά κεφαλίδα `token`, επομένως επαληθεύστε την κεφαλίδα `X-FastComments-Signature`.

## Απόκριση με 410 Gone

Εάν το endpoint μιας συνδρομής API απαντήσει με HTTP `410 Gone`, το FastComments το θεωρεί ως κατάργηση εγγραφής: η συνδρομή διαγράφεται μαζί με τα ουράνια συμβάντα της και δεν γίνονται περαιτέρω παραδόσεις. Τα webhooks που έχουν ρυθμιστεί στον πίνακα ελέγχου δεν διαγράφονται ποτέ αυτόματα· για αυτά το 410 είναι μια συνηθισμένη αποτυχία. Οποιοδήποτε άλλο σφάλμα επαναπροσπαθείται και τελικά απενεργοποιεί το webhook, όπως περιγράφεται στο Πώς Λειτουργεί & Διαχείριση Επαναπροσπαθειών.

## Πίνακας ελέγχου

Οι συνδρομές API εμφανίζονται στη σελίδα Webhooks κάτω από το domain για το οποίο δημιουργήθηκαν, όπου ένας διαχειριστής μπορεί να τις απενεργοποιήσει, να τις ενεργοποιήσει ξανά ή να τις διαγράψει.
