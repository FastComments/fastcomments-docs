Уебкуките също могат да се управляват чрез REST API. По този начин интеграции като Zapier се абонират за събития от коментари, без да докосват таблото, и следват шаблона REST Hooks: абониране, получаване на събития, отписване.

API абонаментите съжителстват с уебкуките, конфигурирани в таблото. Събитие от коментар се доставя на уебкука в таблото за нейния домейн и на всеки съвпадащ API абонамент, всеки като отделна доставка. Няма ограничение от един абонат за събитие.

## Удостоверяване

Всеки заявка изисква вашия API ключ в заглавието `x-api-key` (или като параметър `API_KEY` в заявката) и вашия идентификатор на наемател в параметъра `tenantId`. И двете се показват на страницата API Secret в таблото.

## Абониране

```
POST https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
x-api-key: YOUR_API_KEY
Content-Type: application/json

{
    "url": "https://hooks.zapier.com/hooks/catch/123/abc",
    "event": "comment-created"
}
```

| Поле | Задължително | Описание |
|-------|----------|-------------|
| `url` | Yes | Абсолютен http или https URL. |
| `event` | Yes | `comment-created`, `comment-updated` или `comment-deleted`. |
| `domain` | No | Домейн от конфигурацията на вашия акаунт. По подразбиране е `*`, което получава събития за всеки домейн. |
| `method` | No | `POST` (по подразбиране), `PUT` или `DELETE`. |

Отговорът съдържа абонамента:

```json
{
    "status": "success",
    "webhook": {
        "id": "66f1c4c1e7a2b3d4f5a6b7c8",
        "url": "https://hooks.zapier.com/hooks/catch/123/abc",
        "event": "comment-created",
        "domain": "*",
        "method": "POST",
        "source": "api",
        "enabled": true,
        "createdAt": "2026-09-08T12:00:00.000Z"
    }
}
```

Абонирането на същия URL за същото събитие и домейн отново връща съществуващия абонамент, вместо да създава дубликат, така че клиентът може безопасно да опита отново. Всеки наемател може да има до 50 API абонамента.

## Списък

```
GET https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
```

Връща всяка уебкука за наемателя, включително тези, управлявани в таблото (`"source": "dashboard"`).  
Филтрирайте с `event`, `domain` или `source`.

## Отписване

```
DELETE https://fastcomments.com/api/v1/webhooks/SUBSCRIPTION_ID?tenantId=YOUR_TENANT_ID
```

Изтриването на абонамент също премахва всички събития, които все още са в опашка за него. Само абонаменти, създадени чрез API, могат да се изтриват по този начин. Уебкуките в таблото се редактират на страницата Webhooks.

## Полезни товари и подписване

Доставките използват същия полезен товар като уебкуките в таблото (виж Data Structures) и са подписани със същата HMAC схема (виж Security & API Tokens). API абонаментите никога не получават наследения заглавен `token`, затова проверявайте заглавието `X-FastComments-Signature`.

## Отговор с 410 Gone

Ако крайният пункт на API абонамент отговори с HTTP `410 Gone`, FastComments го счита за отписване: абонаментът се изтрива заедно с опашката от събития и не се правят повече доставки. Уебкуките, конфигурирани в таблото, никога не се изтриват автоматично; за тях 410 е обикновена грешка. Всеки друг статус на грешка се опитва отново и в крайна сметка деактивира уебкуката, както е описано в How it Works & Handling Retries.

## Табло

API абонаментите се показват на страницата Webhooks под домейна, за който са създадени, където администраторът може да ги деактивира, активира отново или изтрие.
