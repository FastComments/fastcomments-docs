FastComments поддерживает вебхуки только для ресурса Comment.

Мы поддерживаем вебхуки для создания комментариев, их удаления и обновления.

Каждое из этих действий считается отдельным событием в нашей системе, поэтому у вебхуков разных событий разные семантика и структура.

Любое количество конечных точек может подписаться на одно и то же событие, через панель управления или через API (см. Управление вебхуками через API). Каждый вебхук доставляется независимо.
