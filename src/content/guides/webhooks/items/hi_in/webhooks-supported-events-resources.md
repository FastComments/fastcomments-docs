FastComments केवल Comment रिसोर्स के लिए webhooks का समर्थन करता है।

हम कमेंट बनाने, हटाने और अपडेट होने पर webhooks का समर्थन करते हैं।

इनमें से प्रत्येक को हमारे सिस्टम में अलग-अलग इवेंट माना जाता है और इसलिए webhook इवेंट्स के लिए इनकी अलग-अलग semantics और संरचनाएँ होती हैं।

कोई भी संख्या में endpoints एक ही इवेंट की सदस्यता ले सकते हैं, चाहे dashboard से या API के माध्यम से (Managing Webhooks via the API देखें)। प्रत्येक webhook स्वतंत्र रूप से डिलीवर किया जाता है।
