कमेंट ऑब्जेक्ट में सिस्टम में होने वाले सभी बदलाव एक इवेंट सक्रिय करते हैं जो एक क्यू (queue) में जाता है।

प्रारंभिक वेबहुक इवेंट आमतौर पर इवेंट स्रोत के घटित होने के छह सेकंड के भीतर भेजा जाता है।

आप अपने API के डाउन होने की स्थिति में Webhooks एडमिन में इस क्यू की निगरानी कर सकते हैं।

यदि आपके API को भेजा गया अनुरोध विफल हो जाता है, तो हम इसे एक शेड्यूल के अनुसार फिर से क्यू में डाल देंगे।

वह शेड्यूल है `1 Minute * the retry count`। यदि कॉल एक बार विफल होती है, तो यह एक मिनट में फिर से प्रयास करेगी। यदि यह दो बार विफल होती है, तो यह दो मिनट प्रतीक्षा करेगी, और इसी तरह आगे भी। ऐसा इसलिए है ताकि यदि आपका API लोड संबंधी कारणों से डाउन हो रहा हो, तो हम उसे ओवरलोड न करें।
