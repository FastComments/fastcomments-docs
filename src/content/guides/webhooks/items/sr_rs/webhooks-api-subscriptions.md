Webhooks се такође могу управљати преко REST API‑ја. Ово је начин на који интеграције попут Zapier‑а претплаћу догађаје коментара без коришћења контролне табле, и прати шаблон REST Hooks: претплата, примање догађаја, одпис.

API претплате живе паралелно са вебхуковима конфигурисаним у контролној табли. Догађај коментара се испоручује вебхуку контролне табле за његов домен и свакој API претплати која се поклапа, свака као посебна испорука. Не постоји ограничење од једног претплатника по догађају.

## Аутентикација

Сваки захтев захтева ваш API кључ у заглављу `x-api-key` (или у параметру упита `API_KEY`) и ваш tenant ID у параметру упита `tenantId`. Оба су приказана на страници API тајне у контролној табли.

## Претплата

```
POST https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
x-api-key: YOUR_API_KEY
Content-Type: application/json

{
    "url": "https://hooks.zapier.com/hooks/catch/123/abc",
    "event": "comment-created"
}
```

| Поље | Обавезно | Опис |
|-------|----------|------|
| `url` | Да | Апсолутни http или https URL. |
| `event` | Да | `comment-created`, `comment-updated` или `comment-deleted`. |
| `domain` | Не | Домен из конфигурације вашег налога. Подразумевано је `*`, који прима догађаје за сваки домен. |
| `method` | Не | `POST` (подразумевано), `PUT` или `DELETE`. |

Одговор садржи претплату:

```json
{
    "status": "success",
    "webhook": {
        "id": "66f1c4c1e7a2b3d4f5a6b7c8",
        "url": "https://hooks.zapier.com/hooks/catch/123/abc",
        "event": "comment-created",
        "domain": "*",
        "method": "POST",
        "source": "api",
        "enabled": true,
        "createdAt": "2026-09-08T12:00:00.000Z"
    }
}
```

Претплата на исти URL за исти догађај и домен поново враћа постојећу претплату уместо креирања дупликата, тако да клијент може безбедно поново покушати. Сваки корисник (тенант) може имати до 50 API претплата.

## Листа

```
GET https://fastcomments.com/api/v1/webhooks?tenantId=YOUR_TENANT_ID
```

Враћа све вебхукове за тенанта, укључујући оне управљане у контролној табли (`"source": "dashboard"`).  
Филтрирајте помоћу `event`, `domain` или `source`.

## Отпис

```
DELETE https://fastcomments.com/api/v1/webhooks/SUBSCRIPTION_ID?tenantId=YOUR_TENANT_ID
```

Брисање претплате такође уклања све догађаје који су још у реду за њу. Само претплате креиране преко API‑ја могу се брисати на овај начин. Вебхукове у контролној табли уређује се на страници Вебхукова.

## Тела захтева и потпис

Испоруке користе исти телесни садржај као вебхукови у контролној табли (види Структуре података) и потписане су истим HMAC шемом (види Безбедност & API токене). API претплате никада не примају наследни `token` заглавље, па проверите `X-FastComments-Signature` заглавље уместо тога.

## Одговор са 410 Gone

Ако крајња тачка API претплате одговори HTTP `410 Gone`, FastComments то сматра одписом: претплата се брише заједно са догађајима у реду, и даље испоруке се не покушавају. Вебхукови конфигурисани у контролној табли се никада аутоматски не бришу; за њих 410 представља обичан неуспех. Сваки други статус неуспеха се поново покушава и на крају онемогућава вебхук, као што је описано у Како ради & Управљање поновним покушајима.

## Контролна табла

API претплате су наведене на страници Вебхукова испод домена за који су креиране, где администратор може онемогућити, поново омогућити или их обрисати.
