Avec FastComments, de nombreux utilisateurs peuvent être ajoutés à votre locataire, et leurs autorisations peuvent être configurées en fonction des rôles de votre  
organisation.

[app-screenshot-start url='/auth/my-account/users/new/edit'; selector = '.account-block'; alt='Formulaire d\'ajout d\'un utilisateur à votre locataire, avec des options d\'autorisation pour son rôle'; title='Ajout d\'un utilisateur' app-screenshot-end]

Les utilisateurs peuvent être ajoutés via cette interface. Si vous avez de nombreux utilisateurs, nous pouvons les importer pour vous [via le support client](https://fastcomments.com/auth/my-account/help).

Pour ajouter des modérateurs, consultez [la documentation correspondante](/guide-moderation.html#moderators-adding).

### Une note sur l'authentification

Vos utilisateurs peuvent chercher un endroit où saisir leur mot de passe. FastComments utilise "magic links" pour se connecter – aucun mot de passe n'est requis.
