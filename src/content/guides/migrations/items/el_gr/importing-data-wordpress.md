Το [Πρόσθετο WordPress](https://wordpress.org/plugins/fastcomments/) διαθέτει έναν ισχυρό μηχανισμό εισαγωγής βασισμένο σε UI. Μετά την εγκατάσταση του πρόσθετου,
θα σας καθοδηγήσει στη σύνδεση της εγκατάστασης WordPress με το FastComments και στην αντιγραφή των υπαρχόντων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς να χρειάζεται να αντιγράψετε ή να κατεβάσετε κάτι χειροκίνητα.**

Η διαδικασία μετανάστευσης θα σας υποδειχθεί μέσω του UI κατά τη διάρκεια της μετανάστευσης. Οι περισσότερες μεταναστεύσεις διαρκούν μόνο λίγα λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβαρύνει υπερβολικά την εγκατάσταση WordPress κατά τη διάρκεια της μετανάστευσης.

Αν μετακινείτε τον ιστότοπό σας εκτός του WordPress, μπορείτε να εισάγετε ένα εξαγόμενο αρχείο XML ή CSV του WordPress αντί να χρησιμοποιήσετε το πρόσθετο. Δείτε
[Μεταφορά των Σχολίων σας σε Νέο Site](/guide-installation-wordpress.html#wordpress-moving-off-wordpress).

### CloudFlare & FireWalls

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να κάνουμε κλήσεις στην εγκατάστασή σας.
Τείχη προστασίας όπως το Cloudflare μπορεί να μας μπλοκάρουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να σας παρέχουμε](https://fastcomments.com/auth/my-account/help) ένα σύνολο IP για whitelist για την ενσωμάτωση.

### Data Ownership

Στην περίπτωση της μετανάστευσης WordPress, οποιαδήποτε νέα ή ενημερωμένη δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια εξυπηρετούνται από το FastComments για να μειώσουν το φορτίο της εγκατάστασής σας,
εμείς **επίσης** τα αποθηκεύουμε στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό επίσης σημαίνει ότι αν θέλετε να απομακρυνθείτε από το FastComments, τα δεδομένα σας
είναι ήδη μεταναστευμένα και ενημερωμένα.
