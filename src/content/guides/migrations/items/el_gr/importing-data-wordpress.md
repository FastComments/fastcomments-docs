Το [WordPress Plugin](https://wordpress.org/plugins/fastcomments/) μας διαθέτει έναν ισχυρό μηχανισμό εισαγωγής βασισμένο σε UI. Κατά την εγκατάσταση του plugin,
σας καθοδηγεί στη σύνδεση της εγκατάστασης WordPress σας με το FastComments και στη μεταφορά των υφιστάμενων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς να αντιγράψετε ή να κατεβάσετε τίποτα χειροκίνητα.**

Η διαδικασία μετεγκατάστασης θα σας υποδεικνύεται μέσω του UI κατά τη διάρκεια της μετεγκατάστασης. Οι περισσότερες μετεγκαταστάσεις διαρκούν μόνο μερικά λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβαρύνει υπερβολικά την εγκατάσταση WordPress σας κατά τη διάρκεια της μετεγκατάστασης.

Αν μεταφέρετε τον ιστότοπό σας εκτός WordPress, μπορείτε να εισαγάγετε μια εξαγωγή WordPress XML ή CSV αντί να χρησιμοποιήσετε το plugin. Δείτε το
[Moving Your Comments to a New Site](/guide-installation-wordpress.html#wordpress-moving-off-wordpress).

### CloudFlare & FireWalls

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να πραγματοποιούμε κλήσεις στην εγκατάσταση WordPress σας.
Τείχη προστασίας όπως το Cloudflare ενδέχεται να μας μπλοκάρουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να σας παρέχουμε](https://fastcomments.com/auth/my-account/help) μια λίστα IP για whitelist για την ενσωμάτωση.

### Ιδιοκτησία Δεδομένων

Στην περίπτωση της μετεγκατάστασης WordPress, τυχόν νέα ή ενημερωμένα δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress σας
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια σερβίρονται από το ίδιο το FastComments για να αφαιρεθεί το φορτίο από την ανάπτυξη WordPress σας,
τα αποθηκεύουμε **επίσης** στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό σημαίνει επίσης ότι αν επιθυμείτε να απομακρυνθείτε από το FastComments, τα δεδομένα σας
έχουν ήδη μεταφερθεί και είναι ενημερωμένα.
