Το [WordPress Plugin](https://wordpress.org/plugins/fastcomments/) μας διαθέτει έναν ισχυρό μηχανισμό εισαγωγής με βάση το UI. Μετά την εγκατάσταση του plugin,
θα σας καθοδηγήσει στη σύνδεση της εγκατάστασης WordPress σας με το FastComments και στην αντιγραφή των υφιστάμενων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς χειροκίνητη αντιγραφή ή λήψη οτιδήποτε.**

Η διαδικασία μετεγκατάστασης θα σας υποδεικνύεται μέσω του UI κατά τη διάρκεια της μετεγκατάστασης. Οι περισσότερες μετεγκαταστάσεις διαρκούν μόνο μερικά λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβάλλει υπερβολικό φορτίο στην εγκατάσταση WordPress σας κατά τη διάρκεια της μετεγκατάστασης.

Αν μεταφέρετε τον ιστότοπό σας εκτός WordPress, μπορείτε να εισαγάγετε μια εξαγωγή WordPress XML ή CSV αντί να χρησιμοποιήσετε το plugin. Δείτε το
[Moving Your Comments to a New Site](/guide-installation-wordpress.html#wordpress-moving-off-wordpress).

### CloudFlare & FireWalls

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να πραγματοποιούμε κλήσεις στην εγκατάσταση WordPress σας.
Τείχη προστασίας όπως το Cloudflare ενδέχεται να μας αποκλείσουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να σας
παρέχουμε](https://fastcomments.com/auth/my-account/help) ένα σύνολο IP για να προσθέσετε στη λίστα επιτρεπόμενων για την ενσωμάτωση.

### Ιδιοκτησία Δεδομένων

Στην περίπτωση της μετεγκατάστασης WordPress, τυχόν νέα ή ενημερωμένα δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress σας
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια σερβίρονται από το ίδιο το FastComments για να ανακουφιστεί το φορτίο της ανάπτυξης WordPress σας,
τα αποθηκεύουμε **επίσης** στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό σημαίνει επίσης ότι αν επιθυμείτε να αποχωρήσετε από το FastComments, τα δεδομένα σας
έχουν ήδη μετεγκατασταθεί και είναι ενημερωμένα.
