Το [Πρόσθετο WordPress](https://wordpress.org/plugins/fastcomments/) διαθέτει έναν ισχυρό μηχανισμό εισαγωγής βασισμένο σε UI. Μετά την εγκατάσταση του πρόσθετου,
θα σας καθοδηγήσει στη σύνδεση της εγκατάστασης WordPress με το FastComments και στην αντιγραφή των υπαρχόντων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς να χρειαστεί να αντιγράψετε ή να κατεβάσετε κάτι χειροκίνητα.**

Η διαδικασία μετεγκατάστασης θα σας υποδεικνύεται μέσω του UI κατά τη διάρκεια της μετεγκατάστασης. Οι περισσότερες μετεγκαταστάσεις διαρκούν μόνο λίγα λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβαρύνει υπερβολικά την εγκατάσταση WordPress σας κατά τη διάρκεια της μετεγκατάστασης.

### CloudFlare & FireWalls

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να κάνουμε κλήσεις στην εγκατάσταση WordPress σας.
Τείχη προστασίας όπως το Cloudflare μπορεί να μας μπλοκάρουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να παρέχουμε
σας](https://fastcomments.com/auth/my-account/help) με ένα σύνολο IP για whitelist στην ενσωμάτωση.

### Data Ownership

Στην περίπτωση της μετεγκατάστασης WordPress μας, οποιαδήποτε νέα ή ενημερωμένα δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress σας
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια εξυπηρετούνται από το FastComments για να μειώσουν το φορτίο της εγκατάστασης WordPress σας,
εμείς **επίσης** τα αποθηκεύουμε στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό επίσης σημαίνει ότι αν θέλετε να μεταβείτε μακριά από το FastComments, τα δεδομένα σας
είναι ήδη μεταφερμένα και ενημερωμένα.
