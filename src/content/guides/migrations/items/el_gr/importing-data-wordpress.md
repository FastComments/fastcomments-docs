Our [Πρόσθετο WordPress](https://wordpress.org/plugins/fastcomments/) έχει έναν ισχυρό μηχανισμό εισαγωγής βασισμένο σε UI. Κατά την εγκατάσταση του πρόσθετου,
θα σας καθοδηγήσει στη σύνδεση της εγκατάστασης WordPress με το FastComments και στην αντιγραφή των υπάρχοντων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς να χρειαστεί να αντιγράψετε ή να κατεβάσετε κάτι χειροκίνητα.**

Η διαδικασία μετανάστευσης θα σας υποδεικνύεται μέσω του UI κατά τη διάρκεια της μετανάστευσης. Οι περισσότερες μεταναστεύσεις διαρκούν μόνο λίγα λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβαρύνει υπερβολικά την εγκατάσταση WordPress σας κατά τη διάρκεια της μετανάστευσης.

Αν μετακινείτε τον ιστότοπό σας εκτός WordPress, μπορείτε να εισάγετε ένα εξαγόμενο αρχείο XML ή CSV του WordPress αντί να χρησιμοποιήσετε το πρόσθετο. Δείτε
[Μεταφορά Σχολίων σε Νέο Site](/guide-installation-wordpress.html#wordpress-moving-off-wordpress).

### CloudFlare & Τείχη προστασίας

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να κάνουμε κλήσεις στην εγκατάσταση WordPress σας.
Τείχη προστασίας όπως το Cloudflare μπορεί να μας μπλοκάρουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να σας παρέχουμε](https://fastcomments.com/auth/my-account/help) ένα σύνολο IP για whitelist στην ενσωμάτωση.

### Ιδιοκτησία Δεδομένων

Στην περίπτωση της μετανάστευσης WordPress, οποιαδήποτε νέα ή ενημερωμένη δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress σας
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια εξυπηρετούνται από το FastComments για να μειώσουν το φορτίο της εγκατάστασης WordPress,
**επίσης** τα αποθηκεύουμε στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό επίσης σημαίνει ότι αν θέλετε να απομακρυνθείτε από το FastComments, τα δεδομένα σας
είναι ήδη μεταναστευμένα και ενημερωμένα.
