Το [WordPress Plugin](https://wordpress.org/plugins/fastcomments/) διαθέτει έναν ισχυρό μηχανισμό εισαγωγής βασισμένο σε UI. Μετά την εγκατάσταση του plugin,
θα σας καθοδηγήσει στη σύνδεση της εγκατάστασης WordPress με το FastComments και στην αντιγραφή των υπαρχόντων δεδομένων σχολίων σας.

**Αυτό γίνεται χωρίς να χρειαστεί να αντιγράψετε ή να κατεβάσετε κάτι χειροκίνητα.**

Η διαδικασία μετεγκατάστασης θα σας υποδεικνύεται μέσω του UI κατά τη διάρκεια της μετεγκατάστασης. Οι περισσότερες μετεγκαταστάσεις διαρκούν μόνο λίγα λεπτά.

Ο μηχανισμός έχει σχεδιαστεί ώστε να μην επιβαρύνει υπερβολικά την εγκατάστασή σας WordPress κατά τη διάρκεια της μετεγκατάστασης.

Αν μετακινείτε τον ιστότοπό σας εκτός WordPress, μπορείτε να εισάγετε ένα εξαγόμενο αρχείο WordPress XML ή CSV αντί να χρησιμοποιήσετε το plugin. Δείτε
[Moving Your Comments to a New Site](/guide-installation-wordpress.html#wordpress-moving-off-wordpress).

### CloudFlare & FireWalls

Για να λειτουργήσει η αυτοματοποιημένη ρύθμιση του WordPress, πρέπει να κάνουμε κλήσεις στην εγκατάστασή σας WordPress.
Τείχη προστασίας όπως το Cloudflare μπορεί να μας μπλοκάρουν και να προκαλέσουν αποτυχία της ενσωμάτωσης. Σε τέτοιες περιπτώσεις, [μπορούμε να σας παρέχουμε](https://fastcomments.com/auth/my-account/help) ένα σύνολο IP για whitelist στην ενσωμάτωση.

### Data Ownership

Στην περίπτωση της μετεγκατάστασης WordPress, οποιαδήποτε νέα ή ενημερωμένα δεδομένα σχολίων συγχρονίζονται αυτόματα πίσω στην εγκατάσταση WordPress
στο παρασκήνιο. Αυτό σημαίνει ότι, ενώ τα σχόλια εξυπηρετούνται από το FastComments για να μειώσουν το φορτίο της εγκατάστασής σας WordPress,
εμείς **επίσης** τα αποθηκεύουμε στη βάση δεδομένων σας ως αντίγραφο ασφαλείας. Αυτό επίσης σημαίνει ότι αν θέλετε να μεταβείτε μακριά από το FastComments, τα δεδομένα σας
είναι ήδη μεταφερμένα και ενημερωμένα.
