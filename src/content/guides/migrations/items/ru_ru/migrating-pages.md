Хотя его название — инструмент миграции доменов, его также можно использовать для переноса комментариев между отдельными страницами.

Просто введите старые и новые значения [urlId](/guide-customizations-and-configuration.html#url-id) в поля ввода `from` и `to`.

### Перенос страниц через API

Чтобы перенести множество страниц за один раз, используйте [`POST /api/v1/pages/migrations`](/guide-api.html#pages-migrations-post). Он принимает до 100 пар `from` и `to` за запрос и выполняет их как пакетную задачу.

Если `type` установлен в `urlId`, перемещается только страница, у которой `urlId` точно совпадает с `from`, поэтому `post-1` не совпадает с `post-10`. Инструмент в панели управления не имеет этой опции.

Каждую миграцию API можно отменить в течение 90 дней с помощью [`POST /api/v1/pages/migrations/:undoId/undo`](/guide-api.html#pages-migrations-undo-post).
