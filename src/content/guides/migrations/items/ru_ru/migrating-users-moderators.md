С FastComments к вашему арендатору можно добавить множество пользователей, а их разрешения можно настроить в соответствии с ролями в вашем  
организации.

[app-screenshot-start url='/auth/my-account/users/new/edit'; selector = '.account-block'; alt='Форма нового пользователя для добавления кого‑то в ваш арендатор, с параметрами разрешений для их роли'; title='Adding a User' app-screenshot-end]

Пользователи могут быть добавлены через этот интерфейс. Если у вас много пользователей, мы можем импортировать их для вас [через службу поддержки клиентов](https://fastcomments.com/auth/my-account/help).

Для добавления модераторов см. [соответствующую документацию](/guide-moderation.html#moderators-adding).

### Примечание об аутентификации

Ваши пользователи могут искать место для ввода пароля. FastComments использует «магические ссылки» для входа — пароли не требуются.
