FastComments предоставляет автоматизированный способ миграции ваших комментариев между доменами.

Для миграции доменов требуется лишь домен `from` и домен `to`.

Это **перемещает** комментарии, а не копирует их. Если вы хотите скопировать комментарии, свяжитесь с нами.

[app-screenshot-start url='/auth/my-account/manage-data/migrate-domains?demo=true'; linkUrl='/auth/my-account/manage-data/migrate-domains'; selector = '.content'; alt='Инструмент миграции доменов с полями from и to и количеством перемещённых комментариев'; title='Миграция доменов' app-screenshot-end]

Это также полезно, например, если часть вашей миграции на FastComments включает миграцию с другого провайдера, поэтому импортируемые данные комментариев могут содержать данные, которые необходимо мигрировать. В этом случае вы можете выполнить импорт, а затем миграцию доменов.

### Мониторинг прогресса

Инструмент миграции доменов использует ту же систему обработки задач FastComments, что и другие инструменты управления данными.

Может быть задержка перед началом вашей миграции. Это нормально, так как система периодически проверяет наличие новых задач для обработки.

Во время выполнения задачи она будет отображать количество найденных для миграции комментариев и количество уже перемещённых.

### Миграция доменов через API

Домены также можно мигрировать с помощью [`POST /api/v1/pages/migrations`](/guide-api.html#pages-migrations-post), задав `type` со значением `domain`. Прогресс доступен через [`GET /api/v1/batch-jobs/:id`](/guide-api.html#batch-job-get-by-id), и миграцию можно отменить в течение 90 дней.
