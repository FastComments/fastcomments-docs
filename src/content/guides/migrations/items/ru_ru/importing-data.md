Хотя служба поддержки FastComments может помочь с миграциями, большинство из них можно выполнить и контролировать без какого-либо вмешательства со стороны сотрудников поддержки.

Мы нативно поддерживаем импорт экспорта из следующих провайдеров:

- Commento
- Disqus
- Hyvor Talk
- Muut Comments
- IntenseDebate
- Just-Comments
- Cusdis
- WordPress (via the plugin, or an XML or CSV export)
- AnyComment (Via WordPress Import/Export)

Перейдя по [here](https://fastcomments.com/auth/my-account/manage-data/import) мы можем загрузить файл, содержащий данные для миграции.

### Monitoring Imports

FastComments использует систему обработки задач для выполнения импортов и экспортов. Как только система захватит вашу задачу, она будет периодически сообщать о статусе задачи в пользовательском интерфейсе импорта или экспорта.

[app-screenshot-start url='/auth/my-account/manage-data/import?demo=true'; selector = '.content'; alt='Страница импорта, показывающая запущенную задачу импорта и статус, сообщаемый системой обработки задач'; title='Статус задачи импорта' app-screenshot-end]

Обратите внимание, что статус импортов импорта и экспорта виден всем администраторам учетной записи.

Если ваша задача завершится с ошибкой, она не будет автоматически перезапущена. Импорт придется попытаться выполнить снова. Если любой импорт или экспорт завершится с ошибкой, наши системные администраторы будут автоматически уведомлены. Если мы обнаружим проблему, мы свяжемся с вами, чтобы узнать, можем ли мы помочь.

### Re-Running The Import

Во время некоторых миграций необходимо запускать импорт несколько раз. Например, часто делают первую проходную миграцию для тестирования, а затем снова запускают импорт с актуальными данными перед окончательным переключением.

Повторный импорт того же контента **не создаст дубликаты**.

### Data Security and Expiration

Файлы импорта недоступны через внешние запросы никаким способом, и файлы импорта удаляются из нашей системы сразу после завершения импорта.
