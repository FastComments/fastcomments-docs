While FastComments Support может помочь с миграциями, большинство из них можно выполнить и контролировать без какого‑либо вмешательства персонала поддержки.

Мы нативно поддерживаем импорт экспорта из следующих провайдеров:

- Commento
- Disqus
- Hyvor Talk
- Muut Comments
- IntenseDebate
- Just-Comments
- Cusdis
- WordPress (через плагин)
- AnyComment (через импорт/экспорт WordPress)

Перейдя по [здесь](https://fastcomments.com/auth/my-account/manage-data/import) вы можете загрузить файл, содержащий данные для миграции.

### Мониторинг импортов

FastComments использует систему обработки задач для выполнения импортов и экспортов. Как только система подхватит вашу задачу, она будет периодически отображать статус задачи в пользовательском интерфейсе импорта или экспорта.

[app-screenshot-start url='/auth/my-account/manage-data/import?demo=true'; selector = '.content'; title='Статус задания импорта' app-screenshot-end]

Обратите внимание, что статус импортов и экспортов виден всем администраторам аккаунта.

Если ваша задача завершится с ошибкой, она не будет автоматически перезапущена. Импорт придётся попытаться выполнить заново. Если любой импорт или экспорт завершится с ошибкой, наши системные администраторы будут автоматически уведомлены. Если мы обнаружим проблему, мы свяжемся с вами, чтобы узнать, можем ли мы помочь.

### Повторный запуск импорта

В некоторых миграциях необходимо запускать импорт несколько раз. Например, часто сначала проводят пробный импорт для тестирования, а затем повторно запускают импорт с актуальными данными перед окончательным переключением.

Повторный импорт того же контента **не создаст дубликаты**.

### Безопасность данных и срок хранения

Файлы импорта недоступны через внешние запросы каким‑либо способом, и файлы импорта удаляются из нашей системы сразу после завершения импорта.
