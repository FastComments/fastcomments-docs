Mit FastComments können viele Benutzer zu Ihrem Mandanten hinzugefügt werden, und ihre Berechtigungen können basierend auf den Rollen in Ihrer Organisation eingerichtet werden.

[app-screenshot-start url='/auth/my-account/users/new/edit'; selector = '.account-block'; alt='Neues Benutzerformular zum Hinzufügen einer Person zu Ihrem Mandanten, mit Berechtigungsoptionen für deren Rolle'; title='Hinzufügen eines Benutzers' app-screenshot-end]

Benutzer können über diese UI hinzugefügt werden. Wenn Sie viele Benutzer haben, können wir sie für Sie [über den Kundensupport](https://fastcomments.com/auth/my-account/help) importieren.

Zum Hinzufügen von Moderatoren siehe [die entsprechende Dokumentation](/guide-moderation.html#moderators-adding).

### Hinweis zur Authentifizierung

Ihre Benutzer suchen möglicherweise nach einer Möglichkeit, ihr Passwort einzugeben. FastComments verwendet "magic links" für die Anmeldung – es werden also keine Passwörter benötigt.
