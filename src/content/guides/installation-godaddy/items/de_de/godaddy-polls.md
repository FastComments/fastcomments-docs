Sobald FastComments auf Ihrer Godaddy‑Website installiert ist, können Sie auch Live‑Umfragen direkt in den Kommentaren durchführen. Aktivieren Sie **Enable Polls** in den Einstellungen zur Widget‑Anpassung, und ein Umfrage‑Button erscheint in der Kommentar‑Symbolleiste. Umfragen können 2 bis 10 Optionen enthalten, die Ergebnisse werden live für alle Besucher der Seite aktualisiert, und Sie entscheiden, wer Umfragen erstellen darf und ob das Abstimmen eine Anmeldung erfordert. Es muss sonst nichts weiter auf Godaddy installiert werden.

[Try the Live Polls demo](https://fastcomments.com/product/live-polls) or read the [Polls documentation](/guide-polls.html) to set them up.
