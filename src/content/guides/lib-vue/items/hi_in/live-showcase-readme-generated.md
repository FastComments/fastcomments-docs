सार्वजनिक `demo` टेनेंट के विरुद्ध लोकल रूप से चलने वाले हर विजेट और फ्लो को देखने के लिए, रिपॉजिटरी क्लोन करें और चलाएँ:

```bash
npm install
npm run serve
```

अलग-अलग डेमो के अपने एंट्री पॉइंट भी हैं (`npm run serve-collab-chat`, `serve-live-chat`, `serve-image-chat`, `serve-pagination`, `serve-toggle-dark-mode`) जो `dev/` के अंतर्गत हैं।
