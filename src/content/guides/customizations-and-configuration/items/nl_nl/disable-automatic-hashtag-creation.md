Wanneer gebruikers hashtags invoeren, in de vorm van `#someexampletag`, zal FastComments automatisch die `HashTag` aanmaken en deze in hun reactie markeren.

In sommige gevallen is het wenselijk om deze functie uit te schakelen, of om te bepalen welke hashtags via de API kunnen worden gebruikt.

Doe dit door simpelweg `Disable Automatic #hashtag Creation` in te schakelen via de Widget Customization UI.
