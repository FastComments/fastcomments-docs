Standaard zal FastComments links weergeven zoals dit: [https://exmaple.com](https://exmaple.com) - waarbij de link-URL een klikbare HTML-anker-tag wordt.

Sommige sites willen dit mogelijk uitschakelen, bijvoorbeeld om oplichters te ontmoedigen. We bieden dit door de `Comment HTML Rendering Option` in te stellen op `Links as Text`.

Dit kan zonder code worden aangepast, op de widget-aanpassingspagina, voor een heel domein of een pagina:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.show-advanced-option']; selector = '.comment-html-rendering-mode'; alt='Comment HTML Rendering Option ingesteld op Links as Text onder Geavanceerde Opties in widget-aanpassing'; title='Render Links als Tekst' app-screenshot-end]
