Standaard wordt er geen zoekvak weergegeven in de commentaarwidget.

We kunnen dit echter inschakelen door de **enableSearch**-vlag op true te zetten:

[code-example-start config = {enableSearch: true}; linesToHighlight = [6]; title = 'Zoeken inschakelen'; code-example-end]

Dit kan ook zonder code. Op de widget-aanpassingspagina, zie de "Enable Search Box" optie.
