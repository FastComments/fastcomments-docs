Enige tekst, zoals een header of bericht, kan worden weergegeven onder het aantal reacties maar boven de tekst van de loginstatus.

We noemen dit de header, en standaard is deze verborgen.

[code-example-start config = {headerHTML: "<h1>Leave a Comment!</h1>"}; linesToHighlight = [6]; title = 'Specifying Header HTML'; code-example-end]
