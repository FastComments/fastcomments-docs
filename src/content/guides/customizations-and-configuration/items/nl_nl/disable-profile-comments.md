Standaard toont FastComments een “Profielreacties” tabblad op gebruikersprofielen, waardoor bezoekers reacties kunnen achterlaten op iemands profiel.

We kunnen dit tabblad echter uitschakelen:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Profielreacties uitschakelen'; code-example-end]

Dit kan ook zonder code worden gedaan. Op de widget‑aanpassingspagina, zie de sectie “Profielreacties uitschakelen”.
