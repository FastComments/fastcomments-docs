Het aantal opmerkingen dat bovenaan de commentaarwidget wordt weergegeven, kan worden aangepast.

Dit kan worden vervangen door een willekeurige tekenreeks, en de waarde **[count]** wordt vervangen door de tellerwaarde, gelokaliseerd voor de gebruiker.

[code-example-start config = {commentCountFormat: "There are [count] comments."}; linesToHighlight = [6]; title = 'De tekst van het aantal opmerkingen aanpassen'; code-example-end]

Dit kan worden aangepast zonder code, op de widget-aanpassingspagina:
