Standaard toont FastComments een werkbalk bij het schrijven van een reactie om snelkoppelingen te bieden voor het opmaken van tekst en het uploaden
afbeeldingen.

Deze werkbalk kan worden uitgeschakeld in code of via de Aanpassings-UI.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'De werkbalk uitschakelen'; code-example-end]

Dit kan ook zonder code worden gedaan. Op de widget-aanpassingspagina, zie de optie "Disable The Reply Toolbar".
