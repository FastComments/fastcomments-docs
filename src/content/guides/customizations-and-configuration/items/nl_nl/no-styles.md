Voor grotere projecten met aangepaste styling kan het wenselijk zijn om met een schone lei te beginnen en de standaardstyling helemaal niet te gebruiken.

Alle standaardstyling kan worden verwijderd door de **noStyles**-parameter op true te zetten, als volgt:

[code-example-start config = {noStyles: true}; linesToHighlight = [6]; title = 'Uitschakelen van alle standaardstijlen'; code-example-end]

Dit kan zonder code worden aangepast op de widget-aanpassingspagina, onder Geavanceerde opties:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.show-advanced-option', '.disable-all-default-styling']; selector = '.disable-all-default-styling'; alt='Uitschakelen van alle standaardstyling selectievakje ingeschakeld onder Geavanceerde opties op de widget-aanpassingspagina'; title='Uitschakelen van alle standaardstijlen' app-screenshot-end]
