Standaard worden de opmaakfunctionaliteiten in FastComments gerealiseerd door zichtbare anker‑tags zoals `<b></b>` rond je tekst toe te voegen. Door op de werkbalk te klikken of sneltoetsen te gebruiken gebeurt dit automatisch. Sommige gemeenschappen willen echter de opmaak gebruiken zonder anker‑tags. Dit wordt het inschakelen van de WYSIWYG (what you see is what you get) editor genoemd. Deze editor ziet er precies hetzelfde uit als de standaardeditor, behalve dat er extra code wordt geladen die gebruikers in staat stelt tekst vet, onderstreept, enz. te maken zonder zichtbare anker‑tags.

Dit kan ook zonder code worden gedaan. Op de widget‑aanpassingspagina vind je de optie "Enable Advanced Formatting".
