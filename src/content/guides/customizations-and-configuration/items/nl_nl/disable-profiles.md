Standaard toont FastComments het profiel van de gebruiker wanneer je op de avatar klikt.

We kunnen deze functionaliteit echter uitschakelen:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Profielen uitschakelen'; code-example-end]

Dit kan ook zonder code worden gedaan. Op de widget‑aanpassingspagina, zie de sectie "Profielen uitschakelen".
