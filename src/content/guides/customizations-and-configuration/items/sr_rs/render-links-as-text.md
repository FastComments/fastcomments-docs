По подразумеваној поставци, FastComments ће приказивати линкове на следећи начин: [https://exmaple.com](https://exmaple.com) – где URL линка постаје кликљиви HTML anchor елемент.

Неки сајтови могу желети да ово онемогуће, на пример да би спречили преварнике. Ово обезбеђујемо поставком `Comment HTML Rendering Option` на `Links as Text`.

Ово се може прилагодити без кода, на страници за прилагођавање виџета, за цео домен или појединачну страницу:
