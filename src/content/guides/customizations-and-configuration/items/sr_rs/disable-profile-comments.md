Подразумевано, FastComments ће приказати језичак „Profile Comments“ на корисничким профилима, омогућавајући посетиоцима да оставе коментаре на нечиј профил.

Међутим, можемо онемогућити овај језичак:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Disable Profile Comments'; code-example-end]

Ово се ово такође може урадити без кода. На страници за прилагођавање виџета, погледајте одељак „Disable Profile Comments“.
