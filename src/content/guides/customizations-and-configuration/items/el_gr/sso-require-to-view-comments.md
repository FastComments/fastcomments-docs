FastComments SSO (<a href="#sso">λεπτομέρειες εδώ</a>) παρέχει στους χρήστες σας έναν τρόπο να σχολιάζουν χωρίς να χρειάζεται να συνδεθούν σε άλλη πλατφόρμα.

Ωστόσο, αυτό από μόνο του δεν ασφαλίζει τις αλληλουχίες σχολίων σας, καθώς από προεπιλογή τα δεδομένα των σχολίων είναι δημόσια διαθέσιμες πληροφορίες - όποιος μπορεί να δει τη σελίδα μπορεί να δει και τα σχόλια.

Αλλάζοντας μια ρύθμιση, μπορούμε να περιορίσουμε την ανάκτηση των σχολίων εκτός εάν γίνει από διαχειριστή ή έγκυρο χρήστη SSO.

#### Ρύθμιση χωρίς κώδικα

Μπορούμε να αποτρέψουμε την προβολή και την αλληλεπίδραση με τις αλληλουχίες σχολίων μας, όταν το SSO είναι ρυθμισμένο, δημιουργώντας έναν <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">κανόνα προσαρμογής</a>.

Κατά τη διαδικασία, αναζητήστε το SSO και θα βρείτε αυτήν την επιλογή:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.require-sso'; selector = '.require-sso'; alt='Απαιτείται SSO για την προβολή σχολίων, επιλογή ενεργοποιημένη σε κανόνα προσαρμογής, με επιλογή επιπέδου ασφαλείας'; title='Απαιτείται SSO για την προβολή σχολίων' app-screenshot-end]

Ενεργοποιήστε το και αποθηκεύστε τον κανόνα προσαρμογής.

#### Προστασία μόνο ενός συγκεκριμένου τομέα ή σελίδας

Για να προστατεύσετε μόνο έναν συγκεκριμένο τομέα ή σελίδα, θα ρυθμίσουμε απλώς τον κανόνα προσαρμογής ώστε να το κάνει.

Στην κορυφή του UI προσαρμογής, θα βρούμε δύο πεδία εισαγωγής, Domain και URL ID.

Για να προστατεύσετε μόνο έναν συγκεκριμένο τομέα, εισάγετε τον εν λόγω τομέα στο πεδίο "domain".

Για να προστατεύσετε μια συγκεκριμένη σελίδα, εισάγετε το URL της σελίδας στο πεδίο "URL ID". Εάν έχετε προσαρμοσμένη ενσωμάτωση με το FastComments, μπορείτε να εισάγετε έναν τύπο αναγνωριστικού εδώ αντί για URL.

#### Επίπεδα ασφαλείας

Κατά την απαίτηση SSO, θα θέλετε να αποφασίσετε αν απαιτείτε Simple SSO ή Secure SSO. Εάν απαιτήσετε Simple SSO, τότε και τα δύο επιτρέπονται, αλλά εάν απαιτήσετε Secure SSO, το περιεχόμενο πρέπει να ανακτηθεί με ένα Secure SSO payload που είναι κρυπτογραφημένο με το κλειδί API σας για να προβληθεί.

Η επιλογή επιπέδου ασφαλείας θα εμφανιστεί όταν επιλέξετε "Απαιτείται SSO για την προβολή σχολίων".

#### Προστασία πέρα από την ανάγνωση

Η ενεργοποίηση αυτής της επιλογής θα προστατεύσει τη σελίδα ή τον τομέα από το να σχολιαστεί, εκτός εάν ο χρήστης είναι συνδεδεμένος μέσω SSO.

#### Προβλήματα

Οποιοιδήποτε χρήστες που δημιούργησαν σχόλια πριν από την ενσωμάτωση του SSO δεν θα μπορούν να τα δουν, εκτός εάν συνδεθούν μέσω της ενσωμάτωσης SSO σας.
