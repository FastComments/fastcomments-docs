[related-parameter-start name = 'urlId'; type = 'string'; related-parameter-end]

Κατά την απόδοση μιας αλυσίδας σχολίων ή κατά την αφήγηση ενός σχολίου, το FastComments χρειάζεται να γνωρίζει σε ποια σελίδα, άρθρο ή προϊόν ανήκουν αυτά τα σχόλια.

Για να το πετύχουμε, χρησιμοποιούμε κάτι που ονομάζουμε «URL ID». Είναι είτε ένας αναγνωριστής, όπως μια συμβολοσειρά ή ένας αριθμός, είτε ένα URL.

Από προεπιλογή, εάν δεν καθορίσετε το urlId, θα γίνει το URL της σελίδας. Θα πάρουμε το τρέχον URL της σελίδας και θα το καθαρίσουμε για να αφαιρέσουμε τυχόν κοινές παραμέτρους μάρκετινγκ ή αναγνωριστικά παρακολούθησης.

Στην περίπτωση ενσωματώσεων τρίτων, όπως το WordPress, το πρόσθετό μας συνήθως χρησιμοποιεί τον αναγνωριστή που αντιπροσωπεύει τις τρέχουσες πληροφορίες που προβάλλονται ως URL ID, για παράδειγμα το αναγνωριστικό του άρθρου/σελίδας.

[code-example-start config = {urlId: 'https://example.com/page'}; linesToHighlight = [6]; title = 'Ορισμός προσαρμοσμένου URL ID'; code-example-end]

Ένα πράγμα στο οποίο θα αναφερόμαστε συχνά σε αυτό το έγγραφο είναι η <a href="https://fastcomments.com/auth/my-account/customize-widget/new">Διεπαφή Προσαρμογής Widget</a>.

Αυτή η διεπαφή μπορεί να χρησιμοποιηθεί για να κάνετε πολλές αλλαγές στο widget σχολίων χωρίς να γράψετε κώδικα.

Κατά τη δημιουργία ενός κανόνα προσαρμογής, συχνά θέλουμε να ισχύει για όλες τις σελίδες του ιστότοπού μας. Ωστόσο, σε ορισμένες περιπτώσεις θέλουμε να προσαρμόσουμε το widget σχολίων σε μια συγκεκριμένη σελίδα, είτε για να εφαρμόσουμε προσαρμοσμένο στυλ, είτε για να κάνουμε τα σχόλια για εκείνη τη σελίδα ανώνυμα. Μπορείτε επίσης, για παράδειγμα, να έχετε ζωντανά σχόλια να εμφανίζονται αμέσως σε ορισμένες σελίδες, ενώ να τα κρύβετε πίσω από κουμπιά ειδοποίησης σε άλλες.

Όλα αυτά είναι δυνατόν μέσω του πεδίου εισαγωγής URL ID σε αυτή τη σελίδα, το οποίο φαίνεται ως εξής:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.url-id'; alt='Πεδίο URL ID που χρησιμοποιείται για να περιορίσει έναν κανόνα προσαρμογής σε μία σελίδα, ή σε ένα μοτίβο όπως */blog/*'; title='Είσοδος URL ID στη Σελίδα Προσαρμογής Widget' app-screenshot-end]

Η τιμή σε αυτό το πεδίο πρέπει να ταιριάζει με την παράμετρο *urlId* που περνιέται στο widget σχολίων. Εάν θέλετε ο κανόνας προσαρμογής σας να είναι ανεξάρτητος από το *urlId*, αφήστε αυτό το πεδίο κενό ή εισάγετε *.

Από το 2023, το πεδίο `URL ID` στην προσαρμογή του widget δέχεται επίσης μοτίβα! Για παράδειγμα, μπορείτε να έχετε `*/blog/*` για να προσθέσετε στυλ ειδικά για το blog σας και `*/store/*` για να έχετε στυλ ειδικά για το κατάστημά σας, ενώ χρησιμοποιείτε τον ίδιο τομέα.

### Πιθανές παγίδες

1. Αν η σελίδα σας έχει παραμέτρους hash (π.χ. example.com#page-1) - αυτό θα γίνει μέρος του URL ID, από προεπιλογή.
2. Κατά τη διάρκεια μεταναστεύσεων, για παράδειγμα από WordPress σε Gatsby, μπορεί να χρειαστεί να μεταφέρετε τις τιμές σχολίων URL ID μετά την αρχική μεταφορά. Για αυτό, επικοινωνήστε μαζί μας.
