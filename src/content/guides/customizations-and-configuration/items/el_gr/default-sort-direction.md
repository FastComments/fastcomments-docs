[related-parameter-start name = 'defaultSortDirection'; type = 'string'; related-parameter-end]

Από προεπιλογή, το FastComments θα ταξινομεί τα σχόλια με τη διεύθυνση ταξινόμησης «Πιο Σχετικό».

Η ταξινόμηση Πιο Σχετικό λαμβάνει υπόψη το χρόνο που αφήθηκε το σχόλιο και τον αριθμό των ψήφων για την ταξινόμηση.

Ο χρήστης μπορεί στη συνέχεια να αλλάξει τη διεύθυνση ταξινόμησης είτε σε Παλαιότερα είτε σε Νεότερα Πρώτα στη διεπαφή του widget σχολίων.

Ωστόσο, μπορούμε να αλλάξουμε την προεπιλογή ώστε να είναι οποιαδήποτε από τις τρεις. Για παράδειγμα, αν θέλετε να εμφανίσετε πρώτα τα παλαιότερα σχόλια:

[code-example-start config = {defaultSortDirection: "OF"}; linesToHighlight = [6]; title = 'Αλλαγή της προεπιλεγμένης ταξινόμησης σε Παλαιότερα Πρώτα'; code-example-end]

Ορίζουμε την τιμή του **defaultSortDirection** σε "OF" για να ορίσουμε τη διεύθυνση σε "OF".

Για τη διεύθυνση ταξινόμησης νεότερα πρώτα, θα κάναμε το εξής:

[code-example-start config = {defaultSortDirection: "NF"}; linesToHighlight = [6]; title = 'Αλλαγή της προεπιλεγμένης ταξινόμησης σε Νεότερα Πρώτα'; code-example-end]

Οι έγκυρες τιμές για το **defaultSortDirection** είναι:

- MR: "Πιο Πρόσφατο"
- NF: "Νεότερα Πρώτα"
- OF: "Παλαιότερα Πρώτα"

Αυτό μπορεί επίσης να γίνει χωρίς κώδικα. Στη σελίδα προσαρμογής του widget, δείτε την ενότητα "Default Sort Direction".

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.default-sort-direction'; alt='Επιλογέας Default Sort Direction που προσφέρει Πιο Σχετικό, Νεότερα Πρώτα και Παλαιότερα Πρώτα'; title='Αλλαγή της προεπιλεγμένης διεύθυνσης ταξινόμησης' app-screenshot-end]

Σημειώστε ότι τα σχόλια σε κάθε σελίδα για κάθε διεύθυνση ταξινόμησης προϋπολογίζονται εκ των προτέρων, έτσι όλες οι διευθύνσεις ταξινόμησης έχουν την ίδια απόδοση.
