Όταν αποστέλλονται email ειδοποιήσεων ή όταν τα σχόλια εμφανίζονται σε διεπαφές χρήστη όπως η σελίδα διαχείρισης, είναι χρήσιμο να υπάρχει δυνατότητα σύνδεσης
από το σχόλιο προς τη σελίδα στην οποία βρίσκεται.

Αν το URL ID δεν είναι πάντα ένα ID, τότε πρέπει να αποθηκεύουμε το URL κάπου αλλού. Αυτός είναι ο σκοπός της ιδιότητας "url", η οποία ορίζεται ως εξής.

[code-example-start config = {url: 'https://example.com/article-5'}; linesToHighlight = [6]; title = 'Ορισμός Προσαρμοσμένου URL'; code-example-end]

Μια συνηθισμένη περίπτωση χρήσης είναι η σύνδεση του νήματος σχολίων με ένα αναγνωριστικό, όπως ένα άρθρο, και στη συνέχεια η επιστροφή σε μια συγκεκριμένη σελίδα, για παράδειγμα:

[code-example-start config = {url: 'https://example.com/article-5', urlId: 'article-5'}; linesToHighlight = [6, 7]; title = 'Ορισμός Προσαρμοσμένου URL και URL ID μαζί'; code-example-end]

Το URL δεν καθαρίζεται από συνηθισμένες παραμέτρους μάρκετινγκ. Από προεπιλογή, όποιο είναι το τρέχον URL της σελίδας, αυτό αποθηκεύεται μαζί με το σχόλιο.
