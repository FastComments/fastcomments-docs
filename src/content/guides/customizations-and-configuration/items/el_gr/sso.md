Το SSO, ή single-sign-on, είναι ένα σύνολο συμβάσεων που σας επιτρέπουν σε εσάς ή στους χρήστες σας να χρησιμοποιείτε το FastComments χωρίς να χρειάζεται να δημιουργήσετε άλλον λογαριασμό.

Υποθέτοντας ότι δεν επιτρέπετε ανώνυμα σχόλια, απαιτείται λογαριασμός για να σχολιάσετε με το FastComments. Κάνουμε τη διαδικασία εγγραφής πολύ εύκολη - ο χρήστης απλώς αφήνει το email του όταν σχολιάζει.
Ωστόσο, κατανοούμε ότι ακόμα και αυτό είναι επιπλέον τριβή που ορισμένοι ιστότοποι θέλουν να αποφύγουν.

Μπορούμε να μειώσουμε αυτή την τριβή έχοντας μόνο μία ροή σύνδεσης για ολόκληρο τον ιστότοπό σας.

### Πώς το αποκτώ;
Όλοι οι τύποι λογαριασμών έχουν επί του παρόντος πρόσβαση στο SSO. Ωστόσο, ο μέγιστος αριθμός χρηστών SSO θα ποικίλλει ανάλογα με το πακέτο σας. Όπως και με άλλες λειτουργίες, τα σχέδια Pro και υψηλότερα παρέχουν άμεση υποστήριξη ανάπτυξης.

Ας συγκρίνουμε τις επιλογές και μετά ας δούμε τις λεπτομέρειες καθεμιάς.

### Μεταφορά Χρηστών και Σχολίων

Κατά τη μετάβαση από μια πλατφόρμα με SSO όπως το Disqus, θα έχετε ήδη χρήστες και τα σχόλιά τους.

Τα σχόλια εισάγονται ως μέρος της μετάβασής σας, είτε μέσω του API, του Import UI μας, είτε της υποστήριξης πελατών. Το Import UI προτιμάται αν υποστηρίζει την πλατφόρμα από την οποία
μεταφέρεστε, καθώς ενσωματώνει διαχείριση σφαλμάτων, εξαγωγή και μεταφόρτωση avatar και πολυμέσων, και σύστημα παρακολούθησης μαζικών εργασιών.

Οι ίδιοι οι χρήστες προστίθενται αυτόματα κατά την πρώτη προβολή των νημάτων σχολίων. Εναλλακτικά, μπορούν να προστεθούν εκ των προτέρων μέσω του API, αλλά αυτή η εργασία δεν έχει
πολλά πλεονεκτήματα.

Αν τα σχόλια έχουν εισαχθεί, και οι χρήστες SSO δεν έχουν προστεθεί χειροκίνητα μέσω του API, τότε τα σχόλια θα μεταφερθούν αυτόματα στον λογαριασμό του χρήστη την πρώτη
φορά που δημιουργείται όταν προβάλει οποιοδήποτε νήμα σχολίων. Στη συνέχεια θα μπορεί να διαχειρίζεται, να επεξεργάζεται και να διαγράφει τα σχόλια που είχε αρχικά γράψει.

Η αυτόματη μετάβαση γίνεται μέσω email ή ονόματος χρήστη. Ορισμένες πλατφόρμες δεν παρέχουν emails στην εξαγωγή, όπως το Disqus, οπότε σε αυτή την περίπτωση χρησιμοποιούμε το όνομα χρήστη.
- Αρκεί να περάσετε ένα αντίστοιχο όνομα χρήστη, και ένα email στο SSO payload, και θα προσθέσουμε το email στα μεμονωμένα αντικείμενα σχολίων ώστε οι ειδοποιήσεις και οι αναφορές να λειτουργούν.

Αν επιθυμείτε να εισαγάγετε τα σχόλια και τους χρήστες σας ταυτόχρονα, συνεργαστείτε με την υποστήριξη για να μεταφερθούν τα σχόλια στους αντίστοιχους λογαριασμούς των χρηστών αφού οι χρήστες εισαχθούν
μέσω του API.

Έτσι, για να συνοψίσουμε την ευκολότερη διαδρομή για τη μετάβαση:

1. Εισαγωγή σχολίων.
   1. Τα avatars και άλλα πολυμέσα μεταφέρονται αυτόματα αν χρησιμοποιείτε το Import UI στο `Manage Data -> Imports`.
2. Ρύθμιση Secure ή Simple SSO.
3. Αφήστε τη μετάβαση να γίνει ανά χρήστη αυτόματα όταν συνδεθεί για πρώτη φορά.
   1. Αυτό συνήθως προσθέτει λιγότερο από ένα δευτερόλεπτο στον χρόνο φόρτωσης της σελίδας αν ο χρήστης έχει λιγότερα από 50k σχόλια.

### Χρήστες WordPress
Αν χρησιμοποιείτε το <a href="https://wordpress.org/plugins/fastcomments/" target="_blank">WordPress plugin</a> μας, τότε δεν χρειάζεται να γράψετε κώδικα! Απλώς πηγαίνετε στη σελίδα Admin του plugin, κάντε κλικ στο SSO Settings, και μετά στο Enable.

Αυτό θα σας οδηγήσει σε έναν οδηγό ενός κλικ που θα δημιουργήσει το API key σας, θα το στείλει στην εγκατάσταση WordPress σας και θα ενεργοποιήσει το SSO. Το έχουμε ενοποιήσει σε ένα μόνο κλικ για εσάς.

Σημειώστε ότι αν εγκαθιστάτε το plugin για πρώτη φορά, θα πρέπει να ολοκληρώσετε τη διαδικασία εγκατάστασης πριν δείτε τη σελίδα admin με το κουμπί SSO Settings.

#### WordPress SSO - Συντονιστές

Σημειώστε ότι επί του παρόντος, για να εμφανίζεται το σήμα "Moderator" δίπλα στους συντονιστές σας όταν σχολιάζουν με το FastComments WordPress plugin,
πρέπει επίσης να έχουν προστεθεί ως Moderators στο dashboard του FastComments, και να έχουν επαληθευμένο email τους.

### Προσαρμοσμένες Ενσωματώσεις

Για προσαρμοσμένες ενσωματώσεις, υπάρχουν δύο επιλογές.

### Επιλογή Ένα - Secure SSO

Με το Secure SSO, το FastComments γνωρίζει ότι ο χρήστης που σχολιάζει, ψηφίζει και διαβάζει σχόλια είναι πραγματικός χρήστης στον ιστότοπό σας.

Αρκεί να δημιουργήσετε ένα έγκυρο payload, ο χρήστης θα έχει πάντα μια απρόσκοπτη εμπειρία σχολιασμού.

Με το Secure SSO, το SSO payload δημιουργείται **server-side** χρησιμοποιώντας HMAC authentication και στη συνέχεια περνάει στο widget στο **client**.

Με το Secure SSO, ο λογαριασμός του χρήστη είναι **εντελώς ξεχωριστός** από την υπόλοιπη βάση χρηστών του FastComments. Αυτό σημαίνει ότι αν έχουμε δύο συνεργάτες
την Εταιρεία Α και την Εταιρεία Β, η καθεμία μπορεί να έχει χρήστη SSO με το όνομα χρήστη "Bob".

#### Απαιτήσεις
- Βασικές γνώσεις ανάπτυξης backend.
- Βασικές γνώσεις διαχείρισης μυστικών API keys.
- Βασικές γνώσεις ανάπτυξης API ή server-side rendering.

#### Πλεονεκτήματα
- Ασφαλές.
- Απρόσκοπτη εμπειρία σχολιασμού.

#### Μειονεκτήματα
- Απαιτεί ανάπτυξη backend.

#### Ενημέρωση Δεδομένων Χρήστη

Με το Secure SSO, κάθε φορά που περνάτε το sso user payload, θα ενημερώνουμε τον χρήστη με τις πιο πρόσφατες πληροφορίες. Για παράδειγμα, αν
ο χρήστης έχει όνομα χρήστη `X`, και περάσετε `Y` στο SSO payload, το όνομα χρήστη του θα γίνει `Y`.

Αν θέλετε να αφαιρέσετε τιμές με αυτή την προσέγγιση, τότε ορίστε τις σε `null` (όχι `undefined`).

#### Secure SSO API

Παρέχουμε επίσης ένα API για αλληλεπίδραση με τους χρήστες SSO. Δείτε [την τεκμηρίωση](/guide-api.html#sso-user-structure).

Σημειώστε ότι όταν χρησιμοποιείτε Secure SSO, οι χρήστες δημιουργούνται αυτόματα στο παρασκήνιο κατά τη φόρτωση της σελίδας. Δεν χρειάζεται να κάνετε μαζική εισαγωγή των χρηστών σας.

### Επιλογή Δύο - Simple SSO

Η εναλλακτική του Secure SSO είναι να περάσετε απλώς τις πληροφορίες του χρήστη στο widget σχολιασμού.

Η παροχή email με το Simple SSO δεν απαιτείται, ωστόσο χωρίς αυτό τα σχόλιά τους θα εμφανίζονται ως "Unverified".

<sup>Σημείωση!</sup> Από τις αρχές του 2022, τα ονόματα χρήστη με Simple SSO δεν χρειάζεται να είναι μοναδικά σε όλο το FastComments.com.

Ιδανικά, το Simple SSO θα πρέπει να επιλέγεται μόνο όταν αναπτύσσετε σε μια πλατφόρμα που δεν παρέχει πρόσβαση σε backend.

#### Απαιτήσεις
- Βασικές γνώσεις ανάπτυξης client-side.
- Πρέπει να γνωρίζετε τουλάχιστον το email του χρήστη.

#### Πλεονεκτήματα
- Απλό.
- Όλη η δραστηριότητα εξακολουθεί να επαληθεύεται.
- Ο χρήστης δεν εισάγει ποτέ το όνομα χρήστη ή το email του.

#### Μειονεκτήματα
- Λιγότερο ασφαλές από το Secure SSO καθώς το payload στο client side θα μπορούσε να κατασκευαστεί ώστε να γίνει οποιοσδήποτε χρήστης.

#### Simple SSO API

Οι χρήστες που δημιουργούνται αυτόματα μέσω της ροής Simple SSO αποθηκεύονται ως αντικείμενα `SSOUser`. Μπορούν να προσπελαστούν και να διαχειριστούν μέσω του API `SSOUser`. Δείτε [την τεκμηρίωση](/guide-api.html#sso-user-structure).
