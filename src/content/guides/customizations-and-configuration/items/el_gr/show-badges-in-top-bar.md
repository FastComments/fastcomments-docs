Από προεπιλογή, το FastComments θα εμφανίζει τα εμβλήματα χρηστών μόνο στα σχόλιά τους μέσα στο νήμα σχολίων.

Ωστόσο, μπορούμε να εμφανίσουμε τα εμβλήματα χρηστών δίπλα στο όνομά τους πάνω από τη φόρμα σχολίου ενεργοποιώντας αυτή τη δυνατότητα στη σελίδα προσαρμογής του widget:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.show-badges-in-top-bar'; alt='Εμφάνιση εμβλημάτων στην επιλογή της επάνω μπάρας στη σελίδα προσαρμογής του widget, τοποθετώντας εμβλήματα δίπλα στο όνομα πάνω από τη φόρμα σχολίου'; title='Επιλογή Εμφάνισης Εμβλημάτων στην Επάνω Μπάρα' app-screenshot-end]

Αυτό θα εμφανίσει τα εμβλήματα του χρήστη δίπλα στο όνομά του στην περιοχή της επάνω μπάρας, καθιστώντας τα επιτεύγματα και την κατάσταση του πιο εμφανή όταν συνθέτει ένα σχόλιο.

Σημειώστε ότι αυτή η δυνατότητα πρέπει να είναι ενεργοποιημένη στη διεπαφή προσαρμογής του widget για να λειτουργήσει. Μπορείτε προαιρετικά να ορίσετε τη σημαία **showBadgesInTopBar** σε false στη διαμόρφωση του κώδικά σας για να την απενεργοποιήσετε επιλεκτικά ακόμη και όταν είναι ενεργοποιημένη σε επίπεδο διακομιστή:

[code-example-start config = {showBadgesInTopBar: false}; linesToHighlight = [6]; title = 'Disable Show Badges in Top Bar'; code-example-end]
