[related-parameter-start name = 'readonly'; type = 'boolean'; related-parameter-end]

Η δυνατότητα σχολιασμού μπορεί να κλειδωθεί ώστε να μην μπορούν να υποβληθούν νέα σχόλια ή ψήφοι ορίζοντας τη σημαία readonly σε true.

Τα σχόλια επίσης δεν θα μπορούν να επεξεργαστούν ή να διαγραφούν.

[code-example-start config = {readonly: true}; linesToHighlight = [6]; title = 'Κλείδωμα του νήματος σχολίων σε κατάσταση μόνο ανάγνωση'; code-example-end]

Αυτό μπορεί να προσαρμοστεί χωρίς κώδικα, στη σελίδα προσαρμογής widget, για ολόκληρο το domain ή τη σελίδα:

## Update!

Από τον Νοέμβριο του 2022, τα νήματα μπορούν να κλειδωθούν ή να ξεκλειδωθούν **ζωντανά** από διαχειριστές και συντονιστές μέσω του μενού με τρία σημεία πάνω από την περιοχή απάντησης.

Αυτό θα αποτρέψει νέα σχόλια, ενώ θα επιτρέπει ακόμη τη ψηφοφορία και θα επιτρέπει στους χρήστες να διαγράψουν τα σχόλιά τους εάν το επιθυμούν, ενώ το `readonly` δεν επιτρέπει αυτά.

Αυτό αντιστοιχεί στο πεδίο `isClosed` του API `Page`.
