Από προεπιλογή, χρησιμοποιούνται τοπικές σχετικές ημερομηνίες. Για παράδειγμα, δίπλα σε ένα πρόσφατα αφήσμένο σχόλιο μπορεί να δείτε "11 λεπτά πριν".

Μπορεί να είναι απαραίτητο ή επιθυμητό να χρησιμοποιηθούν απόλυτες ημερομηνίες, οπότε ορίζετε αυτήν τη παράμετρο σε true. 

[code-example-start config = {absoluteDates: true}; linesToHighlight = [6]; title = 'Use Absolute Dates'; code-example-end]
