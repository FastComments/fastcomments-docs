Από προεπιλογή, κάθε χρήστης μπορεί να υποβάλει έως `5 comments` στο ίδιο λεπτό.

Αυτό παρακολουθείται με βάση το user id, το anon user id και τη διεύθυνση ip (hashed).

Αυτό μπορεί να προσαρμοστεί χωρίς κώδικα, στη σελίδα προσαρμογής του widget:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.max-comments-per-minute'; alt='Πεδίο μέγιστου αριθμού σχολίων ανά λεπτό στη σελίδα προσαρμογής του widget, ορισμένο σε 5 από προεπιλογή'; title='Περιορισμός του όγκου σχολίων ανά χρήστη' app-screenshot-end]

Σημειώστε ότι εάν χρησιμοποιείτε το API δημιουργίας σχολίων, ίσως θέλετε να περάσετε τη αρχική `ip` διεύθυνση του χρήστη στο αίτημα προς το backend μας, ώστε ο περιορισμός ταχύτητας να εφαρμόζεται
ανά χρήστη και όχι παγκοσμίως στον λογαριασμό σας.
