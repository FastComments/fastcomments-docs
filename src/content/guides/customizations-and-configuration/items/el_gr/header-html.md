Κάποιο κείμενο, όπως μια κεφαλίδα ή μήνυμα, μπορεί να εμφανιστεί κάτω από τον αριθμό σχολίων αλλά πάνω από το κείμενο κατάστασης σύνδεσης.

Αυτό το αποκαλούμε κεφαλίδα και, από προεπιλογή, είναι κρυμμένο.

[code-example-start config = {headerHTML: "<h1>Leave a Comment!</h1>"}; linesToHighlight = [6]; title = 'Καθορισμός HTML κεφαλίδας'; code-example-end]

Αυτό μπορεί να προσαρμοστεί χωρίς κώδικα, στη σελίδα προσαρμογής widget, κάτω από τις Προηγμένες Επιλογές:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.show-advanced-option'; selector = '.absolute-dates'; alt='Περιοχή Προηγμένων Επιλογών της σελίδας προσαρμογής widget όπου εισάγεται προσαρμοσμένο HTML κεφαλίδας'; title='Καθορισμός HTML κεφαλίδας' app-screenshot-end]
