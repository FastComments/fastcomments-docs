Από προεπιλογή, το μέγεθος σελίδας του FastComments είναι `30`. Αυτό περιλαμβάνει τις απαντήσεις σε νήματα.

Το μέγεθος σελίδας μπορεί να προσαρμοστεί στη [Widget Configuration UI](https://fastcomments.com/auth/my-account/customize-widget) σε διάφορα μεγέθη που κυμαίνονται από `10` έως `200`.

Σημειώστε ότι η αλλαγή του μεγέθους σελίδας απαιτεί επανυπολογισμό όλων των νήματων σχολίων στον λογαριασμό σας. Αυτό μπορεί να διαρκέσει λίγα λεπτά.

Αυτό δεν μπορεί να ρυθμιστεί στο widget της πλευράς πελάτη, καθώς οι σελίδες υπολογίζονται από τον διακομιστή.

Παράδειγμα διαμόρφωσης φαίνεται παρακάτω:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.page-size'; alt='Επιλογέας μεγέθους σελίδας στη σελίδα προσαρμογής widget, όπου μπορεί να επιλεγεί μια τιμή από 10 έως 200'; title='Προσαρμοσμένα Μεγέθη Σελίδας' app-screenshot-end]

Τα μεγέθη σελίδας μπορούν να προσαρμοστούν παγκοσμίως, ή ανά domain, ή ανά σελίδα, δημιουργώντας διαφορετικούς κανόνες προσαρμογής.

Αυτό θα επηρεάσει όλους τους πελάτες, τις ενσωματώσεις και τα πλαίσια εργασίας που ενδέχεται να χρησιμοποιείτε για την εμφάνιση σχολίων μέσω της πλατφόρμας μας.
