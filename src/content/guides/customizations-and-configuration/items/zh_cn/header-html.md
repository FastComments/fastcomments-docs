[related-parameter-start name = 'headerHTML'; type = 'string'; related-parameter-end]

一些文本，例如标题或消息，可以渲染在评论计数下方但登录状态文本上方。

我们称之为标题，默认情况下它是隐藏的。

[code-example-start config = {headerHTML: "<h1>Leave a Comment!</h1>"}; linesToHighlight = [6]; title = '指定标题 HTML'; code-example-end]

这可以在无需代码的情况下进行自定义，位于小部件自定义页面的高级选项下：
