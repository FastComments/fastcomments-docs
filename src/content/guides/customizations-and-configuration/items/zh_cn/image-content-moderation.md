[related-parameter-start name = 'imageContentProfanityLevel'; type = 'string'; related-parameter-end]

默认情况下，FastComments 评论小部件的图像内容审核已关闭 `off`。

可用的选项有 `off`、`low`、`medium` 和 `high`。

在小部件自定义 UI 中，只要未勾选 `Disable Image Uploads?`，您可以在 `Image Content Moderation Level` 下找到此设置。
