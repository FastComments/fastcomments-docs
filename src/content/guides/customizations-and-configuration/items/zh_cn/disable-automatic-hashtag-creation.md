当用户输入标签（形式为 `#someexampletag`），FastComments 会自动创建该 `HashTag` 并在他们的评论中高亮显示。

在某些情况下，可能需要禁用此功能，或通过 API 控制可以使用的标签。

为此，只需在小部件自定义 UI 中启用 `Disable Automatic #hashtag Creation`。
