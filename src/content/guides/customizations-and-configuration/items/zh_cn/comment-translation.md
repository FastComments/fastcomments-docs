默认情况下，FastComments 会将小部件自身的界面（按钮、标签、错误信息）翻译成观看者的语言，但评论会保持原样显示。

评论翻译功能会对评论本身进行翻译，使得使用多种语言的社区能够阅读每条评论的对应语言版本。

有两种模式：

- **自动**：用非小部件语言撰写的评论会显示翻译后的内容。评论下方会出现“已从西班牙语翻译”行，并带有 **显示原文** 链接，可在翻译文本和未翻译文本之间切换。
- **手动**：每条评论都会出现 **翻译** 链接。点击后会将该评论翻译成观看者的语言，随后同样提供 **显示原文** 切换。已经是观看者语言的评论则会显示相应提示。

目标语言为小部件的语言：如果在同一自定义规则中设置了 [Locale / Language](#locale)（语言/地区）选项，则使用该设置；否则使用访客的浏览器语言。访客无需任何操作，无需账户、扩展或额外软件，无论是在嵌入式小部件还是独立评论页面中都能正常工作。

此功能在每个 <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">自定义规则</a> 中单独开启，因此可以应用于整个站点、单个域名或单个页面。默认情况下为关闭状态。

翻译是服务器端设置。仅在小部件的 JavaScript 配置中传入 `commentTranslation` 并不能启用该功能；必须在规则中开启。

每条评论在每种目标语言下最多翻译一次，翻译结果会与评论一起存储，因此一条被千名西班牙语使用者阅读的评论只会翻译一次。如果作者或版主编辑了评论，已存储的翻译将被丢弃，评论将在下次查看时重新翻译。翻译后的文本会经过与原始评论相同的清理和链接规则。过长的评论或无法检测语言的评论将保持未翻译状态。

使用量按 LLM 令牌计费，费率与 [AI 代理](/guide-ai-agents.html#plans-and-eligibility) 相同，并显示在账单详情的相同位置。
