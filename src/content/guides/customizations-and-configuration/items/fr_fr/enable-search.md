Par défaut, aucune zone de recherche n’est affichée dans le widget de commentaires.

Cependant, nous pouvons l’activer en définissant le drapeau **enableSearch** sur true :

[code-example-start config = {enableSearch: true}; linesToHighlight = [6]; title = 'Activation de la recherche'; code-example-end]

Cela peut également être fait sans code. Dans la page de personnalisation du widget, voir l’option « Activer la zone de recherche ».
