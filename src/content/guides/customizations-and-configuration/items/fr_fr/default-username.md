Lorsque les utilisateurs commentent ou votent sans être connectés, il leur sera demandé de fournir leur e-mail et leur nom d'utilisateur.

Dans le cas des commentaires anonymes, il est parfois souhaitable de définir un nom d'utilisateur par défaut afin de réduire les frictions
lors de la publication de commentaires. Cela peut être fait depuis l'interface de personnalisation. Les commentaires anonymes doivent d'abord être activés.

#### Partage du nom d'utilisateur par défaut

Le nom d'utilisateur par défaut est un nom d'affichage partagé, et non une identité. Un visiteur qui conserve le nom par défaut et saisit son e-mail
obtient son propre compte, avec le nom par défaut affiché comme nom public. Un nombre illimité de visiteurs peut conserver le même nom par défaut,
de sorte que « Anonymous » n'est jamais signalé comme déjà pris.

Les noms d'utilisateur saisis par un visiteur lui-même doivent toujours être uniques.

Si vous préférez que chaque visiteur obtienne un nom distinct sans avoir à en inventer un, consultez
[Générer automatiquement des noms d'utilisateur](/guide-customizations-and-configuration.html#auto-generate-username).
