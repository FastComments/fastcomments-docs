Les sondages permettent aux commentateurs d'attacher une question avec 2 à 10 options à un commentaire. Tout le monde sur la page peut voter sur place et voit les résultats se mettre à jour en direct.

Les sondages sont désactivés par défaut. Cochez **Enable Polls** dans les paramètres de personnalisation du widget pour ajouter un bouton de sondage à la barre d'outils des commentaires. Deux autres paramètres apparaissent alors :

- **Who Can Create Polls** : Administrateurs/Modérateurs uniquement (par défaut), ou Tout le monde.
- **Allow Anonymous Poll Votes** : lorsque la case est décochée (par défaut), seuls les utilisateurs connectés peuvent voter.
