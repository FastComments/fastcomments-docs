[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Par défaut, FastComments affichera le profil de l'utilisateur lorsque vous cliquez sur son avatar.

Cependant, nous pouvons désactiver cette fonctionnalité :

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Disable Profiles'; code-example-end]

Cela peut également être fait sans code. Dans la page de personnalisation du widget, consultez la section « Disable Profiles ».
