Par défaut, FastComments affichera les liens comme ceci : [https://exmaple.com](https://exmaple.com) - où l'URL du lien devient une balise d'ancre HTML cliquable.

Certains sites peuvent souhaiter désactiver cela, par exemple pour décourager les escrocs. Nous le proposons en réglant l'`Comment HTML Rendering Option` sur `Links as Text`.

Cela peut être personnalisé sans code, sur la page de personnalisation du widget, pour un domaine entier ou une page :

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.show-advanced-option']; selector = '.comment-html-rendering-mode'; alt='Option de rendu HTML des commentaires définie sur Liens en texte dans les Options avancées de la personnalisation du widget'; title='Rendre les liens en texte' app-screenshot-end]
