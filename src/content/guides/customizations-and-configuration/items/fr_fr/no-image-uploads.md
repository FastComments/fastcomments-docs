[related-parameter-start name = 'noImageUploads'; type = 'boolean'; related-parameter-end]

Par défaut, FastComments autorise le téléchargement d'images. Cela peut être désactivé en définissant le drapeau noImageUploads sur true.

[code-example-start config = {noImageUploads: true}; linesToHighlight = [6]; title = 'Désactivation des téléchargements d\'images'; code-example-end]

Cela peut être personnalisé sans code, sur la page de personnalisation du widget :
