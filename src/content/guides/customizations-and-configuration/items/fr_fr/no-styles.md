Pour les projets de style personnalisés plus importants, il peut être souhaitable de repartir de zéro et de ne pas utiliser du tout le style par défaut.

Toute la mise en forme par défaut peut être supprimée en définissant le paramètre **noStyles** sur true, comme suit :

[code-example-start config = {noStyles: true}; linesToHighlight = [6]; title = 'Disabling All Default Styles'; code-example-end]

Cela peut être personnalisé sans code, sur la page de personnalisation du widget, sous Options avancées :
