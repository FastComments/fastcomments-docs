사용자가 댓글을 달거나 투표할 때, 로그인하지 않은 경우 이메일과 사용자 이름을 제공하라는 요청을 받게 됩니다.

익명 댓글의 경우, 댓글 작성 시 마찰을 줄이기 위해
기본 사용자 이름을 정의하고 싶을 때가 있습니다. 이는 커스터마이제이션 UI에서 설정할 수 있습니다. 익명 댓글 기능을 먼저 활성화해야 합니다.
