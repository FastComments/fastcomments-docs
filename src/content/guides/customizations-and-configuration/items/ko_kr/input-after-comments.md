기본적으로 댓글 입력 영역은 **앞**에 있는 댓글 스레드입니다. 그러나 이 구성 매개변수를 true로 설정하면 **뒤**로 이동할 수 있습니다.

[code-example-start config = {inputAfterComments: true}; linesToHighlight = [6]; title = '답글 입력 상자를 하단으로 이동'; code-example-end]
