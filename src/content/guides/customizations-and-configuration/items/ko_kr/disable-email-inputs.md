사용자가 댓글을 달고 로그인하지 않은 경우, 이메일을 제공하라는 요청을 받게 됩니다.

이렇게 하면 해당 사용자에 대해 "검증되지 않은 세션"이 생성되며, 이메일을 통해 해당 세션을 검증하도록 요청합니다.

일부 사이트나 애플리케이션에서는 댓글이나 투표 시 사용자에게 이메일을 요청하지 않는 것이 바람직합니다.

익명 댓글을 활성화하면 이메일 입력 필드가 선택 사항이 됩니다. 그러나 이를 완전히 비활성화할 수도 있습니다. 먼저 익명 댓글을 활성화하고, 그러면 이메일 입력 필드를 비활성화하는 옵션이 나타납니다.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.allow-anonymous-comments', '.disable-email-inputs']; selector = '.disable-email-inputs'; alt='익명 댓글이 커스터마이징 UI에서 활성화된 후 표시되는, 이메일 필드를 완전히 숨기는 옵션'; title='이메일 입력 비활성화' app-screenshot-end]

이 옵션을 켜면 모든 댓글 제품에서 이메일 필드가 전혀 표시되지 않습니다.

이 설정에서는 사용자가 계정을 만들고 https://fastcomments.com 에 로그인하지 않는 한 모든 댓글이 검증되지 않은 상태가 됩니다.

[검증되지 않은 라벨 비활성화](/guide-customizations-and-configuration.html#disable-unverified-label)를 고려해 볼 수 있습니다.
