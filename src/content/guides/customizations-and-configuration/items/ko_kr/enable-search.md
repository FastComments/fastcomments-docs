기본적으로 댓글 위젯에 검색 상자가 표시되지 않습니다.

하지만 **enableSearch** 플래그를 true로 설정하면 이를 켤 수 있습니다:

[code-example-start config = {enableSearch: true}; linesToHighlight = [6]; title = '검색 활성화'; code-example-end]

코드 없이도 이 작업을 수행할 수 있습니다. 위젯 맞춤 설정 페이지에서 "Enable Search Box" 옵션을 확인하세요.
