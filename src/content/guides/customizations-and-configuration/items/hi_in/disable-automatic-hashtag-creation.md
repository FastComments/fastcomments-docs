जब उपयोगकर्ता `#someexampletag` के रूप में हैशटैग दर्ज करते हैं, तो FastComments स्वचालित रूप से वह `HashTag` बना देगा और 
उनकी टिप्पणी में उसे हाइलाइट कर देगा।

कुछ मामलों में इस सुविधा को अक्षम करना, या API के माध्यम से यह नियंत्रित करना वांछनीय होता है कि कौन से हैशटैग उपयोग किए जा सकते हैं।

ऐसा करने के लिए, बस Widget Customization UI में `Disable Automatic #hashtag Creation` को सक्षम करें।
