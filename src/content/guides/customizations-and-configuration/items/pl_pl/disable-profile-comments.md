[related-parameter-start name = 'disableProfileComments'; type = 'boolean'; related-parameter-end]

Domyślnie FastComments wyświetla zakładkę „Komentarze profilowe” na profilach użytkowników, umożliwiając odwiedzającym pozostawianie komentarzy na profilu danej osoby.

Jednak możemy wyłączyć tę zakładkę:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Disable Profile Comments'; code-example-end]

Można to również zrobić bez kodu. Na stronie dostosowywania widgetu zobacz sekcję „Wyłącz komentarze profilowe”.
