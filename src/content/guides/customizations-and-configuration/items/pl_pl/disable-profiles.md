[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Domyślnie FastComments wyświetla profil użytkownika po kliknięciu jego awatara.

Jednak możemy wyłączyć tę funkcjonalność:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Wyłącz profile'; code-example-end]

Można to zrobić również bez kodu. Na stronie dostosowywania widgetu, zobacz sekcję „Wyłącz profile”.
