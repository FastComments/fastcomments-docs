[related-parameter-start name = 'noImageUploads'; type = 'boolean'; related-parameter-end]

Domyślnie FastComments zezwala na przesyłanie obrazów. Można to wyłączyć, ustawiając flagę noImageUploads na true.

[code-example-start config = {noImageUploads: true}; linesToHighlight = [6]; title = 'Wyłączanie przesyłania obrazów'; code-example-end]

Można to dostosować bez kodu, na stronie dostosowywania widgetu:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.disable-image-uploads'; selector = '.disable-image-uploads'; alt='Pole wyboru wyłączania przesyłania obrazów włączone w ustawieniach strony dostosowywania widgetu'; title='Wyłączanie przesyłania obrazów' app-screenshot-end]
