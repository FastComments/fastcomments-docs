[related-parameter-start name = 'urlId'; type = 'string'; related-parameter-end]

При відображенні гілки коментарів або залишенні коментаря FastComments має знати, до якої сторінки, статті чи продукту належать ці коментарі.

Для цього ми використовуємо те, що називаємо «URL ID». Це може бути ідентифікатор, наприклад рядок або число, або URL.

За замовчуванням, якщо ви не вкажете urlId, він буде дорівнювати URL сторінки. Ми беремо поточний URL сторінки та очищаємо його, видаляючи загальні маркетингові параметри або ідентифікатори відстеження.

У випадку інтеграцій сторонніх систем, таких як WordPress, наш плагін зазвичай використовує ідентифікатор, який представляє поточну переглянуту інформацію, як URL ID, наприклад ідентифікатор статті/сторінки.

[code-example-start config = {urlId: 'https://example.com/page'}; linesToHighlight = [6]; title = 'Визначення власного URL ID'; code-example-end]

Одним із елементів, на який ми часто посилаємося в цьому документі, є <a href="https://fastcomments.com/auth/my-account/customize-widget/new">Інтерфейс налаштування віджета</a>.

Цей інтерфейс можна використовувати для внесення багатьох змін у віджет коментарів без коду.

При створенні правила налаштування ми часто хочемо, щоб воно застосовувалося до всіх сторінок нашого сайту. Однак у деяких випадках ми хочемо налаштувати віджет коментарів на конкретній сторінці, наприклад, застосувати власний стиль або зробити коментарі на цій сторінці анонімними. Ви також можете, наприклад, дозволити живі коментарі з’являтися одразу на деяких сторінках, а на інших приховувати їх під кнопками сповіщень.

Все це можливо за допомогою поля вводу URL ID на цій сторінці, яке виглядає наступним чином:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.url-id'; alt='Поле URL ID, що використовується для обмеження правила налаштування однією сторінкою або шаблоном, наприклад */blog/*'; title='Введення URL ID на сторінці налаштування віджета' app-screenshot-end]

Значення в цьому полі має відповідати параметру *urlId*, переданому у віджет коментарів. Якщо ви хочете, щоб ваше правило налаштування було незалежним від *urlId*, залиште це поле порожнім або введіть *.

З 2023 року поле `URL ID` у налаштуванні віджета також підтримує шаблони! Наприклад, ви можете використати `*/blog/*` для додавання стилю, специфічного для вашого блогу, і `*/store/*` для стилю, специфічного для вашого магазину, використовуючи один і той самий домен.

### Gotchas

1. Якщо ваша сторінка має хеш‑параметри (наприклад example.com#page-1) — вони за замовчуванням стануть частиною URL ID.
2. Під час міграцій, наприклад з WordPress на Gatsby, вам можливо доведеться перенести значення коментарів URL ID після первинної міграції. Для цього звертайтеся до нас.
