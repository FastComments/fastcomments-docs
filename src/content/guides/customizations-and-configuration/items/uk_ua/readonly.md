[related-parameter-start name = 'readonly'; type = 'boolean'; related-parameter-end]

Коментування можна заблокувати, щоб не залишати нових коментарів або голосів, встановивши прапорець readonly у значення true.

Коментарі також не можна буде редагувати або видаляти.

## Update!

Станом на листопад 2022 року, гілки можна блокувати або розблоковувати **в реальному часі** адміністраторами та модераторами через меню з трьома крапками над областю відповіді.

Це запобігатиме появі нових коментарів, при цьому залишатиметься можливість голосування та дозволятиме користувачам видаляти свої коментарі за потреби, чого не дозволяє `readonly`.

Це відповідає полю `isClosed` у API `Page`.
