[related-parameter-start name = 'customCSS'; type = 'string'; related-parameter-end]

FastComments розроблений для налаштування. Віджет коментування сам працює всередині iframe з міркувань безпеки, тому для застосування користувацького стилю потрібно дотримуватись одного з двох підходів.

Перший, найпростіший підхід, який ми віддаємо перевагу, — це використання [сторінки налаштування віджету](https://fastcomments.com/auth/my-account/customize-widget).

На сторінці налаштування віджету перегляньте розділ «Show Advanced Options», під яким розташована область з міткою «Custom CSS»:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.show-advanced-option'; selector = '.custom-css'; alt='Редактор Custom CSS під розділом Show Advanced Options на сторінці налаштування віджету'; title='Область вводу Custom CSS' app-screenshot-end]

У цьому підході є кілька переваг:
1. Введений CSS мінімізується перед відправкою користувачеві, і форматування зберігається послідовним у інтерфейсі редагування.
2. Ви отримуєте всі переваги інтерфейсу налаштування віджету, наприклад, легко налаштовуючи віджет коментування по-різному для різних сайтів.
3. Коли ми вносимо зміни до віджету коментування, ваші користувацькі стилі будуть протестовані в рамках нашого процесу випуску.

Другий підхід — вказати параметр **customCSS** у конфігурації віджету, як показано нижче:

[code-example-start config = {customCSS: "button { background: red; }" }; linesToHighlight = [6]; title = 'Передача користувацького CSS'; code-example-end]

Однак у цьому є *обмеження*:
1. Існує обмеження на обсяг користувацького CSS, який можна передати, інакше наші сервери відхилять запит через розмір заголовків.
2. Ви повинні керувати користувацьким CSS у вашій інфраструктурі та системі збірки. Це може бути і перевагою, і недоліком.
3. У цьому випадку додається додаткове навантаження на мережу — користувацький CSS надсилається **двічі**, спочатку на наші сервери, а потім назад у вміст iframe. Однак для більшості розмірів навантаження це непомітно.
4. Поширена оптимізація — мінімізувати CSS, щоб зменшити його розмір у мережі, проте в цьому підході вам доведеться робити це самостійно.
5. Ваш користувацький CSS не буде протестований, коли ми вносимо зміни.

### Зовнішні CSS файли

Ви можете вказати віджету завантажувати зовнішній файл за допомогою `@import`!

Рекомендується розміщувати `@import` у правилі налаштування. Таким чином, якщо нам доведеться змінити віджет коментування, ми зможемо використати наші інструменти автоматизації для перевірки вашої конфігурації. Наприклад, ви створюєте правило налаштування у UI налаштування віджету, натискаєте `Advanced` і вводите у `Custom CSS`:

    @import url(https://example.com/styles.css);

#### У коді — не рекомендується

Ви також можете завантажити зовнішній CSS файл через властивість `customCSS`:

[code-example-start config = {customCSS: "@import url(https://example.com/styles.css);" }; linesToHighlight = [6]; title = 'Зовнішній CSS файл'; code-example-end]

Однак пам'ятайте, що ваш CSS не зможе бути протестований нами, якщо ви це зробите.

### Стилізація модального вікна профілю користувача

Модальні вікна профілю користувача також можна стилізувати за допомогою користувацького CSS. Однак, щоб забезпечити застосування користувацького стилю до профілів, усі CSS‑селектори мають мати префікс `.user-profile`. Без цього префікса користувацький стиль буде проігноровано для модальних вікон профілю.

Наприклад:

[code-example-start config = {customCSS: ".user-profile .profile-name { color: blue; }" }; title = 'CSS профілю користувача'; code-example-end]

### Сумісність назад

У FastComments ми знаємо, що наші клієнти налаштовують віджет коментування. Це задумано — останнє, чого ми хочемо, це щоб наш продукт створював несумісності дизайну у вашому продукті.

Оскільки це важлива частина нашого продукту, у нас є конвеєр збірки, який дозволяє нам переглядати зміни у віджеті коментування для кожного клієнта перед кожним випуском.

Якщо ми виявимо незначні проблеми, ми оновимо ваш обліковий запис, щоб забезпечити плавний випуск. Якщо ми помітимо серйозні критичні зміни, це дозволяє нам зупинити випуск.
