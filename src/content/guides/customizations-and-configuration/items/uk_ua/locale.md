[related-parameter-start name = 'locale'; type = 'string'; related-parameter-end]

За замовчуванням FastComments буде відображати віджет коментарів у локалі, визначеній системою та браузером користувача.

Коли користувач залишає коментар або входить у систему, ми оновлюємо його останню використану локаль і також використовуємо її для надсилання електронних листів.

Це впливає на те, як віджет коментування перекладається для користувача. Локаль складається з мови та регіону користувача, тому налаштування локалі зазвичай змінює мову, якою відображається текст для користувача.

#### Через інтерфейс користувача

Це можна визначити за допомогою інтерфейсу налаштування віджета. Дивіться параметр «Locale / Language»:

### Примітка щодо SSO

Якщо ви використовуєте SSO, можливо, ви захочете передати локаль користувача у об’єкті користувача, щоб електронні листи та інші елементи були правильно локалізовані для нього.
