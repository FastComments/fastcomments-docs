Quando os usuários comentam ou votam e não estão logados, eles serão solicitados a fornecer seu e‑mail e nome de usuário.

No caso de comentários anônimos, às vezes é desejável definir um nome de usuário padrão para reduzir o atrito ao comentar. Isso pode ser feito na UI de Personalização. Comentários Anônimos devem ser habilitados primeiro.

#### Compartilhando o Nome de Usuário Padrão

O nome de usuário padrão é um nome de exibição compartilhado, não uma identidade. Um visitante que mantém o padrão e insere seu e‑mail obtém sua própria conta, com o padrão exibido como seu nome público. Qualquer número de visitantes pode manter o mesmo padrão, de modo que “Anonymous” nunca é relatado como já usado.

Nomes de usuário que um visitante digita por conta própria ainda precisam ser únicos.

Se você preferir que cada visitante receba um nome distinto sem precisar pensar em um, veja
[Gerar Nomes de Usuário Automaticamente](/guide-customizations-and-configuration.html#auto-generate-username).
