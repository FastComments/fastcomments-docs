[related-parameter-start name = 'disableToolbar'; type = 'boolean'; related-parameter-end]

Por padrão, o FastComments exibirá uma barra de ferramentas ao escrever um comentário para fornecer atalhos para decorar texto e fazer upload de
imagens.

Esta barra de ferramentas pode ser desativada no código ou com a interface de personalização.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'Desativando a barra de ferramentas'; code-example-end]

Isso também pode ser feito sem código. Na página de personalização do widget, veja a opção "Desativar a barra de ferramentas de resposta".
