[related-parameter-start name = 'disableSuccessMessage'; type = 'boolean'; related-parameter-end]

Por padrão, o FastComments exibirá uma mensagem de sucesso após comentar. Isso pode ser desativado da seguinte forma:

[code-example-start config = {disableSuccessMessage: true}; linesToHighlight = [6]; title = 'Desativar Mensagem de Sucesso'; code-example-end]

Isso também pode ser feito sem código. Na página de personalização do widget:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.disable-success-message']; selector = '.disable-success-message'; alt='Página de personalização do widget com a caixa de seleção Desativar Mensagem de Sucesso marcada para ocultar a confirmação após o comentário'; title='Desativar Mensagem de Sucesso' app-screenshot-end]
