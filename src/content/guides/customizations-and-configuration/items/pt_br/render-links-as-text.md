Por padrão, o FastComments renderizará links assim: [https://exmaple.com](https://exmaple.com) - onde a URL do link se torna uma tag âncora HTML clicável.

Alguns sites podem querer desativar isso, por exemplo, para desencorajar golpistas. Nós fornecemos isso definindo a `Comment HTML Rendering Option` para `Links as Text`.

Isso pode ser personalizado sem código, na página de personalização do widget, para um domínio inteiro ou página:
