[related-parameter-start name = 'disableProfileComments'; type = 'boolean'; related-parameter-end]

Por padrão, o FastComments exibirá uma aba "Comentários de Perfil" nos perfis de usuário, permitindo que os visitantes deixem comentários no perfil de alguém.

No entanto, podemos desativar esta aba:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Desativar Comentários de Perfil'; code-example-end]

Isso também pode ser feito sem código. Na página de personalização do widget, veja a seção "Desativar Comentários de Perfil".
