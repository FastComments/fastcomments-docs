Som standard vil FastComments vise en "Profilkommentarer"-faneblad på brugerprofiler, så besøgende kan efterlade kommentarer på en persons profil.

Men vi kan deaktivere dette faneblad:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Deaktiver profilkommentarer'; code-example-end]

Dette kan også gøres uden kode. På widget-tilpasningssiden, se afsnittet "Deaktiver profilkommentarer".
