[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Som standard viser FastComments brugerens profil, når du klikker på deres avatar.

Vi kan dog deaktivere denne funktionalitet:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Deaktiver profiler'; code-example-end]

Dette kan også gøres uden kode. På widget-tilpasningssiden, se afsnittet "Deaktiver profiler".
