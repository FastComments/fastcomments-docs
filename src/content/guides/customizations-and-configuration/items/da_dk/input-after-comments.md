[related-parameter-start name = 'inputAfterComments'; type = 'boolean'; related-parameter-end]

Som standard er kommentarindtastningsområdet **før** kommentartråden. Men ved at sætte denne konfigurationsparameter til true kan vi flytte den til **efter**.

[code-example-start config = {inputAfterComments: true}; linesToHighlight = [6]; title = 'Flyt svarboksen til bunden'; code-example-end]

Dette kan tilpasses uden kode på widget-tilpasningssiden:
