Por defecto, FastComments mostrará una barra de herramientas al escribir un comentario para proporcionar accesos rápidos para decorar texto y subir imágenes.

Esta barra de herramientas puede desactivarse mediante código o con la interfaz de personalización.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'Desactivando la barra de herramientas'; code-example-end]

Esto también puede hacerse sin código. En la página de personalización del widget, vea la opción "Desactivar la barra de herramientas de respuesta".
