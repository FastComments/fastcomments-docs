[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Por defecto, FastComments mostrará el perfil del usuario cuando hagas clic en su avatar.

Sin embargo, podemos desactivar esta funcionalidad:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Desactivar perfiles'; code-example-end]

Esto también se puede hacer sin código. En la página de personalización del widget, vea la sección "Desactivar perfiles".
