Por defecto, el área de entrada de comentarios está **antes** del hilo de comentarios. Sin embargo, al establecer este parámetro de configuración a true podemos moverlo a **después**.

[code-example-start config = {inputAfterComments: true}; linesToHighlight = [6]; title = 'Moviendo el cuadro de respuesta al final'; code-example-end]

Esto se puede personalizar sin código, en la página de personalización del widget:
