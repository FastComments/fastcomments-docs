Por defecto, FastComments renderizará enlaces como este: [https://exmaple.com](https://exmaple.com) - donde la URL del enlace se convierte en una etiqueta de anclaje HTML clicable
etiqueta de anclaje HTML.

Algunos sitios pueden querer desactivar esto, por ejemplo para desalentar a los estafadores. Proporcionamos esto configurando la `Comment HTML Rendering Option` a `Links as Text`.

Esto se puede personalizar sin código, en la página de personalización del widget, para todo un dominio o página:
