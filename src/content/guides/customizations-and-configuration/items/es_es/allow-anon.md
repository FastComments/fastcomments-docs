Por defecto, FastComments requerirá un correo electrónico para comentar. No tiene que ser un correo válido, sin embargo, hasta que el usuario haga clic en un enlace que se le envíe,  
su comentario mostrará una etiqueta "Comentario no verificado".

Sin embargo, podemos eliminar el requisito de correo electrónico. El campo de entrada de correo electrónico seguirá apareciendo, pero ya no será obligatorio.

Esto se puede configurar a través de la interfaz de personalización del widget:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.allow-anonymous-comments'; alt='Opción de comentarios anónimos en la interfaz de personalización del widget, que hace que el campo de correo electrónico sea opcional'; title='Habilitar comentarios anónimos' app-screenshot-end]

Se sigue requiriendo un nombre de usuario. Para eliminar también ese paso, puedes  
[establecer un nombre de usuario predeterminado](/guide-customizations-and-configuration.html#default-username) que todos compartan, o hacer que FastComments  
[generar un nombre de usuario único](/guide-customizations-and-configuration.html#auto-generate-username) para cada visitante.
