Standardmäßig können Benutzer ihre eigenen Kommentare löschen. Außerdem löscht das Löschen ihres Kommentars automatisch alle untergeordneten und flüchtigen Kommentare im Thread. Dieses Verhalten ist ebenfalls live.

Sie können dies auf folgende Weise einschränken:

- Stattdessen den gelöschten Kommentar anonymisieren (Name und Text auf `[deleted]` oder einen benutzerdefinierten Wert setzen).
- Das Löschen von Kommentaren nicht zulassen, wenn es Antworten gibt. Eine anpassbare Fehlermeldung wird angezeigt.
- Das Löschen, wenn ein Kommentar Antworten hat, nur Administratoren und Moderatoren erlauben.

Dies kann über den Abschnitt `Comment Thread Deletion` in der Widget-Anpassungsoberfläche konfiguriert werden.
