FastComments kann so konfiguriert werden, dass unverifizierte Kommentare nach einer gewünschten Anzahl von Tagen entfernt werden. Dies hilft, Spam zu bekämpfen.

Standardmäßig tut es das nicht.

Dies kann über die <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Moderationseinstellungen</a>-Seite konfiguriert oder deaktiviert werden.
