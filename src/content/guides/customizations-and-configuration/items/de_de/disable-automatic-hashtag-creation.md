Wenn Benutzer Hashtags eingeben, in der Form von `#someexampletag`, erstellt FastComments automatisch dieses `HashTag` und 
hebt es in ihrem Kommentar hervor.

In manchen Fällen ist es wünschenswert, diese Funktion zu deaktivieren oder zu steuern, welche Hashtags über die API verwendet werden können.

Dazu aktivieren Sie einfach `Disable Automatic #hashtag Creation` über die Widget‑Anpassungs‑UI.
