Standardmäßig werden die Formatierungsfunktionen in FastComments durch das Hinzufügen sichtbarer Anker‑Tags wie `<b></b>` um Ihren Text herum umgesetzt. Das Klicken auf die Symbolleiste oder die Verwendung von Tastenkombinationen erledigt das für Sie. Einige Communities möchten jedoch die Formatierung ohne Anker‑Tags verwenden. Dies wird als Aktivieren des WYSIWYG‑Editors (what you see is what you get) bezeichnet. Dieser Editor sieht exakt gleich aus wie der Standard‑Editor, lädt jedoch zusätzlichen Code, der es Benutzern ermöglicht, ihren Text fett, unterstrichen usw. zu formatieren, ohne sichtbare Anker‑Tags.

[code-example-start config = {enableWYSIWYG: true}; linesToHighlight = [6]; title = 'Aktivieren der WYSIWYG-Bearbeitung'; code-example-end]

Dies kann auch ohne Code durchgeführt werden. Auf der Widget‑Anpassungsseite finden Sie die Option „Erweiterte Formatierung aktivieren“.
