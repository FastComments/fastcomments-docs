[related-parameter-start name = 'enableSearch'; type = 'boolean'; related-parameter-end]

Standardmäßig wird im Kommentar-Widget kein Suchfeld angezeigt.

Wir können dies jedoch aktivieren, indem wir das **enableSearch**-Flag auf true setzen:

[code-example-start config = {enableSearch: true}; linesToHighlight = [6]; title = 'Suche aktivieren'; code-example-end]

Dies kann auch ohne Code erledigt werden. Auf der Seite zur Widget-Anpassung finden Sie die Option „Suchfeld aktivieren“.
