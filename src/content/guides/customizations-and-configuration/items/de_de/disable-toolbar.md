Standardmäßig zeigt FastComments eine Symbolleiste an, wenn ein Kommentar geschrieben wird, um Kurzbefehle zum Formatieren von Text und Hochladen
von Bildern bereitzustellen.

Diese Symbolleiste kann im Code oder über die Anpassungs‑UI deaktiviert werden.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'Deaktivieren der Symbolleiste'; code-example-end]

Dies kann auch ohne Code durchgeführt werden. Auf der Widget‑Anpassungsseite finden Sie die Option „Disable The Reply Toolbar“.
