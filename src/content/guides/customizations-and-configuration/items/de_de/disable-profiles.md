[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Standardmäßig zeigt FastComments das Profil des Benutzers, wenn Sie auf dessen Avatar klicken.

Wir können diese Funktion jedoch deaktivieren:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Profile deaktivieren'; code-example-end]

Dies kann auch ohne Code durchgeführt werden. Auf der Widget-Anpassungsseite finden Sie den Abschnitt "Profile deaktivieren".
