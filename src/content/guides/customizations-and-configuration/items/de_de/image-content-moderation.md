[related-parameter-start name = 'imageContentProfanityLevel'; type = 'string'; related-parameter-end]

Standardmäßig ist die Bildinhaltsmoderation im FastComments‑Kommentar‑Widget auf `off` gestellt.

Verfügbare Optionen sind `off`, `low`, `medium` und `high`.

In der UI zur Widget‑Anpassung finden Sie dies unter `Image Content Moderation Level`, solange `Disable Image Uploads?` nicht aktiviert ist.
