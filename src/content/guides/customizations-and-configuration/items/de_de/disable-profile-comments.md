[related-parameter-start name = 'disableProfileComments'; type = 'boolean'; related-parameter-end]

Standardmäßig zeigt FastComments einen Tab „Profilkommentare“ auf Benutzerprofilen an, der es Besuchern ermöglicht, Kommentare auf dem Profil einer Person zu hinterlassen.

Wir können diesen Tab jedoch deaktivieren:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Profilkommentare deaktivieren'; code-example-end]

Dies kann auch ohne Code durchgeführt werden. Auf der Widget-Anpassungsseite finden Sie den Abschnitt „Profilkommentare deaktivieren“.
