[related-parameter-start name = 'headerHTML'; type = 'string'; related-parameter-end]

Einige Texte, wie ein Header oder eine Nachricht, können unterhalb der Kommentaranzahl, aber oberhalb des Anmeldestatus‑Textes angezeigt werden.

Wir nennen dies den Header, und standardmäßig ist er ausgeblendet.

[code-example-start config = {headerHTML: "<h1>Leave a Comment!</h1>"}; linesToHighlight = [6]; title = 'Specifying Header HTML'; code-example-end]

Dies kann ohne Code angepasst werden, auf der Widget‑Anpassungsseite unter Erweiterten Optionen:
