[related-parameter-start name = 'noImageUploads'; type = 'boolean'; related-parameter-end]

Standardmäßig erlaubt FastComments das Hochladen von Bildern. Dies kann deaktiviert werden, indem das noImageUploads-Flag auf true gesetzt wird.

[code-example-start config = {noImageUploads: true}; linesToHighlight = [6]; title = 'Deaktivieren von Bild-Uploads'; code-example-end]

Dies kann ohne Code auf der Widget-Anpassungsseite angepasst werden:
