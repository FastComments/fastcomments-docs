Standardmäßig rendert FastComments Links wie folgt: [https://exmaple.com](https://exmaple.com) – wobei die Link-URL zu einem anklickbaren
HTML-Anker-Tag wird.

Einige Websites möchten dies möglicherweise deaktivieren, zum Beispiel um Betrüger zu entmutigen. Wir ermöglichen dies, indem wir die `Comment HTML Rendering Option` auf `Links as Text` setzen.

Dies kann ohne Code angepasst werden, auf der Widget-Anpassungsseite, für eine gesamte Domain oder Seite:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.show-advanced-option']; selector = '.comment-html-rendering-mode'; alt='Comment HTML Rendering Option auf Links as Text unter Erweiterten Optionen in der Widget-Anpassung gesetzt'; title='Links als Text rendern' app-screenshot-end]
