[related-parameter-start name = 'disableProfileDirectMessages'; type = 'boolean'; related-parameter-end]

Standardmäßig zeigt FastComments einen Tab „Direct Messages“ in Benutzerprofilen an, der es Besuchern ermöglicht, Direktnachrichten an einen Benutzer zu senden.

Wir können diesen Tab jedoch deaktivieren:

[code-example-start config = {disableProfileDirectMessages: true}; linesToHighlight = [6]; title = 'Direktnachrichten im Profil deaktivieren'; code-example-end]

Dies kann auch ohne Code durchgeführt werden. Auf der Widget‑Anpassungsseite finden Sie den Abschnitt „Disable Direct Messages“.
