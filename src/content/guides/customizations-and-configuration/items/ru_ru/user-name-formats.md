По умолчанию FastComments отображает имя пользователя так, как оно было введено, или как оно было передано нам через SSO.

Однако может потребоваться скрыть или отобразить имя пользователя другим способом. Например, если имя пользователя — Allen Rex, возможно, вы захотите показывать только «Allen R.».

Это можно сделать без кода в пользовательском интерфейсе настройки виджета, в параметре под названием `Commenter Name Format`:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.commenter-name-format select'; selector = '.commenter-name-format'; alt='Выпадающий список Commenter Name Format открыт с вариантами, такими как Capitalize, Last Initial и All Initials'; title='Изменить формат имени' app-screenshot-end]

Доступные форматы:

- Capitalize (отображать пример пользователя как Example User)
- Last Initial (отображать Example User как Example U.)
- All Initials (отображать Example User как E. U.)
- Показать "Anonymous"

Эффект от изменения применяется сразу. Пользователи по‑прежнему будут видеть своё полное имя пользователя в верхней части области комментариев для себя, но их комментарии будут отображать изменённое имя пользователя.

Имена пользователей маскируются на стороне сервера для их защиты.
