По умолчанию FastComments не ограничивает языки, используемые для комментариев. 

Может быть желательным ограничить языки, которые использует сообщество.

Это можно настроить без кода на странице настройки виджета:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.allowed-languages']; selector = '.allowed-languages'; alt='Селектор разрешённых языков на странице настройки виджета для ограничения языков, которые могут использоваться в комментариях'; title='Разрешённые языки' app-screenshot-end]

Система проанализирует их комментарий, определит его язык и затем сопоставит его со списком разрешённых.

Если комментарий написан на языке, который не разрешён, будет показано локализованное сообщение об ошибке.
