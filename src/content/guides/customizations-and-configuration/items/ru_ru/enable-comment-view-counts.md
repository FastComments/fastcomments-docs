По умолчанию FastComments не отслеживает, кто просматривал каждый комментарий, и не предоставляет статистику по этому поводу.

Однако мы можем включить эту функцию, и система начнёт отслеживать, когда каждый пользователь прокручивает к комментарию.

Когда это происходит, рядом с иконкой глаза, отображаемой у каждого комментария, увеличивается счётчик. Счётчик обновляется в реальном времени и сокращается в соответствии с локалью пользователя.

Мы можем включить это, установив флаг **enableViewCounts** в значение true:

[code-example-start config = {enableViewCounts: true}; linesToHighlight = [6]; title = 'Включение подсчёта просмотров комментариев'; code-example-end]

Это можно настроить без кода на странице настройки виджета:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.enable-view-counts']; selector = '.enable-view-counts'; alt='Страница настройки виджета с отмеченным флажком подсчёта просмотров, поэтому каждый комментарий показывает значок глаза и количество'; title='Включение подсчёта просмотров комментариев' app-screenshot-end]

Мы отслеживаем user id*, который просмотрел комментарий, чтобы при повторном просмотре комментария счётчик не увеличивался. Если вы просмотрите комментарий снова через два года, счётчик увеличится.

- *Примечание: либо анонимный идентификатор сессии, либо IP‑адрес пользователя в виде хешированного значения.
