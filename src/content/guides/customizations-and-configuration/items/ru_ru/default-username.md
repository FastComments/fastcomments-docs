Когда пользователи оставляют комментарии или голосуют, и они не вошли в систему, их попросят указать электронную почту и имя пользователя.

В случае анонимных комментариев иногда удобно задать имя пользователя по умолчанию, чтобы снизить трение при комментировании. Это можно сделать через интерфейс настройки. Сначала необходимо включить анонимные комментарии.

#### Общий стандартный псевдоним

Стандартное имя пользователя — это общее отображаемое имя, а не идентичность. Посетитель, который оставляет имя по умолчанию и вводит свою электронную почту, получает собственный аккаунт, при этом имя по умолчанию отображается как его публичное имя. Неограниченное количество посетителей может использовать одно и то же имя по умолчанию, поэтому «Anonymous» никогда не считается уже занятым.

Имена пользователей, вводимые посетителем самостоятельно, всё равно должны быть уникальными.

Если вы предпочитаете, чтобы каждый посетитель получал уникальное имя без необходимости придумывать его, см. [Автоматическая генерация имён пользователей](/guide-customizations-and-configuration.html#auto-generate-username).
