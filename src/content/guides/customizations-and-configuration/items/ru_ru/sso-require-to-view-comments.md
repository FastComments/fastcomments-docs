FastComments SSO (<a href="#sso">подробности здесь</a>) предоставляет вашим пользователям возможность комментировать без необходимости входа в другую платформу.

Однако этого недостаточно для защиты ваших веток комментариев, поскольку по умолчанию данные комментариев являются общедоступной информацией — любой, кто может просматривать страницу, может просматривать комментарии.

Изменив настройку, мы можем ограничить получение комментариев только администратором или действительным пользователем SSO.

#### No-Code Setup

Мы можем предотвратить просмотр и взаимодействие с нашими ветками комментариев, когда SSO настроен, создав <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">правило настройки</a>.

При этом выполните поиск SSO, и вы найдете эту опцию:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.require-sso'; selector = '.require-sso'; alt='Опция «Требовать SSO для просмотра комментариев», включённая в правиле настройки, с выбором уровня безопасности'; title='Требовать SSO для просмотра комментариев' app-screenshot-end]

Включите её и сохраните правило настройки.

#### Only Protect a Certain Domain or Page

Чтобы защитить только определённый домен или страницу, мы просто настроим правило настройки соответствующим образом.

В верхней части пользовательского интерфейса настройки мы найдём два поля ввода: Domain и URL ID.

Чтобы защитить только конкретный домен, введите нужный домен в поле «domain».

Чтобы защитить конкретную страницу, введите URL страницы в поле «URL ID». Если у вас есть пользовательская интеграция с FastComments, здесь можно ввести тип идентификатора вместо URL.

#### Security Levels

При требовании SSO вам нужно решить, требовать ли Simple SSO или Secure SSO. Если вы выбираете Simple SSO, то оба варианта допускаются, но если вы выбираете Secure SSO, то контент должен быть получен с помощью Secure SSO‑payload, хешированного вашим API‑ключом, чтобы его можно было просмотреть.

Опция уровня безопасности появится, когда вы выберете «Требовать SSO для просмотра комментариев», и будет действовать только пока эта опция включена.

Настройки <a href="#sso-simple">Автоматической проверки комментариев через Simple SSO и разрешения Simple SSO администраторам</a> являются отдельными и применяются независимо от того, включена эта опция или нет.

#### Protection Beyond Reading

Включение этой опции защитит страницу или домен от комментирования, если пользователь не вошёл через SSO.

#### Gotchas

Любые пользователи, создавшие комментарии до вашей интеграции SSO, не смогут их увидеть, если только они не войдут через вашу интеграцию SSO.
