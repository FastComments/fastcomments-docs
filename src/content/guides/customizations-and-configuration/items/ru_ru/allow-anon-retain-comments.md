FastComments можно настроить так, чтобы удалять непроверенные комментарии через заданное количество дней. Это помогает бороться со спамом.

По умолчанию это не делается.

Это можно настроить или отключить на странице <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Настройки модерации</a>.
