[related-parameter-start name = 'locale'; type = 'string'; related-parameter-end]

По умолчанию FastComments будет отображать виджет комментариев в локали, определенной системой и браузером пользователя.

Когда пользователь оставляет комментарий или входит в систему, мы обновляем его последнюю использованную локаль и также используем её для отправки электронных писем.

Это влияет на то, как виджет комментариев переводится для пользователя. Локаль состоит из языка и региона пользователя, поэтому настройка локали обычно меняет язык, используемый для отображения текста пользователю.

#### Через пользовательский интерфейс

Это можно задать с помощью пользовательского интерфейса настройки виджета. См. параметр «Locale / Language»:

Если вы используете SSO, возможно, вы захотите передать локаль пользователя в объекте пользователя, чтобы электронные письма и другие элементы корректно локализовались для него.
