[related-parameter-start name = 'urlId'; type = 'string'; related-parameter-end]

При отображении ветки комментариев или оставлении комментария FastComments необходимо знать, к какой странице, статье или продукту принадлежат эти комментарии.

Для этого мы используем то, что называем «URL ID». Это может быть идентификатор, например строка или число, либо URL.

По умолчанию, если вы не укажете urlId, он будет равен URL страницы. Мы возьмём текущий URL страницы и очистим его, удалив любые распространённые маркетинговые параметры или идентификаторы отслеживания.

В случае сторонних интеграций, таких как WordPress, наш плагин обычно будет использовать идентификатор, представляющий текущую просматриваемую информацию, в качестве URL ID, например идентификатор статьи/страницы.

[code-example-start config = {urlId: 'https://example.com/page'}; linesToHighlight = [6]; title = 'Определение пользовательского URL ID'; code-example-end]

Одна вещь, которую мы часто будем упоминать в этом документе, — это <a href="https://fastcomments.com/auth/my-account/customize-widget/new">Widget Customization UI</a>.

Этот интерфейс можно использовать для внесения множества изменений в виджет комментариев без написания кода.

При создании правила настройки мы часто хотим, чтобы оно применялось ко всем страницам нашего сайта. Однако в некоторых случаях мы хотим настроить виджет комментариев на конкретной странице, например, применить пользовательские стили или сделать комментарии на этой странице анонимными. Вы также можете, например, отображать живые комментарии сразу на некоторых страницах, а на других скрывать их за кнопками уведомлений.

Все это возможно с помощью поля ввода URL ID на этой странице, которое выглядит следующим образом:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.url-id'; alt='Поле URL ID, используемое для ограничения правила настройки одной страницей или шаблоном, например */blog/*'; title='Поле ввода URL ID на странице настройки виджета' app-screenshot-end]

Значение в этом поле должно соответствовать параметру *urlId*, передаваемому в виджет комментариев. Если вы хотите, чтобы ваше правило настройки было независимым от *urlId*, оставьте это поле пустым или введите *.

Начиная с 2023 года поле `URL ID` в настройке виджета теперь также принимает шаблоны! Например, вы можете использовать `*/blog/*` для добавления стилей, специфичных для вашего блога, и `*/store/*` для стилей, специфичных для вашего магазина, при этом используя один и тот же домен.

### Подводные камни

1. Если на вашей странице есть хеш‑параметры (например example.com#page-1) — они по умолчанию станут частью URL ID.
2. Во время миграций, например из WordPress в Gatsby, вам может потребоваться перенести значения комментариев URL ID после первоначальной миграции. Для этого свяжитесь с нами.
