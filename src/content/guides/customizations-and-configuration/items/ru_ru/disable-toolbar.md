По умолчанию FastComments отображает панель инструментов при написании комментария, предоставляя быстрые клавиши для оформления текста и загрузки изображений.

Эту панель можно отключить в коде или с помощью пользовательского интерфейса настройки.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'Disabling The Toolbar'; code-example-end]

Это также можно сделать без кода. На странице настройки виджета смотрите опцию «Disable The Reply Toolbar» option.
