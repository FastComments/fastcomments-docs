[related-parameter-start name = 'warnOnUnsavedComment'; type = 'boolean'; related-parameter-end]

По умолчанию, если пользователь вводит комментарий, а затем обновляет страницу, закрывает вкладку или переходит на другую страницу до отправки, черновик теряется без предупреждения.

Установка **warnOnUnsavedComment** в значение true заставляет браузер запрашивать подтверждение у пользователя перед уходом со страницы, пока любой блок комментариев или незавершённое редактирование всё ещё содержит текст. После отправки комментария текст очищается, поэтому запрос не отображается.

[code-example-start config = {warnOnUnsavedComment: true}; linesToHighlight = [6]; title = 'Warn On Unsaved Comment'; code-example-end]

Запрос использует собственный диалог браузера. Современные браузеры отображают свой текст и игнорируют пользовательские сообщения, поэтому сообщение нельзя настроить.

Эта опция загружает небольшое расширение по требованию, поэтому она не добавляет ничего к виджету для сайтов, которые её не включают.
