[related-parameter-start name = 'disableNotificationBell'; type = 'boolean'; related-parameter-end]

По умолчанию FastComments будет показывать значок уведомления в правом верхнем углу области комментариев.

Этот значок станет красным и покажет количество уведомлений у пользователя. Некоторые примеры уведомлений:

- Пользователь ответил вам.
- Пользователь ответил в ветке, в которой вы комментировали.
- Пользователь проголосовал за ваш комментарий.
- Пользователь ответил на страницу, на которую вы подписаны.

Значок уведомления также предоставляет механизм подписки на всю страницу.

Однако мы можем полностью отключить значок уведомления:

[code-example-start config = {disableNotificationBell: true}; linesToHighlight = [6]; title = 'Отключить значок уведомления'; code-example-end]

Это также можно сделать без кода. На странице настройки виджета смотрите раздел "Отключить значок уведомления".
