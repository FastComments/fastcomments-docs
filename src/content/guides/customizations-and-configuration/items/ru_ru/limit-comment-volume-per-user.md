По умолчанию каждый пользователь может отправить до `5 комментариев` за одну минуту.

Это отслеживается по идентификатору пользователя, анонимному идентификатору пользователя и IP-адресу (хэшированному).

Это можно настроить без кода на странице настройки виджета:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.max-comments-per-minute'; alt='Поле максимального количества комментариев в минуту на странице настройки виджета, по умолчанию установлено 5'; title='Ограничение объёма комментариев на пользователя' app-screenshot-end]

Обратите внимание, что если вы используете API создания комментариев, возможно, захотите передать оригинальный `ip`-адрес пользователя в запросе к нашему бэкенду, чтобы ограничение скорости применялось
к каждому пользователю, а не глобально к вашей учётной записи.
