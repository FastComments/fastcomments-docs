По умолчанию FastComments будет требовать электронную почту для комментирования. Она не обязана быть действительной, однако пока пользователь не перейдёт по отправленной ему ссылке,
его комментарий будет отображаться с меткой «Неподтверждённый комментарий».

Тем не менее, мы можем убрать требование электронной почты. Поле ввода электронной почты по‑прежнему будет отображаться, но больше не будет обязательным.

Это можно настроить через пользовательский интерфейс настройки виджета:
