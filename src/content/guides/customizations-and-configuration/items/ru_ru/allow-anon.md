По умолчанию FastComments требует указать электронную почту для комментирования. Она не обязана быть действительной, однако пока пользователь не перейдёт по отправленной ему ссылке, его комментарий будет отображать метку «Неподтверждённый комментарий».

Тем не менее, мы можем убрать требование к электронной почте. Поле ввода электронной почты по‑прежнему будет отображаться, но больше не будет обязательным.

Это можно настроить через пользовательский интерфейс настройки виджета:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = '.allow-anonymous-comments'; alt='Опция анонимных комментариев в пользовательском интерфейсе настройки виджета, которая делает поле электронной почты необязательным'; title='Включение анонимных комментариев' app-screenshot-end]

Имя пользователя всё ещё требуется. Чтобы убрать и этот шаг, вы можете [установить имя пользователя по умолчанию](/guide-customizations-and-configuration.html#default-username), которое будет использоваться всеми, или позволить FastComments [создавать уникальное имя пользователя](/guide-customizations-and-configuration.html#auto-generate-username) для каждого посетителя.
