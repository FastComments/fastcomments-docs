По умолчанию FastComments отображает сообщение об успехе после оставления комментария. Это можно отключить следующим образом:

[code-example-start config = {disableSuccessMessage: true}; linesToHighlight = [6]; title = 'Отключить сообщение об успехе'; code-example-end]

Это также можно сделать без кода. На странице настройки виджета:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.disable-success-message']; selector = '.disable-success-message'; alt='Страница настройки виджета с отмеченным флажком Отключить сообщение об успехе, чтобы скрыть подтверждение после комментария'; title='Отключить сообщение об успехе' app-screenshot-end]
