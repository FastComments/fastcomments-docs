[related-parameter-start name = 'enableSearch'; type = 'boolean'; related-parameter-end]

Per impostazione predefinita, non viene mostrata alcuna casella di ricerca nel widget dei commenti.

Tuttavia, possiamo attivarla impostando il flag **enableSearch** su true:

[code-example-start config = {enableSearch: true}; linesToHighlight = [6]; title = 'Abilitare la ricerca'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedere l'opzione "Abilita casella di ricerca".
