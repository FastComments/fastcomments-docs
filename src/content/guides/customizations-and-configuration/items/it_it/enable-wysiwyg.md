Per impostazione predefinita, le funzionalità di formattazione in FastComments vengono eseguite aggiungendo tag di ancoraggio visibili come `<b></b>` intorno al tuo testo. Cliccare sulla barra degli strumenti o utilizzare le scorciatoie lo fa per te. Tuttavia, alcune community potrebbero voler optare per la formattazione senza tag di ancoraggio. Questo è chiamato abilitare l'editor WYSIWYG (what you see is what you get). Questo editor appare esattamente come quello predefinito, ma carica del codice aggiuntivo che consente agli utenti di rendere il testo in grassetto, sottolineato, ecc. senza tag di ancoraggio visibili.

[code-example-start config = {enableWYSIWYG: true}; linesToHighlight = [6]; title = 'Abilitare la modifica WYSIWYG'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedi l'opzione "Enable Advanced Formatting".
