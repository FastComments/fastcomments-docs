[related-parameter-start name = 'disableProfileComments'; type = 'boolean'; related-parameter-end]

Per impostazione predefinita, FastComments mostrerà una scheda "Commenti del profilo" sui profili degli utenti, consentendo ai visitatori di lasciare commenti sul profilo di qualcuno.

Tuttavia, possiamo disabilitare questa scheda:

[code-example-start config = {disableProfileComments: true}; linesToHighlight = [6]; title = 'Disabilita i commenti del profilo'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedere la sezione "Disabilita i commenti del profilo".
