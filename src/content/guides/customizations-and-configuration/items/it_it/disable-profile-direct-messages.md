[related-parameter-start name = 'disableProfileDirectMessages'; type = 'boolean'; related-parameter-end]

Per impostazione predefinita, FastComments mostrerà una scheda "Direct Messages" sui profili degli utenti, consentendo ai visitatori di inviare messaggi diretti a un utente.

Tuttavia, possiamo disabilitare questa scheda:

[code-example-start config = {disableProfileDirectMessages: true}; linesToHighlight = [6]; title = 'Disable Profile Direct Messages'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedere la sezione "Disable Direct Messages".
