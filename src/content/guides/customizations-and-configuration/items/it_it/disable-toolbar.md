Per impostazione predefinita, FastComments mostrerà una barra degli strumenti quando si scrive un commento per fornire scorciatoie per decorare il testo e caricare le immagini.

Questa barra degli strumenti può essere disabilitata nel codice o tramite l'interfaccia di personalizzazione.

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = 'Disabilitare la barra degli strumenti'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedere l'opzione "Disabilita la barra degli strumenti di risposta".
