Per impostazione predefinita, FastComments renderizza i link in questo modo: [https://exmaple.com](https://exmaple.com) - dove l'URL del link diventa un tag HTML anchor cliccabile.

Alcuni siti potrebbero voler disabilitare questa funzionalità, ad esempio per scoraggiare i truffatori. Lo possiamo fare impostando l'opzione `Comment HTML Rendering Option` su `Links as Text`.

Questa impostazione può essere personalizzata senza codice, nella pagina di personalizzazione del widget, per un intero dominio o per una singola pagina:
