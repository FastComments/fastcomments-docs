[related-parameter-start name = 'disableSuccessMessage'; type = 'boolean'; related-parameter-end]

Per impostazione predefinita, FastComments mostrerà un messaggio di conferma dopo aver commentato. Questo può essere disabilitato come segue:

[code-example-start config = {disableSuccessMessage: true}; linesToHighlight = [6]; title = 'Disabilita messaggio di successo'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget:

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelectors = ['.disable-success-message']; selector = '.disable-success-message'; alt='Pagina di personalizzazione del widget con la casella Disabilita messaggio di successo selezionata per nascondere la conferma post-commento'; title='Disabilita messaggio di successo' app-screenshot-end]
