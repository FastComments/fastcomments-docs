[related-parameter-start name = 'disableProfiles'; type = 'boolean'; related-parameter-end]

Per impostazione predefinita, FastComments mostrerà il profilo dell'utente quando fai clic sul suo avatar.

Tuttavia, possiamo disabilitare questa funzionalità:

[code-example-start config = {disableProfiles: true}; linesToHighlight = [6]; title = 'Disable Profiles'; code-example-end]

Questo può essere fatto anche senza codice. Nella pagina di personalizzazione del widget, vedi la sezione "Disabilita Profili".
