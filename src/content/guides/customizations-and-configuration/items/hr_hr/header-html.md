Neki tekst, poput zaglavlja ili poruke, može se prikazati ispod broja komentara, ali iznad teksta statusa prijave.

Ovo nazivamo zaglavljem, a prema zadanim postavkama je skriveno.

[code-example-start config = {headerHTML: "<h1>Leave a Comment!</h1>"}; linesToHighlight = [6]; title = 'Navođenje HTML zaglavlja'; code-example-end]

Ovo se može prilagoditi bez koda, na stranici prilagodbe widgeta, pod Naprednim opcijama:
