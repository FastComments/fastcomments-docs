[related-parameter-start name = 'disableToolbar'; type = 'boolean'; related-parameter-end]

預設情況下，FastComments 會在撰寫評論時顯示工具列，以提供裝飾文字和上傳
圖片的快捷方式。

此工具列可以透過程式碼或自訂 UI 予以停用。

[code-example-start config = {disableToolbar: true}; linesToHighlight = [6]; title = '停用工具列'; code-example-end]

也可以不使用程式碼完成此操作。在小工具自訂頁面中，請查看「停用回覆工具列」選項。
