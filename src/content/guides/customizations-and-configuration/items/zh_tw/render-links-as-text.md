預設情況下，FastComments 會將連結渲染成這樣：[https://exmaple.com](https://exmaple.com) - 其中連結 URL 會變成可點擊的 HTML 錨點標籤。

某些網站可能想要停用此功能，例如為了防止詐騙者。我們提供的方式是將 `Comment HTML Rendering Option` 設定為 `Links as Text`。

此設定可在不撰寫程式碼的情況下於小工具自訂頁面進行調整，適用於整個網域或單一頁面：
