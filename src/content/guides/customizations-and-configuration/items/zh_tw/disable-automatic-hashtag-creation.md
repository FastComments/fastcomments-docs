當使用者輸入標籤（例如 `#someexampletag`）時，FastComments 會自動建立該 `HashTag`，並在他們的評論中將其突顯。

在某些情況下，可能希望停用此功能，或透過 API 控制可使用的標籤。

為此，只需在小工具自訂 UI 中啟用 `Disable Automatic #hashtag Creation`。
