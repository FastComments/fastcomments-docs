FastComments נועדה להיות ניתנת להתאמה. הווידג'ט של ההערות פועל בתוך iframe משיקולי אבטחה, ולכן כדי להחיל
עיצוב מותאם עליך לבחור באחת משתי הגישות.

הגישה הראשונה, הקלה ביותר והעדיפה על ידינו, היא להשתמש ב[דף התאמת הווידג'ט](https://fastcomments.com/auth/my-account/customize-widget).

בדף התאמת הווידג'ט, ראה את סעיף "הצגת אפשרויות מתקדמות", מתחתיו יש אזור המסומן "CSS מותאם":

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.show-advanced-option'; selector = '.custom-css'; alt='עורך CSS מותאם תחת אפשרות הצגת אפשרויות מתקדמות בדף התאמת הווידג\'ט'; title='אזור קלט CSS מותאם' app-screenshot-end]

לגישה זו יש כמה יתרונות:
1. ה‑CSS שהוזן מצומצם לפני שנשלח למשתמש, והעיצוב נשמר עקבי בממשק העריכה.
2. אתה מקבל את כל היתרונות של ממשק התאמת הווידג'ט, למשל התאמה קלה של הווידג'ט למקומות שונים.
3. כאשר אנו מבצעים שינויים בווידג'ט ההערות, העיצוב המותאם שלך ייבדק כחלק מתהליך השחרור שלנו.

הגישה השנייה היא לציין את הפרמטר **customCSS** בתצורת הווידג'ט, כך:

[code-example-start config = {customCSS: "button { background: red; }" }; linesToHighlight = [6]; title = 'העברת CSS מותאם'; code-example-end]

עם זאת, יש ל*הגבלות*:
1. יש מגבלה על כמות ה‑CSS המותאם שניתן להעביר לפני שהשרתים שלנו ידחו את הבקשה, עקב גודל הכותרות.
2. עליך לנהל את ה‑CSS המותאם בתשתית ובמערכת הבנייה שלך. זה עשוי להיות יתרון ולא חיסרון, גם כן.
3. יש עומס נוסף של שליחת ה‑CSS המותאם ברשת **פעמיים** במצב זה, שכן הוא נשלח לשרתים שלנו, ואז חוזר לתוכן ה‑iframe. עם זאת, עבור רוב גדלי המטען, זה אינו מורגש.
4. אופטימיזציה נפוצה היא צמצום ה‑CSS כדי להפחית את גודלו ברשת, אך בגישה זו תצטרך לטפל בכך בעצמך.
5. ה‑CSS המותאם שלך לא ייבדק כאשר אנו מבצעים שינויים.

### קבצי CSS חיצוניים

אתה יכול לגרום לווידג'ט למשוך קובץ חיצוני באמצעות `@import`!

מומלץ למקם את `@import` בכלל התאמה. כך, אם נצטרך לשנות את הווידג'ט, נוכל להשתמש באוטומציה
שלנו כדי לאמת את ההגדרה שלך. לדוגמה, תיצור כלל התאמה בממשק התאמת הווידג'ט, תלחץ על `מתקדם`, ותזין ב‑`CSS מותאם`:

    @import url(https://example.com/styles.css);

#### בקוד - לא מומלץ

אתה יכול גם לטעון קובץ CSS חיצוני דרך המאפיין `customCSS`:

[code-example-start config = {customCSS: "@import url(https://example.com/styles.css);" }; linesToHighlight = [6]; title = 'קובץ CSS חיצוני'; code-example-end]

עם זאת, זכור שה‑CSS שלך לא ייבדק על ידינו אם תעשה זאת. 

### עיצוב מודל פרופיל משתמש

מודלים של פרופיל משתמשים ניתנים גם הם לעיצוב עם CSS מותאם. עם זאת, כדי להבטיח שהעיצוב המותאם יוחל על פרופילי משתמשים, כל בוררי ה‑CSS חייבים להיות עם קידומת `.user-profile`. ללא קידומת זו, העיצוב המותאם יתעלם ממודלים של פרופיל משתמש.

לדוגמה:

[code-example-start config = {customCSS: ".user-profile .profile-name { color: blue; }" }; title = 'CSS פרופיל משתמש'; code-example-end]

### תאימות לאחור

ב‑FastComments, אנו יודעים שהלקוחות שלנו מתאימים את ווידג'ט ההערות. זה מתוכנן – הדבר האחרון שאנחנו רוצים הוא שהמוצר שלנו יגרום לחוסר התאמה בעיצוב במוצר שלך.

מאחר שזה חלק חשוב במוצר שלנו, יש לנו צינור בנייה שמאפשר לנו לסקור שינויים בווידג'ט ההערות, לכל לקוח, בכל שחרור.

אם נמצא בעיות קטנות, נעדכן את החשבון שלך כדי להבטיח שהשחרור יעבור חלק. אם נזהה שינויים משמעותיים ושבורים, זה יאפשר לנו לעצור את השחרור.
