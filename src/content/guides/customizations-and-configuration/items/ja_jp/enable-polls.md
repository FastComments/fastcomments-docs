Polls let commenters attach a question with 2 to 10 options to a comment. Everyone on the page votes in place and sees the results update live.

投票機能を使用すると、コメント投稿者はコメントに2〜10の選択肢を持つ質問を添付できます。ページ上のすべてのユーザーはその場で投票し、結果がリアルタイムで更新されるのを確認できます。

Polls are off by default. Check **Enable Polls** in the widget customization settings to add a poll button to the comment toolbar. Two more settings then appear:

投票はデフォルトで無効になっています。ウィジェットのカスタマイズ設定で **Enable Polls** をチェックすると、コメントツールバーに投票ボタンが追加されます。その後、さらに2つの設定が表示されます：

- **Who Can Create Polls**: Admins/Moderators Only (the default), or Everyone.

- **Who Can Create Polls**: 管理者/モデレーターのみ（デフォルト）または全員。

- **Allow Anonymous Poll Votes**: when unchecked (the default), only logged in users can vote.

- **Allow Anonymous Poll Votes**: チェックが外れている場合（デフォルト）、ログインユーザーのみが投票できます。
