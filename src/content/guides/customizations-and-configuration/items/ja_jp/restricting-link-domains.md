デフォルトでは、FastComments は任意の外部サイトへのリンクを許可します。

これを、希望するサイトやドメインのリストに限定することができます。定義されたリストに含まれないサイトやドメインへのリンクを投稿しようとすると、ユーザーにエラーが表示されます。

この検証は Comment Widget と API のみ対象です。インポートには影響しません。

この設定はコードを書かずに、ウィジェットのカスタマイズページで行えます：

[app-screenshot-start url='/auth/my-account/customize-widget/new'; clickSelector = '.restricted-link-domains-list'; selector = '.external-link-settings'; alt='許可されたサイトを入力する制限付きリンクドメインリストを含む外部リンク設定'; title='外部リンクドメインを制限する' app-screenshot-end]
