[related-parameter-start name = 'imageContentProfanityLevel'; type = 'string'; related-parameter-end]

Varsayılan olarak, FastComments yorum widget'ı görüntü içeriği denetimini `off` konumunda tutar.

Mevcut seçenekler `off`, `low`, `medium` ve `high`'dır.

Widget özelleştirme arayüzünde, `Disable Image Uploads?` işaretli olmadığı sürece bunu `Image Content Moderation Level` altında bulacaksınız.
