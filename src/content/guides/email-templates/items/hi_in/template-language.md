FastComments ईमेल टेम्पलेट्स [EJS टेम्पलेट भाषा](https://ejs.co/#docs) का उपयोग करते हैं।

सिंटैक्स का उदाहरण `<%= object.someValue %>` है जो वेरिएबल प्रिंट करता है, और कंडीशनल स्टेटमेंट इस प्रकार किए जा सकते हैं:

    <% if (some_condition) { %>
        <div>Some content.</div>
    <% } else { %>
        <div>Some other content.</div>
    <% } %>

रॉ HTML प्रिंट करना, जैसे कमेंट कंटेंट के लिए, इस प्रकार किया जाता है: `<%- comment.commentHTML %>`। ध्यान दें `=` के स्थान पर `-` का उपयोग।

सिंटैक्स पर आगे के दस्तावेज़ीकरण के लिए ऊपर दिए गए लिंक को देखें।
