Jeder Link muss zur FastComments-Startseite mit Ihrem Affiliate‑Code führen:

[inline-code-attrs-start title = 'Affiliate-Link-Format'; type = 'text'; inline-code-attrs-end]
[inline-code-start]
https://fastcomments.com/?via=YOUR_CODE
[inline-code-end]

Der Code wird nur auf der Startseite ausgelesen. Ein Link zu einer anderen Seite, wie Preisgestaltung oder Demos, vergütet Sie nicht, selbst wenn `?via=` hinzugefügt wird.
