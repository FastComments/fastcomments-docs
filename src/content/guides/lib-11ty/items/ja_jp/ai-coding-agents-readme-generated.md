コーディングエージェントに FastComments のコンテキスト（ウィジェット、設定、Secure SSO、REST API、SDK）を提供します:

```bash
npx skills add fastcomments/skills
```

Claude Code、Codex、Cursor、Copilot、Gemini、そして他のすべてのエージェントで、[skills CLI](https://github.com/vercel-labs/skills) がサポートされています。
