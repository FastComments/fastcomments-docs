यह गाइड FastComments कमेंटिंग विजेट (v2) द्वारा उपयोग की जाने वाली संपूर्ण डिफ़ॉल्ट CSS और स्टाइल को ओवरराइड करने के कुछ निर्देश प्रदान करती है।

डिफ़ॉल्ट CSS को समझने से आप ये कर सकते हैं:

- विशिष्ट स्टाइल को ओवरराइड करके **रूप को अनुकूलित करें**
- उपलब्ध क्लासेस और सेलेक्टर्स देखकर **स्टाइलिंग समस्याओं का निवारण करें**
- विजेट की संरचना के साथ काम करने वाली **कस्टम थीम बनाएं**
- कस्टम CSS संशोधन जनरेट करने के लिए **AI असिस्टेंट के साथ उपयोग करें**।

## स्टाइल को ओवरराइड कैसे करें

स्टाइल को ओवरराइड करना विजेट के आधार पर भिन्न होता है। कमेंट विजेट के लिए, आपको `customCSS` कॉन्फ़िग पैरामीटर का उपयोग करके CSS को iframe में पास करना होगा, या एडमिन डैशबोर्ड के Customization पेज में CSS निर्दिष्ट करना होगा, जहाँ से CSS हमारे CDN द्वारा सर्व किया जाएगा।
