## कमेंट विजेट स्टाइल को कस्टमाइज़ कैसे करें

आप कमेंट विजेट की स्टाइलिंग को दो तरीकों से कस्टमाइज़ कर सकते हैं:

### विकल्प 1: customCSS पैरामीटर के माध्यम से

विजेट इनिशियलाइज़ करते समय अपनी कस्टम CSS को स्ट्रिंग के रूप में `customCSS` पैरामीटर में पास करें:

```javascript
window.fcConfigs = [{
    target: '#fastcomments-widget',
    tenantId: 'your-tenant-id',
    customCSS: `
        .fast-comments .comment {
            background-color: #f0f0f0 !important;
            border-radius: 8px !important;
        }
    `
}];
```

### विकल्प 2: एडमिन डैशबोर्ड के माध्यम से

1. अपने एडमिन डैशबोर्ड में [Widget Customization पेज](https://fastcomments.com/auth/my-account/customize-widget) पर जाएं
2. "Advanced" के अंतर्गत "Custom CSS" सेक्शन तक स्क्रॉल करें
3. अपनी कस्टम CSS दर्ज करें
4. "Save" पर क्लिक करें

आपकी कस्टम CSS आपकी साइट पर सभी कमेंट विजेट पर लागू हो जाएगी।

## सुझाव

- आवश्यकता होने पर डिफ़ॉल्ट स्टाइल को ओवरराइड करने के लिए `!important` का उपयोग करें
- अपनी साइट के अन्य हिस्सों को प्रभावित करने से बचने के लिए विशिष्ट सिलेक्टर्स को टारगेट करें
- संगतता के लिए अपनी CSS को विभिन्न ब्राउज़रों में टेस्ट करें
- विजेट स्टैंडर्ड CSS का उपयोग करता है - किसी विशेष प्रीप्रोसेसर की आवश्यकता नहीं है
