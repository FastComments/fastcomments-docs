सार्वजनिक `demo` टेनेंट के विरुद्ध लोकल रूप से चलने वाले हर विजेट और फ़्लो को देखने के लिए, रिपॉज़िटरी को क्लोन करें और चलाएँ:

```bash
npm install
npm run dev
```

शोकेस एंट्री पॉइंट `src/App.vue` और `index.html` में स्थित है — प्रत्येक विजेट/फ़्लो उसी ऐप में रेंडर होता है जिसे आप अपने Vue 3 प्रोजेक्ट में कॉपी कर सकते हैं।
