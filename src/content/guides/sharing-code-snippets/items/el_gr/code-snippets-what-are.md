Με το FastComments, η απλή επικόλληση ενός snippet κώδικα θα πρέπει να ανιχνεύεται και να μορφοποιείται αυτόματα.

Κατά το σχολιασμό, το code snippet θα περιβάλλεται από μπλοκ `<code>`, και η μορφοποίηση γίνεται
αφού υποβάλετε το σχόλιό σας.

Η περιβολή σε μπλοκ `<code>` είναι αυτόματη κατά την επικόλληση ενός snippet κώδικα, σε πολλές γλώσσες.

Εναλλακτικά, μπορείτε να επισημάνετε ένα κομμάτι κειμένου και να κάνετε κλικ στο κουμπί `Code` στη γραμμή εργαλείων.
