С FastComments простая вставка фрагмента кода должна автоматически обнаруживаться и форматироваться.

При комментировании фрагмент кода будет обёрнут в блоки `<code>`, а форматирование происходит после отправки вашего комментария.

Оборачивание в блоки `<code>` происходит автоматически при вставке фрагмента кода, во многих языках.

Кроме того, вы можете выделить часть текста и нажать кнопку `Code` на панели инструментов.
