עם FastComments, פשוט הדבקת קטע קוד אמורה להיתפס אוטומטית ולהיות מעוצבת.

כאשר מגיבים, קטע הקוד יעטף בבלוקים של `<code>`, והעיצוב מתרחש
לאחר שתשלח את התגובה שלך.

העטיפה בבלוקים של `<code>` היא אוטומטית כאשר מדביקים קטע קוד, במגוון שפות.

לחלופין, ניתן לסמן קטע טקסט וללחוץ על כפתור `Code` בסרגל הכלים.
