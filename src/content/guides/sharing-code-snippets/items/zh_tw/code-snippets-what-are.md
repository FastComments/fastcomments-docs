使用 FastComments，只要貼上程式碼片段，就會自動偵測並格式化。

在評論時，程式碼片段會被包裹在 `<code>` 區塊中，且格式化會在您提交評論後發生。

在貼上多種語言的程式碼片段時，會自動以 `<code>` 區塊包裹。

或者，您也可以選取一段文字，然後點擊工具列上的 `Code` 按鈕。
