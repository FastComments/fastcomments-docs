Mit FastComments wird das einfache Einfügen eines Code‑Snippets automatisch erkannt und formatiert.

Beim Kommentieren wird das Code‑Snippet in `<code>`‑Blöcke eingeschlossen, und die Formatierung erfolgt, nachdem Sie Ihren Kommentar abgesendet haben.

Das Einwickeln in `<code>`‑Blöcke erfolgt automatisch, wenn ein Code‑Snippet in vielen Sprachen eingefügt wird.

Alternativ können Sie einen Textabschnitt markieren und in der Symbolleiste auf die Schaltfläche `Code` klicken.
