使用 FastComments，只需粘贴代码片段，即可自动检测并进行格式化。

在评论时，代码片段会被包裹在 `<code>` 块中，格式化会在提交评论后进行。

在粘贴代码片段时，自动将其包裹在 `<code>` 块中，支持多种语言。

或者，您可以选中一段文本，然后点击工具栏中的 `Code` 按钮。
