कोड स्निपेट साझा करते समय, FastComments यह निर्धारित करने की पूरी कोशिश करता है कि कोड स्निपेट किस प्रोग्रामिंग भाषा में है, ताकि स्वचालित रूप से फ़ॉर्मेटिंग और सिंटैक्स हाइलाइटिंग लागू की जा सके।

FastComments सिंटैक्स हाइलाइटिंग वर्तमान में 39 सामान्य भाषाओं का समर्थन करती है:

लेकिन कोई सिंटैक्स हाइलाइटिंग या रीफ़ॉर्मेटिंग लागू नहीं की जाएगी।
