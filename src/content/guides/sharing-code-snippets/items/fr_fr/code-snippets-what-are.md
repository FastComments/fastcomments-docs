Les extraits de code sont de petits morceaux de code, d'où le terme « snippets » de code, qui peuvent être partagés lors de la rédaction de commentaires.

Avec FastComments, il suffit de coller un extrait de code pour qu'il soit automatiquement détecté et formaté.

Lors de la rédaction d'un commentaire, l'extrait de code sera enveloppé dans des blocs `<code>`, et le formatage s'effectue après que vous avez soumis votre commentaire.

L'enveloppement dans des blocs `<code>` est automatique lors du collage d'un extrait de code, dans de nombreux langages.

Alternativement, vous pouvez sélectionner un morceau de texte et cliquer sur le bouton `Code` dans la barre d'outils.
