Η τιμολόγηση βασίζεται στην τιμολόγηση σχολίων, δηλαδή χρεώνεστε για αξιολογήσεις και κριτικές όπως για τα σχόλια - ανάλογα με το πακέτο σας.

Χρεώνεστε (στο Flex) ή περιορίζεστε (σε σταθερά πλάνα) με βάση τα εξής:

- Ο αριθμός των κριτικών που έχετε στον λογαριασμό σας (ίδιο με την τιμολόγηση σχολίων).
- Χρήση του widget σύνοψης:
  - Κάθε φόρτωση σελίδας χρησιμοποιεί 1 πίστωση API για κάθε ερώτηση + υποερώτηση, αν η συγκέντρωση είναι αποθηκευμένη στην προσωρινή μνήμη, και διπλάσιες αν όχι.
  - Έτσι, αν έχετε μια κύρια ερώτηση και τρεις υποερωτήσεις, τις περισσότερες φορές χρεώνεστε 4 πιστώσεις ανά φόρτωση σελίδας, και μερικές φορές, όταν τα αποτελέσματα χρειάζεται να επανυπολογιστούν, χρεώνεστε 8 πιστώσεις.
- Χρήση API (χρήση πιστώσεων για κάθε κλήση API που περιλαμβάνεται στην αντίστοιχη τεκμηρίωση).

Όταν τα αποτελέσματα συγκεντρώνονται είτε μέσω του API είτε μέσω των widgets σύνοψης, χρεώνεστε επίσης.
