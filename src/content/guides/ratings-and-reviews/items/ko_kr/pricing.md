가격은 댓글 가격 기준으로 책정됩니다. 즉, 평점 및 리뷰는 패키지에 따라 댓글과 동일하게 청구됩니다.

다음 기준으로 청구되거나(Flex 플랜) 제한됩니다(고정 플랜):

- 계정에 보유한 리뷰 수(댓글 가격과 동일).
- 요약 위젯 사용량:
  - 각 페이지 로드 시 집계가 캐시되어 있으면 각 질문 + 하위 질문당 API 크레딧 1개가 사용되며, 캐시되어 있지 않으면 그 두 배가 사용됩니다.
  - 따라서 기본 질문 하나와 하위 질문 세 개가 있는 경우, 대부분의 경우 페이지 로드 시 4크레딧이 청구되고, 결과를 다시 계산해야 하는 경우에는 8크레딧이 청구됩니다.
- API 사용량(각 API 호출에 대한 크레딧 사용량은 해당 문서에 포함되어 있습니다).

API를 통해서든 요약 위젯을 통해서든 결과가 집계될 때에도 청구됩니다.
