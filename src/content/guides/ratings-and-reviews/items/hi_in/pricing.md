मूल्य निर्धारण कमेंट प्राइसिंग पर आधारित है, यानी आपसे रेटिंग्स और रिव्यूज़ के लिए वही बिलिंग होती है जो कमेंट्स के लिए होती है - आपके पैकेज के अनुसार।

आपसे बिलिंग (Flex पर) या सीमित (fixed प्लान पर) निम्नलिखित आधारों पर की जाती है:

- आपके अकाउंट में रिव्यूज़ की संख्या (Comment प्राइसिंग के समान)।
- Summary widget का उपयोग:
  - प्रत्येक पेज लोड पर प्रत्येक प्रश्न + उप-प्रश्न के लिए 1 API क्रेडिट उपयोग होता है यदि एग्रीगेशन कैश्ड है, और यदि नहीं है तो उससे दोगुना।
  - इसलिए यदि आपके पास एक मुख्य प्रश्न और तीन उप-प्रश्न हैं, तो अधिकांश समय आपसे प्रत्येक पेज लोड पर 4 क्रेडिट बिल होते हैं, और कभी-कभी जब परिणामों को पुनः गणना की आवश्यकता होती है तो 8 क्रेडिट बिल होते हैं।
- API उपयोग (प्रत्येक API कॉल के लिए क्रेडिट उपयोग संबंधित दस्तावेज़ों में शामिल है)।

जब परिणाम API या summary widgets के माध्यम से एग्रीगेट किए जाते हैं, तो आपसे वहाँ भी बिलिंग होती है।
