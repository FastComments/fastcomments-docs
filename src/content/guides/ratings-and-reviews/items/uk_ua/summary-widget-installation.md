Нижче наведено код Vanilla JS для встановлення віджету підсумку. Бібліотека React також має цей віджет.

[inline-code-attrs-start title = 'Встановлення віджету підсумку'; type = 'html'; isFunctional = true; type = 'html';  inline-code-attrs-end]
[inline-code-start]
<script src="https://cdn.fastcomments.com/js/embed-reviews-summary.min.js"></script>
<div id="summary-widget"></div>
<script>
    window.FastCommentsReviewsReviewsSummaryWidget(document.getElementById('summary-widget'), {
        tenantId: 'demo'
    });
</script>
[inline-code-end]

Віджет автоматично знайде питання, які потрібно показати у підсумку, на основі відповідної конфігурації віджету для цієї сторінки/сайту.

### Фільтрація коментарів за рейтингом

Коли віджет коментарів для тієї ж сторінки також розміщений на сторінці і налаштований показувати відповідь кожного коментатора у їхньому коментарі, рядки розбивки стають клікабельними. Клікання на рядок, наприклад "5", фільтрує віджет коментарів до коментарів, які дали цю відповідь. Повторне клікання на рядок або на X на чіпі "Показувати лише" у віджеті коментарів відображає всі коментарі знову. Це не потребує ніякої конфігурації: віджет підсумку знаходить віджет коментарів з тим же `tenantId` і `urlId`.

Це працює працює для питань зі зірочками, пальцями, емодзі, шкалою та одиничним вибором. Розбивка, яку віджет коментарів показує над полем коментаря, може бути клікнута таким же способом.

Якщо вам потрібен віджет в одній з наших інших бібліотек, де його немає, створіть запит у службу підтримки, щоб ми знали, що його додати.
