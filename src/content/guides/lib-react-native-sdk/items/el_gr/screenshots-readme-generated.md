### Επεξεργαστής Πλούσιου Κειμένου

Αυτή η βιβλιοθήκη χρησιμοποιεί [`react-native-enriched`](https://github.com/software-mansion/react-native-enriched-html) για επεξεργασία πλούσιου κειμένου, το οποίο προσφέρει μια ισχυρή εμπειρία WYSIWYG. Ο ίδιος επεξεργαστής τροφοδοτεί iOS, Android και το web (μέσω `react-native-web`), έτσι ο συνθέτης συμπεριφέρεται συνεπώς σε κάθε πλατφόρμα με μία μόνο υλοποίηση.

`react-native-enriched` απαιτεί τη Νέα Αρχιτεκτονική του React Native (Fabric) σε native (η προεπιλογή από RN 0.76, επιλογή σε RN 0.72‑0.75) και έναν bundler που επιλύει τις συνθήκες `exports` του πακέτου. Αυτό το SDK αναπτύχθηκε και δοκιμάστηκε εναντίον RN 0.81 / React 19. Ο ίδιος επεξεργαστής λειτουργεί επίσης στο web μέσω `react-native-web`; η web‑έκδοση του enriched editor παραμένει πειραματική upstream.

### Συστατικά

Το SDK παρέχει τρία συστατικά, που αντικατοπτρίζουν το FastComments Android SDK:

- `FastCommentsLiveCommenting` – νήματα σχολίων με ψήφους, απαντήσεις, σελιδοποίηση, αναφορές, ειδοποιήσεις και ζωντανές ενημερώσεις.
- `FastCommentsLiveChat` – μια προεπιλογή συνομιλίας πάνω στον ίδιο κινητήρα: χρονολογικά μηνύματα με τα νέα στο κάτω μέρος, ο συνθέτης κάτω από τη λίστα, μια ζωντανή γραμμή κεφαλίδας (σημείο σύνδεσης + αριθμός χρηστών), άπειρο ιστορικό που φορτώνεται με κύλιση προς τα πάνω, αυτόματη κύλιση σε νέα μηνύματα, χωρίς ψήφους ή ιεραρχία απαντήσεων. Κάθε προεπιλογή μπορεί να παρακαμφθεί μέσω `config`.
- `FastCommentsFeed` – κοινωνική ροή με συνθέτη ανάρτησης, πολυμέσα, αντιδράσεις, ακολουθήσεις και ζωντανές ταινίες νέων αναρτήσεων.

```tsx
    <FastCommentsLiveChat config=\{{ tenantId: 'demo', urlId: 'my-room' }}/>
```

### Θέματα

Η προεπιλεγμένη εμφάνιση δημιουργείται από ένα σύνολο σημασιολογικών διακριτικών σχεδίασης (`FastCommentsTheme`): χρώματα, αποστάσεις, ακτίνες, μεγέθη γραμματοσειράς, βάρη γραμματοσειράς και μεγέθη avatar. Περνάτε μερικές παρακάμψεις διακριτικών (τυποποιημένες ως `FastCommentsThemeOverrides`) μέσω της ιδιότητας `theme` σε οποιοδήποτε συστατικό και ολόκληρο το δέντρο στυλ επανασχεδιάζεται συνεπώς:

```tsx
    <FastCommentsLiveCommenting config={config} theme=\{{ colors: { primary: '#FF5500' } }}/>
```

Το σκοτεινό θέμα είναι ένα σύνολο διακριτικών μακριά:

```tsx
    import { getDarkTheme } from 'fastcomments-react-native-sdk';

    <FastCommentsLiveCommenting config={config} theme={getDarkTheme()}/>
```

Η ιδιότητα `styles` εξακολουθεί να δέχεται ένα ακατέργαστο δέντρο `IFastCommentsStyles` για χειρουργικό έλεγχο. Όταν παρέχονται και `theme` και `styles`, τα ρητά στυλ υπερισχύουν του θεματικού δέντρου· όταν παρέχεται μόνο `styles`, αντικαθιστά πλήρως τις προεπιλογές (η αρχική συμπεριφορά, ώστε υπάρχουσες ενσωματώσεις και skins να μην επηρεάζονται). Το `setupDarkModeSkin` έχει καταργηθεί υπέρ της ιδιότητας `theme`.

### Επιλογές Διαμόρφωσης

Αυτή η βιβλιοθήκη στοχεύει να υποστηρίξει όλες τις επιλογές διαμόρφωσης που ορίζονται στο [fastcomments-typescript](https://github.com/FastComments/fastcomments-typescript/blob/main/src/fast-comments-comment-widget-config.ts), όπως και η υλοποίηση web.

Πέρα από αυτές, το React Native προσθέτει μερικές επιλογές ειδικές για το SDK μέσω `FastCommentsRNConfig`:

- `hideTopBar` – απόκρυψη της γραμμής χρήστη συνδεδεμένου / καμπάνας ειδοποιήσεων που εμφανίζεται πάνω από τον συνθέτη.
- `usePressToEdit` – πάτημα‑και‑κράτημα ενός σχολίου για άνοιγμα του μενού του.
- `disableDownVoting` – απόκρυψη κουμπιών αρνητικής ψήφου.
- `renderCommentInline` – απόδοση πληροφοριών σχολιαστή μέσα στο ίδιο HTML μπλοκ με το περιεχόμενο του σχολίου.
- `renderLikesToRight` – μετακίνηση της περιοχής ψήφου/μουσουλίας δεξιά του σχολίου αντί κάτω από αυτό.
- `renderDateBelowComment` – απόδοση της ημερομηνίας κάτω από το σχόλιο.
- `showLiveStatus` – εμφάνιση της γραμμής κεφαλίδας τύπου chat «Live» + αριθμός χρηστών πάνω από τα σχόλια.
- `useInlineSubmitButton` – απόδοση του κουμπιού υποβολής ως εικονίδιο μέσα στον συνθέτη.
- `countAboveToggle` – με `useShowCommentsToggle`, πόσα σχόλια εμφανίζονται πάνω από το κουμπί «Show Comments».
- `preserveFeedScrollPosition` – το `FastCommentsFeed` θυμάται τη θέση κύλισης του μεταξύ αποσύνδεσης/επανασύνδεσης (προεπιλογή true).

### Έννοιες FastComments

Οι κύριες έννοιες που πρέπει να γνωρίζετε για να ξεκινήσετε είναι `tenantId` και `urlId`. Το `tenantId` είναι το αναγνωριστικό λογαριασμού σας στο FastComments.com. Το `urlId` είναι το σημείο στο οποίο θα συνδεθούν τα νήματα σχολίων. Αυτό μπορεί να είναι ένα URL σελίδας, ή ένα αναγνωριστικό προϊόντος, ένα αναγνωριστικό άρθρου κ.λπ.

### Τοπικοποίηση

Όλο το κείμενο που βλέπουν οι χρήστες σε αυτά τα συστατικά (ετικέτες κουμπιών, placeholders, κενές καταστάσεις, σχετικές ημερομηνίες όπως «5 λεπτά πριν», μηνύματα σφάλματος κ.λπ.) είναι **διαχειριζόμενο από τον διακομιστή**. Τα συστατικά δεν κωδικοποιούν σκληρά αγγλικές συμβολοσειρές· εμφανίζουν τις μεταφράσεις που παρέχει το FastComments για τη ζητούμενη γλώσσα.

Για να ζητήσετε μια γλώσσα, ορίστε `locale` στη διαμόρφωσή σας:

```ts
const config = {
    tenantId: 'your-tenant-id',
    urlId: 'some-page',
    locale: 'de_de', // de_de, fr_fr, ja_jp, es_es, κ.λπ.
};
```

Όταν δεν οριστεί `locale`, το FastComments εξυπηρετεί τη γλώσσα προεπιλογής του ενοικιαστή.

**Επεξεργασία του κειμένου:** οι μεταφράσεις διαχειρίζονται στον πίνακα ελέγχου του FastComments, όχι σε αυτό το SDK. Για να αλλάξετε τη διατύπωση, παρακάμψτε το προεπιλεγμένο κείμενο ή προσθέστε μια γλώσσα, επεξεργαστείτε τις μεταφράσεις για τον λογαριασμό σας στον πίνακα ελέγχου – η αλλαγή υιοθετείται αυτόματα από τα συστατικά χωρίς να απαιτείται νέα έκδοση της εφαρμογής. Το SDK δεν παρέχει αγγλικές εναλλακτικές, έτσι οποιοδήποτε κλειδί αφήσετε κενό στον πίνακα ελέγχου εμφανίζεται κενό· διατηρήστε τα κλειδιά γεμάτα για κάθε γλώσσα που υποστηρίζετε.

### Ειδοποιήσεις Χρηστών

Το FastComments υποστηρίζει ειδοποιήσεις για [πολλά σενάρια](https://docs.fastcomments.com/guide-notifications.html). Οι ειδοποιήσεις είναι διαμορφώσιμες, μπορούν να απενεργοποιηθούν παγκοσμίως ή σε επίπεδο ειδοποίησης/σχολίου, και υποστηρίζουν συνδρομές σε επίπεδο σελίδας ώστε οι χρήστες να μπορούν να εγγραφούν σε νήματα μιας συγκεκριμένης σελίδας ή άρθρου.

Για παράδειγμα, είναι δυνατόν να χρησιμοποιήσετε Secure SSO για έλεγχο ταυτότητας του χρήστη και στη συνέχεια να ελέγχετε περιοδικά για αδιάβαστες ειδοποιήσεις και να τις σπρώχνετε στον χρήστη.

Δείτε το [παράδειγμα AppNotificationSecureSSO](https://github.com/FastComments/fastcomments-react-native-sdk/blob/main/example/src/AppNotificationsSecureSSO.tsx) για το πώς να λάβετε και να μεταφράσετε αδιάβαστες ειδοποιήσεις χρήστη.
