- `nl_nl`: Niederländisch
- `en_us`: Englisch (Nordamerika)
- `fr_fr`: Französisch (Frankreich)
- `de_de`: Deutsch (Deutschland)
- `el_cy`: Griechisch (Zypern)
- `el_gr`: Griechisch (Griechenland)

- `it_it`: Italienisch (Italien)

### Rechts-nach-Links-Sprachen

Arabisch (`ar`) und Hebräisch (`he`) sind Rechts-nach-Links-Sprachen. Wenn einer dieser Sprachregionen verwendet wird, legt FastComments das Kommentar-Widget, E‑Mails und das Dashboard von rechts nach links an. Es ist keine zusätzliche Konfiguration erforderlich.

Jeder Kommentar und Benutzername folgt der Schreibrichtung seines eigenen Textes. Ein englischer Kommentar wird von links nach rechts auf einer arabischen Seite angezeigt, und ein arabischer Kommentar wird von rechts nach links auf einer englischen Seite angezeigt.

Code‑Snippets werden immer von links nach rechts gelesen.

### Pluralformen

Text, das eine Zählung enthält, wie „3 Kommentare“, verwendet die korrekte Pluralform für jede Sprache. Zum Beispiel hat Arabisch separate Formen für eins, zwei, wenige und viele, und Russisch sowie Polnisch haben separate Formen für wenige und viele.
