Tous les produits FastComments qui sont **intégrables dans votre application ou site web**, sont localisés.

Tous les **e‑mails** sont entièrement localisés. La langue utilisée pour générer les e‑mails que nous envoyons est basée sur la dernière
langue que l'utilisateur a utilisée lorsqu'il s'est connecté pour la dernière fois ou a commenté avec le widget de commentaire.

Le **tableau de bord admin et utilisateur** est localisé. Chaque utilisateur peut choisir sa langue préférée sur la page des détails de son compte.
