### 오른쪽에서 왼쪽으로 쓰는 언어

아랍어(`ar`)와 히브리어(`he`)는 오른쪽에서 왼쪽으로 쓰는 언어입니다. 이러한 로케일 중 하나가 사용되면 FastComments는 댓글 위젯, 이메일, 대시보드를 오른쪽에서 왼쪽으로 배치합니다. 추가 설정이 필요하지 않습니다.

각 댓글과 사용자 이름은 해당 텍스트 자체의 방향을 따릅니다. 아랍어 페이지의 영어 댓글은 왼쪽에서 오른쪽으로 읽히며, 영어 페이지의 아랍어 댓글은 오른쪽에서 왼쪽으로 읽힙니다.

코드 스니펫은 항상 왼쪽에서 오른쪽으로 읽힙니다.

### 복수형

"3 comments"와 같이 개수가 포함된 텍스트는 각 언어에 맞는 올바른 복수형을 사용합니다. 예를 들어, 아랍어는 하나, 둘, 몇몇, 많음에 대해 별도의 형태를 가지며, 러시아어와 폴란드어는 몇몇과 많음에 대해 별도의 형태를 가집니다.
