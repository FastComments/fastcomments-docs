Пользователи с правом `Super Admin` могут добавлять и удалять других модераторов.

Пользователя можно добавить, перейдя [на страницу Пользователи](https://fastcomments.com/auth/my-account/users) и
нажав `Add User` внизу.

[app-screenshot-start url='/auth/my-account/users'; selector = '.content'; alt='Страница пользователей, показывающая администраторов учетной записи, с кнопкой Add User внизу'; title='Страница пользователей' app-screenshot-end]

При добавлении пользователя мы можем задать его аватар, имя пользователя, электронную почту, локаль и права.

[app-screenshot-start url='/auth/my-account/users/new/edit'; selector = '.content'; alt='Форма редактирования пользователя с заполненными полями аватара, имени пользователя, электронной почты, локали и прав'; title='Добавление пользователя' app-screenshot-end]

При добавлении администратора ему будет отправлено приветственное письмо и ссылка для входа.
