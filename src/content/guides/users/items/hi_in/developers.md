उन डेवलपर्स के लिए, जिन्हें आप `Administrators` नहीं बनाना चाहते, निम्नलिखित अनुमतियों के साथ एक `Administrator` उपयोगकर्ता बनाने पर विचार करें:

1. Analytics Admin
2. Customizations Admin
3. Data Management Admin
4. Comment Moderation Admin
5. API/SSO Admin

अनुमतियों का यह सेट डेवलपर को FastComments सेटअप करने के लिए आवश्यक सब कुछ देगा, साथ ही
यह सुनिश्चित करने के लिए आवश्यक सिस्टम की दृश्यता भी देगा कि यह ठीक से काम कर रहा है।

इन अनुमतियों का कारण इस प्रकार है:

1. **Analytics Admin**: इसका उपयोग FastComments के उपयोग को डीबग करने के लिए किया जा सकता है।
2. **Customizations Admin**: कमेंट विजेट पर कस्टम स्टाइलिंग लागू करने के लिए यह आवश्यक होगा।
3. **Data Management Admin**: इंपोर्ट और एक्सपोर्ट प्रबंधित करने और वेबहुक सेटअप करने के लिए यह आवश्यक होगा।
4. **Comment Moderation Admin**: कमेंट डेटा देखने के लिए यह आवश्यक होगा, कम से कम सेटअप के दौरान।
5. **API/SSO Admin**: यह उन्हें सीधे हमारे प्लेटफ़ॉर्म से API कुंजियाँ प्राप्त करने की अनुमति देगा। हम इसे
`Administrator` द्वारा कुंजी कॉपी करके ईमेल के माध्यम से API Secret भेजने से अधिक सुरक्षित मानते हैं, क्योंकि
   ईमेल बहुत सुरक्षित नहीं हो सकता।
