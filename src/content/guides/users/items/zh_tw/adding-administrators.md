Users with the `Super Admin` permission can add and remove other moderators.

A user can be added by navigating [Users 頁面](https://fastcomments.com/auth/my-account/users) and clicking `Add User` at the bottom.

[app-screenshot-start url='/auth/my-account/users'; selector = '.content'; alt='帳戶中列出管理員的 Users 頁面，底部有 Add User 按鈕'; title='Users 頁面' app-screenshot-end]

When adding a user we can set their avatar, username, email, locale, and permissions.

[app-screenshot-start url='/auth/my-account/users/new/edit'; selector = '.content'; alt='已填寫 avatar、username、email、locale 與 permission 欄位的使用者編輯表單'; title='新增使用者' app-screenshot-end]

When adding an administrator, they will be sent a welcome email and login link.
