Коли SAML увімкнено у FastComments, система автоматично генерує інформацію постачальника послуг (SP), яку потрібно налаштувати у вашому постачальнику ідентифікації.

### Доступ до інформації постачальника послуг

Інформація SP відображається на сторінці конфігурації SAML після увімкнення SAML-автентифікації. Ця інформація містить усі деталі, які потрібні вашому постачальнику ідентифікації для встановлення довірчих відносин SAML.

### Кінцеві точки постачальника послуг

#### SP Entity ID / Audience
**Призначення**: Унікально ідентифікує ваш екземпляр FastComments як постачальника послуг
**Формат**: `https://fastcomments.com/saml/{your-tenant-id}`
**Використання**: Налаштуйте це як Entity ID або Audience у вашому IdP

Цей ідентифікатор гарантує, що SAML-відповіді призначені саме для вашого тенанта FastComments, і запобігає прийняттю SAML-відповідей іншими екземплярами.

#### Assertion Consumer Service (ACS) URL
**Призначення**: Кінцева точка, куди ваш IdP надсилає SAML-відповіді після автентифікації користувача
**Формат**: `https://fastcomments.com/saml/callback/{your-tenant-id}`
**Використання**: Налаштуйте це як ACS URL або Reply URL у вашому IdP

Сюди користувачі перенаправляються після успішної автентифікації у вашому постачальнику ідентифікації разом із SAML-твердженням, що містить інформацію про користувача.

#### SP Metadata URL
**Призначення**: Надає повну конфігурацію SAML у стандартному форматі XML
**Формат**: `https://fastcomments.com/saml/metadata/{your-tenant-id}`
**Використання**: Деякі IdP можуть автоматично імпортувати конфігурацію за цією URL-адресою

Metadata URL містить усю необхідну інформацію SP у форматі XML, що дозволяє легко автоматично налаштувати сумісні постачальники ідентифікації.

#### SAML Login URL
**Призначення**: Пряме посилання для ініціації SAML-автентифікації для вашого тенанта
**Формат**: `https://fastcomments.com/saml/login/{your-tenant-id}`
**Використання**: Направляйте користувачів безпосередньо на SAML-автентифікацію або тестуйте процес

Ви можете використовувати цю URL-адресу для тестування SAML-автентифікації або надати користувачам пряме посилання для входу через SAML.

### Підтримка SAML-прив'язок

FastComments підтримує такі SAML-прив'язки:

#### HTTP-POST Binding
- **Основний метод**: Найпоширеніша прив'язка для SAML-відповідей
- **Безпека**: SAML-відповідь надсилається через HTTP POST на ACS URL
- **Використання**: Рекомендується для робочих розгортань

#### HTTP-Redirect Binding
- **Альтернативний метод**: SAML-відповідь надсилається через HTTP-перенаправлення
- **Обмеження**: Обмежений розмір даних через обмеження довжини URL
- **Використання**: Підтримується, але HTTP-POST є кращим

### Політика Name ID

FastComments налаштовує таку політику Name ID у SAML-запитах:

- **Формат за замовчуванням**: `urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress`
- **Альтернативні формати**: Persistent, Transient, Unspecified (налаштовується)
- **Вимога**: Адреса електронної пошти використовується як основний ідентифікатор користувача

### Атрибути SAML-запиту

Під час ініціації SAML-автентифікації FastComments надсилає запити з такими характеристиками:

#### Підписання запиту
- **Статус**: Необов'язково (налаштовується)
- **Алгоритм**: Відповідає налаштованому алгоритму підпису
- **Сертифікат**: Використовується сертифікат, специфічний для тенанта, якщо підписання запитів увімкнено

#### Запитувані атрибути
FastComments запитує такі атрибути в SAML AuthnRequests:

- **Email**: Обов'язковий для ідентифікації користувача
- **Ім'я**: Необов'язкове для цілей відображення
- **Прізвище**: Необов'язкове для цілей відображення
- **Ролі/Групи**: Необов'язкові для контролю доступу та дозволів

### Копіювання інформації SP

Сторінка конфігурації SAML надає клікабельні поля, які автоматично копіюють інформацію SP у буфер обміну:

1. Клацніть будь-яке поле інформації SP (Entity ID, ACS URL тощо)
2. Значення автоматично копіюється у буфер обміну
3. Вставте значення у конфігурацію вашого постачальника ідентифікації
4. Коротке підсвічування вказує на успішне копіювання

Це дозволяє легко точно перенести інформацію SP у ваш IdP без помилок введення.

### Інформація про сертифікат SP

#### Використання сертифіката
- **Призначення**: Шифрує комунікації та перевіряє ідентичність SP
- **Ротація**: Сертифікати автоматично керуються FastComments
- **Доступ**: Публічні сертифікати доступні через metadata URL

#### Деталі сертифіката
- **Алгоритм**: RSA-2048 або вище
- **Термін дії**: Сертифікати автоматично поновлюються до закінчення терміну дії
- **Розповсюдження**: Доступні через стандартні метадані SAML

### Усунення несправностей конфігурації SP

Якщо ваш постачальник ідентифікації повідомляє про проблеми з інформацією SP:

1. **Перевірте URL**: Переконайтеся, що всі URL використовують HTTPS і містять правильний ID тенанта
2. **Перевірте метадані**: Використовуйте metadata URL для перевірки конфігурації
3. **Перевірте з'єднання**: Переконайтеся, що ваш IdP може досягти кінцевих точок FastComments
4. **Перевірте формат**: Підтвердіть, що ваш IdP підтримує формат інформації SP

Типові проблеми включають:
- Неправильний ID тенанта в URL
- Проблеми з мережевим з'єднанням між IdP та FastComments
- IdP очікує інші формати URL або додаткові параметри конфігурації
