Το FastComments αντιστοιχίζει τους ρόλους χρηστών SAML σε εσωτερικά δικαιώματα, επιτρέποντας έλεγχο πρόσβασης βάσει ρόλων για τον οργανισμό σας.

### Σύστημα Ρόλων του FastComments

Το FastComments χρησιμοποιεί ένα σύστημα δικαιωμάτων βάσει ρόλων, όπου οι χρήστες μπορούν να έχουν έναν ή περισσότερους ρόλους που καθορίζουν τα επίπεδα πρόσβασης και τις δυνατότητές τους.

### Διαθέσιμοι Ρόλοι του FastComments

#### Διοικητικοί Ρόλοι

**fc-account-owner**
- **Δικαιώματα**: Πλήρης διοικητική πρόσβαση
- **Δυνατότητες**: Όλες οι λειτουργίες, διαχείριση χρεώσεων, διαχείριση χρηστών
- **Περίπτωση χρήσης**: Κύριοι διαχειριστές και ιδιοκτήτες λογαριασμού

**fc-admin-admin**  
- **Δικαιώματα**: Διοικητική πρόσβαση στις περισσότερες λειτουργίες
- **Δυνατότητες**: Διαχείριση χρηστών, ρυθμίσεις, συντονισμός. **Μπορεί να διαχειρίζεται άλλους διαχειριστές.**
- **Περίπτωση χρήσης**: Δευτερεύοντες διαχειριστές και προσωπικό IT

**fc-billing-admin**
- **Δικαιώματα**: Διαχείριση χρεώσεων και συνδρομών
- **Δυνατότητες**: Τρόποι πληρωμής, τιμολόγια, αλλαγές συνδρομής
- **Περίπτωση χρήσης**: Μέλη οικονομικού τμήματος και υπεύθυνοι χρεώσεων

#### Εξειδικευμένοι Ρόλοι

**fc-analytics-admin**
- **Δικαιώματα**: Πρόσβαση σε αναλυτικά στοιχεία και αναφορές
- **Δυνατότητες**: Προβολή στατιστικών ιστότοπου, δεδομένων αλληλεπίδρασης χρηστών
- **Περίπτωση χρήσης**: Ομάδες μάρκετινγκ και αναλυτές δεδομένων

**fc-api-admin**
- **Δικαιώματα**: Πρόσβαση και διαχείριση API
- **Δυνατότητες**: Διαπιστευτήρια API, ρύθμιση webhooks
- **Περίπτωση χρήσης**: Προγραμματιστές και τεχνικοί ενσωματωτές

**fc-moderator**
- **Δικαιώματα**: Δυνατότητες συντονισμού σχολίων
- **Δυνατότητες**: Έγκριση/απόρριψη σχολίων, διαχείριση spam
- **Περίπτωση χρήσης**: Συντονιστές κοινότητας και διαχειριστές περιεχομένου

### Ρύθμιση Αντιστοίχισης Ρόλων

#### Πηγές Χαρακτηριστικών SAML

Το FastComments δέχεται πληροφορίες ρόλων από διάφορα ονόματα χαρακτηριστικών SAML για να εξασφαλίσει συμβατότητα με διαφορετικούς παρόχους ταυτότητας:

**Τυπικά Ονόματα Χαρακτηριστικών**:
- `roles`
- `groups` 
- `memberOf`
- `role`
- `group`

**Χαρακτηριστικά Microsoft/ADFS**:
- `http://schemas.microsoft.com/ws/2008/06/identity/claims/role`
- `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/role`

#### Υποστήριξη Μορφής Ρόλων

**Μορφή Πίνακα** *(Προτιμώμενη)*:
```xml
<saml:Attribute Name="roles">
    <saml:AttributeValue>fc-admin-admin</saml:AttributeValue>
    <saml:AttributeValue>fc-moderator</saml:AttributeValue>
</saml:Attribute>
```

**Μορφή Διαχωρισμένη με Κόμματα**:
```xml
<saml:Attribute Name="roles">
    <saml:AttributeValue>fc-admin-admin,fc-moderator</saml:AttributeValue>
</saml:Attribute>
```

**Μορφή Μεμονωμένου Ρόλου**:
```xml
<saml:Attribute Name="roles">
    <saml:AttributeValue>fc-admin-admin</saml:AttributeValue>
</saml:Attribute>
```

### Ρύθμιση Ρόλων στον Πάροχο Ταυτότητας

#### Microsoft Azure AD

1. **Ρύθμιση Ρόλων Εφαρμογής**:
   - Ορίστε ρόλους FastComments στην εφαρμογή Azure AD σας
   - Αναθέστε χρήστες σε κατάλληλους ρόλους εφαρμογής
   - Ρυθμίστε τα claims ώστε να περιλαμβάνουν τους ανατεθειμένους ρόλους

2. **Αντιστοίχιση Χαρακτηριστικών**:
   ```
   Attribute Name: roles
   Source Attribute: user.assignedroles
   ```

#### Okta

1. **Ανάθεση Ομάδων**:
   - Δημιουργήστε ομάδες που αντιστοιχούν στα ονόματα ρόλων του FastComments
   - Αναθέστε χρήστες σε κατάλληλες ομάδες
   - Ρυθμίστε τις δηλώσεις χαρακτηριστικών

2. **Δήλωση Χαρακτηριστικού**:
   ```
   Name: roles
   Value: user.groups
   Filter: Starts with "fc-"
   ```

#### Google Workspace

1. **Αντιστοίχιση Ομάδων**:
   - Δημιουργήστε οργανωτικές μονάδες ή ομάδες
   - Ονομάστε τις ομάδες με προθέματα ρόλων του FastComments
   - Ρυθμίστε την αντιστοίχιση χαρακτηριστικών

2. **Προσαρμοσμένα Χαρακτηριστικά**:
   ```
   Attribute Name: roles
   Value: Groups or custom schema attribute
   ```

### Προεπιλεγμένη Συμπεριφορά Χρηστών

#### Χρήστες Χωρίς Ρόλους

Όταν ένας χρήστης SAML δεν έχει ρόλους ή έχει μη αναγνωρίσιμους ρόλους:
- Ο χρήστης δημιουργείται ως απλός σχολιαστής
- Δεν χορηγείται διοικητική πρόσβαση
- Μπορεί να δημοσιεύει και να διαχειρίζεται τα δικά του σχόλια
- Δεν μπορεί να έχει πρόσβαση στις λειτουργίες του διαχειριστικού πίνακα

#### Κληρονομικότητα Ρόλων

- Οι χρήστες μπορούν να έχουν πολλαπλούς ρόλους ταυτόχρονα
- Τα δικαιώματα είναι αθροιστικά (ισχύει το υψηλότερο επίπεδο δικαιωμάτων)
- Οι αλλαγές ρόλων στον IdP αντικατοπτρίζονται στην επόμενη σύνδεση

### Διαχείριση Χρηστών SAML

#### Δημιουργία Χρήστη

Όταν ένας χρήστης συνδέεται μέσω SAML για πρώτη φορά:
1. **Λογαριασμός Χρήστη**: Δημιουργείται αυτόματα με το email ως αναγνωριστικό
2. **Ανάθεση Ρόλων**: Οι ρόλοι εφαρμόζονται βάσει των χαρακτηριστικών SAML
3. **Πληροφορίες Προφίλ**: Όνομα/επώνυμο συμπληρώνονται αν παρέχονται
4. **Ενεργοποίηση Δικαιωμάτων**: Οι ρόλοι γίνονται ενεργοί αμέσως

#### Ενημερώσεις Ρόλων

Οι υπάρχοντες χρήστες SAML λαμβάνουν ενημερώσεις ρόλων:
1. **Ενεργοποίηση μέσω Σύνδεσης**: Οι ενημερώσεις ρόλων πραγματοποιούνται σε κάθε σύνδεση SAML
2. **Άμεση Επίδραση**: Τα νέα δικαιώματα εφαρμόζονται αμέσως
3. **Αφαίρεση Ρόλων**: Οι αφαιρεθέντες ρόλοι ανακαλούνται αυτόματα
4. **Ιχνηλασιμότητα**: Οι αλλαγές ρόλων καταγράφονται στα αρχεία ελέγχου

### Προσαρμοσμένη Αντιστοίχιση Ρόλων

#### Προσαρμογή για Επιχειρήσεις

Για εταιρικούς πελάτες με ειδικές απαιτήσεις:
- Προσαρμοσμένα ονόματα ρόλων μπορούν να αντιστοιχιστούν σε δικαιώματα του FastComments
- Μπορούν να υλοποιηθούν σύνθετες ιεραρχίες ρόλων
- Μπορούν να ρυθμιστούν έλεγχοι πρόσβασης ανά τμήμα

Επικοινωνήστε με την υποστήριξη του FastComments για προσαρμοσμένες ρυθμίσεις αντιστοίχισης ρόλων.

#### Επικύρωση Ρόλων

Το FastComments επικυρώνει τους εισερχόμενους ρόλους:
- Οι μη αναγνωρίσιμοι ρόλοι αγνοούνται (δεν απορρίπτονται)
- Οι κακοδιατυπωμένες ιδιότητες ρόλων καταγράφονται για αντιμετώπιση προβλημάτων
- Οι χρήστες διατηρούν τους υπάρχοντες ρόλους τους αν η δήλωση SAML δεν περιέχει πληροφορίες ρόλων

### Βέλτιστες Πρακτικές

#### Διαχείριση Ρόλων

1. **Αρχή της Ελάχιστης Δικαιοδοσίας**: Αναθέστε τα ελάχιστα απαραίτητα δικαιώματα
2. **Τακτικός Έλεγχος**: Επανεξετάζετε περιοδικά τους ρόλους και την πρόσβαση των χρηστών  
3. **Σαφής Ονομασία**: Χρησιμοποιήστε περιγραφικά ονόματα ομάδων στον IdP σας
4. **Τεκμηρίωση**: Διατηρείτε τεκμηρίωση των αναθέσεων ρόλων

#### Ζητήματα Ασφαλείας

1. **Χαρακτηριστικά Ρόλων**: Βεβαιωθείτε ότι τα χαρακτηριστικά ρόλων είναι κατάλληλα προστατευμένα στις απαντήσεις SAML
2. **Επικύρωση Χαρακτηριστικών**: Επαληθεύστε ότι μόνο εξουσιοδοτημένα συστήματα μπορούν να αναθέτουν ρόλους
3. **Αναθεωρήσεις Πρόσβασης**: Επανεξετάζετε τακτικά τις αναθέσεις διοικητικών ρόλων
4. **Παρακολούθηση**: Παρακολουθείτε τις αλλαγές ρόλων και τις διοικητικές ενέργειες

### Αντιμετώπιση Προβλημάτων Ρόλων

#### Συνηθισμένα Προβλήματα

**Οι Ρόλοι Δεν Εφαρμόζονται**:
- Ελέγξτε ότι τα ονόματα των χαρακτηριστικών SAML ταιριάζουν με τις υποστηριζόμενες μορφές
- Επαληθεύστε ότι ο IdP στέλνει πληροφορίες ρόλων
- Επιβεβαιώστε ότι οι τιμές των ρόλων ταιριάζουν ακριβώς με τα ονόματα ρόλων του FastComments

**Άρνηση Πρόσβασης**:
- Επαληθεύστε ότι ο χρήστης έχει τον κατάλληλο ρόλο ανατεθειμένο στον IdP
- Ελέγξτε την ορθογραφία του ρόλου και την ευαισθησία σε πεζά/κεφαλαία
- Επιβεβαιώστε ότι ο ρόλος είναι σωστά διαμορφωμένος στην απάντηση SAML

**Λείπουν Δικαιώματα**:
- Επανεξετάστε τους ορισμούς ρόλων και τα απαιτούμενα δικαιώματα
- Ελέγξτε για αντικρουόμενες αναθέσεις ρόλων
- Επαληθεύστε ότι ο χρήστης έχει συνδεθεί μετά τις αλλαγές ρόλων
