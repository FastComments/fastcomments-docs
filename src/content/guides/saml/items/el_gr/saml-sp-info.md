Όταν το SAML είναι ενεργοποιημένο στο FastComments, το σύστημα δημιουργεί αυτόματα πληροφορίες Service Provider (SP) που χρειάζεστε για να ρυθμίσετε στον πάροχο ταυτότητάς σας.

### Πρόσβαση στις Πληροφορίες Service Provider

Οι πληροφορίες SP εμφανίζονται στη σελίδα ρυθμίσεων SAML μετά την ενεργοποίηση του SAML authentication. Αυτές οι πληροφορίες περιλαμβάνουν όλα τα στοιχεία που χρειάζεται ο πάροχος ταυτότητάς σας για να establish τη σχέση εμπιστοσύνης SAML.

### Endpoints του Service Provider

#### SP Entity ID / Audience
**Σκοπός**: Ταυτοποιεί μοναδικά την παρουσία FastComments σας ως service provider
**Μορφή**: `https://fastcomments.com/saml/{your-tenant-id}`
**Χρήση**: Ρυθμίστε το ως Entity ID ή Audience στον IdP σας

Αυτό το αναγνωριστικό διασφαλίζει ότι οι απαντήσεις SAML προορίζονται για τον συγκεκριμένο tenant του FastComments σας και αποτρέπει την αποδοχή απαντήσεων SAML από άλλες παρουσίες.

#### Assertion Consumer Service (ACS) URL
**Σκοπός**: Το endpoint όπου ο IdP σας στέλνει απαντήσεις SAML μετά την αυθεντικοποίηση του χρήστη
**Μορφή**: `https://fastcomments.com/saml/callback/{your-tenant-id}`
**Χρήση**: Ρυθμίστε το ως ACS URL ή Reply URL στον IdP σας

Εκεί ανακατευθύνονται οι χρήστες μετά την επιτυχή αυθεντικοποίηση με τον πάροχο ταυτότητάς σας, μαζί με το SAML assertion που περιέχει τις πληροφορίες χρήστη.

#### SP Metadata URL
**Σκοπός**: Παρέχει πλήρη ρύθμιση SAML σε τυπική μορφή XML
**Μορφή**: `https://fastcomments.com/saml/metadata/{your-tenant-id}`
**Χρήση**: Κάποιοι IdP μπορούν να εισάγουν αυτόματα τη ρύθμιση μέσω αυτού του URL

Το metadata URL περιέχει όλες τις απαραίτητες πληροφορίες SP σε μορφή XML, διευκολύνοντας την αυτόματη ρύθμιση συμβατών παρόχων ταυτότητας.

#### SAML Login URL
**Σκοπός**: Άμεσος σύνδεσμος για την έναρξη SAML authentication για τον tenant σας
**Μορφή**: `https://fastcomments.com/saml/login/{your-tenant-id}`
**Χρήση**: Συνδέστε χρήστες απευθείας με το SAML authentication ή δοκιμάστε τη ροή

Μπορείτε να χρησιμοποιήσετε αυτό το URL για να δοκιμάσετε το SAML authentication ή να δώσετε στους χρήστες άμεσο σύνδεσμο σύνδεσης μέσω SAML.

### Υποστήριξη SAML Bindings

Το FastComments υποστηρίζει τα εξής SAML bindings:

#### HTTP-POST Binding
- **Κύρια μέθοδος**: Η πιο συνηθισμένη μέθοδος για απαντήσεις SAML
- **Ασφάλεια**: Η απάντηση SAML αποστέλλεται μέσω HTTP POST στο ACS URL
- **Χρήση**: Συνιστάται για παραγωγικές αναπτύξεις

#### HTTP-Redirect Binding
- **Εναλλακτική μέθοδος**: Η απάντηση SAML αποστέλλεται μέσω HTTP redirect
- **Περιορισμοί**: Περιορισμένο μέγεθος payload λόγω περιορισμών μήκους URL
- **Χρήση**: Υποστηρίζεται, αλλά προτιμάται το HTTP-POST

### Name ID Policy

Το FastComments ρυθμίζει την εξής πολιτική Name ID στα αιτήματα SAML:

- **Προεπιλεγμένη μορφή**: `urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress`
- **Εναλλακτικές μορφές**: Persistent, Transient, Unspecified (ρυθμιζόμενο)
- **Απαίτηση**: Η διεύθυνση email χρησιμοποιείται ως το κύριο αναγνωριστικό χρήστη

### Χαρακτηριστικά Αιτημάτων SAML

Κατά την έναρξη του SAML authentication, το FastComments στέλνει αιτήματα με τα εξής χαρακτηριστικά:

#### Υπογραφή Αιτημάτων
- **Κατάσταση**: Προαιρετική (ρυθμιζόμενη)
- **Αλγόριθμος**: Ταιριάζει με τον ρυθμισμένο αλγόριθμο υπογραφής
- **Πιστοποιητικό**: Χρησιμοποιεί πιστοποιητικό ειδικό για τον tenant αν η υπογραφή αιτημάτων είναι ενεργοποιημένη

#### Ζητούμενα Χαρακτηριστικά
Το FastComments ζητά τα εξής χαρακτηριστικά στα SAML AuthnRequests:

- **Email**: Απαραίτητο για την ταυτοποίηση χρήστη
- **Όνομα**: Προαιρετικό για σκοπούς εμφάνισης
- **Επώνυμο**: Προαιρετικό για σκοπούς εμφάνισης
- **Ρόλοι/Ομάδες**: Προαιρετικά για έλεγχο πρόσβασης και δικαιώματα

### Αντιγραφή Πληροφοριών SP

Η σελίδα ρυθμίσεων SAML παρέχει πεδία με κλικ που αντιγράφουν αυτόματα τις πληροφορίες SP στο πρόχειρό σας:

1. Κάντε κλικ σε οποιοδήποτε πεδίο πληροφοριών SP (Entity ID, ACS URL, κ.λπ.)
2. Η τιμή αντιγράφεται αυτόματα στο πρόχειρό σας
3. Επικολλήστε την τιμή στη ρύθμιση του παρόχου ταυτότητάς σας
4. Μια σύντομη επισήμανση δείχνει επιτυχή αντιγραφή

Αυτό διευκολύνει την ακριβή μεταφορά των πληροφοριών SP στον IdP σας χωρίς τυπογραφικά λάθη.

### Πληροφορίες Πιστοποιητικού SP

#### Χρήση Πιστοποιητικού
- **Σκοπός**: Κρυπτογραφεί τις επικοινωνίες και επαληθεύει την ταυτότητα του SP
- **Εναλλαγή**: Τα πιστοποιητικά διαχειρίζονται αυτόματα από το FastComments
- **Πρόσβαση**: Τα δημόσια πιστοποιητικά είναι διαθέσιμα μέσω του metadata URL

#### Λεπτομέρειες Πιστοποιητικού
- **Αλγόριθμος**: RSA-2048 ή υψηλότερος
- **Ισχύς**: Τα πιστοποιητικά ανανεώνονται αυτόματα πριν τη λήξη
- **Διανομή**: Διαθέσιμα μέσω τυπικών SAML metadata

### Αντιμετώπιση Προβλημάτων Ρύθμισης SP

Αν ο πάροχος ταυτότητάς σας αναφέρει προβλήματα με τις πληροφορίες SP:

1. **Επαληθεύστε τα URLs**: Βεβαιωθείτε ότι όλα τα URLs χρησιμοποιούν HTTPS και περιλαμβάνουν το σωστό tenant ID
2. **Ελέγξτε τα Metadata**: Χρησιμοποιήστε το metadata URL για να επαληθεύσετε τη ρύθμιση
3. **Δοκιμάστε τη Συνδεσιμότητα**: Βεβαιωθείτε ότι ο IdP σας μπορεί να φτάσει στα endpoints του FastComments
4. **Επαληθεύστε τη Μορφή**: Επιβεβαιώστε ότι ο IdP σας υποστηρίζει τη μορφή των πληροφοριών SP

Συνηθισμένα προβλήματα περιλαμβάνουν:
- Λανθασμένο tenant ID στα URLs
- Προβλήματα δικτυακής συνδεσιμότητας μεταξύ IdP και FastComments
- Ο IdP να περιμένει διαφορετικές μορφές URL ή πρόσθετες επιλογές ρύθμισης
