이 가이드는 일반적인 SAML 인증 문제와 해결 방법을 다룹니다.

### 인증서 및 보안 문제

#### 잘못된 인증서 오류

**증상**:
- "Certificate validation failed" 오류
- 사용자가 SAML 인증을 완료할 수 없음
- SAML 응답이 거부됨

**일반적인 원인**:
- 인증서 형식이 올바르지 않음
- 인증서가 만료됨
- 잘못된 인증서가 제공됨
- 인증서에 불필요한 문자나 공백이 포함됨

**해결 방법**:
1. **인증서 형식 확인**:
   - 인증서에 `-----BEGIN CERTIFICATE-----` 및 `-----END CERTIFICATE-----` 마커가 포함되어 있는지 확인
   - 불필요한 공백이나 줄바꿈 제거
   - IdP 메타데이터 또는 구성에서 인증서를 직접 복사

2. **인증서 유효성 확인**:
   - 인증서가 만료되지 않았는지 확인
   - 인증서가 올바른 IdP에 대한 것인지 확인
   - 온라인 인증서 검증 도구를 사용하여 형식 확인

3. **인증서 재다운로드**:
   - IdP에서 최신 인증서 다운로드
   - 가능한 경우 IdP 메타데이터 URL 사용
   - 인증서가 현재 IdP 구성과 일치하는지 확인

#### 서명 검증 실패

**증상**:
- SAML assertion 서명 검증 오류
- IdP 로그인 후 인증 실패
- "Invalid signature" 오류 메시지

**해결 방법**:
1. **알고리즘 불일치**:
   - FastComments의 서명 알고리즘이 IdP와 일치하는지 확인
   - 다른 서명 알고리즘 시도 (SHA-256, SHA-1, SHA-512)
   - 다이제스트 알고리즘이 IdP 구성과 일치하는지 확인

2. **인증서 문제**:
   - 올바른 서명 인증서가 구성되어 있는지 확인
   - 인증서가 IdP에서 사용하는 개인 키와 대응되는지 확인
   - IdP에서 인증서 교체 여부 확인

### 구성 문제

#### 잘못된 Entity ID 또는 ACS URL

**증상**:
- IdP에서 "Unknown Service Provider" 보고
- SAML 응답이 잘못된 엔드포인트로 전송됨
- 인증이 완료되지 않음

**해결 방법**:
1. **SP 정보 확인**:
   - FastComments 구성에서 정확한 Entity ID 복사
   - ACS URL이 다음 형식과 일치하는지 확인: `https://fastcomments.com/saml/callback/{tenant-id}`
   - 테넌트 ID의 오타 확인

2. **IdP 구성**:
   - 올바른 SP Entity ID로 IdP 업데이트
   - 적절한 ACS/Reply URL 구성
   - IdP 바인딩 설정 확인 (HTTP-POST 권장)

#### 누락되거나 잘못된 속성

**증상**:
- 적절한 역할 없이 사용자 생성됨
- 사용자 프로필 정보 누락
- "Email required" 오류

**해결 방법**:
1. **이메일 속성**:
   - IdP가 이메일 속성을 전송하는지 확인
   - 속성 이름 매핑 확인 (email, emailAddress 등)
   - 이메일 값이 유효한 이메일 주소인지 확인

2. **역할 속성**:
   - IdP가 역할/그룹 정보를 전송하는지 확인
   - 역할 속성 이름이 FastComments의 기대와 일치하는지 확인
   - 역할 값이 FastComments 역할 이름과 정확히 일치하는지 확인

3. **속성 형식**:
   - 배열 형식과 쉼표로 구분된 역할 형식 모두 테스트
   - 속성 값에 불필요한 공백이 없는지 확인
   - 역할 이름의 대소문자 구분 확인

### 인증 흐름 문제

#### 리디렉션 루프

**증상**:
- 브라우저가 FastComments와 IdP 사이에서 무한히 리디렉션됨
- 인증이 완료되지 않음
- 브라우저 개발자 도구에서 여러 리디렉션이 표시됨

**해결 방법**:
1. **SP 구성 확인**:
   - Entity ID가 IdP 구성과 정확히 일치하는지 확인
   - IdP에서 ACS URL이 올바르게 구성되어 있는지 확인
   - URL의 후행 슬래시 확인

2. **세션 문제**:
   - 브라우저 쿠키를 지우고 다시 시도
   - 시크릿/개인 브라우저 창에서 테스트
   - 세션 타임아웃 설정 확인

#### 인증 후 접근 거부

**증상**:
- SAML 인증 성공
- 사용자가 FastComments로 리디렉션됨
- "Access denied" 또는 권한 오류 표시됨

**해결 방법**:
1. **역할 할당**:
   - 사용자가 IdP에서 적절한 역할을 가지고 있는지 확인
   - SAML 응답에 역할 속성이 전송되고 있는지 확인
   - 역할 이름이 FastComments 요구 사항과 정확히 일치하는지 확인

2. **패키지 제한**:
   - 계정에 Flex 또는 Pro 플랜이 있는지 확인
   - 패키지에 SAML 기능이 활성화되어 있는지 확인
   - 패키지에 SAML이 포함되어 있지만 기능을 사용할 수 없는 경우 지원팀에 문의

### IdP(Identity Provider)별 문제

#### Microsoft Azure AD

**일반적인 문제**:
- 앱 역할 할당이 토큰에 반영되지 않음
- 클레임이 제대로 전송되지 않음
- 사용자 할당 요구 사항

**해결 방법**:
- FastComments 애플리케이션에 사용자 할당 확인
- 앱 역할이 올바르게 구성되어 있는지 확인
- 클레임 매핑에 필수 속성이 포함되어 있는지 확인

#### Okta

**일반적인 문제**:
- 그룹 필터가 올바르게 작동하지 않음
- 속성 문(attribute statement)이 잘못 구성됨
- 애플리케이션 할당 문제

**해결 방법**:
- 속성 문 구성 검토
- 그룹 할당 및 필터링 규칙 확인
- 애플리케이션이 적절한 사용자/그룹에 할당되어 있는지 확인

#### Google Workspace

**일반적인 문제**:
- 사용자 지정 속성이 올바르게 매핑되지 않음
- 그룹 멤버십이 전송되지 않음
- SAML 애플리케이션 구성 오류

**해결 방법**:
- 역할 속성을 위한 사용자 지정 스키마 구성
- 그룹 멤버십 전파 확인
- SAML 애플리케이션 속성 매핑 확인

### 네트워크 및 연결 문제

#### 타임아웃 오류

**증상**:
- 인증 프로세스 타임아웃
- "Request timeout" 또는 유사한 오류
- 느린 인증 흐름

**해결 방법**:
1. **네트워크 연결**:
   - 방화벽 규칙이 FastComments 통신을 허용하는지 확인
   - fastcomments.com의 DNS 확인 테스트
   - IdP에서 FastComments로의 네트워크 연결 테스트

2. **성능 문제**:
   - IdP 응답 시간 확인
   - 인증서 체인 검증이 느리지 않은지 확인
   - IdP와 사용자 간의 네트워크 지연 고려

#### SSL/TLS 문제

**증상**:
- 인증 중 인증서 경고
- SSL 핸드셰이크 실패
- "Secure connection failed" 오류

**해결 방법**:
- 모든 SAML 엔드포인트가 HTTPS를 사용하는지 확인
- 관련된 모든 도메인의 인증서 유효성 확인
- TLS 버전 호환성 확인

### 디버깅 및 로깅

#### 디버그 정보 활성화

1. **브라우저 개발자 도구**:
   - SAML 흐름 중 네트워크 탭 모니터링
   - 콘솔에서 JavaScript 오류 확인
   - SAML POST 요청 검사 (보이는 경우)

2. **IdP 로깅**:
   - IdP에서 SAML 디버깅 활성화
   - IdP 로그에서 SAML 요청/응답 세부 정보 검토
   - 속성 매핑 문제 확인

#### 일반적인 로그 메시지

**FastComments 로그**:
- "SAML config not found" - SAML이 활성화되지 않았거나 잘못 구성됨
- "Invalid certificate" - 인증서 검증 실패
- "Missing email attribute" - SAML 응답에 필수 이메일이 제공되지 않음

**IdP 로그**:
- "Unknown service provider" - Entity ID 불일치
- "Invalid ACS URL" - Assertion Consumer Service URL이 잘못됨
- "User not assigned" - 사용자가 SAML 애플리케이션에 대한 접근 권한이 없음
