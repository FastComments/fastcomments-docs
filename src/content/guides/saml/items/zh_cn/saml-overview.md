SAML（安全断言标记语言）是一种基于 XML 的开放标准，用于在各方之间交换身份验证和授权数据，特别是在身份提供方（IdP）和服务提供方（SP）之间。

### SAML 的工作原理

SAML 通过允许用户只需向其身份提供方进行一次身份验证，然后即可访问多个应用程序而无需重新输入凭据，从而实现单点登录（SSO）。当用户尝试访问 FastComments 时：

1. **身份验证请求**：FastComments 将用户重定向到您的身份提供方
2. **用户身份验证**：用户向您的 IdP（例如 Active Directory、Okta、Azure AD）进行身份验证
3. **SAML 响应**：IdP 将签名的 SAML 断言发送回 FastComments
4. **用户访问**：FastComments 验证断言并向已通过身份验证的用户授予访问权限

### SAML 的优势

- **增强的安全性**：集中式身份验证降低了与密码相关的安全风险
- **改善的用户体验**：用户只需登录一次即可无缝访问多个应用程序
- **合规性**：有助于满足访问控制和审计跟踪方面的监管要求
- **管理控制**：IT 管理员可以维护集中式的用户管理

### SAML 2.0 支持

FastComments 实现了 SAML 2.0，这是 SAML 标准中被最广泛采用的版本。我们的实现支持：

- HTTP-POST 和 HTTP-Redirect 绑定
- 签名的 SAML 响应和断言
- 加密断言（可选）
- 多种签名和摘要算法
- 各种名称标识符格式
