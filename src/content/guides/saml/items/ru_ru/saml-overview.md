SAML (Security Assertion Markup Language) — это открытый стандарт на основе XML для обмена данными аутентификации и авторизации между сторонами, 
в частности между поставщиком идентификации (IdP) и поставщиком услуг (SP).

### Как работает SAML

SAML обеспечивает единый вход (SSO), позволяя пользователям проходить аутентификацию один раз у своего поставщика идентификации и затем получать доступ 
к нескольким приложениям без повторного ввода учетных данных. Когда пользователь пытается получить доступ к FastComments:

1. **Запрос аутентификации**: FastComments перенаправляет пользователя к вашему поставщику идентификации
2. **Аутентификация пользователя**: Пользователь проходит аутентификацию у вашего IdP (например, Active Directory, Okta, Azure AD)
3. **SAML-ответ**: IdP отправляет подписанное SAML-утверждение обратно в FastComments
4. **Доступ пользователя**: FastComments проверяет утверждение и предоставляет доступ аутентифицированному пользователю

### Преимущества SAML

- **Повышенная безопасность**: Централизованная аутентификация снижает риски, связанные с паролями
- **Улучшенный пользовательский опыт**: Пользователи входят один раз и получают доступ к нескольким приложениям без затруднений
- **Соответствие требованиям**: Помогает выполнять нормативные требования к контролю доступа и журналам аудита
- **Административный контроль**: ИТ-администраторы сохраняют централизованное управление пользователями

### Поддержка SAML 2.0

FastComments реализует SAML 2.0 — наиболее широко распространённую версию стандарта SAML. Наша реализация поддерживает:

- Привязки HTTP-POST и HTTP-Redirect
- Подписанные SAML-ответы и утверждения
- Зашифрованные утверждения (опционально)
- Несколько алгоритмов подписи и дайджеста
- Различные форматы идентификаторов имен
