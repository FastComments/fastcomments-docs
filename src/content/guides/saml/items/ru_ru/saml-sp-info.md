Когда SAML включен в FastComments, система автоматически генерирует информацию о поставщике услуг (SP), которую необходимо настроить в вашем поставщике идентификационных данных (IdP).

### Доступ к информации о поставщике услуг

Информация SP отображается на странице конфигурации SAML после включения аутентификации SAML. Эта информация содержит все детали, необходимые вашему поставщику идентификационных данных для установления доверительных отношений SAML.

### Конечные точки поставщика услуг

#### SP Entity ID / Audience
**Назначение**: Уникально идентифицирует ваш экземпляр FastComments как поставщика услуг
**Формат**: `https://fastcomments.com/saml/{your-tenant-id}`
**Использование**: Укажите это значение как Entity ID или Audience в вашем IdP

Этот идентификатор гарантирует, что SAML-ответы предназначены именно для вашего тенанта FastComments, и предотвращает принятие SAML-ответов другими экземплярами.

#### Assertion Consumer Service (ACS) URL
**Назначение**: Конечная точка, куда ваш IdP отправляет SAML-ответы после аутентификации пользователя
**Формат**: `https://fastcomments.com/saml/callback/{your-tenant-id}`
**Использование**: Укажите это значение как ACS URL или Reply URL в вашем IdP

Сюда пользователи перенаправляются после успешной аутентификации у вашего поставщика идентификационных данных вместе с SAML-утверждением, содержащим информацию о пользователе.

#### SP Metadata URL
**Назначение**: Предоставляет полную конфигурацию SAML в стандартном формате XML
**Формат**: `https://fastcomments.com/saml/metadata/{your-tenant-id}`
**Использование**: Некоторые IdP могут автоматически импортировать конфигурацию с помощью этого URL

URL метаданных содержит всю необходимую информацию SP в формате XML, что упрощает автоматическую настройку совместимых поставщиков идентификационных данных.

#### SAML Login URL
**Назначение**: Прямая ссылка для инициации SAML-аутентификации для вашего тенанта
**Формат**: `https://fastcomments.com/saml/login/{your-tenant-id}`
**Использование**: Направляйте пользователей напрямую на SAML-аутентификацию или тестируйте процесс

Вы можете использовать этот URL для тестирования SAML-аутентификации или предоставить пользователям прямую ссылку для входа через SAML.

### Поддержка SAML-привязок (Bindings)

FastComments поддерживает следующие SAML-привязки:

#### HTTP-POST Binding
- **Основной метод**: Наиболее распространенная привязка для SAML-ответов
- **Безопасность**: SAML-ответ отправляется через HTTP POST на ACS URL
- **Использование**: Рекомендуется для производственных развертываний

#### HTTP-Redirect Binding
- **Альтернативный метод**: SAML-ответ отправляется через HTTP-редирект
- **Ограничения**: Ограниченный размер полезной нагрузки из-за ограничений на длину URL
- **Использование**: Поддерживается, но предпочтителен HTTP-POST

### Политика Name ID

FastComments настраивает следующую политику Name ID в SAML-запросах:

- **Формат по умолчанию**: `urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress`
- **Альтернативные форматы**: Persistent, Transient, Unspecified (настраивается)
- **Требование**: Адрес электронной почты используется в качестве основного идентификатора пользователя

### Атрибуты SAML-запросов

При инициации SAML-аутентификации FastComments отправляет запросы со следующими характеристиками:

#### Подпись запросов
- **Статус**: Необязательно (настраивается)
- **Алгоритм**: Соответствует настроенному алгоритму подписи
- **Сертификат**: Используется сертификат, специфичный для тенанта, если подпись запросов включена

#### Запрашиваемые атрибуты
FastComments запрашивает следующие атрибуты в SAML AuthnRequests:

- **Email**: Требуется для идентификации пользователя
- **Имя**: Необязательно, для отображения
- **Фамилия**: Необязательно, для отображения
- **Роли/Группы**: Необязательно, для контроля доступа и прав

### Копирование информации SP

Страница конфигурации SAML предоставляет кликабельные поля, которые автоматически копируют информацию SP в буфер обмена:

1. Нажмите на любое поле информации SP (Entity ID, ACS URL и т.д.)
2. Значение автоматически копируется в буфер обмена
3. Вставьте значение в конфигурацию вашего поставщика идентификационных данных
4. Краткая подсветка указывает на успешное копирование

Это позволяет легко и без ошибок при вводе перенести информацию SP в ваш IdP.

### Информация о сертификате SP

#### Использование сертификата
- **Назначение**: Шифрует коммуникации и подтверждает подлинность SP
- **Ротация**: Сертификатами автоматически управляет FastComments
- **Доступ**: Публичные сертификаты доступны через URL метаданных

#### Детали сертификата
- **Алгоритм**: RSA-2048 или выше
- **Срок действия**: Сертификаты автоматически обновляются до истечения срока
- **Распространение**: Доступны через стандартные SAML-метаданные

### Устранение неполадок конфигурации SP

Если ваш поставщик идентификационных данных сообщает о проблемах с информацией SP:

1. **Проверьте URL**: Убедитесь, что все URL используют HTTPS и содержат правильный ID тенанта
2. **Проверьте метаданные**: Используйте URL метаданных для проверки конфигурации
3. **Проверьте связность**: Убедитесь, что ваш IdP может достигать конечных точек FastComments
4. **Проверьте формат**: Убедитесь, что ваш IdP поддерживает формат информации SP

К распространенным проблемам относятся:
- Неверный ID тенанта в URL
- Проблемы с сетевой связностью между IdP и FastComments
- IdP ожидает другие форматы URL или дополнительные параметры конфигурации
