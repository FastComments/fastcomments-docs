FastComments में SAML प्रमाणीकरण सेट अप करने के लिए आपके एडमिन डैशबोर्ड में कॉन्फ़िगरेशन और आपके आइडेंटिटी प्रोवाइडर में सेटअप — दोनों की आवश्यकता होती है।

### पूर्वापेक्षाएँ

SAML कॉन्फ़िगर करने से पहले, सुनिश्चित करें कि आपके पास है:

- FastComments Flex या Pro प्लान (Creators प्लान पर SAML उपलब्ध नहीं है)
- अपने FastComments खाते तक एडमिनिस्ट्रेटिव पहुँच
- अपने आइडेंटिटी प्रोवाइडर तक एडमिनिस्ट्रेटिव पहुँच
- अपने IdP की SAML मेटाडेटा या सर्टिफिकेट जानकारी

### SAML कॉन्फ़िगरेशन तक पहुँच

1. अपने [FastComments एडमिन डैशबोर्ड](https://fastcomments.com/auth/my-account) में लॉग इन करें
2. बाएँ साइडबार में **API/SSO Settings** पर जाएँ
3. **SAML Config** बटन पर क्लिक करें

यदि आपको SAML Config बटन नहीं दिखता, तो जाँचें कि:
- आपके खाते में आवश्यक पैकेज (Flex या Pro) है
- आपके पास एडमिनिस्ट्रेटिव अनुमतियाँ हैं
- आपके यूज़र के पास API Admin या Admin Admin भूमिकाएँ हैं

### बुनियादी SAML कॉन्फ़िगरेशन

#### SAML प्रमाणीकरण सक्षम करें

1. **Enable SAML Authentication** चेकबॉक्स पर टिक करें
2. इससे आपके टेनेंट के लिए SAML सक्रिय हो जाता है और कॉन्फ़िगरेशन फ़ील्ड उपलब्ध हो जाते हैं

#### आवश्यक फ़ील्ड

**IdP Single Sign-On URL** *(आवश्यक)*
- वह URL जहाँ उपयोगकर्ता प्रमाणीकरण के लिए रीडायरेक्ट किए जाएँगे
- आमतौर पर आपका आइडेंटिटी प्रोवाइडर इसे प्रदान करता है
- उदाहरण: `https://your-company.okta.com/app/fastcomments/sso/saml`

**IdP X.509 Certificate** *(आवश्यक)*
- आपके आइडेंटिटी प्रोवाइडर का सार्वजनिक सर्टिफिकेट
- SAML प्रतिक्रियाओं की प्रामाणिकता सत्यापित करने के लिए उपयोग किया जाता है
- BEGIN/END मार्कर सहित पूरा सर्टिफिकेट शामिल होना चाहिए
- उदाहरण प्रारूप:
```
-----BEGIN CERTIFICATE-----
MIICXjCCAcegAwIBAgIBADANBgkqhkiG9w0BAQsFADA...
-----END CERTIFICATE-----
```

#### वैकल्पिक फ़ील्ड

**IdP Entity ID / Issuer**
- आपके आइडेंटिटी प्रोवाइडर की पहचान करता है
- खाली छोड़ने पर, यह आपके FastComments URL पर डिफ़ॉल्ट हो जाता है
- यह आपके IdP में कॉन्फ़िगर किए गए issuer से मेल खाना चाहिए

### उन्नत कॉन्फ़िगरेशन

#### सुरक्षा सेटिंग्स

**Signature Algorithm**
- डिफ़ॉल्ट SHA-256 है (अनुशंसित)
- विकल्प: SHA-1, SHA-256, SHA-512
- यह आपके IdP की कॉन्फ़िगरेशन से मेल खाना चाहिए

**Digest Algorithm**
- डिफ़ॉल्ट SHA-256 है (अनुशंसित)
- SAML प्रतिक्रियाओं में डाइजेस्ट गणना के लिए उपयोग किया जाता है
- यह आपके IdP की कॉन्फ़िगरेशन से मेल खाना चाहिए

**Name ID Format**
- डिफ़ॉल्ट ईमेल पता प्रारूप है
- यह तय करता है कि यूज़र पहचानकर्ता किस प्रारूप में होंगे
- सामान्य विकल्प: Email Address, Persistent, Transient

#### एन्क्रिप्शन (वैकल्पिक)

**Private Key for Decryption**
- केवल तब आवश्यक जब आपका IdP SAML असर्शन एन्क्रिप्ट करता हो
- डिक्रिप्शन के लिए उपयोग की जाने वाली अपनी प्राइवेट की पेस्ट करें
- अधिकांश डिप्लॉयमेंट में असर्शन एन्क्रिप्शन की आवश्यकता नहीं होती

### कॉन्फ़िगरेशन सहेजना

1. सभी सेटिंग्स की सटीकता की समीक्षा करें
2. **Save SAML Configuration** पर क्लिक करें
3. सिस्टम आपकी कॉन्फ़िगरेशन को सत्यापित करेगा
4. सफल होने पर, आपको एक पुष्टि संदेश दिखाई देगा

### अगले कदम

अपनी FastComments SAML कॉन्फ़िगरेशन सहेजने के बाद:

1. Service Provider जानकारी का उपयोग करके अपने आइडेंटिटी प्रोवाइडर को कॉन्फ़िगर करें
2. प्रमाणीकरण प्रवाह का परीक्षण करें
3. आवश्यकतानुसार यूज़र भूमिकाएँ और अनुमतियाँ सेट अप करें

SAML सक्षम होने के बाद आपके IdP कॉन्फ़िगरेशन के लिए आवश्यक Service Provider जानकारी प्रदर्शित की जाएगी।
