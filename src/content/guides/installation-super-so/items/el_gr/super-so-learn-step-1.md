Πρώτα πρέπει να ανοίξουμε τον επεξεργαστή κώδικα. Αν θέλετε να προσθέσετε το FastComments σε όλες τις σελίδες, απλώς επιλέξτε Code στην κάτω αριστερή γωνία:

Αν θέλετε να το προσθέσετε σε μια συγκεκριμένη σελίδα, τότε επιλέξτε `Edit Custom Code` στις ρυθμίσεις αυτής της σελίδας.

Τώρα ας επιλέξουμε την καρτέλα `Body`. **Αυτό είναι σημαντικό!** Η εγκατάσταση του τμήματος κώδικα στο `Head` **δεν λειτουργεί**.
