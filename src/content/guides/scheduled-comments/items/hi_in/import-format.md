### फॉर्मेट विवरण

Scheduled Comments CSV फ़ाइल निम्नलिखित कॉलम को सपोर्ट करती है:

- ID
- Parent ID
- URL ID
- URL
- Name
- Avatar
- Comment
- Hours
- Minutes
- Seconds

निम्नलिखित कॉलम **आवश्यक** हैं:

- ID
- URL ID
- Name
- Comment
- Hours
- Minutes
- Seconds

यदि आप स्वचालित नेस्टेड रिप्लाई का समर्थन करना चाहते हैं, तो आपको Parent ID कॉलम की आवश्यकता होगी।

### फॉर्मेट कैसे काम करता है

इंपोर्ट फॉर्मेट इस तरह काम करता है:

1. आप जितनी कमेंट्स पोस्ट करना चाहते हैं, उनमें से प्रत्येक के लिए CSV में एक पंक्ति परिभाषित करते हैं।
2. कमेंट निर्दिष्ट देरी (घंटे + मिनट + सेकंड) के बाद पोस्ट किया जाता है।
   1. Manually Scheduled इंपोर्ट के लिए, देरी उस समय के सापेक्ष होती है जब आप इंपोर्ट पूरा होने के बाद UI में "play" दबाते हैं - **इंपोर्ट शुरू होने के समय से नहीं**।
   2. Auto Schedules इंपोर्ट के लिए, देरी पेज लोड होने के समय से होती है।
3. आपको एक ID परिभाषित करनी होगी। आप 1, 2, 3, 4, 5 जैसे बढ़ते हुए पहचानकर्ताओं का उपयोग कर सकते हैं।
4. यदि आप नेस्टेड रिप्लाई का उपयोग करना चाहते हैं, तो आप बस `Parent ID` कॉलम का मान किसी अन्य कमेंट की `ID` पर सेट करते हैं।
5. `Comment` फ़ील्ड वही सिंटैक्स सपोर्ट करता है जो FastComments अपने कमेंट विजेट में टेक्स्ट स्टाइलिंग और इमेज जोड़ने के लिए सपोर्ट करता है।
6. `Avatar` फ़ील्ड, यदि उपयोग किया जाता है, तो एक सार्वजनिक रूप से सुलभ इमेज होनी चाहिए। इसे हमारे CDN पर कॉपी करके वहाँ से सर्व किया जाएगा।
7. आप रिप्ले के बाद, या यदि रिप्ले रोक दिया जाता है, तो सभी कमेंट्स डिलीट कर सकते हैं।
8. डिलीशन लाइव होता है, इसलिए आप उसी scheduled इंपोर्ट को बार-बार दोबारा उपयोग कर सकते हैं।
