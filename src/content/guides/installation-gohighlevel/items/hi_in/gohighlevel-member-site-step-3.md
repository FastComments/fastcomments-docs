अब हम आपका कस्टम FastComments कोड जनरेट करेंगे। नीचे दिए गए विज़ार्ड का उपयोग करके कॉन्फ़िगर करें कि आपकी GoHighLevel साइट पर FastComments कैसे काम करे:

[snippet id="gohighlevel-wizard"]

### अलग-अलग कमेंट बॉक्स प्रकार

आप `TYPE = 'commenting'` लाइन को कॉन्फ़िगर करके उपयोग किया जाने वाला प्रोडक्ट बदल सकते हैं (उदाहरण के लिए आप इसे स्ट्रीमिंग चैट के लिए `live` या कोलैब चैट के लिए `collab` में बदल सकते हैं)।

### कमेंट बॉक्स को अपनी इच्छित जगह पर रखना

मान लीजिए आप पेज के विशेष हिस्सों पर कमेंट बॉक्स रखना चाहते हैं, न कि डिफ़ॉल्ट स्थानों पर।
इस लाइन को बदलें:

    const TARGET_ELEMENT_ID = ''; // set to use target div mode

इसमें:

    const TARGET_ELEMENT_ID = 'fc_box'; // set to use target div mode

फिर GHL एडिटर में, "code" बटन पर क्लिक करें और जहाँ आप कमेंट्स चाहते हैं वहाँ यह जोड़ें:

[inline-code-attrs-start title = 'GoHighLevel FastComments Div'; type = 'html'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
<div
  id="fc_box"
  type="commenting"
  urlid="custom-chat-id"
></div>
[inline-code-end]

### प्रत्येक पेज के लिए अलग कमेंट बॉक्स प्रकार

मान लीजिए आप चाहते हैं कि उपयोगकर्ता टेक्स्ट के हिस्सों को हाइलाइट करके उन पर चर्चा करें, या स्ट्रीमिंग चैट UI का उपयोग करें।

पहले ऊपर "कमेंट बॉक्स को अपनी इच्छित जगह पर रखना" में दिए गए चरणों का पालन करें।

ध्यान दें कि उस छोटे स्निपेट में `type="commenting"` है।

यदि आप उदाहरण के लिए कोलैब चैट सक्षम करना चाहते हैं तो type को `type="collab"` में बदलें।

### केवल विशेष पेजों पर दिखाएँ

यदि आप `TARGET_ELEMENT_ID` सेट नहीं करते हैं, तो आप इसके बजाय `VALID_PATTERNS` वेरिएबल को कॉन्फ़िगर कर सकते हैं, ताकि यह सेट किया जा सके कि कमेंट्स किन URL रूट्स पर दिखाई दें। डिफ़ॉल्ट रूप से, यह उन पेजों पर दिखाई देगा
जिनके URL में `/post` होता है।

### कोलैब चैट कॉन्फ़िगर करना

आप कोलैब चैट को बता सकते हैं कि वह केवल किसी विशेष क्षेत्र के अंदर HTML के चारों ओर सहयोगात्मक कार्यक्षमता जोड़े, उदाहरण के लिए, मान लीजिए आप
ऊपर दिया गया फुटर कोड जोड़ते हैं और फिर कोलैब चैट सक्षम करने के लिए पोस्ट/पेज कंटेंट में यह div जोड़ते हैं:

[inline-code-attrs-start title = 'निर्दिष्ट कंटेंट के साथ कोलैब चैट'; type = 'html'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
<div
  id="fc_box"
  type="collab"
  urlid="custom-chat-id"
><p>This content will have collab chat!</p></div>
[inline-code-end]

तब `<div>` के अंदर का पैराग्राफ एलिमेंट कोलैब चैट सक्षम हो जाएगा, और पेज पर और कुछ नहीं। यदि आप
`<div>` में कोई कंटेंट नहीं डालते हैं, तो यह पूरे पोस्ट बॉडी पर कोलैब चैट सक्षम कर देगा।
