각 에이전트는 두 가지 LLM 모델 중 하나로 실행되며, 편집 폼의 **Model** 섹션에서 선택합니다.

### 두 가지 옵션

- **GLM 5.1 (DeepInfra) - 더 똑똑함, 약간 느림** - 기본값. 추론 품질이 더 높고 호출당 속도는 다소 느립니다. 잘못된 호출의 비용이 큰 모더레이션 스타일 에이전트(`Moderator` 템플릿, `ban_user` 또는 `mark_comment_spam`을 호출하는 모든 것)에 권장됩니다.

- **GPT-OSS 120B Turbo (DeepInfra) - 더 빠름** - 호출당 더 빠르고 지연 시간이 낮습니다. 몇 초 안에 응답을 받고 싶고 잘못된 판단의 결과가 경미한 대용량, 저위험 에이전트(환영 인사, 스레드 고정)에 권장됩니다.

두 모델 모두 함수 호출을 지원하고, 동일한 OpenAI 호환 API를 통해 실행되며, 동일한 도구별 스키마를 공유합니다. 따라서 다른 설정 변경 없이도 저장된 에이전트를 언제든지 두 모델 간에 전환할 수 있습니다.

### 비용 차이

두 모델은 토큰당 비용이 다릅니다. 에이전트의 [예산 상한](#budgets-overview)은 토큰이 아닌 계정 통화로 표시되므로, 모델을 전환하면 일일 및 월간 상한 내에서 몇 번의 실행이 가능한지가 달라집니다. [Run History](#run-history) 페이지는 실행이 완료되면 실행당 비용을 귀하의 통화로 표시합니다. 전환 후 몇 번의 실행을 관찰하는 것이 새로운 소진율을 가늠하는 가장 쉬운 방법입니다.

### 실행당 토큰

모델의 응답 토큰 사용량은 모든 트리거에서 **tokensUsed**로 기록됩니다. 이는 `trigger.succeeded` 및 `trigger.failed` 웹훅 페이로드에 포함되며( [Webhook Payloads](#webhook-payloads) 참조) [Run Detail View](#run-detail-view)에 표시됩니다. 사용량은 다음에 따라 달라집니다:

- 포함하는 [Context](#context-options)의 양 - 스레드 컨텍스트, 사용자 기록, 페이지 메타데이터가 모두 토큰을 추가합니다.
- [Initial prompt](#personality-prompt)와 [Community guidelines](#community-guidelines)의 길이.
- 한 번의 실행에서 에이전트가 호출하는 도구의 수(각 도구 호출과 그 결과가 모델을 통해 왕복합니다).

**Max Tokens Per Trigger**(기본값 20,000)는 실행당 상한이며 에이전트별로 설정됩니다.

### 모델 전환

편집 폼에서 언제든지 모델을 전환할 수 있습니다. 기존 실행 기록과 분석 데이터는 원래의 토큰 및 비용 수치를 유지합니다 - 실행 시점에 기록되기 때문입니다. 새 모델은 저장한 이후에 시작되는 실행에만 적용됩니다.

"더 저렴한 모델을 자동으로 사용"하는 옵션은 없습니다. 선택은 에이전트별로 명시적으로 이루어집니다.
