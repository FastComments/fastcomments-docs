[Run History](#run-history)의 행에서 **보기**를 클릭하면 실행별 상세 페이지가 열립니다. 여기에서 에이전트의 추론 과정을 읽고 그 결정을 판단할 수 있습니다.

### 상단: 실행 요약

- **에이전트** - 실행된 에이전트.
- **시간** - 타임스탬프.
- **상태** - Started / Success / Error, 해당하는 경우 **Dry Run** 배지 표시.
- **비용** - 테넌트 통화 기준 실행당 비용.
- **액션당 비용** - 대기 중이 아닌 액션 수로 나눈 비용으로, 비정상적으로 비용이 많이 드는 실행을 찾는 데 유용합니다.

### 수행된 액션

실행 중 수행된 모든 도구 호출의 순서대로 정렬된 목록입니다. 각 항목에는 다음이 표시됩니다:

- **액션 라벨** - "댓글 작성", "댓글을 스팸으로 표시", "사용자 차단" 등. 라벨은 액션 타입 enum에서 매핑됩니다.
- **참조 ID** - 영향을 받은 댓글, 사용자 또는 배지 ID로, 고정폭 텍스트로 표시됩니다(하이퍼링크 아님).
- **에이전트 추론** - 에이전트가 호출과 함께 제공한 근거.
- **신뢰도** - 에이전트가 스스로 평가한 신뢰도로, 백분율로 표시됩니다.
- **승인 대기** 배지 - 액션이 실행되는 대신 [승인 수신함](#approval-workflow)에 대기 중인 경우 표시됩니다.

실행에서 액션을 수행하지 않은 경우, 이 섹션에는 "이 실행 중 수행된 액션이 없습니다."라고 표시됩니다.

### LLM 트랜스크립트

액션 아래에 에이전트와 LLM 간 대화의 전체 트랜스크립트가 표시됩니다:

- **System** - 시스템 프롬프트(플랫폼 접미사 + 사용자의 초기 프롬프트 + 커뮤니티 가이드라인).
- **User** - 트리거를 설명하는 컨텍스트 메시지.
- **Assistant** - 도구 호출을 포함한 모델의 응답.
- **Tool** - 모델에 다시 전달된 도구 결과(예: `search_memory`가 반환한 내용).

긴 메시지는 접을 수 있으며, **펼치기** / **접기**를 클릭하여 확인할 수 있습니다.

### 트랜스크립트 읽기

트랜스크립트는 튜닝을 위해 가장 중요한 페이지입니다. 에이전트가 사용자가 동의하지 않는 결정을 내렸을 때, 다음을 확인하기 위해 다시 읽어보세요:

- 모델이 **본 것** (User 컨텍스트 메시지).
- 모델이 **결정한 것** (Assistant 도구 호출).
- 모델이 **고려한 것** (도구 결과 - 예: 에이전트가 실제로 `search_memory`를 호출했는지, 그리고 차단하기 전에 무언가를 찾았는지 여부).

모델이 일관되게 같은 종류의 실수를 하는 경우, [초기 프롬프트](#personality-prompt)를 수정하거나 - 거부된 승인에서 [프롬프트 개선](#refining-prompts)을 사용하세요.

### 액션 참조

참조 ID는 고정폭 텍스트로 표시됩니다(하이퍼링크 아님):

- 댓글: 댓글 ID.
- 사용자: 사용자 ID.
- 배지: 배지 ID.

해당 ID를 복사하여 관련 중재/관리 페이지에서 영향을 받은 레코드를 조회할 수 있습니다.

### 드라이런에서 누락되는 것

드라이런 실행에서는 **동일한** 액션, 근거, 신뢰도 점수가 표시됩니다. 유일한 차이점은 상태 행의 **Dry Run** 배지입니다. 댓글 / 사용자 / 배지의 참조 ID는 여전히 표시되지만 - 에이전트는 실제로 영향을 주지 않았습니다.

### 오류

`Error` 상태의 실행에 대해서는 상세 페이지에 기본 오류 메시지가 표시됩니다. 일반적인 오류:

- **LLM API 키가 구성되지 않음** - 테넌트 또는 플랫폼 구성 오류.
- **LLM 호출 시간 초과** - LLM 공급자가 느리거나 사용할 수 없었음.
- **도구 디스패치 실패** - 에이전트가 잘못된 인수로 도구를 선택함(예: 더 이상 존재하지 않는 댓글 ID).
- **실행 중 예산 소진** - 실행이 진행되는 동안 에이전트의 상한에 도달함. 실행이 중단되었습니다.

오류가 발생해도 부분적으로 수행된 액션은 롤백되지 않습니다 - 오류 발생 전에 완료된 도구 호출은 그대로 유지됩니다.
