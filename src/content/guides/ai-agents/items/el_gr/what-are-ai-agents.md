Ένα **AI Agent** είναι ένας αυτόνομος εργαζόμενος, με πεδίο εφαρμογής στο FastComments tenant σας, που παρακολουθεί για γεγονότα στην κοινότητά σας και αναλαμβάνει δράση εκ μέρους σας.

Κάθε agent έχει τρία πράγματα που ελέγχετε:

1. **Μια προσωπικότητα.** Ένα ελεύθερου κειμένου αρχικό prompt που ορίζει τον τόνο, τον ρόλο και το στυλ λήψης αποφάσεων («Είσαι ένας ζεστός καλωσορίζων της κοινότητας», «Επιβάλλεις τους κανόνες της κοινότητας αλλά τείνεις προς προειδοποίηση αντί για αποκλεισμό», και ούτω καθεξής).
2. **Ένα ή περισσότερα triggers.** Μια λίστα γεγονότων που ξυπνούν το agent - ένα νέο σχόλιο, ένα σχόλιο που ξεπερνά ένα όριο ψήφων ή αναφορών, μια ενέργεια moderator, το πρώτο σχόλιο ενός χρήστη στον ιστότοπο, και άλλα. Η πλήρης λίστα βρίσκεται στο [Trigger Events Overview](#triggers-overview).
3. **Μια allowlist εργαλείων.** Τι επιτρέπεται να κάνει το agent - δημοσίευση σχολίου, ψήφος, καρφίτσωμα, κλείδωμα, επισήμανση ως spam, αποκλεισμός χρήστη, προειδοποίηση μέσω DM, απονομή badge, αποστολή email, αποθήκευση και αναζήτηση κοινόχρηστης μνήμης. Η πλήρης λίστα βρίσκεται στο [Allowed Tool Calls Overview](#tools-overview).

Όταν ενεργοποιείται ένα trigger, το agent λαμβάνει ένα μήνυμα περιεχομένου που περιγράφει τι συνέβη (το σχόλιο, η σελίδα, προαιρετικό πλαίσιο νήματος/χρήστη/σελίδας) και προκαλείται με το αρχικό του prompt και τις οδηγίες της κοινότητάς σας. Στη συνέχεια καλεί εργαλεία για να δράσει, καταγράφοντας μια αιτιολόγηση και μια βαθμολογία εμπιστοσύνης με κάθε κλήση.

### Τα agents εκτελούνται ασύγχρονα

Τα agents **ποτέ δεν μπλοκάρουν την ενέργεια του χρήστη που τα προκάλεσε**. Ένας αναγνώστης δημοσιεύει ένα σχόλιο, το σχόλιο αποθηκεύεται και εμφανίζεται στο νήμα, η απάντηση επιστρέφεται, και μόνο *τότε* εκτελείται το agent πάνω του - είτε αμέσως είτε μετά από μια ρυθμισμένη καθυστέρηση (βλ. [Deferred Triggers](#trigger-deferred-delay)). Τίποτα από όσα κάνει το agent δεν προσθέτει καθυστέρηση στην εμπειρία του χρήστη.

### Γιατί να τα χρησιμοποιήσετε

- **Συντονισμός σε μεγάλη κλίμακα.** Επισημάνστε το προφανές spam και αποκλείστε τους επαναλαμβανόμενους παραβάτες χωρίς να παρακολουθείτε την ουρά μέρα και νύχτα.
- **Καλωσορίστε νέους σχολιαστές.** Απαντήστε σε σχολιαστές πρώτης φοράς με τη δική σας φωνή.
- **Αναδείξτε το καλύτερο περιεχόμενο.** Καρφιτσώστε ουσιαστικά σχόλια κορυφαίου επιπέδου μόλις ξεπεράσουν ένα όριο ψήφων.
- **Εφαρμόστε τις οδηγίες σας με συνέπεια.** Εφαρμόστε το ίδιο κείμενο πολιτικής σε κάθε οριακό σχόλιο.
- **Συνοψίστε μακριά νήματα.** Δημοσιεύστε ουδέτερες συνοψίσεις συζητήσεων πολλών σελίδων.

### Τι σας κρατά υπό έλεγχο

- **Λειτουργία Dry-run.** Κάθε νέο agent ξεκινά σε **Dry Run**: επεξεργάζεται τα triggers, εκτελεί το μοντέλο, και καταγράφει τι *θα* έκανε, αλλά δεν αναλαμβάνει πραγματικές ενέργειες. Βλ. [Dry-Run Mode](#dry-run-mode).
- **Εγκρίσεις.** Οποιοδήποτε υποσύνολο ενεργειών μπορεί να απαιτεί ανθρώπινη έγκριση. Βλ. [Approval Workflow](#approval-workflow).
- **Προϋπολογισμοί ανά agent και ανά λογαριασμό.** Σκληρά ημερήσια και μηνιαία όρια. Βλ. [Budgets Overview](#budgets-overview).
- **Allowlist εργαλείων.** Τα μη επιτρεπόμενα εργαλεία αφαιρούνται από την παλέτα του μοντέλου - το agent κυριολεκτικά δεν μπορεί να τα ζητήσει. Βλ. [Allowed Tool Calls Overview](#tools-overview).
- **Πεδία ελέγχου σε κάθε ενέργεια.** Το μοντέλο πρέπει να περιλαμβάνει αιτιολόγηση και βαθμολογία εμπιστοσύνης. Και τα δύο εμφανίζονται στο χρονοδιάγραμμα εκτέλεσης και σε κάθε έγκριση. Βλ. [Run Detail View](#run-detail-view).
- **EU DSA Article 17.** Στην περιοχή της ΕΕ, οι πλήρως αυτοματοποιημένοι αποκλεισμοί είναι μπλοκαρισμένοι. Βλ. [EU DSA Article 17 Compliance](#eu-dsa-compliance).
- **Καμία εκπαίδευση στα δεδομένα σας.** Το FastComments χρησιμοποιεί παρόχους που δεν εκπαιδεύονται στα prompts ή τα σχόλιά σας.

### Πού εντάσσονται δίπλα στη ανθρώπινη συντονισμό

Τα agents και οι ανθρώπινοι moderators μοιράζονται την ίδια πλατφόρμα σχολίων: τα agents αναλαμβάνουν ενέργειες μέσω των ίδιων καναλιών (έγκριση, spam, αποκλεισμός, badge, καρφίτσωμα, κλείδωμα, γραφή) και αυτές οι ενέργειες εμφανίζονται στα ίδια [Comment Logs](/guide-moderation.html#comment-logs), στην ίδια [Σελίδα Συντονισμού](/guide-moderation.html#moderate-comments-page), και στις ίδιες ροές ειδοποιήσεων. Τα agents και οι άνθρωποι βλέπουν τη δουλειά ο ένας του άλλου και μπορούν ο καθένας να αντιδράσει στον άλλον - οι ενέργειες των moderators είναι οι ίδιες έγκυρα triggers για τα agents (βλ. [Trigger: Moderator Reviewed Comment](#trigger-moderator-reviewed) και συναφή).

Αν χρειάζεστε ανθρώπους στην ουρά επίσης, το FastComments προσφέρει [Human Moderation Services](/guide-moderation.html#human-moderation-services): οι moderators μας εργάζονται δίπλα στα agents σας, στο dashboard σας, υπό τις οδηγίες σας.
