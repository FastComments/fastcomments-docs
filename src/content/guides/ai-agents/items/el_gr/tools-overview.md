Τα **εργαλεία** ενός agent είναι οι ενέργειες που μπορεί να εκτελέσει. Η φόρμα επεξεργασίας του agent διαθέτει μια ενότητα **Allowed tool calls** όπου επιλέγετε τα εργαλεία που επιτρέπεται να χρησιμοποιεί το agent, και μια ενότητα **Approvals** όπου επιλέγετε τις ενέργειες που πρέπει να εγκριθούν από άνθρωπο πριν τεθούν σε ισχύ.

Υπάρχουν τρία επίπεδα για κάθε εργαλείο:

- **Μη επιτρεπόμενο** - το agent δεν μπορεί να το δει ούτε να το χρησιμοποιήσει.
- **Επιτρεπόμενο, χωρίς έγκριση** - το agent το χρησιμοποιεί απευθείας. Καταγράφεται στο ιστορικό εκτέλεσης.
- **Επιτρεπόμενο, με έγκριση** - η κλήση του agent τίθεται σε ουρά για ανθρώπινη αναθεώρηση και εκτελείται μόνο όταν κάποιος άνθρωπος την εγκρίνει.

Τα μη επιτρεπόμενα εργαλεία είναι σιωπηλά: το agent δεν μπορεί να τα ζητήσει και η πλατφόρμα τα απορρίπτει κατηγορηματικά. Τα εργαλεία με έγκριση περνούν πάντα από τα [εισερχόμενα εγκρίσεων](#approval-workflow).

### Ίχνος ελέγχου σε κάθε ενέργεια

Κάθε ενέργεια του agent καταγράφεται με μια σύντομη αιτιολόγηση (1-2 προτάσεις που εξηγούν το γιατί) και μια βαθμολογία εμπιστοσύνης (0.0-1.0). Και τα δύο εμφανίζονται στην [Προβολή Λεπτομερειών Εκτέλεσης](#run-detail-view) και σε κάθε [έγκριση](#approval-workflow). Η αναζήτηση στη μνήμη είναι η μοναδική εξαίρεση μόνο-ανάγνωσης: δεν καταγράφεται ως ενέργεια και είναι πάντα διαθέσιμη ανεξάρτητα από τη λίστα επιτρεπόμενων.

### Αναφορά εργαλείων

#### Δημοσίευση σχολίων

Επιτρέπει στο agent να δημοσιεύσει ένα σχόλιο με το όνομά του. Το σχόλιο εμφανίζεται δημόσια με το εμφανιζόμενο όνομα του agent. Χρησιμοποιείται από agents υποδοχής και σύνοψης. Είναι αντιστρέψιμο - οποιοσδήποτε συντονιστής μπορεί να αφαιρέσει ένα κακό σχόλιο. Περιορίστε το με έγκριση αν η κοινότητά σας απαιτεί κάθε δημόσιο μήνυμα να ελέγχεται από άνθρωπο.

#### Επεξεργασία σχολίου

Επιτρέπει στο agent να ξαναγράψει το κείμενο ενός σχολίου εντός πεδίου εφαρμογής. Το αρχικό κείμενο διατηρείται στο αρχείο ελέγχου του σχολίου. Κρατήστε το για στενές περιπτώσεις - απόκρυψη προσωπικών δεδομένων που διέρρευσε ένας χρήστης, ή διόρθωση της προηγούμενης απάντησης του ίδιου του agent. Όχι για επανεγγραφή απόψεων ή εξομάλυνση τόνου. Δείτε το [Επεξεργασία σχολίου](#tool-edit-comment) για την πλήρη σελίδα.

#### Ψηφισμός σε σχόλια

Επιτρέπει στο agent να ψηφίσει θετικά ή αρνητικά σε ένα σχόλιο. Η ψήφος μετρά στο σύνολο ψήφων του σχολίου όπως κάθε άλλη ψήφος. Οι περισσότερες κοινότητες προτιμούν να μην ψηφίζουν bots· δεν είναι ενεργοποιημένο σε κανένα starter template. Αν το επιτρέψετε, ο ψηφισμός είναι αντιστρέψιμος.

#### Καρφίτσωμα / ξεκαρφίτσωμα σχολίου

Επιτρέπει στο agent να καρφιτσώσει ένα σχόλιο στην κορυφή της σελίδας ή να ξεκαρφιτσώσει ένα ήδη καρφιτσωμένο. Η πλατφόρμα δεν επιβάλλει κανόνα ενός καρφιτσώματος ανά νήμα, οπότε ένα agent καρφιτσώματος θα πρέπει να καθοδηγείται να ξεκαρφιτσώσει πρώτα το προηγούμενο καρφιτσωμένο σχόλιο. Για να ανακαλύψει τι είναι ήδη καρφιτσωμένο στην ίδια σελίδα, το agent μπορεί να καλέσει το εργαλείο μόνο-ανάγνωσης `get_pinned_comments` (βλ. παρακάτω). Χρησιμοποιείται από το template Top Comment Pinner.

#### Κλείδωμα / ξεκλείδωμα σχολίου

Επιτρέπει στο agent να αποτρέψει περαιτέρω απαντήσεις κάτω από ένα σχόλιο, ή να τις επαναφέρει. Το κλειδωμένο σχόλιο παραμένει ορατό. Χρήσιμο για ψύξη θερμών νημάτων, σε συνδυασμό με καθυστερημένο ξεκλείδωμα. Για να ανακαλύψει τι είναι προς το παρόν κλειδωμένο στην ίδια σελίδα, το agent μπορεί να καλέσει το εργαλείο μόνο-ανάγνωσης `get_locked_comments` (βλ. παρακάτω).

#### Σήμανση / αποσήμανση ως spam

Επιτρέπει στο agent να σημάνει ένα σχόλιο ως spam (κρύβοντάς το από τους αναγνώστες και τροφοδοτώντας τον ταξινομητή spam) ή να αφαιρέσει αυτή τη σήμανση. Το βασικό εργαλείο για κάθε agent συντονισμού. Είναι αντιστρέψιμο.

#### Έγκριση / ανάκληση έγκρισης σχολίου

Επιτρέπει στο agent να εμφανίσει στους αναγνώστες ένα σχόλιο σε αναμονή, ή να αποκρύψει ένα ήδη ορατό. Πιο χρήσιμο σε tenants που κρατούν νέα σχόλια για αναθεώρηση από συντονιστή.

#### Σήμανση σχολίου ως ελεγμένου

Ένα εργαλείο κατάστασης ουράς: σημειώνει ένα σχόλιο ως «έχει δει αυτό κάποιος συντονιστής (ή agent)». Δεν αλλάζει την ορατότητα. Χαμηλού ρίσκου· σπάνια απαιτεί έγκριση.

#### Απονομή παράσημου

Επιτρέπει στο agent να δώσει σε έναν χρήστη ένα παράσημο που έχετε ρυθμίσει για το tenant σας. Είναι αντιστρέψιμο από συντονιστή. Όταν αυτό το εργαλείο είναι ενεργοποιημένο, το agent μπορεί να δει τα παράσημα του tenant σας και να επιλέξει το σωστό μόνο του, οπότε δεν χρειάζεται να επικολλήσετε αναγνωριστικά παρασήμων στις οδηγίες κοινότητας ή στο αρχικό prompt. Για να καθοδηγήσετε ποιο παράσημο απονέμεται για ποια συμπεριφορά, αναφερθείτε στα παράσημα με το **Display Label** τους στο prompt.

#### Αποστολή email

Επιτρέπει στο agent να στείλει ένα email απλού κειμένου στον συγγραφέα ενός σχολίου εντός του πεδίου εφαρμογής του trigger. Το agent δεν βλέπει ποτέ τη διεύθυνση email του παραλήπτη - επιλέγει ένα σχόλιο και η πλατφόρμα παραδίδει στη διεύθυνση που άφησε ο σχολιαστής όταν δημοσίευσε. Η διεύθυνση αποστολέα είναι το branded sender του tenant σας (με DKIM) όταν ο τομέας του σχολίου ταιριάζει με έναν ρυθμισμένο τομέα, αλλιώς η προεπιλογή της πλατφόρμας. Χρησιμοποιήστε το με φειδώ - το email είναι το εργαλείο με τη μεγαλύτερη τριβή και τα κακά email είναι δύσκολο να αναιρεθούν.

#### Αποθήκευση / αναζήτηση μνήμης agent

Δύο συνδυαζόμενα εργαλεία που διαβάζουν και γράφουν μια κοινή δεξαμενή σημειώσεων για τον χρήστη για τον οποίο ενεργοποιήθηκε ένα trigger. Η μνήμη είναι κοινή για όλα τα agents στο tenant σας, οπότε οι σημειώσεις ενός agent ταξινόμησης ενημερώνουν τις αποφάσεις ενός agent συντονισμού. Η αναζήτηση είναι μόνο-ανάγνωσης και πάντα διαθέσιμη· η αποθήκευση σπάνια απαιτεί έγκριση. Δείτε το [Σύστημα Μνήμης Agent](#agent-memory-system) για την πλήρη σχεδίαση.

#### Get pinned comments / Get locked comments

Δύο εργαλεία ανακάλυψης μόνο-ανάγνωσης που απαριθμούν τα καρφιτσωμένα (ή κλειδωμένα) σχόλια στην ίδια σελίδα (`urlId`) όπου ενεργοποιήθηκε το trigger. Δεν δέχονται ορίσματα - η σελίδα διαβάζεται από το πλαίσιο του trigger, οπότε το agent δεν μπορεί να μεταπηδήσει σε άλλες σελίδες. Χρησιμοποιήστε τα όταν ένα agent χρειάζεται να δράσει σε ένα σχόλιο που είναι ήδη καρφιτσωμένο ή κλειδωμένο - τυπικά ως πρώτη κλήση πριν από το `unpin_comment` ή το `unlock_comment`, ή πριν το καρφίτσωμα νέου σχολίου ώστε το υπάρχον να ξεκαρφιτσωθεί πρώτα.

Κάθε εργαλείο ελέγχεται ξεχωριστά στα **Allowed tool calls** (ο διαχειριστής τικάρει το `List pinned comments on the current page` ή το `List locked comments on the current page`). Δεν μπορούν να απαιτούν έγκριση - τα εργαλεία μόνο-ανάγνωσης δεν έχουν παρενέργεια προς έγκριση. Η κλήση τους δεν καταγράφεται ως ενέργεια στο ιστορικό εκτέλεσης· εμφανίζεται μόνο η επακόλουθη κλήση `unpin_comment` / `unlock_comment` / `pin_comment` (αν υπάρχει). Η λίστα περιορίζεται στα 20 πιο πρόσφατα αποτελέσματα ανά κλήση.

Σημαντικό να κατανοήσετε: όταν ένα από αυτά τα εργαλεία επιστρέφει ένα commentId, αυτό το commentId προστίθεται στο πεδίο εφαρμογής του agent για τη συγκεκριμένη εκτέλεση, οπότε η επακόλουθη κλήση `unpin_comment` / `unlock_comment` επικυρώνεται έναντι του ελέγχου ασφαλείας στόχου εργαλείου της πλατφόρμας. Χωρίς πρώτη κλήση του εργαλείου ανακάλυψης, το agent δεν μπορεί να δράσει σε σχόλια που δεν είναι ήδη στο άμεσο πεδίο εφαρμογής του trigger. Έτσι, ένα agent ξεκαρφιτσώματος τυπικά έχει ενεργοποιημένα και τα δύο εργαλεία (π.χ. `get_pinned_comments` μαζί με `unpin_comment`).

#### Προειδοποίηση χρήστη

Στέλνει ένα ιδιωτικό DM προειδοποίησης σε έναν χρήστη για ένα συγκεκριμένο σχόλιο, και καταγράφει ατομικά την προειδοποίηση στη μνήμη του agent. Η πολιτική κλιμάκωσης της πλατφόρμας βασίζεται σε αυτό το εργαλείο - πρώτα προειδοποίηση, αποκλεισμός μόνο αν ο χρήστης υποπέσει ξανά. Δείτε το [Προειδοποίηση χρήστη](#tool-warn-user) για την πλήρη σελίδα.

#### Αποκλεισμός χρήστη

Το πιο βαρύ εργαλείο που μπορεί να καλέσει ένα agent. Αποκλείει έναν χρήστη με σταθερή διάρκεια, προαιρετικά ως shadow ban, προαιρετικά αποκλείοντας και την IP, προαιρετικά διαγράφοντας και όλα τα σχόλια του χρήστη. Οι δύο καταστροφικές επιλογές (IP, διαγραφή όλων) απαιτούν επιπλέον opt-ins στη φόρμα επεξεργασίας. Στην περιοχή της ΕΕ, όλοι οι αποκλεισμοί απαιτούν ανθρώπινη έγκριση (βλ. [Συμμόρφωση EU DSA Άρθρο 17](#eu-dsa-compliance)). Δείτε το [Αποκλεισμός χρήστη](#tool-ban-user) για την πλήρη σελίδα.

### Υπο-επιλογές εργαλείου αποκλεισμού

Το εργαλείο αποκλεισμού εκθέτει δύο καταστροφικές επιλογές - delete-all-comments και ban-by-IP - που είναι εντελώς κρυμμένες από το μοντέλο μέχρι να τις ενεργοποιήσετε μέσω της ενότητας **Ban options** στη φόρμα επεξεργασίας. Ακόμα κι αν το μοντέλο φανταστεί την παράμετρο, η πλατφόρμα απορρίπτει τιμές που δεν έχετε ενεργοποιήσει. Δείτε το [Αποκλεισμός χρήστη](#tool-ban-user).
