Ενεργοποιείται όταν ένας συντονιστής απονέμει ένα παράσημο σε έναν χρήστη.

### Πλαίσιο που λαμβάνει ο agent

- Το **ID του παρασήμου** του απονεμηθέντος παρασήμου.
- Το **ID του χρήστη που προκάλεσε την ενέργεια** - ο συντονιστής που απένειμε το παράσημο.
- Προαιρετικό πλαίσιο νήματος / ιστορικού χρήστη / σελίδας, όπως έχει ρυθμιστεί.

Η ενεργοποίηση **δεν** περιλαμβάνει ένα `commentId` στο payload του trigger, ακόμη και αν το παράσημο απονεμήθηκε σε σχέση με ένα συγκεκριμένο σχόλιο.

### Ποιος το ενεργοποιεί

Μια ανθρώπινη ενέργεια συντονιστή.

### Σημαντικά σημεία

- Περιλαμβάνεται μόνο το ID του παρασήμου· ο agent δεν λαμβάνει τα μεταδεδομένα του παρασήμου (όνομα, εικόνα). Αν ο agent χρειάζεται να συλλογιστεί *ποιο* παράσημο απονεμήθηκε, ενσωματώστε αυτό το πλαίσιο στο [initial prompt](#personality-prompt) ή στις [οδηγίες κοινότητας](#community-guidelines).
- Το trigger ενεργοποιείται μία φορά ανά απονομή παρασήμου, όχι ανά χρήστη. Η απονομή του ίδιου παρασήμου σε έναν χρήστη δύο φορές το ενεργοποιεί δύο φορές (κάθε απονομή είναι ξεχωριστό γεγονός).

### Συχνές χρήσεις

- **Αμοιβαία αναγνώριση** - ένας agent μπορεί να δημοσιεύσει μια απάντηση "ευχαριστούμε για τη σπουδαία συνεισφορά" όταν απονεμηθεί ένα συγκεκριμένο παράσημο.
- **Εξωτερική ροή εργασίας αναγνώρισης** μέσω [Webhooks](#webhooks-overview) - αντιγράψτε τις απονομές παρασήμων στο δικό σας σύστημα αλληλεπίδρασης χρηστών.
- **Καταγραφή στη μνήμη** - σημειώσεις όπως "αυτός ο χρήστης είναι αναγνωρισμένος συνεισφέρων" που οι μελλοντικοί agents συντονισμού θα πρέπει να λαμβάνουν υπόψη στις αποφάσεις τους.
