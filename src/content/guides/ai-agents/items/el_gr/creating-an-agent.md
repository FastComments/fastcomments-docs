Από τη σελίδα [AI Agents](https://fastcomments.com/auth/my-account/ai-agents) μπορείτε να δημιουργήσετε έναν agent με δύο τρόπους:

- **Από πρότυπο.** Κάντε κλικ στο **Browse templates** και επιλέξτε έναν από τους τέσσερις ενσωματωμένους agents εκκίνησης. Η φόρμα εμφανίζεται προ-συμπληρωμένη και η κατάσταση του agent είναι **Dry Run**. Δείτε [Starter Templates](#starter-templates).
- **Από την αρχή.** Κάντε κλικ στο **Create new agent**. Η φόρμα εμφανίζεται κενή.

Και στις δύο περιπτώσεις, η ίδια φόρμα επεξεργασίας είναι αυτή που αποθηκεύετε και επεξεργάζεστε στη συνέχεια. Αυτή η σελίδα παρουσιάζει τη φόρμα από πάνω προς τα κάτω.

### Βασικά στοιχεία

- **Εσωτερικό όνομα.** Ένα σύντομο αναγνωριστικό που χρησιμοποιείται μόνο στα διαχειριστικά dashboards (ιστορικό εκτελέσεων, αναλυτικά στοιχεία, audit logs). Τα πεζά γράμματα με κάτω παύλες λειτουργούν καλά: `moderator`, `welcome_greeter`. Αν το εσωτερικό όνομα ενός προτύπου είναι ήδη κατειλημμένο, η φόρμα προσθέτει αυτόματα κατάληξη (`tos_enforcer_2`, κ.λπ.).
- **Εμφανιζόμενο όνομα.** Εμφανίζεται δημόσια κάθε φορά που ο agent δημοσιεύει ένα σχόλιο. Αυτό βλέπουν οι αναγνώστες σας.
- **Κατάσταση.** Disabled, Dry Run ή Enabled. Οι νέοι agents έχουν πάντα προεπιλογή το Dry Run. Δείτε [Status States](#status-states).

### Μοντέλο

Επιλέξτε το LLM. Δείτε [Choosing a Model](#choosing-a-model).

### Προϋπολογισμός

Προαιρετικά ημερήσια και μηνιαία όρια στο νόμισμα του λογαριασμού σας, plus μια λίστα ελέγχου **Alert thresholds** (προεπιλογή 80% και 100%). Δείτε [Budgets Overview](#budgets-overview) και [Budget Alerts](#budget-alerts).

### Προσωπικότητα

Το **Initial prompt** είναι το system prompt που ορίζει τον τόνο, τον ρόλο και τους κανόνες αποφάσεων. Απλό κείμενο, χωρίς σύνταξη προτύπων. Δείτε [Personality and the Initial Prompt](#personality-prompt).

### Πλαίσιο

Το πεδίο Context έχει τρία checkbox, μια περιοχή κειμένου για οδηγίες και τα πεδία εμβέλειας:

- Συμπερίληψη του γονικού σχολίου και των προηγούμενων απαντήσεων στο ίδιο νήμα.
- Συμπερίληψη του trust factor του σχολιαστή, της ηλικίας του λογαριασμού, του ιστορικού ban και των πρόσφατων σχολίων.
- Συμπερίληψη τίτλου σελίδας, υπότιτλου, περιγραφής και meta tags.
- Ένα προαιρετικό μπλοκ κειμένου **Community guidelines** που προσαρτάται σε κάθε prompt.
- **Περιορισμός σε συγκεκριμένες σελίδες** - allowlist μοτίβων URL (ένα ανά γραμμή). Κενό σημαίνει σε όλο τον tenant.
- **Περιορισμός σε συγκεκριμένα locales** - allowlist locales μέσω dual-list picker. Κενό σημαίνει κάθε locale.

Περισσότερο πλαίσιο παράγει καλύτερες αποφάσεις αλλά αυξάνει το κόστος token ανά εκτέλεση. Δείτε [Context Options](#context-options), [Community Guidelines](#community-guidelines) και [Scope: URL and Locale Filters](#scope-url-locale).

### Εναύσματα

Επιλέξτε τουλάχιστον ένα συμβάν από τη λίστα. Για triggers ορίου ψήφων και ορίου σημάνσεων πρέπει επίσης να ορίσετε το όριο. Το προαιρετικό πεδίο **Delay before running** αναβάλλει την εκτέλεση αφού ενεργοποιηθεί ένα trigger (χρήσιμο για όρια σημάνσεων όπου οι ψήφοι εξακολουθούν να διαμορφώνονται). Δείτε [Trigger Events Overview](#triggers-overview) και [Deferred Triggers](#trigger-deferred-delay).

### Επιτρεπόμενες κλήσεις εργαλείων

Τσεκάρετε **Allow any tool calls** για να εκτεθεί η πλήρης παλέτα εργαλείων. Διαφορετικά, τσεκάρετε τα συγκεκριμένα εργαλεία που επιτρέπεται να χρησιμοποιεί ο agent - τα μη επιτρεπόμενα εργαλεία αφαιρούνται από την παλέτα του μοντέλου και απορρίπτονται κατά την αποστολή. Η υποενότητα **Ban options** ελέγχει τις καταστροφικές παραλλαγές ban (delete-all-comments, ban-by-IP) πίσω από ρητές ενεργοποιήσεις. Δείτε [Allowed Tool Calls Overview](#tools-overview) και [Tool: ban_user](#tool-ban-user).

### Εγκρίσεις

Τσεκάρετε τις ενέργειες που πρέπει να εγκρίνονται από άνθρωπο πριν τις εκτελέσει ο agent. Οι εγκρίσεις ισχύουν μόνο για τα εργαλεία που επιτρέπεται να καλεί ο agent· τα μη επιτρεπόμενα εργαλεία απορρίπτονται ευθέως. Στην περιοχή της ΕΕ, το **ban_user** είναι κλειδωμένο σε ενεργό λόγω του Άρθρου 17 του Digital Services Act. Δείτε [Approval Workflow](#approval-workflow) και [EU DSA Article 17 Compliance](#eu-dsa-compliance).

### Ειδοποιήσεις εγκρίσεων

Αν οι εγκρίσεις είναι ενεργές, επιλέξτε ποιοι θα λαμβάνουν email:

- **Όλοι οι διαχειριστές και moderators** - ιδιοκτήτες λογαριασμού, super admins και admins moderators σχολίων.
- **Συγκεκριμένοι χρήστες** - επιλεγμένοι χειροκίνητα από ένα dual-list picker.

Η ατομική συχνότητα παράδοσης κάθε αναθεωρητή (άμεσα, ωριαία σύνοψη, ημερήσια σύνοψη) ορίζεται στο δικό του προφίλ. Δείτε [Approval Notifications](#approval-notifications).

### Στατιστικά

Μόνο για ανάγνωση. Συνολικές εκτελέσεις, χρονική σήμανση τελευταίας εκτέλεσης και το ID του πιο πρόσφατου σχολίου που έγραψε ο agent (αν υπάρχει).

### Αποθήκευση

Κάντε κλικ στο **Save agent**. Η σελίδα ανακατευθύνει πίσω στη λίστα agents. Οι νέοι agents είναι άμεσα επιλέξιμοι να λάβουν triggers σε dry-run.

### Μεταγενέστερη επεξεργασία

Κάθε γραμμή στη σελίδα λίστας agents παρέχει ενέργειες ανά agent: **Edit**, **Clone**, **Runs**, **Replays**, **Test run**, **Analytics**, **Approvals** και **Delete**. Η επεξεργασία ενός agent δεν επηρεάζει αναδρομικά ήδη καταγεγραμμένες εκτελέσεις - το ιστορικό διατηρείται. Τα snapshots των replays επίσης παγώνουν τη διαμόρφωση του agent στο σημείο που ξεκίνησε το replay, ώστε τα αποτελέσματα ενός αποθηκευμένου replay να παραμένουν αναπαραγώγιμα ακόμα και μετά την επεξεργασία του prompt.
