Ενεργοποιεί τον agent κάθε φορά που δημοσιεύεται ένα νέο σχόλιο σε μια σελίδα που καλύπτεται από το [scope](#scope-url-locale) του agent.

### Context που λαμβάνει ο agent

- Το νέο σχόλιο στο σύνολό του - κείμενο, συγγραφέας, ψήφοι, parent ID, page URL ID.
- Προαιρετικά: το γονικό σχόλιο και προηγούμενες απαντήσεις στο ίδιο thread, αν το [thread context](#context-options) είναι ενεργό.
- Προαιρετικά: ο trust factor του σχολιαστή, η ηλικία του λογαριασμού, το ιστορικό bans και πρόσφατα σχόλια, αν το [user history context](#context-options) είναι ενεργό.
- Προαιρετικά: metadata της σελίδας, αν το [page context](#context-options) είναι ενεργό.

### Σημαντικά σημεία

- Το trigger ενεργοποιείται **μετά** την αποθήκευση του σχολίου. Ο agent μπορεί να αναφερθεί σε αυτό απευθείας σε tool calls.
- Δεν ενεργοποιείται για σχόλια που έχουν γραφτεί από άλλον agent στον ίδιο tenant.
- Ενεργοποιείται τόσο για επαληθευμένα όσο και για μη επαληθευμένα σχόλια. Αν ο tenant σας απαιτεί έγκριση από moderator πριν γίνει ορατό ένα σχόλιο (βλ. [How Approvals Work](/guide-moderation.html#moderation-approvals) στον οδηγό moderation), το trigger ενεργοποιείται όταν δημιουργείται το σχόλιο, όχι όταν εγκρίνεται αργότερα. Το moderator bot μπορεί να οδηγηθεί να εγκρίνει σχόλια για εσάς μετά από έλεγχο.

### Συνηθισμένες χρήσεις

- **Moderation** - έλεγχος του σχολίου βάσει των κανόνων της κοινότητας, επισήμανση spam ή προειδοποίηση νέων χρηστών.
- **Καλωσόρισμα** - αν και το [Trigger: New User First Comment](#trigger-new-user-first-comment) είναι συνήθως πιο κατάλληλο για χαιρετισμούς, καθώς ενεργοποιείται μία φορά ανά χρήστη.
- **Σύνοψη thread** - συνήθως σε συνδυασμό με [trigger delay](#trigger-deferred-delay), ώστε το thread να ηρεμήσει πριν εκτελεστεί ο agent.
