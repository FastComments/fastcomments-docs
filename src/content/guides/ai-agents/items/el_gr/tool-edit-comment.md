Το εργαλείο Edit επιτρέπει στον agent να αντικαθιστά το κείμενο ενός υπάρχοντος σχολίου. Είναι καταστροφικό με τρόπο που δεν είναι τα περισσότερα άλλα εργαλεία συντονισμού: αντικαθιστά περιεχόμενο γραμμένο από τον χρήστη. Κρατήστε το για στενές, σαφείς περιπτώσεις.

### Τι κάνει

Ο agent περνά ένα ID σχολίου και ένα νέο σώμα κειμένου. Η πλατφόρμα γράφει το νέο κείμενο στο σχόλιο και καταγράφει μια εγγραφή `TextChanged` στο audit log του σχολίου, καταγράφοντας τόσο το παλιό όσο και το νέο κείμενο. Το πρωτότυπο δεν χάνεται ποτέ - οι συντονιστές μπορούν να δουν τι έλεγε το σχόλιο πριν ο agent το επεξεργαστεί.

Η αντικατάσταση περνά από την ίδια διαδικασία απόδοσης με μια ανθρώπινη επεξεργασία: η απόκρυψη βλασφημιών, η ανάλυση αναφορών, η εξαγωγή hashtag και η διαχείριση συνδέσμων/εικόνων συμπεριφέρονται ακριβώς σαν ο αρχικός συγγραφέας να είχε υποβάλει το νέο κείμενο.

### Πεδίο εφαρμογής

Όπως κάθε εργαλείο που τροποποιεί σχόλια, το Edit περιορίζεται στην allowlist του trigger - ο agent μπορεί να επεξεργαστεί μόνο το σχόλιο στο οποίο ενεργοποιήθηκε το trigger, τον γονέα του, ή άλλο σχόλιο εντός πεδίου από το ίδιο πλαίσιο trigger. Μια προσπάθεια prompt injection για "edit comment XYZ" όπου το XYZ δεν σχετίζεται θα απορριφθεί από τον server πριν εκτελεστεί ο executor.

### Βρόχοι

Όταν ο agent επεξεργάζεται ένα σχόλιο, η πλατφόρμα ενεργοποιεί ένα trigger `COMMENT_EDIT` όπως θα έκανε για μια ανθρώπινη επεξεργασία, αλλά **καταστέλλει την αποστολή σε άλλους agents**. Αυτό αποτρέπει δύο agents που ακούν και τα δύο για `COMMENT_EDIT` από το να ανταλλάσσουν συνεχώς επεξεργασίες μεταξύ τους.

### Πότε να το επιτρέψετε

Για agents που χειρίζονται την απόκρυψη PII, ή για agents σύνοψης/digest που αυτο-επεξεργάζονται. Τα περισσότερα εργαλεία συντονισμού **δεν** χρειάζονται αυτό το εργαλείο - το mark-spam, το warn και το ban καλύπτουν τον τυπικό κύκλο ζωής.

### Εγκρίσεις

**Εξετάστε σοβαρά το ενδεχόμενο να το περιορίσετε πίσω από έγκριση**, ειδικά όσο χτίζετε εμπιστοσύνη στον agent. Ένας agent που ξαναγράφει τα λόγια ενός χρήστη είναι το είδος δράσης που μια κοινότητα θα παρατηρήσει και θα αντιδράσει, και είναι πιο δύσκολο να "αναιρεθεί" σε επίπεδο φήμης από μια διαγραφή.
