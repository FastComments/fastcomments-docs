Η μνήμη agent είναι μια δεξαμενή key-value με εύρος tenant, **κοινόχρηστη**, από την οποία κάθε agent στον tenant σας μπορεί να διαβάζει και να γράφει. Υπάρχει ώστε τα agents να μπορούν να μεταφέρουν το πλαίσιο μεταξύ εκτελέσεων.

### Γιατί υπάρχει η μνήμη

Το πλαίσιο LLM είναι ανά εκτέλεση. Χωρίς μνήμη, ένα agent που εκδίδει προειδοποίηση σε έναν χρήστη δεν έχει τρόπο να γνωρίζει για αυτήν την προειδοποίηση την επόμενη φορά που θα δει τον ίδιο χρήστη. Η πολιτική κλιμάκωσης της πλατφόρμας - "προειδοποίηση πριν από το ban" - εξαρτάται από το να μπορεί το agent να βρει την προηγούμενη προειδοποίηση. Η μνήμη είναι αυτό που το καθιστά δυνατό.

### Δύο είδη μνήμης

- **WARNING** - γράφεται αυτόματα ως μέρος της ροής [`warn_user`](#tool-warn-user). Το agent δεν γράφει εγγραφές `WARNING` χειροκίνητα· είναι παρενέργεια της προειδοποίησης ενός χρήστη.
- **NOTE** - γράφεται από το [`save_memory`](#tools-overview). Γενικού σκοπού πλαίσιο που το agent θέλει τα μελλοντικά agents να γνωρίζουν.

Η πολιτική κλιμάκωσης αναζητά συγκεκριμένα εγγραφές `WARNING` όταν αποφασίζει αν ένα ban είναι δικαιολογημένο.

### Με εύρος tenant, κοινόχρηστη μεταξύ agents

Όλα τα agents στον tenant σας μοιράζονται **μία δεξαμενή μνήμης**. Μια σημείωση που αποθηκεύει το Agent A είναι ορατή στις κλήσεις `search_memory` του Agent B. Αυτό είναι σκόπιμο - θέλετε οι σημειώσεις ενός agent ταξινόμησης να ενημερώνουν τις αποφάσεις ενός agent συντονιστή.

Το `tenantId` ορίζεται από τον executor από τον δικό του tenant του agent - ποτέ από τα ορίσματα του LLM - έτσι διαρροές μνήμης μεταξύ tenants είναι αδύνατες εξ ορισμού.

### Τι περιέχει μια εγγραφή μνήμης

Κάθε καταχώρηση μνήμης περιέχει:

- **Ποιο agent την έγραψε**, και πότε.
- **Ποιον αφορά** - τον χρήστη που περιγράφει αυτή η μνήμη. Το agent δεν μπορεί να το κατασκευάσει· η πλατφόρμα το συμπληρώνει αυτόματα από ό,τι ενεργοποίησε το agent.
- **Ένα κρυφό σήμα εναλλακτικού λογαριασμού** - η πλατφόρμα καταγράφει επίσης (ιδιωτικά) το fingerprint IP του σχολίου προέλευσης, ώστε μελλοντικές αναζητήσεις μνήμης να μπορούν να αναδείξουν σημειώσεις για άλλους λογαριασμούς που δημοσιεύουν από την ίδια IP. Το fingerprint δεν εμφανίζεται ποτέ στο agent ή στο LLM.
- **Η ίδια η σημείωση** - έως 2000 χαρακτήρες ελεύθερου κειμένου.
- **Tags** για ανάκτηση - έως 10 σύντομα tags.
- **Ένα είδος** - είτε προειδοποίηση είτε γενική σημείωση.
- **Ένας προαιρετικός σύνδεσμος σχολίου** - αν η μνήμη συνδέεται με συγκεκριμένο σχόλιο.

### Συμπεριφορά αναζήτησης

Το [`search_memory`](#tools-overview) επιστρέφει έως 25 εγγραφές, ταξινομημένες από τις νεότερες προς τις παλαιότερες, με εύρος αυτόματα σε (τον χρήστη του trigger) Ή (άλλους λογαριασμούς στην IP του trigger). Τα αποτελέσματα έχουν επίσης όριο χαρακτήρων στα 8000 συνολικά χαρακτήρες σε όλο το επιστρεφόμενο περιεχόμενο - παλαιότερες εγγραφές απορρίπτονται αν επιτευχθεί το όριο.

Το agent δεν περνά `userId` ή `targetIpHash`. Και τα δύο ορίζονται από τον executor.

### Διατήρηση

Η μνήμη δεν έχει **TTL**. Οι εγγραφές παραμένουν μέχρι να αφαιρεθούν ρητά. Οι εγγραφές WARNING για έναν χρήστη δεν διαγράφονται ποτέ αυτόματα σκόπιμα - το ιστορικό κλιμάκωσης πρέπει να είναι ανευρετικό επ' αόριστον, αλλιώς ο έλεγχος "αναζήτηση πριν από το ban" της πλατφόρμας είναι άχρηστος.

Οι τρεις τρόποι με τους οποίους αφαιρείται μνήμη:

- Ένας συντονιστής διαγράφει το υποκείμενο σχόλιο - οποιαδήποτε μνήμη συνδέεται με αυτό το σχόλιο διαγράφεται αλυσιδωτά.
- Ένας χρήστης διαγράφεται - όλες οι καταχωρήσεις μνήμης για αυτόν τον χρήστη αφαιρούνται στην ίδια συναλλαγή.
- Ο tenant σας διαγράφεται.

Δεν υπάρχει admin UI για διαγραφή μεμονωμένων εγγραφών μνήμης σήμερα.

### Μνήμη σε dry-run

Τα agents dry-run δεν γράφουν μνήμη. Αυτό είναι σκόπιμο: οι υποθετικές αποφάσεις ενός agent dry-run δεν πρέπει να μολύνουν την κοινόχρηστη δεξαμενή μνήμης. Η ανάγνωση μέσω `search_memory` λειτουργεί κανονικά σε dry-run - το agent μπορεί να δει πραγματικές μνήμες από live agents - απλώς δεν μπορεί να προσθέσει σε αυτές.

### Μνήμη σε replays

Το ίδιο με το dry-run: τα agents replay δεν γράφουν μνήμη. Τα replays είναι μόνο για προεπισκόπηση. Δείτε [Test Runs (Replays)](#test-runs-replays).
