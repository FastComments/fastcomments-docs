Το Analytics είναι το cross-agent dashboard. Είναι προσβάσιμο από τη σελίδα AI Agents μέσω της καρτέλας **Analytics** (σε επίπεδο tenant) ή ανά agent μέσω του κουμπιού **Analytics** στη γραμμή κάθε agent.

### Φίλτρο

Ένα dropdown στο πάνω μέρος - **All agents** ή ένα συγκεκριμένο agent. Η υπόλοιπη σελίδα προσαρμόζεται ανάλογα.

### Χρήση budget

Τέσσερις μπάρες προόδου που δείχνουν τη δαπάνη της τρέχουσας περιόδου σε σχέση με το όριο:

- **Agent today** (όταν το φίλτρο είναι σε συγκεκριμένο agent) - ημερήσιο όριο agent.
- **Agent this month** - μηνιαίο όριο agent.
- **Account today** - ημερήσιο όριο tenant.
- **Account this month** - μηνιαίο όριο tenant.

Όταν δεν έχει οριστεί όριο, η μπάρα εμφανίζει "(no cap set)" και δείχνει τη γνήσια δαπάνη.

### Ημερήσιο κόστος (τελευταίες 30 ημέρες)

Ένας πίνακας με το ημερήσιο κόστος στο νόμισμα του tenant σας για το επιλεγμένο εύρος. Χρήσιμο για τον εντοπισμό:

- **Ξαφνικών αιχμών κόστους** - συνήθως από έναν runaway loop ή από ένα viral σχόλιο που ενεργοποιεί πολλαπλά triggers.
- **Αύξησης κόστους** - σταδιακά αυξανόμενο ημερήσιο κόστος καθώς μεγαλώνει η κοινότητά σας.

### Ενέργειες που έγιναν

Μια ανάλυση των τύπων ενεργειών για τον τρέχοντα μήνα - "Wrote a comment: 47", "Marked a comment as spam: 12", και ούτω καθεξής. Χρήσιμο για να επιβεβαιώσετε ότι το agent κάνει αυτό που περιμένατε.

### Παραλειπόμενα triggers (αυτόν τον μήνα)

Μετρήσεις ομαδοποιημένες ανά [λόγο απόρριψης](#drop-reasons):

- Υπέρβαση agent daily / agent monthly / account daily / account monthly.
- Rate-limited.
- Κορεσμός concurrency.

Αν βλέπετε απορρίψεις εδώ, το agent σας χτυπάει όριο budget ή rate limit και χάνει triggers που διαφορετικά θα εκτελούσε. Δείτε [Drop Reasons](#drop-reasons).

### Dry-run vs live (αυτόν τον μήνα)

- **Enabled runs** - πλήθος εκτελέσεων που έκαναν πραγματικές ενέργειες αυτόν τον μήνα.
- **Dry runs** - πλήθος εκτελέσεων σε λειτουργία dry-run αυτόν τον μήνα.

Ένα χρήσιμο σήμα ρύθμισης: ένα ολοκαίνουργιο agent που δεν έχει προαχθεί ακόμα σε Enabled θα δείχνει μόνο dry runs. Ένα agent σε Enabled με μηδενικές μετρήσεις σε αυτή την ενότητα είναι αδρανές - είτε δεν ενεργοποιείται, είτε αποκλείεται από το εύρος, είτε τα triggers του δεν είναι σωστά ρυθμισμένα.

### Top agents ανά μηνιαίο κόστος

Όταν το φίλτρο είναι **All agents**, η σελίδα εμφανίζει agents καταταγμένα ανά κόστος από την αρχή του μήνα. Ο εντοπισμός του πιο ακριβού agent σας είναι το πρώτο βήμα για βελτιστοποίηση κόστους - συνήθως η λύση είναι να "σφίξετε τις [επιλογές context](#context-options)" ή να "χαμηλώσετε το [όριο budget](#budgets-overview)".

### Agents στο όριο ή κοντά σε αυτό

Ανάλυση ανά agent για agents των οποίων η δαπάνη βρίσκεται στο όριο ή κοντά στα per-agent όριά τους στην τρέχουσα περίοδο:

- **near cap** - πάνω από ένα ρυθμιζόμενο ποσοστό του ορίου.
- **over cap** - πραγματικά περικομμένα, με `{count} dropped` triggers σε αυτή την περίοδο.

Κάντε κλικ στο agent από αυτόν τον πίνακα για να αυξήσετε το όριο, να στενέψετε το εύρος ή να το κάνετε pause.

### Σύνοψη λογαριασμού

Όταν το φίλτρο είναι **All agents**:

- **Triggers today** - πλήθος.
- **Triggers this month** - πλήθος.
- Για καθένα: ένα επίθημα `dropped` που δείχνει πόσα παραλείφθηκαν.

### Νόμισμα

Όλες οι νομισματικές τιμές εμφανίζονται στο νόμισμα του tenant σας.

### Τι δεν κάνει αυτή η σελίδα

- Δεν δείχνει **αναλύσεις κόστους ανά ενέργεια** - αυτές βρίσκονται στο [Run Detail View](#run-detail-view).
- Δεν δείχνει **transcripts** ή **απαντήσεις LLM**.
- Δεν σας επιτρέπει να κάνετε ενέργειες στα agents - η επεξεργασία, το pause και η διαγραφή γίνονται όλα από τη λίστα agents / τη σελίδα επεξεργασίας.
