エージェントのコストは **トークンベース** です。すべての LLM 呼び出しはトークン数を返し、プラットフォームはモデルのトークン単価を使用して USD セントに換算し、そのセントがエージェントとテナントの予算に対して請求されます。

### 請求対象

- **すべての LLM 呼び出し**、ツールアクションがゼロになる呼び出し（「エージェントが何もしないことを決定した」）も含みます。アクションが結果として得られなくても推論は支払われます。  
- **ドライラン呼び出し**。ドライランは「実行しないが、LLM を呼び出す」ことで、LLM 呼び出しのコストは同じです。詳しくは [Dry-Run Mode](#dry-run-mode) を参照してください。  
- **リプレイ呼び出し**。リプレイは過去のコメントに対して行うドライランで、トークンがかかります。詳しくは [Test Runs (Replays)](#test-runs-replays) を参照してください。

### 請求対象外

- **LLM 呼び出しを生成しないトリガー**。ドロップ前（予算超過、レート制限、スコープ不一致、請求無効、ループ防止）ケースはトークンがゼロです。詳しくは [Drop Reasons](#drop-reasons) を参照してください。  
- **ツールのディスパッチ**。`pin_comment` やその他のツールを呼び出すこと自体にはトークンはかかりません—LLM の往復だけが課金対象です。  
- **`search_memory`**。読み取り専用であり、独自の LLM 往復は発生しません。

### 実行あたりのコスト

単一のエージェント実行は LLM を複数回呼び出すことがあります—各ツール呼び出しの結果はモデルにフィードバックされ、別のツールを呼び出すか完了します。そのため、実行の `tokensUsed` はその実行内のすべての LLM 往復の合計です。

実行ごとのトークンコストの最大要因:

- **長い [initial prompts](#personality-prompt) と [community guidelines](#community-guidelines)** — すべての実行で使用されます。  
- **[Context options](#context-options)** — スレッドコンテキスト、ユーザー履歴、ページメタデータ。各項目がトークンを追加します。  
- **コメント本文そのもの** — 長いコメントはコストが高くなります。  
- **1 回の実行で複数のツール呼び出し** — 各ツールの結果メッセージがモデルに送られます。  
- **メモリ読み取り** — `search_memory` は最大 25 件（合計 8000 文字に制限）を返します。その多くのバイトが次のプロンプトに組み込まれます。

**Max Tokens Per Trigger**（デフォルト 20,000）は、LLM 呼び出しごとの **応答** サイズを上限します。入力サイズは上限されません。

### トークンからセントへの換算

プラットフォームはテナントパッケージごとの単一レート（`flexLLMCostCents` per `flexLLMUnit` トークン）を適用します。トークン単価はパッケージレベルであり、モデルごとではありません—利用可能なすべてのモデル（[GLM 5.1 と GPT-OSS Turbo](#choosing-a-model)）は同じパッケージで同一レートで請求されます。[Run Detail View](#run-detail-view) では、実行完了後に通貨単位で実行ごとのコストが表示されます。

### コストの記録場所

各実行は生のトークン数と実行ごとのコストを記録します。日次・月次の合計は [Analytics page](#analytics-page) に集計されます。

### コストの読み取り方

- **実行ごとのコスト**: [Run Detail View](#run-detail-view) → `Cost` フィールド。  
- **日次 / 月次の集計**: [Analytics page](#analytics-page) → 予算使用量と日次コストチャート。  
- **アクションごとのコスト**: 同じく Run Detail View に表示され、エージェントのツールループが異常に長い場合のチューニングに役立ちます。
