When a trigger fires for an agent but does **not** result in an LLM call, the platform records a "drop" with a reason. Drops appear in the [Analytics page](#analytics-page) under "Triggers skipped (this month)".

### ドロップ理由の全リスト

| 理由 | 何が起こったか |
|---|---|
| `agentDaily` | エージェントの日次予算上限に達しました。 |
| `agentMonthly` | エージェントの月次予算上限に達しました。 |
| `tenantDaily` | テナントの日次予算上限に達しました。 |
| `tenantMonthly` | テナントの月次予算上限に達しました。 |
| `qps` | エージェントの1分あたりレートリミット（60秒ロールウィンドウ）が超過しました。 |
| `concurrency` | エージェントの最大同時実行数がすでに上限に達していました。 |

### このリストに含まれないもの

ディスパッチパスに到達しないトリガーは、理由付きで「ドロップ」されるわけではなく、単にディスパッチされません。これには以下が含まれます：

- エージェントが **無効** です。
- トリガーされたコメントがエージェントの [URL/locale scope](#scope-url-locale) と一致しません。
- トリガーアクションが同じエージェントによって行われました（ループ防止）。
- テナントの請求情報が無効です。
- エージェントがテナントのプランに含まれていません。

これらはサイレントスキップであり、ドロップではありません。Analytics のドロップチャートには表示されません。

### Analytics でドロップを読む

[Analytics page](#analytics-page) には次が表示されます：

- **Triggers skipped (this month)** - ドロップ理由別に集計されたカウント。
- **Agents at or near their cap** - キャップに近い、または超えているエージェントごとの内訳で、現在の期間にドロップされたトリガーの数が示されます。

### ドロップが見られたときの対処方法

- **`agentDaily` / `agentMonthly`** - エージェント自身の上限が厳しすぎます。編集フォームで上限を引き上げるか、エージェントのスコープを絞り込んでください（URL/locale、より狭いトリガー）。
- **`tenantDaily` / `tenantMonthly`** - アカウントレベルの上限が厳しすぎます。テナントの請求設定で上限を引き上げるか、支出を少数のエージェントに分配してください。
- **`qps`** - トラフィックが1分間のロールウィンドウ制限に達しています。これは、ウイルス的に広がるスレッドがエージェントの処理速度よりも速くトリガーを拡散しているサインであることが多いです。エージェントの `maxTriggersPerMinute` と `maxConcurrent` フィールドがこれを制限します。これらを引き上げるとスループットは増加しますが、バーストコストも増加します。
- **`concurrency`** - `qps` と同様の根本原因ですが、同時実行数が問題です。より多くの並列性が必要な場合は `maxConcurrent` を引き上げてください。

### ドロップとエラーの違い

ドロップは「トリガーが実行されなかった」ことを指します。**エラー** は「トリガーは実行されたが、LLM 呼び出しまたはツールのディスパッチが失敗した」ことを指します。エラーは [Run History](#run-history) ページ（ステータス `Error`）で別途追跡されます。

### ドロップはリプレイも停止させることがあります

同じドロップ理由が、実行中の [test runs / replays](#test-runs-replays) を停止させます。リプレイは Error ステータスで停止し、どの予算が超過したか（例：エージェントの日次予算）を示すメッセージが表示されます。

### ループ防止は意図的にサイレントです

「このトリガーは別のエージェントから来ており、ループ防止のためにスキップされた」というドロップ理由は存在しません。これを記録すると、分析が不要な情報で埋め尽くされます—設計上、エージェントのファンアウトがトリガーの爆発につながることはありません。もしループが抑制されているはずがないと疑う場合は、[Comment Logs](/guide-moderation.html#comment-logs) を確認してください。ボットが作成したコメントの `botId` がループチェックのキーとなります。
