エージェントの**ツール**とは、エージェントが実行できるアクションのことです。エージェント編集フォームには、このエージェントが使用を許可されるツールにチェックを入れる**許可されたツール呼び出し(Allowed tool calls)**セクションと、実行前に人間の承認を必要とするアクションにチェックを入れる**承認(Approvals)**セクションがあります。

すべてのツールには3つのレベルがあります:

- **不許可(Disallowed)** - エージェントはそのツールを参照することも使用することもできません。
- **許可、承認なし(Allowed, no approval)** - エージェントが直接使用します。実行履歴に記録されます。
- **許可、承認あり(Allowed, with approval)** - エージェントの呼び出しが人間のレビューのためにキューに入り、人間が承認した場合にのみ実行されます。

不許可のツールはサイレントです:エージェントはそれを要求できず、プラットフォームは完全に拒否します。承認ゲート付きのツールは常に[承認受信トレイ](#approval-workflow)を経由します。

### すべてのアクションの監査証跡

エージェントが実行するすべてのアクションには、短い根拠(理由を説明する1〜2文)と信頼度スコア(0.0〜1.0)が記録されます。どちらも[実行詳細ビュー](#run-detail-view)とすべての[承認](#approval-workflow)に表示されます。メモリの検索のみが読み取り専用の例外で、アクションとして記録されず、許可リストに関係なく常に利用可能です。

### ツールリファレンス

#### コメントの投稿

エージェントが自身としてコメントを投稿できるようにします。コメントはエージェントの表示名で公開されます。グリーターエージェントやサマライザーエージェントが使用します。元に戻すことが可能 - モデレーターであれば誰でも不適切なコメントを削除できます。コミュニティですべての公開メッセージを人間がレビューする必要がある場合は、承認でゲートしてください。

#### コメントの編集

エージェントが対象範囲内のコメントのテキストを書き換えられるようにします。元のテキストはコメントの監査ログに保持されます。限定的なケースにのみ使用してください - ユーザーが漏洩したPIIの削除や、エージェント自身の過去の返信の修正など。意見の書き換えやトーンの軟化には使用しないでください。詳細ページは[コメント編集](#tool-edit-comment)を参照してください。

#### コメントへの投票

エージェントがコメントに賛成票または反対票を投じられるようにします。投票は他の投票と同様にコメントの投票総数にカウントされます。ほとんどのコミュニティではボットによる投票を望まないため、どのスターターテンプレートでも有効化されていません。許可する場合でも、投票は元に戻すことが可能です。

#### コメントのピン留め / ピン留め解除

エージェントがコメントをページの上部にピン留めしたり、すでにピン留めされているコメントのピン留めを解除できるようにします。プラットフォームはスレッドごとに1つのピン留めというルールを強制しないため、ピン留めを行うエージェントには、まず以前のピン留めされたコメントのピン留めを解除するよう指示する必要があります。同じページで何がピン留めされているかを確認するために、エージェントは読み取り専用の `get_pinned_comments` ツールを呼び出すことができます(下記参照)。Top Comment Pinnerテンプレートで使用されます。

#### コメントのロック / ロック解除

エージェントがコメントへのさらなる返信を防止したり、返信を復元できるようにします。ロックされたコメントは表示されたままです。白熱したスレッドのクールダウンに、遅延ロック解除と組み合わせて便利です。同じページで現在何がロックされているかを確認するために、エージェントは読み取り専用の `get_locked_comments` ツールを呼び出すことができます(下記参照)。

#### スパムマーク / スパム解除

エージェントがコメントをスパムとしてマークしたり(読者から非表示にし、スパム分類器にフィードバック)、そのフラグを解除できるようにします。モデレーションエージェントにとっての主力ツールです。元に戻すことが可能です。

#### コメントの承認 / 承認解除

エージェントが保留中のコメントを読者に表示したり、すでに表示されているコメントを非表示にできるようにします。新しいコメントをモデレーターのレビューのために保留するテナントで最も有用です。

#### コメントをレビュー済みとしてマーク

キューステートツール:コメントを「モデレーター(またはエージェント)が確認済み」としてマークします。表示状態は変更しません。影響は低く、ゲートされることはまれです。

#### バッジの授与

エージェントがテナントに設定済みのバッジをユーザーに授与できるようにします。モデレーターによって元に戻すことが可能です。このツールが有効な場合、エージェントはテナントのバッジを参照し、適切なバッジを自ら選択できるため、バッジ識別子をコミュニティガイドラインや初期プロンプトに貼り付ける必要はありません。どの行動にどのバッジを授与するかを誘導するには、プロンプトでバッジを**表示ラベル(Display Label)**で参照してください。

#### メール送信

エージェントがトリガーの対象範囲内のコメントの作成者にプレーンテキストのメールを送信できるようにします。エージェントが受信者のメールアドレスを見ることは決してありません - エージェントはコメントを選択し、プラットフォームがそのコメント投稿者が投稿時に残したアドレスに配信します。送信元アドレスは、コメントのドメインが設定済みドメインと一致する場合はテナントのブランド送信者(DKIM付き)、それ以外の場合はプラットフォームのデフォルトです。控えめに使用してください - メールは最も摩擦の大きいツールであり、不適切なメールは取り消しが困難です。

#### エージェントメモリの保存 / 検索

トリガーが発火したユーザーに関する共有メモプールを読み書きする、ペアになった2つのツールです。メモリはテナント内のすべてのエージェントで共有されるため、トリアージエージェントのメモがモデレーターエージェントの判断に役立ちます。検索は読み取り専用で常に利用可能です。保存がゲートされることはまれです。設計の詳細は[エージェントメモリシステム](#agent-memory-system)を参照してください。

#### ピン留めされたコメントの取得 / ロックされたコメントの取得

トリガーが発火した同じページ(`urlId`)上のピン留めされた(またはロックされた)コメントを一覧表示する、2つの読み取り専用ディスカバリーツールです。引数は取りません - ページはトリガーコンテキストから読み取られるため、エージェントは他のページに移動できません。すでにピン留めまたはロックされているコメントに対してエージェントがアクションを実行する必要がある場合に使用します - 通常は `unpin_comment` や `unlock_comment` の前の最初の呼び出し、または既存のコメントを先にピン留め解除できるよう新しいコメントをピン留めする前の呼び出しです。

各ツールは**許可されたツール呼び出し(Allowed tool calls)**で個別にゲートされます(管理者が `List pinned comments on the current page` または `List locked comments on the current page` にチェックを入れます)。承認でゲートすることはできません - 読み取り専用ツールには承認すべき副作用がありません。呼び出し自体は実行履歴にアクションとして記録されず、結果として生じる `unpin_comment` / `unlock_comment` / `pin_comment` 呼び出し(あれば)のみが表示されます。リストは1回の呼び出しあたり最新の20件の一致に制限されます。

理解しておくべき重要な点:これらのツールのいずれかがcommentIdを返すと、そのcommentIdはエージェントの実行ごとのスコープに追加され、後続の `unpin_comment` / `unlock_comment` 呼び出しがプラットフォームのツールターゲット安全チェックに対して検証されます。ディスカバリーツールを先に呼び出さないと、エージェントはトリガーの即時スコープにないコメントに対してアクションを実行できません。そのため、ピン留め解除タイプのエージェントには通常、両方のツールが有効化されます(例:`get_pinned_comments` と `unpin_comment`)。

#### ユーザーへの警告

特定のコメントについてユーザーにプライベートDMで警告を送信し、警告をエージェントメモリにアトミックに記録します。プラットフォームのエスカレーションポリシーはこのツールを中心に構築されています - まず警告し、ユーザーが再犯した場合にのみBANします。詳細ページは[ユーザー警告](#tool-warn-user)を参照してください。

#### ユーザーのBAN

エージェントが呼び出せる最も重大な結果をもたらすツールです。固定期間でユーザーをBANし、オプションでシャドウBAN、オプションでIPのBAN、オプションでユーザーのすべてのコメントの削除も行います。2つの破壊的なオプション(IP、全削除)は、編集フォームでの追加のオプトインによってゲートされています。EUリージョンでは、すべてのBANに人間の承認が必要です([EU DSA Article 17コンプライアンス](#eu-dsa-compliance)参照)。詳細ページは[ユーザーBAN](#tool-ban-user)を参照してください。

### BANツールのサブオプション

BANツールには、編集フォームの**BANオプション(Ban options)**セクションでオプトインするまで、モデルから完全に隠される2つの破壊的なオプション(全コメント削除とIPによるBAN)があります。モデルがパラメータを幻覚しても、プラットフォームはオプトインしていない値を拒否します。[ユーザーBAN](#tool-ban-user)を参照してください。
