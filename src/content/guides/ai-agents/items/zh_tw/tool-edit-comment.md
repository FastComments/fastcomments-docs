Edit 工具讓代理能夠替換現有留言的文字。它具有破壞性，這是大多數其他審核工具所沒有的：它會覆寫使用者撰寫的內容。請僅將其保留用於狹窄且明確的情況。

### 它的作用

代理傳遞一個留言 ID 和替換內容。平台將新文字寫入該留言，並在留言的稽核日誌中記錄一個 `TextChanged` 項目，同時擷取舊文字與新文字。原始內容永遠不會遺失——審核人員可以查看代理編輯前留言的內容。

替換內容會經過與人工編輯相同的渲染管線：髒話遮罩、提及解析、主題標籤擷取以及連結/圖片處理，其行為完全如同原始作者提交了新文字一般。

### 範圍

與每個會修改留言的工具一樣，Edit 受限於觸發器的允許清單——代理只能編輯觸發器所針對的留言、其父留言，或來自相同觸發器上下文中範圍內的其他留言。嘗試提示注入以「編輯留言 XYZ」(其中 XYZ 與上下文無關) 的請求，將在執行器執行之前於伺服器端被拒絕。

### 迴圈

當代理編輯留言時，平台會像處理人工編輯一樣觸發 `COMMENT_EDIT` 觸發器，但**會抑制向其他代理的分發**。這可防止兩個同時監聽 `COMMENT_EDIT` 的代理互相來回編輯而形成乒乓效應。

### 何時允許使用

適用於處理 PII 去識別化的代理，或用於自我編輯的摘要/彙整代理。大多數審核代理**不**需要此工具——標記垃圾訊息、警告和封鎖已涵蓋典型的生命週期。

### 審批

**強烈建議將其置於審批機制之後**，尤其是在您建立對代理的信任期間。代理改寫使用者的文字是社群會注意到並做出反應的行為類型，而且在聲譽上比刪除更難「復原」。
