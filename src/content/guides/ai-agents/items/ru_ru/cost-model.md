Стоимость работы агента **основана на токенах**. Каждый вызов LLM возвращает количество токенов, платформа конвертирует его в центы USD по тарифу модели за токен, и эти центы списываются с бюджетов агента и тенанта.

### Что тарифицируется

- **Все вызовы LLM**, включая вызов, в результате которого не выполняется ни одного действия с инструментами («агент решил ничего не делать»). Инференс оплачивается, даже если действие не выполнено.
- **Вызовы в режиме dry-run**. Dry-run означает «не действовать, но всё равно вызвать LLM» — вызов LLM стоит столько же. См. [Режим Dry-Run](#dry-run-mode).
- **Вызовы Replay**. Replays — это dry-run запуски по историческим комментариям. Они расходуют токены. См. [Тестовые запуски (Replays)](#test-runs-replays).

### Что не тарифицируется

- **Триггеры, которые никогда не приводят к вызову LLM.** Случаи отбрасывания до вызова LLM (превышение бюджета, ограничение частоты, несоответствие scope, недействительный биллинг, предотвращение циклов) стоят ноль токенов. См. [Причины отбрасывания](#drop-reasons).
- **Диспетчеризация инструментов.** Вызов `pin_comment` или любого другого инструмента сам по себе не стоит токенов — платится только за круговой обмен с LLM.
- **`search_memory`.** Он работает только на чтение и не порождает собственный круговой обмен с LLM.

### Стоимость за запуск

Один запуск агента может вызывать LLM несколько раз — результат каждого вызова инструмента передаётся обратно в модель, чтобы она могла либо вызвать другой инструмент, либо завершить работу. Поэтому `tokensUsed` для запуска — это сумма по всем круговым обменам с LLM в рамках этого запуска.

Основные факторы, увеличивающие расход токенов за запуск:

- **Длинные [начальные промпты](#personality-prompt) и [правила сообщества](#community-guidelines)** — они включаются в каждый запуск.
- **[Опции контекста](#context-options)** — контекст треда, история пользователя, метаданные страницы. Каждая добавляет токены.
- **Сам текст комментария** — длинные комментарии стоят дороже.
- **Несколько вызовов инструментов в одном запуске** — результат каждого инструмента отправляется обратно в модель.
- **Чтение памяти** — `search_memory` возвращает до 25 записей (с ограничением в 8000 символов суммарного содержимого). Большая часть этих байтов попадает в следующий промпт.

**Max Tokens Per Trigger** (по умолчанию 20 000) ограничивает размер **ответа** на каждый вызов LLM. Он не ограничивает размер входных данных.

### Конвертация токенов в центы

Платформа применяет единый тариф на пакет тенанта (`flexLLMCostCents` за `flexLLMUnit` токенов). Стоимость за токен задаётся на уровне пакета, а не модели — обе доступные модели ([GLM 5.1 и GPT-OSS Turbo](#choosing-a-model)) тарифицируются по одинаковой ставке в рамках данного пакета. [Просмотр деталей запуска](#run-detail-view) показывает стоимость запуска в вашей валюте после его завершения.

### Где фиксируется стоимость

Каждый запуск записывает исходное количество токенов и стоимость за запуск. Дневные и месячные итоги агрегируются на [странице Analytics](#analytics-page).

### Как посмотреть стоимость

- **Стоимость за запуск**: [Просмотр деталей запуска](#run-detail-view) -> поле `Cost`.
- **Дневной / месячный агрегат**: [страница Analytics](#analytics-page) -> графики использования бюджета и дневной стоимости.
- **Стоимость за действие**: также в Просмотре деталей запуска, полезно для настройки, когда цикл инструментов агента необычно длинный.
