`fastcomments-react-native` को `react-native-webview` की आवश्यकता होती है। इसलिए, आपको `react-native-webview` के इंस्टॉलेशन चरणों का पालन करना चाहिए।

### अकाउंट क्षेत्र (ध्यान दें: EU ग्राहकों के लिए)

यदि आपका अकाउंट EU में स्थित है, तो विजेट कॉन्फ़िगरेशन में `region = 'eu'` सेट करें।
अन्यथा, आपको `region` परिभाषित करने की आवश्यकता नहीं है।
