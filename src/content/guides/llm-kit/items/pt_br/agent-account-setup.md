A coding agent such as Claude Code, Cursor, or an MCP-based assistant can set up FastComments for you without you filling in the signup form. This is useful when you ask an agent to "add comments to my site" and you do not have an account yet.

### Como funciona

1. O agente cria uma nova conta e recebe uma chave de API e um link de reivindicação. A chave de API funciona imediatamente, permitindo que o agente configure a conta e instale o widget em seu site.  
2. O agente lhe fornece o link de reivindicação. Abra‑o em seu navegador, faça login ou crie um login, e confirme a reivindicação. A conta então será sua: você a gerencia, sua cobrança e suas chaves de API a partir do painel. A página lista a chave de API que o agente possui, para que você possa revogá‑la se não quiser mais que o agente, ou quem quer que o execute, tenha acesso.  
3. Se ninguém abrir o link de reivindicação dentro de 72 horas, a conta e sua chave são excluídas. Peça ao agente que crie uma nova.

Até que seja reivindicada, a conta tem os mesmos limites de um teste gratuito normal.

### Se você já tem uma conta

Cada login possui uma conta. Se você abrir um link de reivindicação enquanto estiver conectado a uma conta existente, a página permite que você escolha:

- **Anexar à minha conta** torna a nova conta um inquilino gerenciado da conta na qual você está conectado. Isso requer um plano pago com marca branca, e o uso do novo inquilino é cobrado na sua conta.  
- **Sair e reivindicar com outro login** desconecta você e o leva de volta à página de reivindicação para que possa reivindicá‑la com um login diferente.

### Para autores de agentes

As instruções para agentes em [fastcomments.com/agents.md](https://fastcomments.com/agents.md) descrevem a chamada de criação de conta, os campos na resposta e como entregar o link de reivindicação à pessoa para quem você está trabalhando. A chamada não requer chave de API e tem limite de taxa por endereço IP.
