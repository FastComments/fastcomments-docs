סוכן קידוד כגון Claude Code, Cursor, או עוזר מבוסס MCP יכול להגדיר את FastComments עבורך מבלי שתצטרך למלא את טופס ההרשמה. זה שימושי כאשר אתה מבקש מסוכן "להוסיף תגובות לאתר שלי" ואין לך עדיין חשבון.

### איך זה עובד

1. הסוכן יוצר חשבון חדש ומקבל מפתח API וקישור תביעה. מפתח ה-API פועל מיידית, כך שהסוכן יכול להגדיר את החשבון ולהתקין את הווידג'ט באתר שלך.  
2. הסוכן נותן לך את קישור התביעה. פתח אותו בדפדפן שלך, התחבר או צור חשבון, ואשר את התביעה. החשבון הופך להיות שלך: אתה מנהל אותו, את החיוב שלו, ואת מפתחות ה-API שלו מלוח הבקרה. העמוד מציג את מפתח ה-API שהסוכן מחזיק כדי שתוכל לבטלו אם אינך רוצה שהסוכן, או מי שמפעיל אותו, ימשיך לקבל גישה.  
3. אם אף אחד לא פותח את קישור התביעה בתוך 72 שעות, החשבון והמפתח שלו יימחקו. בקש מהסוכן ליצור אחד חדש.

עד שיתבע, החשבון מקבל את אותם מגבלות כמו ניסיון חינמי רגיל.

### אם כבר יש לך חשבון

כל כניסה (login) מחזיקה חשבון אחד. אם אתה פותח קישור תביעה בזמן שאתה מחובר לחשבון קיים, העמוד מאפשר לך לבחור:

- **הצמד לחשבון שלי** הופך את החשבון החדש לשוכר מנוהל של החשבון שאתה מחובר אליו. זה דורש תוכנית בתשלום עם מיתוג לבן, והשימוש של השוכר החדש מחויב לחשבון שלך.  
- **התנתק ותבע עם כניסה אחרת** מתנתק אותך ומחזיר אותך לעמוד התביעה כדי שתוכל לתבוע אותו עם כניסה שונה.

### למחברי סוכנים

ההוראות לסוכנים בכתובת [fastcomments.com/agents.md](https://fastcomments.com/agents.md) מתארות את קריאת יצירת החשבון, השדות בתגובה, וכיצד להעביר את קישור התביעה לאדם שאתה עובד עבורו. הקריאה אינה דורשת מפתח API והיא מוגבלת בקצב לפי כתובת IP.
