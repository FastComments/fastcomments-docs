像 Claude Code、Cursor 或基于 MCP 的助手这样的编码代理可以为您设置 FastComments，而无需您填写注册表单。当您请求代理“在我的站点添加评论”，但您还没有账户时，这非常有用。

### How it works

1. 代理创建一个新账户并获取 API 密钥和认领链接。API 密钥可立即使用，代理因此可以配置账户并在您的站点上安装小部件。
2. 代理将认领链接提供给您。请在浏览器中打开它，登录或创建登录，然后确认认领。此时账户归您所有：您可以通过仪表板管理它、其计费以及 API 密钥。页面会列出代理持有的 API 密钥，以便您在不再希望代理或其运行者拥有访问权限时撤销该密钥。
3. 如果在 72 小时内没有人打开认领链接，账户及其密钥将被删除。请让代理重新创建一个。

在被认领之前，账户拥有与普通免费试用相同的限制。

### If you already have an account

每个登录对应一个账户。如果您在已登录的账户状态下打开认领链接，页面会让您进行选择：

- **Attach to my account** 将新账户设为您当前登录账户的受管租户。这需要具备白标功能的付费计划，并且新租户的使用量将计入您的账户计费。
- **Sign out and claim with another login** 会将您登出，并返回认领页面，以便您使用其他登录进行认领。

### For agent authors

在 [fastcomments.com/agents.md](https://fastcomments.com/agents.md) 上的代理说明文档描述了账户创建请求、响应中的字段以及如何将认领链接交给您所服务的对象。该请求不需要 API 密钥，并且对每个 IP 地址进行速率限制。
