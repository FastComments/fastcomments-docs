像 Claude Code、Cursor 或基于 MCP 的助手这样的编码代理可以为您设置 FastComments，而无需您填写注册表单。当您让代理“为我的网站添加评论”而您还没有账户时，这非常有用。

### 工作原理

1. 代理创建一个新账户，并获得一个 API 密钥和一个认领链接。API 密钥立即可用，因此代理可以配置账户并在您的网站上安装评论组件。
2. 代理将认领链接提供给您。在浏览器中打开该链接，登录或创建一个登录账号，并确认认领。此后该账户就归您所有：您可以在仪表板中管理它、它的账单以及它的 API 密钥。该页面列出了代理持有的 API 密钥，如果您不再希望该代理（或运行它的人）拥有访问权限，您可以撤销它。
3. 如果 72 小时内没有人打开认领链接，该账户及其密钥将被删除。请让代理重新创建一个。

在认领之前，该账户与普通免费试用具有相同的限制。

### 如果您已有账户

每个登录账号拥有一个账户。如果您在登录现有账户的情况下打开认领链接，页面会让您选择：

- **附加到我的账户**会将新账户设为您当前登录账户的托管租户。这需要一个带白标功能的付费套餐，并且新租户的使用量会计入您账户的账单。
- **退出登录并用其他登录账号认领**会将您退出登录，并带您回到认领页面，以便您使用其他登录账号进行认领。

### 面向代理作者

[fastcomments.com/agents.md](https://fastcomments.com/agents.md) 上的代理说明描述了账户创建调用、响应中的字段，以及如何将认领链接交给您的委托人。该调用不需要 API 密钥，并且按 IP 地址进行速率限制。
