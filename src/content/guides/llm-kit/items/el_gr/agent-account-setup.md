Ένας κωδικοποιητικός πράκτορας όπως ο Claude Code, ο Cursor ή ένας βοηθός βασισμένος σε MCP μπορεί να ρυθμίσει το FastComments για εσάς χωρίς να συμπληρώσετε τη φόρμα εγγραφής. Αυτό είναι χρήσιμο όταν ζητάτε από έναν πράκτορα να "add comments to my site" και δεν έχετε ακόμη λογαριασμό.

### Πώς λειτουργεί

1. Ο πράκτορας δημιουργεί έναν νέο λογαριασμό και λαμβάνει ένα κλειδί API και έναν σύνδεσμο αξίωσης. Το κλειδί API λειτουργεί αμέσως, ώστε ο πράκτορας να μπορεί να ρυθμίσει το λογαριασμό και να εγκαταστήσει το widget στον ιστότοπό σας.
2. Ο πράκτορας σας δίνει τον σύνδεσμο αξίωσης. Ανοίξτε τον στο πρόγραμμα περιήγησής σας, συνδεθείτε ή δημιουργήστε έναν λογαριασμό, και επιβεβαιώστε την αξίωση. Ο λογαριασμός γίνεται δικός σας: τον διαχειρίζεστε, τη χρέωση του και τα κλειδιά API από τον πίνακα ελέγχου. Η σελίδα εμφανίζει το κλειδί API που κατέχει ο πράκτορας ώστε να μπορείτε να το ανακαλέσετε εάν δεν θέλετε πλέον ο πράκτορας, ή όποιος το εκτελεί, να έχει πρόσβαση.
3. Εάν κανείς δεν ανοίξει τον σύνδεσμο αξίωσης εντός 72 ωρών, ο λογαριασμός και το κλειδί του διαγράφονται. Ζητήστε από τον πράκτορα να δημιουργήσει ένα νέο.

Μέχρι να αξιώσει, ο λογαριασμός έχει τα ίδια όρια με μια κανονική δωρεάν δοκιμή.

### Εάν έχετε ήδη λογαριασμό

Κάθε σύνδεση (login) κατέχει έναν λογαριασμό. Εάν ανοίξετε έναν σύνδεσμο αξίωσης ενώ είστε συνδεδεμένοι σε έναν υπάρχοντα λογαριασμό, η σελίδα σας επιτρέπει να επιλέξετε:

- **Attach to my account** κάνει τον νέο λογαριασμό έναν διαχειριζόμενο ενοικιαστή του λογαριασμού στον οποίο είστε συνδεδεμένοι. Αυτό απαιτεί ένα πληρωμένο πρόγραμμα με λευκή σήμανση, και η χρήση του νέου ενοικιαστή χρεώνεται στον λογαριασμό σας.
- **Sign out and claim with another login** σας αποσυνδέει και σας επιστρέφει στη σελίδα αξίωσης ώστε να το αξιώσετε με διαφορετική σύνδεση.

### Για δημιουργούς πρακτόρων

Οι οδηγίες για τους πράκτορες στο [fastcomments.com/agents.md](https://fastcomments.com/agents.md) περιγράφουν την κλήση δημιουργίας λογαριασμού, τα πεδία στην απάντηση, και πώς να παραδώσετε τον σύνδεσμο αξίωσης στο άτομο για το οποίο εργάζεστε. Η κλήση δεν απαιτεί κλειδί API και περιορίζεται ανά IP διεύθυνση.
