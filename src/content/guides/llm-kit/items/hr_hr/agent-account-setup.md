A coding agent such as Claude Code, Cursor, or an MCP-based assistant can set up FastComments for you without you filling in the signup form. This is useful when you ask an agent to "add comments to my site" and you do not have an account yet.

### Kako funkcionira

1. Agent kreira novi račun i dobiva API ključ i poveznicu za preuzimanje. API ključ odmah funkcionira, pa agent može konfigurirati račun i instalirati widget na vašu stranicu.  
2. Agent vam daje poveznicu za preuzimanje. Otvorite je u pregledniku, prijavite se ili kreirajte prijavu, i potvrdite preuzimanje. Račun tada postaje vaš: vi ga upravljate, njegovu naplatu i API ključeve iz nadzorne ploče. Stranica prikazuje API ključ koji agent posjeduje kako biste ga mogli opozvati ako više ne želite da agent ili tko god ga koristi ima pristup.  
3. Ako nitko ne otvori poveznicu za preuzimanje u roku od 72 sata, račun i njegov ključ se brišu. Zamolite agenta da kreira novi.

Dok se ne preuzme, račun ima iste ograničenja kao obična besplatna probna verzija.

### Ako već imate račun

Svaka prijava posjeduje jedan račun. Ako otvorite poveznicu za preuzimanje dok ste prijavljeni na postojeći račun, stranica vam omogućuje odabir:

- **Attach to my account** čini novi račun upravljanim najemnikom onog na koji ste prijavljeni. To zahtijeva plaćeni plan s bijelim označavanjem, a korištenje novog najemnika naplaćuje se s vašeg računa.  
- **Sign out and claim with another login** odjavljuje vas i vraća na stranicu za preuzimanje kako biste ga mogli preuzeti s drugom prijavom.

### Za autore agenata

Upute za agente na [fastcomments.com/agents.md](https://fastcomments.com/agents.md) opisuju poziv za kreiranje računa, polja u odgovoru i kako predati poveznicu za preuzimanje osobi za koju radite. Poziv ne zahtijeva API ključ i ograničen je po IP adresi.
