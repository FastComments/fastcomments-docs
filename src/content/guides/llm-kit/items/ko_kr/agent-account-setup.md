Claude Code, Cursor 또는 MCP 기반 어시스턴트 같은 코딩 에이전트가 가입 양식을 직접 작성하지 않아도 FastComments를 설정해 줄 수 있습니다. 에이전트에게 "내 사이트에 댓글 추가해 줘"라고 요청했는데 아직 계정이 없는 경우에 유용합니다.

### 작동 방식

1. 에이전트가 새 계정을 생성하고 API 키와 클레임 링크를 받습니다. API 키는 즉시 사용할 수 있으므로 에이전트가 계정을 구성하고 사이트에 위젯을 설치할 수 있습니다.
2. 에이전트가 클레임 링크를 전달합니다. 브라우저에서 링크를 열고, 로그인하거나 계정을 생성한 뒤 클레임을 확정하세요. 그러면 해당 계정은 당신의 소유가 됩니다: 대시보드에서 계정, 결제, API 키를 직접 관리하게 됩니다. 클레임 페이지에는 에이전트가 보유한 API 키가 표시되므로, 더 이상 에이전트(또는 에이전트를 운영하는 사람)에게 접근 권한을 주고 싶지 않다면 해당 키를 취소할 수 있습니다.
3. 72시간 이내에 아무도 클레임 링크를 열지 않으면 계정과 키가 삭제됩니다. 에이전트에게 새 계정을 생성하도록 요청하세요.

클레임되기 전까지 해당 계정은 일반 무료 체험판과 동일한 제한을 갖습니다.

### 이미 계정이 있는 경우

각 로그인은 하나의 계정을 소유합니다. 기존 계정으로 로그인한 상태에서 클레임 링크를 열면 페이지에서 다음 중 선택할 수 있습니다:

- **내 계정에 연결**을 선택하면 새 계정이 현재 로그인된 계정의 관리형 테넌트가 됩니다. 이를 위해서는 화이트 라벨링이 포함된 유료 플랜이 필요하며, 새 테넌트의 사용량은 당신의 계정에 청구됩니다.
- **로그아웃 후 다른 로그인으로 클레임**을 선택하면 로그아웃되고 클레임 페이지로 돌아가 다른 로그인으로 클레임할 수 있습니다.

### 에이전트 개발자를 위해

[fastcomments.com/agents.md](https://fastcomments.com/agents.md)의 에이전트 지침에는 계정 생성 호출, 응답의 필드, 그리고 작업 대상자에게 클레임 링크를 전달하는 방법이 설명되어 있습니다. 이 호출은 API 키가 필요 없으며 IP 주소별로 요청이 제한됩니다.
