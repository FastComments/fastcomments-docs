A coding agent such as Claude Code, Cursor, or an MCP-based assistant can set up FastComments for you without you filling in the signup form. This is useful when you ask an agent to "add comments to my site" and you do not have an account yet.

### 작동 방식

1. 에이전트가 새 계정을 생성하고 API 키와 클레임 링크를 받습니다. API 키는 즉시 사용할 수 있어 에이전트가 계정을 구성하고 위젯을 사이트에 설치할 수 있습니다.
2. 에이전트가 클레임 링크를 제공합니다. 브라우저에서 해당 링크를 열고 로그인하거나 계정을 생성한 뒤 클레임을 확인합니다. 그러면 계정은 여러분의 것이 됩니다: 대시보드에서 계정, 청구 및 API 키를 관리할 수 있습니다. 페이지에는 에이전트가 보유하고 있는 API 키가 표시되므로, 더 이상 에이전트나 운영자가 접근하지 않도록 원한다면 해당 키를 취소할 수 있습니다.
3. 72시간 이내에 아무도 클레임 링크를 열지 않으면, 계정과 해당 키가 삭제됩니다. 에이전트에게 새 계정을 만들도록 요청하세요.

클레임이 완료될 때까지, 해당 계정은 일반 무료 체험과 동일한 제한을 가집니다.

### 이미 계정이 있는 경우

각 로그인은 하나의 계정을 소유합니다. 기존 계정에 로그인한 상태에서 클레임 링크를 열면, 페이지에서 다음 중 하나를 선택할 수 있습니다:

- **내 계정에 연결**은 새 계정을 현재 로그인한 계정의 관리형 테넌트로 만듭니다. 이를 위해서는 화이트 라벨링이 포함된 유료 플랜이 필요하며, 새 테넌트의 사용량은 귀하의 계정에 청구됩니다.
- **로그아웃하고 다른 로그인으로 클레임**은 로그아웃을 수행하고 클레임 페이지로 돌아가 다른 로그인으로 클레임할 수 있게 합니다.

### 에이전트 작성자를 위한 안내

에이전트 안내서는 [fastcomments.com/agents.md](https://fastcomments.com/agents.md)에서 확인할 수 있으며, 계정 생성 호출, 응답에 포함된 필드, 그리고 작업 중인 사람에게 클레임 링크를 전달하는 방법을 설명합니다. 이 호출은 API 키가 필요 없으며 IP 주소당 속도 제한이 적용됩니다.
