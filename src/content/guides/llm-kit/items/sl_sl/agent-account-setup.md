A coding agent such as Claude Code, Cursor, or an MCP-based assistant can set up FastComments for you without you filling in the signup form. This is useful when you ask an agent to "add comments to my site" and you do not have an account yet.

### Kako deluje

1. Agent ustvari nov račun in prejme API ključ ter povezavo za prevzem. API ključ deluje takoj, zato lahko agent konfigurira račun in namesti gradnik na vašo stran.  
2. Agent vam da povezavo za prevzem. Odprite jo v brskalniku, se prijavite ali ustvarite prijavo ter potrdite prevzem. Račun je potem vaš: upravljate ga, njegovo obračunavanje in njegove API ključe prek nadzorne plošče. Stran izpiše API ključ, ki ga ima agent, da ga lahko prekličete, če ne želite, da ima agent ali kdorkoli, ki ga uporablja, dostop.  
3. Če nihče ne odpre povezave za prevzem v 72 urah, se račun in njegov ključ izbrišeta. Prosite agenta, da ustvari novega.

Dokler ni prevzet, ima račun enake omejitve kot običajna brezplačna preizkusna različica.

### Če že imate račun

Vsaka prijava ima en račun. Če odprete povezavo za prevzem, ko ste prijavljeni v obstoječ račun, vam stran omogoči izbiro:

- **Pripni k mojemu računu** naredi nov račun upravljanega najemnika računa, v katerega ste prijavljeni. To zahteva plačani načrt z belim označevanjem, uporaba novega najemnika pa se zaračuna vašemu računu.  
- **Odjavi se in prevzemi z drugo prijavo** vas odjavi ter vas vrne na stran za prevzem, da jo lahko prevzamete z drugo prijavo.

### Za avtorje agentov

Navodila za agente na [fastcomments.com/agents.md](https://fastcomments.com/agents.md) opisujejo klic za ustvarjanje računa, polja v odgovoru in kako predati povezavo za prevzem osebi, za katero delate. Klic ne potrebuje API ključa in je omejen po hitrosti na IP naslov.
