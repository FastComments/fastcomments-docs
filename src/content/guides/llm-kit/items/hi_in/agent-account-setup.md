Claude Code, Cursor, या MCP-आधारित असिस्टेंट जैसा कोडिंग एजेंट आपके लिए साइनअप फॉर्म भरे बिना FastComments सेट अप कर सकता है। यह तब उपयोगी होता है जब आप एजेंट से "मेरी साइट पर कमेंट्स जोड़ो" कहते हैं और आपके पास अभी कोई खाता नहीं है।

### यह कैसे काम करता है

1. एजेंट एक नया खाता बनाता है और एक API key तथा एक claim link प्राप्त करता है। API key तुरंत काम करती है, इसलिए एजेंट खाते को कॉन्फ़िगर कर सकता है और आपकी साइट पर विजेट इंस्टॉल कर सकता है।
2. एजेंट आपको claim link देता है। इसे अपने ब्राउज़र में खोलें, लॉग इन करें या एक लॉगिन बनाएं, और claim की पुष्टि करें। तब खाता आपका हो जाता है: आप इसे, इसकी बिलिंग, और इसकी API keys को डैशबोर्ड से प्रबंधित करते हैं। पृष्ठ उस API key को सूचीबद्ध करता है जो एजेंट के पास है, ताकि यदि आप नहीं चाहते कि एजेंट, या जो इसे चलाता है, के पास एक्सेस रहे, तो आप उसे रद्द कर सकें।
3. यदि 72 घंटों के भीतर कोई claim link नहीं खोलता, तो खाता और उसकी key डिलीट कर दी जाती है। एजेंट से एक नया बनाने के लिए कहें।

Claim होने तक, खाते पर एक सामान्य निःशुल्क ट्रायल जैसी ही सीमाएं होती हैं।

### यदि आपके पास पहले से खाता है

प्रत्येक लॉगिन के पास एक खाता होता है। यदि आप किसी मौजूदा खाते में लॉग इन होते हुए एक claim link खोलते हैं, तो पृष्ठ आपको चुनने देता है:

- **Attach to my account** नए खाते को आपके लॉग इन खाते का एक प्रबंधित tenant बना देता है। इसके लिए white labeling के साथ एक सशुल्क प्लान चाहिए, और नए tenant का उपयोग आपके खाते पर बिल किया जाता है।
- **Sign out and claim with another login** आपको साइन आउट करके claim पृष्ठ पर वापस ले आता है ताकि आप इसे किसी अन्य लॉगिन से claim कर सकें।
