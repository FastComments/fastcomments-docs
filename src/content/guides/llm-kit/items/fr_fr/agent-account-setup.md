Un agent de codage tel que Claude Code, Cursor ou un assistant basé sur MCP peut configurer FastComments pour vous sans que vous ayez à remplir le formulaire d'inscription. Cela est utile lorsque vous demandez à un agent d'« ajouter des commentaires à mon site » et que vous n'avez pas encore de compte.

### Comment ça fonctionne

1. L'agent crée un nouveau compte et reçoit une clé API ainsi qu'un lien de réclamation. La clé API fonctionne immédiatement, ce qui permet à l'agent de configurer le compte et d'installer le widget sur votre site.  
2. L'agent vous donne le lien de réclamation. Ouvrez-le dans votre navigateur, connectez‑vous ou créez un compte, puis confirmez la réclamation. Le compte devient alors le vôtre : vous le gérez, ainsi que sa facturation et ses clés API depuis le tableau de bord. La page répertorie la clé API détenue par l'agent afin que vous puissiez la révoquer si vous ne souhaitez plus que l'agent, ou quiconque l'utilise, y ait accès.  
3. Si personne n'ouvre le lien de réclamation dans les 72 heures, le compte et sa clé sont supprimés. Demandez à l'agent d'en créer un nouveau.

Jusqu'à ce qu'il soit réclamé, le compte bénéficie des mêmes limites qu'un essai gratuit standard.

### Si vous avez déjà un compte

Chaque identifiant possède un compte. Si vous ouvrez un lien de réclamation alors que vous êtes connecté à un compte existant, la page vous propose de choisir :

- **Attacher à mon compte** rend le nouveau compte un locataire géré de celui auquel vous êtes connecté. Cela nécessite un plan payant avec marque blanche, et l'utilisation du nouveau locataire est facturée à votre compte.  
- **Se déconnecter et réclamer avec un autre identifiant** vous déconnecte et vous ramène à la page de réclamation afin que vous puissiez la réclamer avec un identifiant différent.

### Pour les auteurs d'agents

Les instructions pour les agents disponibles sur [fastcomments.com/agents.md](https://fastcomments.com/agents.md) décrivent l'appel de création de compte, les champs de la réponse, et la manière de transmettre le lien de réclamation à la personne pour laquelle vous travaillez. L'appel ne nécessite aucune clé API et est limité en fréquence par adresse IP.
