Un agente de codificación como Claude Code, Cursor o un asistente basado en MCP puede configurar FastComments para ti sin que tengas que rellenar el formulario de registro. Esto es útil cuando le pides a un agente que "añada comentarios a mi sitio" y aún no tienes una cuenta.

### Cómo funciona

1. El agente crea una nueva cuenta y recibe una clave API y un enlace de reclamación. La clave API funciona de inmediato, por lo que el agente puede configurar la cuenta e instalar el widget en tu sitio.  
2. El agente te entrega el enlace de reclamación. Ábrelo en tu navegador, inicia sesión o crea un inicio de sesión, y confirma la reclamación. Entonces la cuenta es tuya: la gestionas, su facturación y sus claves API desde el panel de control. La página muestra la clave API que posee el agente para que puedas revocarla si ya no deseas que el agente, o quien lo ejecute, tenga acceso.  
3. Si nadie abre el enlace de reclamación dentro de las 72 horas, la cuenta y su clave se eliminan. Pide al agente que cree una nueva.

Hasta que se reclame, la cuenta tiene los mismos límites que una prueba gratuita normal.

### Si ya tienes una cuenta

Cada inicio de sesión posee una cuenta. Si abres un enlace de reclamación mientras estás conectado a una cuenta existente, la página te permite elegir:

- **Adjuntar a mi cuenta** hace que la nueva cuenta sea un inquilino gestionado de la cuenta en la que has iniciado sesión. Esto requiere un plan de pago con marca blanca, y el uso del nuevo inquilino se factura a tu cuenta.  
- **Cerrar sesión y reclamar con otro inicio de sesión** cierra tu sesión y te lleva de vuelta a la página de reclamación para que puedas reclamarla con un inicio de sesión diferente.

### Para autores de agentes

Las instrucciones para agentes en [fastcomments.com/agents.md](https://fastcomments.com/agents.md) describen la llamada de creación de cuenta, los campos en la respuesta y cómo entregar el enlace de reclamación a la persona para la que trabajas. La llamada no necesita una clave API y está limitada por tasa por dirección IP.
