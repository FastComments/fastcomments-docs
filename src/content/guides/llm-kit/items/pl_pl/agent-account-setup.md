Agent programistyczny, taki jak Claude Code, Cursor lub asystent oparty na MCP, może skonfigurować FastComments za Ciebie, bez wypełniania formularza rejestracji. Jest to przydatne, gdy prosisz agenta o "add comments to my site" i nie masz jeszcze konta.

### Jak to działa

1. Agent tworzy nowe konto i otrzymuje klucz API oraz link do przejęcia. Klucz API działa od razu, więc agent może skonfigurować konto i zainstalować widget na Twojej stronie.  
2. Agent przekazuje Ci link do przejęcia. Otwórz go w przeglądarce, zaloguj się lub utwórz konto, i potwierdź przejęcie. Konto staje się Twoje: zarządzasz nim, jego rozliczeniami oraz kluczami API z panelu. Strona wyświetla klucz API, który posiada agent, abyś mógł go odwołać, jeśli nie chcesz, aby agent lub jego operator miał dostęp.  
3. Jeśli nikt nie otworzy linku do przejęcia w ciągu 72 godzin, konto i jego klucz zostaną usunięte. Poproś agenta o utworzenie nowego.

Do momentu przejęcia konto ma te same limity co standardowy darmowy okres próbny.

### Jeśli już masz konto

Każde logowanie posiada jedno konto. Jeśli otworzysz link do przejęcia będąc zalogowanym na istniejące konto, strona pozwoli Ci wybrać:

- **Dołącz do mojego konta** sprawia, że nowe konto staje się zarządzanym najemcą tego, na które jesteś zalogowany. Wymaga to płatnego planu z białą etykietą, a zużycie nowego najemcy jest rozliczane na Twoim koncie.  
- **Wyloguj się i przejmij przy użyciu innego logowania** wylogowuje Cię i przenosi z powrotem na stronę przejęcia, abyś mógł przejąć je przy użyciu innego konta.

### Dla autorów agentów

Instrukcje dla agentów dostępne pod adresem [fastcomments.com/agents.md](https://fastcomments.com/agents.md) opisują wywołanie tworzenia konta, pola w odpowiedzi oraz sposób przekazania linku do przejęcia osobie, dla której pracujesz. Wywołanie nie wymaga klucza API i jest limitowane pod względem liczby żądań na adres IP.
