Bei der Moderation gibt es manchmal eine Reihe von Aktionen, die wir alle auf einmal ausführen möchten. Vielleicht finden Sie zum Beispiel eine Reihe von Kommentaren, die Sie löschen, als Spam markieren, die Freigabe aufheben oder einfach als geprüft markieren möchten. Statt bei jedem Kommentar auf „Löschen" und „Bestätigen" zu klicken, gibt es einen besseren Weg.

Neben jedem Kommentar befindet sich ein Kontrollkästchen, das wir anklicken können, um eine Massenaktion zu starten. Von dort aus können wir eine Massenaktion auswählen und bestätigen.

Sie sehen den Fortschritt, während Ihre Massenaktionen ausgeführt werden, und Sie können mit ctrl+z jede Massenaktion rückgängig machen. Massenaktionen können auch pausiert, gestoppt oder fortgesetzt werden.

### Auswahl über sichtbare Kommentare hinaus

Wenn Sie das Kontrollkästchen „Alle auswählen" aktivieren, werden standardmäßig nur die sichtbaren Kommentare auf der Seite ausgewählt, aber es wird Ihnen eine Option angeboten, alle Kommentare auf dem Server auszuwählen, die Ihren Filtern entsprechen. Selbst wenn Sie also Millionen von Kommentaren genehmigen, löschen usw. müssen, können Sie dies mit wenigen Klicks erledigen.
