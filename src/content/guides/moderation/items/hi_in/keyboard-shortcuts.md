कमेंट मॉडरेशन पेज कीबोर्ड शॉर्टकट्स को सपोर्ट करता है, जिनसे कमेंट्स के बीच नेविगेट किया जा सकता है, एक्शन किए जा सकते हैं, और पेजिनेट किया जा सकता है - बिना माउस का उपयोग किए।

मॉडरेशन पेज पर कभी भी **?** दबाएँ ताकि एक हेल्प डायलॉग खुले जिसमें सभी उपलब्ध शॉर्टकट्स की सूची हो।

## नेविगेशन

| की | एक्शन |
|-----|--------|
| `j` | अगले कमेंट पर फोकस करें |
| `k` | पिछले कमेंट पर फोकस करें |
| `x` या `Enter` | फोकस किए गए कमेंट का चयन टॉगल करें |
| `Shift+j` | फोकस किए गए कमेंट का चयन करें और अगले पर जाएँ |
| `Shift+k` | फोकस किए गए कमेंट का चयन करें और पिछले पर जाएँ |

फोकस किए गए कमेंट को नीली रूपरेखा से हाइलाइट किया जाता है। यह "चयनित" (चेक किए गए) कमेंट्स से अलग है।

## फोकस किए गए कमेंट पर एक्शन

| की | एक्शन |
|-----|--------|
| `a` | अप्रूव / अनअप्रूव टॉगल करें |
| `s` | स्पैम / नॉट स्पैम टॉगल करें |
| `d` | डिलीट करें |
| `u` | अनडिलीट करें |
| `r` | रिव्यूड / नॉट रिव्यूड टॉगल करें |
| `e` | एडिट करें |
| `b` | बैन / बैन प्रबंधित करें |
| `p` | पिन / अनपिन टॉगल करें |
| `f` | अनफ्लैग करें |
| `i` | उस IP से आए सभी कमेंट देखें |
| `t` | ट्रस्ट फैक्टर सेट करें |
| `m` | बैज प्रबंधित करें |
| `l` | लॉग देखें |
| `c` | कॉन्टेक्स्ट टॉगल करें |

ये शॉर्टकट्स केवल तब लागू होते हैं जब कोई कमेंट फोकस में हो। यदि कोई कमेंट फोकस में नहीं है, तो पहले `j` या `k` दबाएँ।

## ग्लोबल शॉर्टकट्स

| की | एक्शन |
|-----|--------|
| `Ctrl+a` | सभी कमेंट्स चुनें |
| `Ctrl+z` | अंतिम एक्शन पूर्ववत करें |
| `?` | कीबोर्ड शॉर्टकट्स हेल्प दिखाएँ |
| `g` | शॉर्टकट गाइडर्स ओवरले टॉगल करें |
| `/` | सर्च इनपुट पर फोकस करें |

## पेजिनेशन

| की | एक्शन |
|-----|--------|
| `[` | पिछला पेज |
| `]` | अगला पेज |

## शॉर्टकट गाइडर्स

गाइडर्स मोड टॉगल करने के लिए `g` दबाएँ। सक्रिय होने पर, फोकस किए गए कमेंट के एक्शन बटनों पर छोटे बैज दिखाई देते हैं जो प्रत्येक बटन के लिए कीबोर्ड शॉर्टकट दिखाते हैं। यह शॉर्टकट्स सीखते समय उपयोगी है। उन्हें छिपाने के लिए फिर से `g` दबाएँ।

## इनपुट सप्रेशन

निम्नलिखित स्थितियों में शॉर्टकट्स स्वतः सप्रेस हो जाते हैं:

- जब कर्सर सर्च बॉक्स, टेक्स्ट इनपुट, या कंटेंट-एडिटेबल फ़ील्ड में हो। फ़ील्ड को ब्लर करने और शॉर्टकट्स पर लौटने के लिए `Escape` दबाएँ।
- जब कोई डायलॉग खुला हो। पहले डायलॉग बंद करें।
