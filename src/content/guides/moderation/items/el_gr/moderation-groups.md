Οι συντονιστές μπορούν να τοποθετηθούν σε ομάδες για να συντονίζουν διαφορετικές σελίδες ή κατηγορίες περιεχομένου.

Όταν ένας συντονιστής ανήκει σε μία ή περισσότερες ομάδες, θα βλέπει μόνο σχόλια από αυτές τις ομάδες στη σελίδα Συντονισμού Σχολίων.

Για παράδειγμα, ας πούμε ότι διαχειριζόμαστε έναν ιστότοπο που εμφανίζει βίντεο ανά κατηγορία. Μπορεί να θέλουμε διαφορετικούς συντονιστές για βίντεο Γάτας, Σκύλου και Παπαγάλου, έτσι [ας προσθέσουμε αυτές τις ομάδες](https://fastcomments.com/auth/my-account/moderate-comments/moderation-groups).

[app-screenshot-start url='/auth/my-account/moderate-comments/moderation-groups?demo=true'; linkUrl='/auth/my-account/moderate-comments/moderation-groups'; selector = '.content'; alt='Λίστα ομάδων συντονισμού με τις ομάδες Γάτα, Σκύλος και Παπαγάλος που δημιουργήθηκαν για κάθε κατηγορία βίντεο'; title='Η Σελίδα Ομάδων Συντονισμού' app-screenshot-end]

Όταν προσθέτουμε έναν συντονιστή, τώρα έχουμε την επιλογή να επιλέξουμε μία ή περισσότερες ομάδες στις οποίες θα ανήκει ο συντονιστής:

[app-screenshot-start url='/auth/my-account/moderate-comments/moderator/new?demo=true'; linkUrl='/auth/my-account/moderate-comments/moderator/new'; selector = '.account-block'; alt='Φόρμα προσθήκης συντονιστή με τον επιλογέα ομάδας που χρησιμοποιείται για την ανάθεση του συντονιστή σε μία ή περισσότερες ομάδες'; title='Προσθήκη Συντονιστή και Επιλογή Ομάδας' app-screenshot-end]

Τέλος, τα σχόλια πρέπει να συνδέονται με μία ή περισσότερες ομάδες ώστε οι σωστοί συντονιστές να τα βλέπουν.

Αυτό μπορεί να ρυθμιστεί προσθέτοντας κάποιες ομάδες [εδώ](https://fastcomments.com/auth/my-account/moderate-comments/moderation-groups) και στη συνέχεια καθορίζοντας τα αντίστοιχα `Moderation Group` ids στο widget σχολίων,
[όπως περιγράφεται εδώ](/guide-customizations-and-configuration.html#moderation-group-ids).
