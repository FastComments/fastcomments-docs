Для администраторов в верхней части страницы модерации комментариев находится кнопка «Добавить модераторов».

[app-screenshot-start url='/auth/my-account/moderate-comments?filter=&text-search=&page=1&count=3&demo=true'; linkUrl='/auth/my-account/moderate-comments'; selector = '.moderation-settings-options'; alt='Ряд кнопок в верхней части страницы модерации комментариев, включая кнопку «Добавить модераторов»'; title='Кнопки настроек модерации комментариев' app-screenshot-end]

Если у вас уже есть модераторы, эта кнопка будет отображать «Редактировать модераторов».

Давайте посмотрим страницу «Добавить модератора».

[app-screenshot-start url='/auth/my-account/moderate-comments/moderator/new'; selector = '.account-block'; alt='Страница «Добавить модератора», запрашивающая только имя и электронную почту нового модератора перед отправкой приглашения'; title='Страница «Добавить модератора»' app-screenshot-end]

Чтобы добавить модератора, требуется только имя и электронная почта.

Если электронная почта связана с существующей учётной записью FastComments, её владелец получит приглашение по электронной почте присоединиться к вашей учётной записи в качестве модератора.

Если указанная электронная почта не связана с существующей учётной записью FastComments, для неё будет создана новая учётная запись.

Ссылка‑приглашение будет отправлена модератору, и она может автоматически выполнить вход. В дальнейшем, если они захотят войти, они могут просто посетить
<a href="https://fastcomments.com/auth/login" target="_blank">страницу входа</a> и ввести имя/электронную почту, которые вы указали ранее. Это отправит им
ссылку для входа.

Если они не выйдут из системы, они останутся в системе в течение тридцати дней.
