Per impostazione predefinita, FastComments include una blacklist di parole con circa 450 frasi e parole.

Se nel testo di un nuovo commento viene trovata una parola presente nella blacklist, quel testo verrà sostituito con asterischi (***).

La pagina per personalizzare la blacklist è raggiungibile tramite Moderate Comments -> Edit Moderation Settings -> Edit Word Blacklist, oppure
andando direttamente <a href="https://fastcomments.com/auth/my-account/moderate-comments/blacklist" target="_blank">qui</a>.

Inoltre, puoi disattivare il rilevamento delle parolacce nella pagina <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Edit Moderation Settings</a>.
