Human Moderation Services est une modération gérée par l'équipe FastComments. Nos modérateurs traitent votre file d'attente, dans votre tableau de bord, selon vos consignes. Il n'y a pas d'outil séparé ni d'export de vos données vers un tiers : le service s'appuie sur les fonctionnalités de modération dont dispose déjà chaque compte.

### Comment ça fonctionne

1. **Nous convenons des règles.** Vous partagez les règles de votre communauté et nous indiquons quoi approuver, supprimer et escalader. Les deux parties signent un playbook écrit avant que quiconque ne touche à votre file d'attente.
2. **Nous rejoignons votre compte.** Les modérateurs FastComments sont ajoutés via [Adding Moderators](/guide-moderation.html#moderators-adding) et leur périmètre est défini par [Moderation Groups](/guide-moderation.html#moderation-groups), afin qu'ils ne voient que les pages, catégories ou sites que vous leur attribuez.
3. **Les machines d'abord, les humains ensuite.** [Spam Detection](/guide-moderation.html#spam-detection) et [AI Agents](/guide-ai-agents.html) traitent les cas évidents. Nos modérateurs s'occupent du reste : contexte, ton, appels et tout ce qu'un agent a escaladé.
4. **Vous voyez tout.** Chaque action est consignée dans [Comment Logs](/guide-moderation.html#comment-logs) et [Moderator Stats](/guide-moderation.html#moderator-stats) avec le nom du modérateur. Les questions de politique sont adressées à votre contact d'escalade désigné.

### Ce que vous contrôlez

- **Consignes.** Nos modérateurs suivent le playbook rédigé à partir de vos règles. Lorsqu'un cas n'est pas couvert, il vous est escaladé plutôt que tranché à votre place.
- **Périmètre.** Élargissez ou restreignez l'accès à tout moment en modifiant le Moderation Group auquel appartiennent nos modérateurs.
- **Contacts d'escalade.** Vous désignez qui, chez vous, reçoit les questions de politique, et nous désignons qui, chez nous, est responsable de la file d'attente.
- **Accès.** [Removing a moderator](/guide-moderation.html#moderators-removing) met fin immédiatement à son accès.

### Travailler aux côtés des AI Agents

Les agents et les modérateurs FastComments agissent via les mêmes outils, de sorte que chaque action apparaît dans les mêmes journaux et sur la même page de modération. Une configuration typique exécute la détection de spam et les AI Agents en première passe, les modérateurs humains traitant les commentaires signalés pour examen par les agents. Consultez [AI Agents](/guide-ai-agents.html) pour savoir comment les agents escaladent vers un humain.

Le [trust factor](/guide-moderation.html#spam-detection) relie les deux. Chaque commentateur porte un score de 0 à 100 construit à partir de son ancienneté, de son nombre de commentaires et de ses commentaires épinglés. La détection de spam et les AI Agents s'en servent pour déterminer le niveau de rigueur appliqué à un commentaire, et nos modérateurs l'ajustent manuellement lorsque le score automatique est erroné. Chaque modification est consignée dans [Comment Logs](/guide-moderation.html#comment-logs), de sorte qu'une décision humaine aujourd'hui change la façon dont les couches automatisées traitent cette personne par la suite.

### Où se trouvent nos modérateurs

Pour les clients mondiaux et américains, les modérateurs FastComments sont basés aux États-Unis, afin que vos données ne quittent pas le pays. Sur le déploiement UE, seuls des modérateurs basés dans l'UE traitent votre file d'attente, afin que les données de commentaires ne quittent pas l'UE.
