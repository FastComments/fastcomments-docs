Par défaut, FastComments est fourni avec une liste noire de mots contenant environ 450 expressions et mots.

Si du texte présent dans la liste noire de mots est trouvé dans un nouveau commentaire, ce texte sera remplacé par des astérisques (***) .

La page permettant de personnaliser la liste noire peut être trouvée via Modérer les commentaires -> Modifier les paramètres de modération -> Modifier la liste noire de mots, ou en allant directement <a href="https://fastcomments.com/auth/my-account/moderate-comments/blacklist" target="_blank">ici</a>.

[app-screenshot-start url='/auth/my-account/moderate-comments/blacklist?blurList=true'; linkUrl='/auth/my-account/moderate-comments/blacklist'; selector = '.account-block'; alt='Éditeur de liste noire de mots où les mots et expressions bloqués par défaut peuvent être ajoutés ou supprimés'; title='Liste noire de mots de commentaire' app-screenshot-end]

De plus, vous pouvez désactiver la détection de profanity sur la page <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Modifier les paramètres de modération</a>.
