Por defecto, FastComments incluye una lista negra de palabras con ~450 frases y palabras.

Si se encuentra texto de la lista negra de palabras en un nuevo comentario, ese texto será reemplazado por asteriscos (***).

La página para personalizar la lista negra se puede encontrar a través de Moderación de Comentarios -> Editar Configuración de Moderación -> Editar Lista Negra de Palabras, o yendo directamente <a href="https://fastcomments.com/auth/my-account/moderate-comments/blacklist" target="_blank">aquí</a>.

Además, puedes desactivar la detección de blasfemias en la página <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Editar Configuración de Moderación</a> página.
