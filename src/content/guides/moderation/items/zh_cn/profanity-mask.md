默认情况下，FastComments 附带约 450 条短语和词汇的词汇黑名单。

如果在新评论中发现词汇黑名单中的文本，该文本将被星号（***）替换。

可以通过 Moderate Comments -> Edit Moderation Settings -> Edit Word Blacklist 找到自定义黑名单的页面，或直接访问 <a href="https://fastcomments.com/auth/my-account/moderate-comments/blacklist" target="_blank">此处</a>。

[app-screenshot-start url='/auth/my-account/moderate-comments/blacklist?blurList=true'; linkUrl='/auth/my-account/moderate-comments/blacklist'; selector = '.account-block'; alt='词汇黑名单编辑器，可在此添加或删除默认被阻止的词语和短语'; title='评论词汇黑名单' app-screenshot-end]

此外，您可以在 <a href="https://fastcomments.com/auth/my-account/moderate-comments/settings" target="_blank">Edit Moderation Settings</a> 页面上禁用 Profanity Detection。
