可以直接在评论线程本身执行一部分审核操作，而无需前往评论审核页面。

登录后，点击评论右上角的编辑按钮。作为审核员，你应该会看到以下选项：

- **置顶**该评论
- **删除**该评论
- **删除**该评论 + **封禁该用户**（永久或影子封禁，稍后详细介绍）
- **编辑**该评论
- **锁定**或**解锁**该评论（详见下文）
- 将该评论标记为**已批准**（显示）或**未批准**（隐藏）
- 将该评论标记为**垃圾信息**或**非垃圾信息**

### 锁定评论

锁定单条评论会阻止任何新的回复，同时在该评论解锁之前，也会阻止该评论本身被编辑或删除。这适用于所有人，包括管理员和审核员。如果你需要编辑或删除一条已锁定的评论，请先解锁，进行更改，然后根据需要重新锁定。

已锁定的评论右上角会显示一个挂锁图标，让读者一眼就能看出该线程已关闭。在评论小部件和公开 API 中，已锁定评论的“编辑”和“删除”菜单项都会被隐藏（如果对已锁定的评论调用 `PATCH` 和 `DELETE`，将返回 `code: 'locked'`）。

有两种有意设计的例外情况会绕过锁定，因为否则会留下孤立数据：当用户删除其整个账户时（无论锁定状态如何，其评论都会被清理），以及当审核员使用“删除该用户的所有评论”选项封禁用户时（清理过程会解除锁定）。

### 关闭评论线程

审核员和管理员如果已登录，可以通过评论区域顶部的三点菜单选择 `Close Thread` 来锁定（关闭）评论线程。他们之后可以随时选择 `Re-Open Thread` 重新开启评论。

关闭评论线程会阻止新评论，但仍然允许投票，并且用户仍可以根据需要删除自己的评论。

关闭和重新开启评论线程会立即影响所有正在查看该线程的用户。

你还可以通过专门为该页面创建自定义规则，将线程标记为只读，这会同时移除投票和删除选项。

### 实时更新

所有这些操作都会立即更新其他用户的评论线程，而无需他们重新加载页面。但是，像隐藏评论或将其标记为垃圾信息这样的审核员操作，不会将评论从**审核员自己的**屏幕上移除，以便他们在需要时可以快速撤销该操作。为了表明该评论已被隐藏，它会相对于其他评论被高亮显示（高亮颜色取决于移除原因）。

例如，假设有用户 `A (commenter)`、`B (Moderator 1)` 和 `C (Moderator 2)`。

...以及以下场景：

1. `User B (Moderator 1)` 隐藏了一条评论。
2. 对于 `User A (commenter)`，该评论立即被隐藏。
3. 对于 `User C (Moderator 2)`，该评论立即被隐藏。
4. 对于执行更改的用户 `User B (Moderator 1)`，该评论仍保留在其屏幕上，但会被高亮显示为已移除。他们可以选择撤销操作，此时其他用户将再次实时看到更新。
