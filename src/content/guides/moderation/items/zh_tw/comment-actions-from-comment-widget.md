部分審核動作可以直接在留言串中執行，無需前往留言審核頁面。

當您登入後，點擊留言右上角的編輯按鈕。作為審核員，您應該會看到以下選項：

- **釘選**該留言
- **刪除**該留言
- **刪除**該留言 + **封禁該使用者**（永久或影子封禁，詳情稍後說明）
- **編輯**該留言
- **鎖定**或**解鎖**該留言（詳情見下方）
- 將該留言標記為**已核准**（顯示）或**未核准**（隱藏）
- 將該留言標記為**垃圾訊息**或**非垃圾訊息**

### 鎖定留言

鎖定單則留言會阻止任何新的回覆，同時也會防止該留言本身被編輯或刪除，直到解鎖為止。這適用於所有人，包括管理員和審核員。如果您需要編輯或移除已鎖定的留言，請先解鎖、進行修改，然後視需要重新鎖定。

已鎖定的留言右上角會顯示一個掛鎖圖示，讓讀者一眼就能看出該討論串已關閉。在留言小工具和公開 API 中，已鎖定留言的「編輯」和「刪除」選單項目都會被隱藏（若對已鎖定的留言呼叫 `PATCH` 和 `DELETE`，將回傳 `code: 'locked'`）。

有兩個刻意設計的例外情況會繞過鎖定，因為否則會留下孤立的資料：當使用者刪除其整個帳號時（無論鎖定狀態為何，其留言都會被清理），以及當審核員以「刪除該使用者的所有留言」選項封禁使用者時（清理過程會解除鎖定）。

### 關閉留言串

審核員和管理員若已登入，可以透過留言區頂端三點選單中的 `Close Thread` 來鎖定或關閉留言串。他們之後可以隨時選擇 `Re-Open Thread` 重新開啟留言功能。

關閉留言串會阻止新留言，但仍允許投票，並允許使用者視需要刪除自己的留言。

關閉和重新開啟留言串會立即影響所有正在檢視該留言串的使用者。

您也可以將留言串標記為唯讀，這會同時移除投票和刪除選項，方法是專門為該頁面建立自訂規則。

### 即時更新

所有這些動作都會立即更新其他使用者的留言串，無需重新載入頁面。然而，審核員的動作（例如隱藏留言或將其標記為垃圾訊息）不會將留言從**審核員自己的**畫面上移除，以便在需要時可以快速復原該動作。為了表示該留言已被隱藏，它會與其他留言相比以高亮顯示（高亮顏色取決於移除的原因）。

例如，假設有使用者 `A (commenter)`、`B (Moderator 1)` 和 `C (Moderator 2)`。

...以及以下情境：

1. `User B (Moderator 1)` 隱藏了一則留言。
2. 對於 `User A (commenter)`，該留言立即被隱藏。
3. 對於 `User C (Moderator 2)`，該留言立即被隱藏。
4. 對於執行變更的使用者 `User B (Moderator 1)`，該留言仍保留在其畫面上，但會以高亮顯示為已移除。他們可以選擇復原該動作，在這種情況下，其他使用者將再次即時看到更新。
