דף ניהול התגובות תומך בקיצורי מקלדת לניווט בין תגובות, ביצוע פעולות ודפדוף - הכל בלי להשתמש בעכבר.

לחצו על **?** בכל עת בדף הניהול כדי לפתוח תיבת דו-שיח של עזרה המפרטת את כל הקיצורים הזמינים.

## ניווט

| מקש | פעולה |
|-----|--------|
| `j` | מיקוד התגובה הבאה |
| `k` | מיקוד התגובה הקודמת |
| `x` או `Enter` | החלפת בחירה בתגובה הממוקדת |
| `Shift+j` | בחירת התגובה הממוקדת ומעבר לבאה |
| `Shift+k` | בחירת התגובה הממוקדת ומעבר לקודמת |

התגובה הממוקדת מסומנת במסגרת כחולה. זה נפרד מתגובות "נבחרות" (מסומנות).

## פעולות על התגובה הממוקדת

| מקש | פעולה |
|-----|--------|
| `a` | החלפת אישור / אי-אישור |
| `s` | החלפת ספאם / לא ספאם |
| `d` | מחיקה |
| `u` | שחזור מחיקה |
| `r` | החלפת נבדק / לא נבדק |
| `e` | עריכה |
| `b` | חסימה / ניהול חסימה |
| `p` | החלפת נעיצה / ביטול נעיצה |
| `f` | הסרת דגל |
| `i` | צפייה בכל התגובות מ-IP |
| `t` | הגדרת גורם אמון |
| `m` | ניהול תגים |
| `l` | צפייה ביומנים |
| `c` | החלפת הצגת הקשר |

קיצורים אלה חלים רק כאשר תגובה ממוקדת. אם אין תגובה ממוקדת, לחצו קודם על `j` או `k`.

## קיצורים גלובליים

| מקש | פעולה |
|-----|--------|
| `Ctrl+a` | בחירת כל התגובות |
| `Ctrl+z` | ביטול הפעולה האחרונה |
| `?` | הצגת עזרה לקיצורי מקלדת |
| `g` | החלפת שכבת המדריכים של הקיצורים |
| `/` | מיקוד שדה החיפוש |

## דפדוף

| מקש | פעולה |
|-----|--------|
| `[` | עמוד קודם |
| `]` | עמוד הבא |

## מדריכי קיצורים

לחצו על `g` כדי להפעיל/לכבות מצב מדריכים. כשהוא פעיל, תגים קטנים מופיעים על כפתורי הפעולה של התגובה הממוקדת ומציגים את קיצור המקלדת של כל כפתור. זה שימושי בזמן למידת הקיצורים. לחצו על `g` שוב כדי להסתיר אותם.

## השתקת קלט

קיצורים מושתקים אוטומטית כאשר:

- הסמן נמצא בתיבת החיפוש, בשדה קלט טקסט או בשדה עריכת תוכן. לחצו על `Escape` כדי לצאת מהשדה ולחזור לקיצורים.
- תיבת דו-שיח פתוחה. סגרו קודם את תיבת הדו-שיח.
