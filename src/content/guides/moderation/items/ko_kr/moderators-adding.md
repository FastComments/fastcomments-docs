관리자에게는 댓글 검토 페이지 상단에 모더레이터 추가 버튼이 있습니다.

[app-screenshot-start url='/auth/my-account/moderate-comments?filter=&text-search=&page=1&count=3&demo=true'; linkUrl='/auth/my-account/moderate-comments'; selector = '.moderation-settings-options'; alt='댓글 검토 페이지 상단에 있는 버튼 행, 여기에는 모더레이터 추가 버튼이 포함됩니다.'; title='댓글 검토 설정 버튼' app-screenshot-end]

이미 모더레이터가 있는 경우, 이 버튼은 "모더레이터 편집"이라고 표시됩니다.

"모더레이터 추가" 페이지를 살펴보겠습니다.

[app-screenshot-start url='/auth/my-account/moderate-comments/moderator/new'; selector = '.account-block'; alt='새 모더레이터의 이름과 이메일만 요청하는 모더레이터 추가 페이지, 초대 전'; title='모더레이터 추가 페이지' app-screenshot-end]

모더레이터를 추가하려면 이름과 이메일만 있으면 됩니다.

이메일이 기존 FastComments 계정과 연결되어 있으면, 해당 이메일을 통해 모더레이터로 귀하의 계정에 초대됩니다.

제공된 이메일이 기존 FastComments 계정과 연결되어 있지 않으면, 새로운 계정이 생성됩니다.

초대 링크가 모더레이터에게 전송되며, 이를 통해 자동으로 로그인할 수 있습니다. 앞으로 로그인하고 싶을 경우, <a href="https://fastcomments.com/auth/login" target="_blank">로그인 페이지</a>를 방문하고 이전에 제공한 이름/이메일을 입력하면 로그인 링크가 전송됩니다.

로그아웃하지 않는 한, 30일 동안 로그인 상태가 유지됩니다.
