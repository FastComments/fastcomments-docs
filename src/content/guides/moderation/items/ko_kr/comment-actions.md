FastComments에서는 관리자와 중재자가 각 댓글에 대해 다음과 같은 여러 작업을 수행할 수 있습니다:

- 해당 댓글 **삭제**
- 해당 댓글 **삭제** + **사용자 차단** (영구 또는 셰도우, 자세한 내용은 아래에서 설명)
- 해당 댓글 **편집**
- 해당 댓글의 **투표 수 조정**
- 해당 댓글을 **검토됨** 또는 **검토 안 됨**으로 표시
- 해당 댓글을 **승인됨** 또는 **승인 안 됨**으로 표시
- 해당 댓글을 **스팸** 또는 **스팸 아님**으로 표시
- 동일한 IP 주소의 모든 댓글 보기 *<sup>1</sup>.
- 댓글의 플래그 카운트 초기화.

예를 들어, 댓글을 유지하면서 숨기려면 단순히 **승인 안 됨**으로 표시하면 됩니다.

또한 관리자와 중재자는 댓글을 고정할 수 있지만, 이 작업은 댓글 스레드 자체에서만 수행할 수 있습니다.

위의 모든 작업은 키보드 단축키로도 수행할 수 있습니다. 자세한 내용은 [키보드 단축키](#keyboard-shortcuts) 섹션을 참조하세요.

*<sup>1</sup> 이 기능을 위해 원시 IP 주소는 저장하지 않습니다.
