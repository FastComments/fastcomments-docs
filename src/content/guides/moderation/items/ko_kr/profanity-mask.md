기본적으로 FastComments는 약 450개의 문구와 단어로 구성된 단어 블랙리스트를 제공합니다.

새 댓글에서 단어 블랙리스트에 포함된 텍스트가 발견되면 해당 텍스트는 별표(***)로 대체됩니다.

블랙리스트를 사용자 지정하는 페이지는 Moderate Comments -> Edit Moderation Settings -> Edit Word Blacklist를 통해 이동하거나,
<a href="https://fastcomments.com/auth/my-account/moderate-comments/blacklist" target="_blank">여기</a>에서 직접 이동할 수 있습니다.
