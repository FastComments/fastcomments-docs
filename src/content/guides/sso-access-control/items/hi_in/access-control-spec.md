कई उपयोगकर्ताओं के इंटरैक्ट करने के तरीके को परिभाषित करना, और उसका परीक्षण करना, जटिल है। यहाँ वह विनिर्देश (spec) है जिसका हम एक्सेस कंट्रोल के लिए पालन करते हैं,
जिसका उपयोग आप अपने कार्यान्वयन (implementation) के परीक्षण के लिए कर सकते हैं:

    null group ids वाला पेज, null group ids वाला उपयोगकर्ता - एक्सेस होना चाहिए।
    null group ids वाला पेज, group ids वाला उपयोगकर्ता - एक्सेस होना चाहिए।
    group ids वाला पेज, null group ids वाला उपयोगकर्ता - एक्सेस होना चाहिए।
    group ids वाला पेज, खाली लिस्ट वाला उपयोगकर्ता - एक्सेस नहीं होना चाहिए।
    group ids वाला पेज, group ids वाला उपयोगकर्ता - इंटरसेक्शन मौजूद है - एक्सेस होना चाहिए।
    group ids वाला पेज, group ids वाला उपयोगकर्ता - इंटरसेक्शन मौजूद नहीं है - एक्सेस नहीं होना चाहिए।
    group ids की खाली लिस्ट वाला पेज (किसी को एक्सेस नहीं), null वाला उपयोगकर्ता - एक्सेस नहीं होना चाहिए।
    
    SSO User A = कोई group ids परिभाषित नहीं (null = पूर्ण एक्सेस)।
    SSO User B = कोई group ids परिभाषित नहीं (null = पूर्ण एक्सेस)।
    A, B को @ कर सकता है।
    
    SSO User A = कोई group ids परिभाषित नहीं (null = पूर्ण एक्सेस)।
    SSO User B = group ids परिभाषित हैं।
    A, B को @ कर सकता है।
    
    SSO User A = group ids परिभाषित हैं।
    SSO User B = कोई group ids परिभाषित नहीं (null = पूर्ण एक्सेस)।
    A, B को @ कर सकता है।
    
    SSO User A = Group ids = [a]।
    SSO User B = Group ids = [b]।
    A, B को @ नहीं कर सकता।
    
    SSO User A = Group ids = [a]।
    SSO User B = Group ids = [a, b]।
    A, B को @ कर सकता है।
