#### अन्य समूहों के उपयोगकर्ताओं का उल्लेख करना

यदि दो उपयोगकर्ता दो अलग-अलग समूहों के सेट से संबंधित हैं, और उनके बीच कोई समानता नहीं है, तो वे एक-दूसरे को `@mention` नहीं कर सकेंगे।

यदि कोई उपयोगकर्ता मैन्युअल रूप से एक `@mention` टाइप करता है और अपनी टिप्पणी सबमिट करता है, तो वह सादे टेक्स्ट के रूप में ही रहेगी। दूसरे उपयोगकर्ता को टैग नहीं किया जाएगा।

#### समूहों का रखरखाव

`Groups` को क्रमशः `Pages` और `SSOUsers` API संसाधनों का उपयोग करके परिभाषित किया जाता है।

`Pages` API को यह परिभाषित करने के लिए बुलाया जा सकता है कि कौन से समूह पेज तक पहुँचने की अनुमति रखते हैं। डिफ़ॉल्ट रूप से, सभी समूह, और जो उपयोगकर्ता किसी समूह से संबंधित नहीं हैं, उन्हें पहुँच प्राप्त होती है।

इसी प्रकार, `SSOUsers` API को प्रत्येक उपयोगकर्ता से संबंधित समूहों को परिभाषित करने के लिए बुलाया जा सकता है।

दोनों संसाधनों के लिए, समूहों को कब सेट या अपडेट किया जा सकता है, इसमें कोई सीमा नहीं है।

यदि केवल उपयोगकर्ताओं को एक-दूसरे को `@mention` करने से सीमित करना है, तो `Pages` पर विचार करने की आवश्यकता नहीं है।

##### ध्यान दें!

SSO उपयोगकर्ता समूहों को परिभाषित और अपडेट करने के लिए API का उपयोग करने की आवश्यकता नहीं है, और इसके बजाय कमेंट विजेट को दिए गए SSO पेलोड में समूह आईडी परिभाषित करके इन्हें स्वचालित रूप से अपडेट किया जा सकता है। हालाँकि, समूहों की बड़ी सूचियों के लिए यह अनुशंसित नहीं है, क्योंकि उपयोगकर्ता को हर पेज लोड पर यह पेलोड सबमिट करना होगा।
