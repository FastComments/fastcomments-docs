Με το FastComments SSO Access Control, που μερικές φορές αναφέρεται ως RBAC, οι χρήστες μπορούν να περιοριστούν ώστε να έχουν πρόσβαση μόνο σε συγκεκριμένες σελίδες ή νήματα σχολίων. Επιπλέον,
οι χρήστες μπορούν να κάνουν `@mention` ο ένας τον άλλον μόνο μέσα στην ίδια ομάδα.

## Αναλυτικά

Μπορούμε να τοποθετήσουμε `Users` και προαιρετικά `Pages` σε ομάδες.

Όταν οι `Users` τοποθετούνται σε ομάδες και η επιλογή `Limit Comments by SSO User Groups` είναι ενεργοποιημένη στις Ρυθμίσεις Widget, τότε οι χρήστες
θα βλέπουν μόνο σχόλια από χρήστες στις ίδιες ομάδες τους και θα μπορούν να κάνουν `@mention` μόνο χρήστες στις ίδιες ομάδες.

Επιπλέον, οι `Pages` μπορούν να τοποθετηθούν σε ομάδες, και τότε οι χρήστες μπορούν να έχουν πρόσβαση μόνο στα σχόλια των σελίδων στις οποίες έχουν πρόσβαση.

Το ονομάζουμε ομάδες "Επιπέδου Χρήστη" (User-Level) σε αντίθεση με ομάδες "Επιπέδου Σελίδας" (Page-Level).

Ποια λοιπόν είναι η κατάλληλη για εσάς;

#### Χρησιμοποιήστε Ομάδες Επιπέδου Χρήστη αν...

- Θέλετε να χρησιμοποιήσετε την ίδια τιμή `urlId` (URL σελίδας ή ID άρθρου), αλλά να περιορίσετε τα σχόλια ανά ομάδα.
- Για παράδειγμα, θέλετε να έχετε ομάδες "Νέος Χρήστης" και "Έμπειρος Χρήστης", και να μην βλέπουν ποτέ τα σχόλια του ενός του άλλου στις ίδιες σελίδες.

#### Χρησιμοποιήστε Ομάδες Επιπέδου Σελίδας αν...

- Οι ομάδες σας έχουν συγκεκριμένες σελίδες.
- Για παράδειγμα, οι χρήστες της ομάδας "Δημόσιες Σελίδες" δεν θα πρέπει ποτέ να βλέπουν άρθρα των "Απόρρητων" άρθρων.
