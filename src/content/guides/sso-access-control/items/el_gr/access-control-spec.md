Ο ορισμός του τρόπου αλληλεπίδρασης πολλαπλών χρηστών, και ο έλεγχός του, είναι πολύπλοκος. Ακολουθεί η προδιαγραφή που ακολουθούμε για τον έλεγχο πρόσβασης,
την οποία μπορείτε να χρησιμοποιήσετε για να δοκιμάσετε την υλοποίησή σας:

    Σελίδα με null group ids, χρήστης με null group ids - θα πρέπει να έχει πρόσβαση.
    Σελίδα με null group ids, χρήστης με group ids - θα πρέπει να έχει πρόσβαση.
    Σελίδα με group ids, χρήστης με null group ids - θα πρέπει να έχει πρόσβαση.
    Σελίδα με group ids, χρήστης με κενή λίστα - δεν θα πρέπει να έχει πρόσβαση.
    Σελίδα με group ids, χρήστης με group ids - υπάρχει τομή - θα πρέπει να έχει πρόσβαση.
    Σελίδα με group ids, χρήστης με group ids - δεν υπάρχει τομή - δεν θα πρέπει να έχει πρόσβαση.
    Σελίδα με κενή λίστα group ids (κανείς δεν έχει πρόσβαση), χρήστης με null - δεν θα πρέπει να έχει πρόσβαση.
    
    SSO User A = Χωρίς ορισμένα group ids (null = πλήρης πρόσβαση).
    SSO User B = Χωρίς ορισμένα group ids (null = πλήρης πρόσβαση).
    Ο A μπορεί να κάνει @B.
    
    SSO User A = Χωρίς ορισμένα group ids (null = πλήρης πρόσβαση).
    SSO User B = Με ορισμένα group ids.
    Ο A μπορεί να κάνει @B.
    
    SSO User A = Με ορισμένα group ids.
    SSO User B = Χωρίς ορισμένα group ids (null = πλήρης πρόσβαση).
    Ο A μπορεί να κάνει @B.
    
    SSO User A = Group ids = [a].
    SSO User B = Group ids = [b].
    Ο A δεν μπορεί να κάνει @B.
    
    SSO User A = Group ids = [a].
    SSO User B = Group ids = [a, b].
    Ο A μπορεί να κάνει @B.
