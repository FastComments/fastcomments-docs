FastComments SSO Access Control(RBAC라고도 함)을 사용하면 사용자가 특정 페이지 또는 댓글 스레드에만 접근하도록 제한할 수 있습니다. 또한,
사용자는 같은 그룹 내의 사용자에게만 `@mention`을 할 수 있습니다.

## 상세 설명

`Users`와 선택적으로 `Pages`를 그룹에 넣을 수 있습니다.

`Users`가 그룹에 배치되고 Widget Settings에서 `Limit Comments by SSO User Groups`가 활성화되면, 사용자는
같은 그룹에 속한 사용자의 댓글만 볼 수 있으며 같은 그룹의 사용자에게만 `@mention`을 할 수 있습니다.

또한, `Pages`를 그룹에 배치하면 사용자는 접근 권한이 있는 페이지의 댓글에만 접근할 수 있습니다.

이를 "사용자 수준(User-Level)" 그룹과 "페이지 수준(Page-Level)" 그룹이라고 부릅니다.

그렇다면 어느 쪽이 적합할까요?

#### 다음 경우에 사용자 수준 그룹을 사용하세요...

- 동일한 `urlId` 값(페이지 URL 또는 아티클 ID)을 사용하면서 그룹별로 댓글을 제한하고 싶은 경우.
- 예를 들어, "신규 사용자"와 "베테랑 사용자" 그룹을 만들고, 같은 페이지에서 서로의 댓글을 볼 수 없게 하고 싶은 경우.

#### 다음 경우에 페이지 수준 그룹을 사용하세요...

- 그룹이 특정 페이지를 가지고 있는 경우.
- 예를 들어, "공개 페이지" 그룹의 사용자는 "Top Secret" 아티클을 볼 수 없어야 하는 경우.
