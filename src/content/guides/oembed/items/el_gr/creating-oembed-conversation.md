Με το FastComments, μια συζήτηση πρέπει πρώτα να δημιουργηθεί πριν μπορεί να ενσωματωθεί.

Για να το κάνετε, απλώς επισκεφθείτε [fastcomments.com/create](https://fastcomments.com/create).

[app-screenshot-start url='/create'; selector = '.content'; alt='Η σελίδα fastcomments.com/create με το πεδίο ονόματος συζήτησης και το κουμπί που δημιουργεί έναν ασφαλή σύνδεσμο'; title='Η Φόρμα Δημιουργίας Συζήτησης' app-screenshot-end]

Μόλις επιλέξετε ένα όνομα, θα δημιουργηθεί ένας ασφαλής σύνδεσμος. 

Αυτός ο σύνδεσμος μπορεί να επισκεφθεί και να χρησιμοποιηθεί ως δική του συνομιλία. Ή, μπορεί να δοθεί απευθείας σε μια εφαρμογή που υποστηρίζει oEmbed ή https://embed.ly, για να ενσωματώσει τη συζήτηση.

Οι ενσωματωμένες συζητήσεις μπορούν να προσαρμοστούν όπως οποιαδήποτε άλλη εγκατάσταση FastComments χρησιμοποιώντας το UI Προσαρμογής. Διαβάστε για την προσαρμογή του widget σχολίων [εδώ](/guide-customizations-and-configuration.html).
