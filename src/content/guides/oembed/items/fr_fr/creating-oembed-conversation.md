Avec FastComments, une conversation doit d'abord être créée avant de pouvoir être intégrée.

Pour ce faire, il suffit de visiter [fastcomments.com/create](https://fastcomments.com/create).

[app-screenshot-start url='/create'; selector = '.content'; alt='La page fastcomments.com/create avec le champ du nom de la conversation et le bouton qui génère un lien sécurisé'; title='Le formulaire de création d\'une conversation' app-screenshot-end]

Une fois le nom choisi, un lien sécurisé sera créé. 

Ce lien peut être visité et utilisé comme son propre chat. Ou il peut être fourni directement à une application qui prend en charge oEmbed, ou https://embed.ly, pour insérer la conversation.

Les conversations intégrées peuvent être personnalisées comme n'importe quelle autre installation FastComments à l'aide de l'interface de personnalisation. Lisez comment personnaliser le widget de commentaires [ici](/guide-customizations-and-configuration.html).
