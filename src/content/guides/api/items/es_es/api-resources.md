### Uso de recursos

Debe tenerse en cuenta que la obtención de datos de la API se cuenta como uso en su cuenta.

Cada recurso enumerará ese uso en su propia sección.

Algunos recursos cuestan más de servir que otros. Cada endpoint tiene un costo fijo de créditos por llamada a la API. Para algunos endpoints, el número de créditos varía según las opciones y los tamaños de respuesta.

El uso de la API se puede verificar en la página [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) y se actualiza cada pocos minutos.

#### ¡Nota!

Sugerimos leer primero la documentación de Pages, para ayudar a limitar la confusión al determinar qué valores pasar para `urlId` en la API de Comentarios.

### Webhooks

Las suscripciones a Webhooks tienen su propia guía. `POST`, `GET` y `DELETE /api/v1/webhooks`, y `GET /api/v1/webhooks/sample-payloads`, están documentados bajo [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), y las cargas útiles de eventos bajo [Webhook Structures](/guide-webhooks.html#webhooks-structures).
