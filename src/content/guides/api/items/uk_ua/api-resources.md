### Використання ресурсів

Слід зазначити, що отримання даних з API враховується як використання вашого облікового запису.

Кожен ресурс буде вказувати, яке саме використання він має, у власному розділі.

Деякі ресурси коштують більше для обслуговування, ніж інші. Кожна кінцева точка має встановлену вартість у кредитах за виклик API. Для деяких кінцевих точок кількість кредитів змінюється залежно від параметрів та розмірів відповіді.

Використання API можна перевірити на сторінці [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) і воно оновлюється кожні кілька хвилин.

#### Примітка!

Ми радимо спочатку ознайомитися з документацією Pages, щоб зменшити плутанину при визначенні, які значення передавати для `urlId` у Comment API.

### Вебхуки

Підписки на вебхуки мають власний посібник. `POST`, `GET` і `DELETE /api/v1/webhooks`, а також `GET /api/v1/webhooks/sample-payloads`, задокументовані в розділі [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), а структури подій — у [Webhook Structures](/guide-webhooks.html#webhooks-structures).
