Об'єкт `HashTag` представляє тег, який може залишити користувач. Хештеги можна використовувати для посилання на зовнішній контент або для
зв'язування пов'язаних коментарів між собою.

Структура об'єкта `HashTag` виглядає наступним чином:

[inline-code-attrs-start title = 'Структура HashTag'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface HashTag {
    /** Має починатися з символу "#" або іншого бажаного символу. **/
    tag: string
    /** Необов'язковий URL, на який може вказувати хештег. Замість фільтрації коментарів за хештегом інтерфейс при кліку перенаправить на цю адресу. **/
    url?: string
    /** READONLY **/
    createdAt: string
}
[inline-code-end]

Примітки:

- У деяких кінцевих точках API ви побачите, що хештег використовується в URL. Пам'ятайте про URI-кодування значень. Наприклад, `#` слід представляти як `%23`.
- Деякі з цих полів позначені як `READONLY` — вони повертаються API, але їх не можна встановлювати.
