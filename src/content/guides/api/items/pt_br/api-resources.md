### Uso de Recursos

Deve‑se observar que a obtenção de dados da API é contabilizada como uso em sua conta.

Cada recurso listará qual é esse uso em sua própria seção.

Alguns recursos custam mais para servir do que outros. Cada endpoint tem um custo fixo de créditos por chamada de API. Para alguns endpoints, o número de créditos varia com base nas opções e nos tamanhos das respostas.

O uso da API pode ser verificado na página [Análise de Faturamento](https://fastcomments.com/auth/my-account/analytics/billing) e é atualizado a cada poucos minutos.

#### Nota!

Recomendamos ler a documentação de Pages primeiro, para ajudar a limitar a confusão ao determinar quais valores passar para `urlId` na API de Comentários.

### Webhooks

As assinaturas de Webhook têm seu próprio guia. `POST`, `GET` e `DELETE /api/v1/webhooks`, e `GET /api/v1/webhooks/sample-payloads`, estão documentados em [Gerenciando Assinaturas via API](/guide-webhooks.html#webhooks-api-subscriptions), e as cargas úteis de eventos em [Estruturas de Webhook](/guide-webhooks.html#webhooks-structures).
