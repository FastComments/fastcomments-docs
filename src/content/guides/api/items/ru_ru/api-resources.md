### Использование ресурсов

Следует отметить, что получение данных из API учитывается как использование вашего аккаунта.

Каждый ресурс будет перечислять, какое именно использование относится к нему, в отдельном разделе.

Некоторые ресурсы стоят дороже в обслуживании, чем другие. Каждый эндпоинт имеет фиксированную стоимость в кредитах за вызов API. Для некоторых эндпоинтов количество кредитов варьируется в зависимости от параметров и размеров ответа.

Использование API можно проверить на странице [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing), и данные обновляются каждые несколько минут.

#### Примечание!

Мы рекомендуем сначала ознакомиться с документацией по Pages, чтобы уменьшить путаницу при определении, какие значения передавать для `urlId` в Comment API.

### Вебхуки

Подписки на вебхуки имеют собственное руководство. `POST`, `GET` и `DELETE /api/v1/webhooks`, а также `GET /api/v1/webhooks/sample-payloads`, задокументированы в разделе [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), а структуры событий — в разделе [Webhook Structures](/guide-webhooks.html#webhooks-structures).
