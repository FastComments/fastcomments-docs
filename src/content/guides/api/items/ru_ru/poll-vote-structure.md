A `PollVote` — это ответ одного человека на опрос. Счётчики, отображаемые непосредственно в опросе, синхронны с этими записями, поэтому они нужны только тогда, когда вам нужно знать *кто* за что проголосовал, а не общие итоги.

У избирателя может быть не более одного голоса в опросе. При повторном голосовании его существующий голос перемещается к новому варианту вместо того, чтобы добавить второй, а `updatedAt` фиксирует, когда это произошло.

`voterId` — это `userId`, если избиратель был авторизован, иначе используется `anonUserId`.

[inline-code-attrs-start title = 'Структура PollVote'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface PollVote {
    id: string
    tenantId: string
    commentId: string
    urlId: string
    /** userId, когда избиратель был авторизован, иначе anonUserId. **/
    voterId: string
    optionId: string
    createdAt: string
    /** Когда избиратель в последний раз переместил свой голос на другой вариант. **/
    updatedAt?: string
}
[inline-code-end]

### Privacy

Настройка `privacy` опроса применяется к этому API так же, как и в виджете комментариев:

- **Anonymous** (по умолчанию): никто не может увидеть, как кто‑то проголосовал, поэтому голоса недоступны для чтения. `GET /api/v1/poll-votes` и `GET /api/v1/poll-votes/:id` отвечают `poll-anonymous`. Счётчики опроса всё ещё доступны через `GET /api/v1/polls/:commentId`.
- **Admins and moderators**: ваш API‑ключ принадлежит администратору вашего сайта, поэтому он может читать голоса.
- **Everyone**: голоса могут быть прочитаны.

Настройки конфиденциальности опроса можно сузить, но нельзя расширить после того, как в нём появились голоса.
