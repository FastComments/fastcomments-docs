A `Poll` привязан к комментарию, а не является отдельным объектом. Он создаётся вместе с комментарием (см. `POST /api/v1/comments`), или позже добавляется к существующему комментарию с помощью `PUT /api/v1/polls/:commentId`.

Подсчёты голосов хранятся непосредственно в опросе, поэтому чтение опроса сразу даёт результаты без необходимости суммировать данные. Отдельные голоса, лежащие в основе этих подсчётов, являются объектами `PollVote`.

Каждый вариант имеет `id`, генерируемый при создании опроса. Этот id используется для голосования, переименования варианта и сохранения варианта (и его голосов) при `PUT` опроса с добавленными или удалёнными вариантами. Это единственный надёжный способ ссылки на вариант — никогда не используйте его позицию в списке.

[inline-code-attrs-start title = 'Структура опроса'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface CommentPollOption {
    id: string
    label: string
    votes: number
}

interface CommentPoll {
    question: string
    options: CommentPollOption[]
    totalVotes: number
    /** Если установлено и находится в прошлом, опрос закрыт и больше не принимает голоса. **/
    closesAt?: string | null
    /** 0 — анонимный (по умолчанию), 1 — администраторы и модераторы, 2 — все. Отсутствие означает анонимный. **/
    privacy?: 0 | 1 | 2 | null
    /** Если true, подсчёты скрыты от всех, кто ещё не проголосовал. Отсутствие означает false. **/
    requireVoteToSeeResults?: boolean | null
}
[inline-code-end]

### Ограничения

- Вопрос обязателен и может содержать не более 200 символов.
- Опрос должен содержать от 2 до 10 вариантов.
- Метка варианта обязательна, может содержать не более 100 символов и должна быть уникальной в рамках опроса (без учёта регистра).
- `closesAt` должен указывать на будущее время при создании опроса. Чтобы закрыть опрос немедленно, выполните `PATCH` с датой в прошлом.

### Настройки сайта

Опросы подчиняются конфигурации вашего сайта, которую можно изменить в разделе Customize Widget:

- Опросы должны быть включены, прежде чем можно создать опрос, иначе API вернёт `polls-disabled`.
- Голосование может быть ограничено только авторизованными пользователями; в этом случае голос, отправленный только с `anonUserId`, будет отклонён с ошибкой `poll-login-required`.
