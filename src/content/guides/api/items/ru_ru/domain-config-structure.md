Объект `DomainConfig` представляет конфигурацию домена для тенанта.

Структура объекта `DomainConfig` выглядит следующим образом:

[inline-code-attrs-start title = 'Структура конфигурации домена'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface DomainConfig {
    /** Домен, а не URL, например "fastcomments.com" или "www.example.com". Поддомен может быть указан, если требуется ограничение поддоменом. Максимум 1000 символов. **/
    domain: string
    /** Имя отправителя (From-Name), используемое при отправке писем. **/
    emailFromName?: string
    /** Email отправителя (From-Email), используемый при отправке писем. Убедитесь, что SPF настроен так, чтобы mail.fastcomments.com мог отправлять письма от имени домена, указанного в этом атрибуте. **/
    emailFromEmail?: string
    /** ТОЛЬКО ДЛЯ ЧТЕНИЯ. Когда объект был создан. **/
    createdAt: string
    /** Логотип, связанный с этим доменом. Используется в письмах. Используйте HTTPS. **/
    logoSrc?: string
    /** Уменьшенный логотип, связанный с этим доменом. Используйте HTTPS. **/
    logoSrc100px?: string
    /** ТОЛЬКО SSO. URL, используемый в подвале каждого отправляемого письма. Поддерживает переменную "[userId]". **/
    footerUnsubscribeURL?: string
    /** ТОЛЬКО SSO. Заголовки, используемые в каждом отправляемом письме. Полезно, например, для установки заголовков, связанных с отпиской, для улучшения доставляемости. Запись List-Unsubscribe в этом Record, если она существует, поддерживает переменную "[userId]". **/
    emailHeaders?: Record<string, string>
    /** Отключить все ссылки для отписки. Не рекомендуется, может ухудшить доставляемость. **/
    disableUnsubscribeLinks?: boolean
    /** Конфигурация DKIM. **/
    dkim?: DomainConfigDKIM
}
[inline-code-end]

[inline-code-attrs-start title = 'Структура конфигурации DKIM'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface DomainConfigDKIM {
    /** Имя домена в вашей DKIM-записи. **/
    domainName: string
    /** Селектор DKIM-ключа для использования. **/
    keySelector: string
    /** Публичный ключ в формате PEM. Возвращается в GET-ответах. **/
    publicKey: string
    /** @deprecated Больше не возвращается в ответах API. Принимается при записи для обратной совместимости. **/
    privateKey?: string
}

### Для аутентификации

Конфигурация домена используется для определения того, какие сайты могут размещать виджет FastComments для вашего аккаунта. Это базовая форма
аутентификации, а это значит, что добавление или удаление любой конфигурации домена может повлиять на доступность вашей установки FastComments
в продакшене.

Не удаляйте и не обновляйте свойство `domain` объекта `Domain Config` для домена, который в данный момент используется, если только вы не намерены отключить этот домен.

Это поведение аналогично удалению домена на странице [/auth/my-account/configure-domains](https://fastcomments.com/auth/my-account/configure-domains).

Также обратите внимание, что удаление домена через интерфейс `My Domains` удалит любую соответствующую конфигурацию для этого домена, которая могла быть добавлена через этот интерфейс.

### Для настройки email

Ссылка для отписки в подвале письма, а также функция отписки в один клик, предлагаемая многими почтовыми клиентами, могут быть настроены через этот API путем определения `footerUnsubscribeURL` и `emailHeaders` соответственно.

### Для DKIM

После определения ваших DKIM DNS-записей просто обновите DomainConfig вашей конфигурацией DKIM, используя определенную структуру.
