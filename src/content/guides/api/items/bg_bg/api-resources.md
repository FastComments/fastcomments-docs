### Използване на ресурси

Трябва да се отбележи, че извличането на данни от API се брои като използване във вашия акаунт.

Всеки ресурс ще изброи това използване в своя собствен раздел.

Някои ресурси струват повече за обслужване от други. Всеки крайна точка има зададена цена в кредити за API повикване. За някои крайни точки броят на кредитите варира в зависимост от опциите и размерите на отговора.

Използването на API може да се провери на страницата [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) и се актуализира на всеки няколко минути.

#### Забележка!

Препоръчваме първо да прочетете документацията за Pages, за да намалите объркването при определяне какви стойности да предадете за `urlId` в Comment API.

### Уебкуки

Абонаментите за уебкуки имат собствено ръководство. `POST`, `GET` и `DELETE /api/v1/webhooks`, както и `GET /api/v1/webhooks/sample-payloads`, са документирани в [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), а натоварванията на събитията – в [Webhook Structures](/guide-webhooks.html#webhooks-structures).
