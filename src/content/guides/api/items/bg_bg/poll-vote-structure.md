A `PollVote` е отговорът на един човек на анкета. Броячетата, показвани в самата анкета, се поддържат в съответствие с тях, така че ви трябват тези само когато искате да знаете *кой* е гласувал за какво, вместо общите суми.

Гласуващият може да има най‑много един глас за анкета. Гласуването отново премества съществуващия им глас към новата опция вместо да добавя втори, а `updatedAt` записва кога се е случило.

`voterId` е `userId`, когато гласуващият е бил влезнал, иначе е `anonUserId`.

[inline-code-attrs-start title = 'Структура на PollVote'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface PollVote {
    id: string
    tenantId: string
    commentId: string
    urlId: string
    /** userId, когато гласуващият е бил влезнал, иначе anonUserId. **/
    voterId: string
    optionId: string
    createdAt: string
    /** Кога гласуващият последно премести гласа си към различна опция. **/
    updatedAt?: string
}
[inline-code-end]

### Поверителност

Настройката за `privacy` на анкетата се прилага към това API по същия начин, както се прилага в уиджета за коментари:

- **Анонимно** (по подразбиране): никой не може да види как е гласувал никой, така че гласовете не могат да бъдат прочетени.  
  `GET /api/v1/poll-votes` и `GET /api/v1/poll-votes/:id` отговарят с `poll-anonymous`. Броячетата на анкетата все още са достъпни чрез `GET /api/v1/polls/:commentId`.
- **Администратори и модератори**: вашият API ключ принадлежи на администратора на вашия сайт, така че може да чете гласовете.
- **Всеки**: гласовете могат да бъдат прочетени.

Поверителността на анкетата може да бъде стеснявана, но не и разширявана, след като има гласове.
