`Poll` е прикачен към коментар, а не е самостоятелен обект. Той се създава заедно с коментара
(виж `POST /api/v1/comments`) или се добавя към съществуващ коментар по-късно с `PUT /api/v1/polls/:commentId`.

Броячите на гласове се съхраняват в самия poll, така че четенето на poll ви дава резултатите, без да се налага
да събирате нищо. Отделните гласове зад тези броячи са обекти `PollVote`.

Всяка опция има `id`, който се генерира при създаването на poll. Този id се използва за подаване на глас,
за преименуване на опция и за запазване на опция (и нейните гласове), когато изпратите `PUT` на poll с добавени
или премахнати опции. Това е единственият безопасен начин за препратка към опция - никога нейната позиция в списъка.

[inline-code-attrs-start title = 'Структура на Poll'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface CommentPollOption {
    id: string
    label: string
    votes: number
}

interface CommentPoll {
    question: string
    options: CommentPollOption[]
    totalVotes: number
    /** Когато е зададено и е в миналото, poll е затворен и вече не приема гласове. **/
    closesAt?: string | null
    /** 0 анонимно (по подразбиране), 1 администратори и модератори, 2 всички. Липсващо означава анонимно. **/
    privacy?: 0 | 1 | 2 | null
    /** Когато е true, броячите са скрити от всеки, който все още не е гласувал. Липсващо означава false. **/
    requireVoteToSeeResults?: boolean | null
}
[inline-code-end]

### Ограничения

- Въпросът е задължителен и е с максимум 200 символа.
- Едно проучване има между 2 и 10 опции.
- Етикетът на опцията е задължителен, с максимум 100 символа, и трябва да е уникален в рамките на проучването (без значение на регистъра).
- `closesAt` трябва да е в бъдещето при създаването на проучването. За да затворите проучване веднага, изпратете `PATCH`
  с дата в миналото.

### Настройки на сайта

Проучванията следват конфигурацията на вашия сайт, която можете да промените под Customize Widget:

- Проучванията трябва да са активирани, преди да може да се създаде проучване, в противен случай API отговаря с `polls-disabled`.
- Гласуването може да бъде ограничено до влезли потребители, в който случай глас, изпратен само с `anonUserId`, се отхвърля
  с `poll-login-required`.
