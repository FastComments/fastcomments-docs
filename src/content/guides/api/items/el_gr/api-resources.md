### Χρήση Πόρων

Θα πρέπει να σημειωθεί ότι η λήψη δεδομένων από το API μετράται ως χρήση στον λογαριασμό σας.

Κάθε πόρος θα αναφέρει ποια είναι αυτή η χρήση στη δική του ενότητα.

Κάποιοι πόροι κοστίζουν περισσότερο για εξυπηρέτηση από άλλους. Κάθε τελικό σημείο έχει ένα καθορισμένο κόστος σε μονάδες ανά κλήση API. Για ορισμένα τελικά σημεία, ο αριθμός των μονάδων διαφέρει ανάλογα με τις επιλογές και τα μεγέθη των απαντήσεων.

Η χρήση του API μπορεί να ελεγχθεί στη σελίδα [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) και ενημερώνεται κάθε λίγα λεπτά.

#### Σημείωση!

Σας προτείνουμε να διαβάσετε πρώτα την τεκμηρίωση των Σελίδων, ώστε να περιορίσετε τη σύγχυση κατά τον καθορισμό των τιμών που πρέπει να περάσετε για το `urlId` στο Comment API.

### Webhooks

Οι συνδρομές Webhook έχουν τον δικό τους οδηγό. Τα `POST`, `GET` και `DELETE /api/v1/webhooks`, καθώς και το `GET /api/v1/webhooks/sample-payloads`, τεκμηριώνονται στο [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), και τα payloads των γεγονότων στο [Webhook Structures](/guide-webhooks.html#webhooks-structures).
