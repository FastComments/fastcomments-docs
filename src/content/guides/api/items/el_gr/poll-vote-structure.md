Ένα `PollVote` είναι η απάντηση ενός ατόμου σε μια ψηφοφορία. Οι μετρήσεις που εμφανίζονται στην ίδια την ψηφοφορία διατηρούνται συγχρονισμένες με αυτά,
οπότε τα χρειάζεστε μόνο όταν θέλετε να μάθετε *ποιος* ψήφισε τι, και όχι τα σύνολα.

Ένας ψηφοφόρος έχει το πολύ μία ψήφο ανά ψηφοφορία. Αν ψηφίσει ξανά, η υπάρχουσα ψήφος του μεταφέρεται στη νέα επιλογή αντί να
προστεθεί δεύτερη, και το `updatedAt` καταγράφει πότε συνέβη αυτό.

Το `voterId` είναι το `userId` όταν ο ψηφοφόρος ήταν συνδεδεμένος, και το `anonUserId` διαφορετικά.

[inline-code-attrs-start title = 'Δομή PollVote'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface PollVote {
    id: string
    tenantId: string
    commentId: string
    urlId: string
    /** Το userId όταν ο ψηφοφόρος ήταν συνδεδεμένος, διαφορετικά το anonUserId. **/
    voterId: string
    optionId: string
    createdAt: string
    /** Πότε ο ψηφοφόρος μετέφερε τελευταία φορά την ψήφο του σε διαφορετική επιλογή. **/
    updatedAt?: string
}
[inline-code-end]

### Απόρρητο

Η ρύθμιση `privacy` της ψηφοφορίας ισχύει για αυτό το API με τον ίδιο τρόπο που ισχύει στο widget σχολίων:

- **Ανώνυμο** (η προεπιλογή): κανείς δεν μπορεί να δει πώς ψήφισε ο καθένας, οπότε οι ψήφοι δεν μπορούν να διαβαστούν.
  Το `GET /api/v1/poll-votes` και το `GET /api/v1/poll-votes/:id` απαντούν με `poll-anonymous`. Οι μετρήσεις της ψηφοφορίας
  παραμένουν διαθέσιμες από το `GET /api/v1/polls/:commentId`.
- **Διαχειριστές και συντονιστές**: το κλειδί API σας ανήκει στον διαχειριστή του ιστότοπού σας, οπότε μπορεί να διαβάσει τις ψήφους.
- **Όλοι**: οι ψήφοι μπορούν να διαβαστούν.

Το απόρρητο της ψηφοφορίας μπορεί να περιοριστεί αλλά όχι να διευρυνθεί αφού έχει λάβει ψήφους.
