A `Poll` συνδέεται με ένα σχόλιο, αντί να είναι ξεχωριστό αντικείμενο. Δημιουργείται με το σχόλιο  
(δείτε `POST /api/v1/comments`), ή προστίθεται σε υπάρχον σχόλιο αργότερα με `PUT /api/v1/polls/:commentId`.

Οι μετρήσεις ψήφων διατηρούνται στην ίδια τη δημοσκόπηση, έτσι η ανάγνωση μιας δημοσκόπησης σας δίνει τα αποτελέσματα χωρίς να χρειάζεται να τα αθροίσετε. Οι μεμονωμένες ψήφοι πίσω από αυτές τις μετρήσεις είναι αντικείμενα `PollVote`.

Κάθε επιλογή έχει ένα `id` που δημιουργείται όταν δημιουργείται η δημοσκόπηση. Αυτό το id είναι αυτό που χρησιμοποιείτε για να καταθέσετε ψήφο, για να μετονομάσετε μια επιλογή και για να διατηρήσετε μια επιλογή (και τις ψήφους της) όταν κάνετε `PUT` στη δημοσκόπηση με προσθήκη ή αφαίρεση επιλογών. Είναι ο μοναδικός ασφαλής τρόπος να αναφέρεστε σε μια επιλογή – ποτέ τη θέση της στη λίστα.

[inline-code-attrs-start title = 'Δομή Δημοσκόπησης'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface CommentPollOption {
    id: string
    label: string
    votes: number
}

interface CommentPoll {
    question: string
    options: CommentPollOption[]
    totalVotes: number
    /** Όταν ορίζεται και είναι στο παρελθόν, η δημοσκόπηση κλείνει και δεν δέχεται πλέον ψήφους. **/
    closesAt?: string | null
    /** 0 ανώνυμη (η προεπιλογή), 1 διαχειριστές και συντονιστές, 2 όλοι. Η απουσία σημαίνει ανώνυμη. **/
    privacy?: 0 | 1 | 2 | null
    /** Όταν είναι true, οι μετρήσεις κρύβονται από όποιον δεν έχει ακόμη ψηφίσει. Η απουσία σημαίνει false. **/
    requireVoteToSeeResults?: boolean | null
}
[inline-code-end]

### Όρια

- Απαιτείται ερώτηση και το μέγιστο μήκος είναι 200 χαρακτήρες.  
- Μια δημοσκόπηση πρέπει να έχει μεταξύ 2 και 10 επιλογές.  
- Απαιτείται ετικέτα επιλογής, το μέγιστο μήκος είναι 100 χαρακτήρες και πρέπει να είναι μοναδική εντός της δημοσκόπησης (χωρίς διάκριση πεζών/κεφαλαίων).  
- Το `closesAt` πρέπει να είναι στο μέλλον όταν δημιουργείται η δημοσκόπηση. Για να κλείσετε μια δημοσκόπηση αμέσως, κάντε `PATCH` με μια ημερομηνία στο παρελθόν.

### Ρυθμίσεις Ιστοσελίδας

Οι δημοσκοπήσεις ακολουθούν τη ρύθμιση του ιστότοπού σας, την οποία μπορείτε να αλλάξετε στο Customize Widget:

- Οι δημοσκοπήσεις πρέπει να είναι ενεργοποιημένες πριν δημιουργηθεί μια δημοσκόπηση, αλλιώς το API επιστρέφει `polls-disabled`.  
- Η ψηφοφορία μπορεί να περιοριστεί σε συνδεδεμένους χρήστες, οπότε μια ψήφος που αποστέλλεται μόνο με `anonUserId` απορρίπτεται με `poll-login-required`.
