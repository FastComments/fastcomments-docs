### שימוש במשאבים

יש לציין כי שליפת נתונים מה-API נספרת כשימוש בחשבון שלך.

כל משאב יציג מהו השימוש שלו בחלקו הנפרד.

חלק מהמשאבים יקרים יותר לשרת מאחרים. לכל נקודת קצה יש עלות קבועה של קרדיטים לכל קריאת API. עבור כמה נקודות קצה, מספר הקרדיטים משתנה בהתאם לאפשרויות ולגודל התגובות.

ניתן לבדוק את השימוש ב-API בדף [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) והוא מתעדכן כל כמה דקות.

#### הערה!

אנו ממליצים לקרוא תחילה את תיעוד ה-Pages, כדי לצמצם בלבול בקביעת הערכים שיש להעביר עבור `urlId` ב-Comment API.

### ווב-הוקים

למנויים של ווב-הוקים יש מדריך משלהם. `POST`, `GET` ו-`DELETE /api/v1/webhooks`, וכן `GET /api/v1/webhooks/sample-payloads`, מתועדים תחת [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), והמטענים של האירועים תחת [Webhook Structures](/guide-webhooks.html#webhooks-structures).
