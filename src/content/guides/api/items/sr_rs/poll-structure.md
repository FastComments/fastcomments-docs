A `Poll` је придружен коментару, уместо да буде објекат сам по себи. Креира се заједно са коментаром
(види `POST /api/v1/comments`), или се касније додаје постојећем коментару помоћу `PUT /api/v1/polls/:commentId`.

Бројеви гласова се чувају у самој анкети, тако да читање анкете даје резултате без потребе да их сабираш.
Појединачни гласови иза тих бројева су `PollVote` објекти.

Свака опција има `id` који се генерише приликом креирања анкете. Тај id се користи за гласање,
за преименовање опције, и за задржавање опције (и њених гласова) када `PUT`-ујеш анкету са додатим или
уклоњеним опцијама. То је једини сигуран начин да се реферишеш на опцију – никада на њен позицију у листи.

[inline-code-attrs-start title = 'Структура анкете'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface CommentPollOption {
    id: string
    label: string
    votes: number
}

interface CommentPoll {
    question: string
    options: CommentPollOption[]
    totalVotes: number
    /** Када је постављено и у прошлости, анкета је затворена и више не прихвата гласове. **/
    closesAt?: string | null
    /** 0 анонимно (подразумевано), 1 администратори и модератори, 2 сви. Ако је одсутно, подразумева се анонимно. **/
    privacy?: 0 | 1 | 2 | null
    /** Када је true, бројеви су скривени за све који још нису гласали. Ако је одсутно, подразумева се false. **/
    requireVoteToSeeResults?: boolean | null
}
[inline-code-end]

### Ограничења

- Питање је обавезно и може имати највише 200 знакова.
- Анкета има између 2 и 10 опција.
- Опис опције је обавезан, може имати највише 100 знакова и мора бити јединствен унутар анкете (без обзира на величину слова).
- `closesAt` мора бити у будућности када се анкета креира. Да бисте одмах затворили анкету, `PATCH` је са датумом у прошлости.

### Подешавања сајта

Анкете се придржавају конфигурације вашег сајта, коју можете променити у оквиру Прилагођавање виџета:

- Анкете морају бити омогућене пре него што се може креирати анкета, иначе API враћа `polls-disabled`.
- Гласање може бити ограничено на пријављене кориснике, у ком случају глас послат само са `anonUserId` се одбија
  са `poll-login-required`.
