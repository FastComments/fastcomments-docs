FastComments пружа једноставно решење за SSO. Ажурирање информација о кориснику путем HMAC-засноване интеграције је једноставно као то да корисник учита страницу са ажурираним payload-ом.

Међутим, може бити пожељно управљати корисником ван тог тока, ради побољшања конзистентности ваше апликације.

SSO User API пружа начин за CRUD операције над објектима које називамо SSOUsers. Ови објекти се разликују од обичних корисника (Users) и одржавају се одвојено ради типске безбедности.

Структура SSOUser објекта је следећа:

[inline-code-start]
interface SSOUser {
    id: string
    username: string
    email?: string
    websiteUrl?: string
    signUpDate: number
    createdFromUrlId?: string
    loginCount?: number
    avatarSrc?: string
    optedInNotifications?: boolean
    optedInSubscriptionNotifications?: boolean
    displayLabel?: string
    displayName?: string
    isAccountOwner?: boolean // Админ дозвола - SSO корисници са овом заставицом се наплаћују као SSO Админи (одвојено од обичних SSO корисника)
    isAdminAdmin?: boolean // Админ дозвола - SSO корисници са овом заставицом се наплаћују као SSO Админи (одвојено од обичних SSO корисника)
    isCommentModeratorAdmin?: boolean // Дозвола модератора - SSO корисници са овом заставицом се наплаћују као SSO Модератори (одвојено од обичних SSO корисника)
    /** Ако је null, контрола приступа неће бити примењена на корисника. Ако је празна листа, овај корисник неће моћи да види никакве странице нити да @mention-ује друге кориснике. **/
    groupIds?: string[] | null
    createdFromSimpleSSO?: boolean
    /** Не дозволите другим корисницима да виде активност овог корисника, укључујући коментаре, на његовом профилу. Подразумевано је true ради сигурних профила. **/
    isProfileActivityPrivate?: boolean
    /** Не дозволите другим корисницима да остављају коментаре на профилу корисника нити да виде постојеће коментаре на профилу. Подразумевано false. **/
    isProfileCommentsPrivate?: boolean
    /** Не дозволите другим корисницима да шаљу директне поруке овом кориснику. Подразумевано false. **/
    isProfileDMDisabled?: boolean
    karma?: number
    /** Опциона конфигурација за значке корисника. **/
    badgeConfig?: {
        /** Низ ID-ијева значки које треба доделити кориснику. Ограничено на 30 значки. Редослед се поштује. Ово су глобалне значке видљиве на свим страницама. **/
        badgeIds: string[]
        /** Низ ID-ијева значки обима на тренутну страницу (urlId). Ове значке се приказују само на страници на којој су додељене. **/
        pageBadgeIds?: string[]
        /** Ако је true, замењује све постојеће приказане значке датим. Глобалне значке и значке обима странице се замењују независно. Ако је false, додаје се на постојеће значке. **/
        override?: boolean
        /** Ако је true, ажурира својства приказа значки из конфигурације тенанта. **/
        update?: boolean
    }
}

### Наплата за SSO кориснике

SSO корисници се наплаћују различито у зависности од њихових заставица дозвола:

- **Обични SSO корисници**: Корисници без админ или модератор дозвола се наплаћују као обични SSO корисници
- **SSO Админи**: Корисници са заставицама `isAccountOwner` или `isAdminAdmin` се наплаћују одвојено као SSO Админи (иста стопа као за обичне админе тенанта)
- **SSO Модератори**: Корисници са заставицом `isCommentModeratorAdmin` се наплаћују одвојено као SSO Модератори (иста стопа као за обичне модераторе)

**Важно**: Да би се спречила двострука наплата, систем аутоматски дедуплицира SSO кориснике у односу на обичне кориснике и модераторе тенанта према адреси е-поште. Ако SSO корисник има исту е-пошту као обичан корисник или модератор тенанта, неће бити наплаћен двапут.

### Контрола приступа

Корисници могу бити подељени у групе. За то служи поље `groupIds`, и оно је опционално.

### @Mentions (помињања)

Подразумевано, `@mentions` ће користити `username` за претрагу других sso корисника када се укуца знак `@`. Ако се користи `displayName`, онда ће резултати који одговарају `username` бити занемарени када постоји подударање за `displayName`, а резултати претраге `@mention` ће користити `displayName`.

### Претплате

Са FastComments-ом, корисници могу да се претплате на страницу кликом на икону звона у виџету за коментаре и кликом на Претплати се.

Код обичног корисника, шаљемо им е-пошту са обавештењима на основу њихових подешавања обавештења.

Код SSO корисника, ово раздвајамо ради уназадне компатибилности. Корисници ће добити ове додатне е-поруке о претплати само ако поставите `optedInSubscriptionNotifications` на `true`.

### Значке

Можете доделити значке SSO корисницима користећи својство `badgeConfig`. Значке су визуелни индикатори који се појављују поред имена корисника у коментарима.

- `badgeIds` - Низ ID-ијева значки које треба доделити кориснику. Ово су глобалне значке видљиве на свим страницама. Морају бити важећи ID-ијеви значки креирани у вашем FastComments налогу. Ограничено на 30 значки.
- `pageBadgeIds` - Опционални низ ID-ијева значки обима на тренутну страницу (`urlId`). Ове значке се приказују само на страници на којој су додељене. Различите странице могу имати различите значке обима странице за истог корисника.
- `override` - Ако је true, све постојеће приказане значке биће замењене датим. Глобалне значке и значке обима странице се замењују независно — замена глобалних значки не утиче на значке обима странице, и обрнуто. Ако је false или изостављено, дате значке биће додате на постојеће.
- `update` - Ако је true, својства приказа значки биће ажурирана из конфигурације тенанта при свакој пријави корисника.
