### संसाधन उपयोग

यह ध्यान दिया जाना चाहिए कि API से डेटा प्राप्त करना आपके खाते पर उपयोग के रूप में गिना जाता है।

प्रत्येक संसाधन अपने स्वयं के अनुभाग में यह बताएगा कि वह उपयोग क्या है।

कुछ संसाधनों को सर्व करना अन्य की तुलना में अधिक महंगा होता है। प्रत्येक एंडपॉइंट की प्रति API कॉल क्रेडिट्स की एक निश्चित लागत होती है। कुछ एंडपॉइंट्स के लिए, क्रेडिट्स की संख्या विकल्पों और रिस्पॉन्स साइज़ के आधार पर भिन्न होती है।

API उपयोग की जांच [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) पेज पर की जा सकती है और यह हर कुछ मिनटों में अपडेट होता है।

#### ध्यान दें!

हम सुझाव देते हैं कि पहले Pages दस्तावेज़ीकरण पढ़ें, ताकि Comment API में `urlId` के लिए कौन से मान पास करने हैं, यह निर्धारित करते समय भ्रम को सीमित करने में मदद मिले।

### Webhooks

Webhook सब्सक्रिप्शन की अपनी एक गाइड है। `POST`, `GET` और `DELETE /api/v1/webhooks`, तथा `GET /api/v1/webhooks/sample-payloads`, को [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions) के अंतर्गत दस्तावेज़ित किया गया है, और इवेंट पेलोड्स को [Webhook Structures](/guide-webhooks.html#webhooks-structures) के अंतर्गत।
