एक `HashTag` ऑब्जेक्ट एक ऐसे टैग को दर्शाता है जिसे उपयोगकर्ता द्वारा छोड़ा जा सकता है। HashTags का उपयोग किसी बाहरी सामग्री से लिंक करने या संबंधित टिप्पणियों को एक साथ जोड़ने के लिए किया जा सकता है।

`HashTag` ऑब्जेक्ट की संरचना इस प्रकार है:

[inline-code-attrs-start title = 'HashTag संरचना'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface HashTag {
    /** इसे "#" या इच्छित वर्ण से शुरू होना चाहिए। **/
    tag: string
    /** एक वैकल्पिक URL जिसकी ओर हैशटैग इंगित कर सकता है। हैशटैग द्वारा टिप्पणियों को फ़िल्टर करने के बजाय, क्लिक करने पर UI इस पर रीडायरेक्ट कर देगा। **/
    url?: string
    /** READONLY **/
    createdAt: string
}
[inline-code-end]

नोट्स:

- कुछ API endpoints में आप देखेंगे कि हैशटैग का उपयोग URL में किया जाता है। URI-Encoded मानों को याद रखें। उदाहरण के लिए, `#` को इसके बजाय `%23` के रूप में दर्शाया जाना चाहिए।
- इनमें से कुछ फ़ील्ड `READONLY` चिह्नित हैं - इन्हें API द्वारा लौटाया जाता है लेकिन इन्हें सेट नहीं किया जा सकता।
