[api-resource-header-start name = 'BatchJob'; route = 'GET /api/v1/batch-jobs/:id'; creditsCost = 1; api-resource-header-end]

Questa rotta restituisce lo stato, il progresso e, una volta terminato, il risultato di un batch job. Usala per monitorare un job avviato da [`POST /api/v1/pages/migrations`](#pages-migrations-post) o [`POST /api/v1/pages/migrations/:undoId/undo`](#pages-migrations-undo-post).

Un job è terminato quando il suo `status` è `success` o `failed`. Ogni chiamata costa `1` credito, quindi effettua il polling ogni pochi secondi anziché continuamente.

[inline-code-attrs-start title = 'Esempio cURL BatchJob per ID'; type = 'bash'; useDemoTenant = true; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
curl --request GET \
  --url 'https://fastcomments.com/api/v1/batch-jobs/my-batch-job-id?tenantId=demo&API_KEY=DEMO_API_SECRET'
[inline-code-end]

[inline-code-attrs-start title = 'Struttura della Richiesta BatchJob per ID'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface BatchJobQueryParams {
    tenantId: string
    API_KEY: string
}
[inline-code-end]

[inline-code-attrs-start title = 'Struttura della Risposta BatchJob per ID'; type = 'typescript'; isFunctional = false; inline-code-attrs-end]
[inline-code-start]
interface BatchJobResponse {
    status: 'success' | 'failed'
    /** Included on failure. **/
    code?: 'missing-tenant-id' | 'invalid-tenant-id' | 'invalid-api-key' | 'missing-api-key' | 'not-found' | 'internal'
    /** Included on failure. **/
    reason?: string
    batchJob?: BatchJob
}
[inline-code-end]
