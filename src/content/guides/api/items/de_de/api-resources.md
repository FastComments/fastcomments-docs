### Ressourcennutzung

Es sollte beachtet werden, dass das Abrufen von Daten über die API als Nutzung Ihres Kontos gezählt wird.

Jede Ressource listet die entsprechende Nutzung in ihrem eigenen Abschnitt auf.

Einige Ressourcen kosten mehr zu bedienen als andere. Jeder Endpunkt hat feste Kosten in Credits pro API-Aufruf. Für einige Endpunkte variiert die Anzahl der Credits je nach Optionen und Antwortgrößen.

Die API-Nutzung kann auf der Seite [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) eingesehen werden und wird alle paar Minuten aktualisiert.

#### Hinweis!

Wir empfehlen, zuerst die Pages-Dokumentation zu lesen, um Verwirrungen zu vermeiden, wenn Sie bestimmen, welche Werte für `urlId` in der Comment API übergeben werden sollen.

### Webhooks

Webhook-Abonnements haben ihre eigene Anleitung. `POST`, `GET` und `DELETE /api/v1/webhooks` sowie `GET /api/v1/webhooks/sample-payloads` sind unter [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions) dokumentiert, und die Ereignis-Payloads unter [Webhook Structures](/guide-webhooks.html#webhooks-structures).
