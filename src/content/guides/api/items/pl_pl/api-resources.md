### Użycie zasobów

Należy zauważyć, że pobieranie danych z API jest liczone jako użycie na Twoim koncie.

Każdy zasób wymieni, jakie jest to użycie, w swojej własnej sekcji.

Niektóre zasoby kosztują więcej w obsłudze niż inne. Każdy punkt końcowy ma ustalony koszt kredytów za wywołanie API. Dla niektórych punktów końcowych liczba kredytów zmienia się w zależności od opcji i rozmiarów odpowiedzi.

Użycie API można sprawdzić na stronie [Billing Analytics](https://fastcomments.com/auth/my-account/analytics/billing) i jest aktualizowane co kilka minut.

#### Uwaga!

Zalecamy najpierw przeczytać dokumentację Pages, aby ograniczyć zamieszanie przy określaniu, jakie wartości przekazać dla `urlId` w API komentarzy.

### Webhooki

Subskrypcje webhooków mają własny przewodnik. `POST`, `GET` i `DELETE /api/v1/webhooks`, oraz `GET /api/v1/webhooks/sample-payloads`, są udokumentowane w sekcji [Managing Subscriptions via API](/guide-webhooks.html#webhooks-api-subscriptions), a ładunki zdarzeń w [Webhook Structures](/guide-webhooks.html#webhooks-structures).
