私人訊息(DM)讓 FastComments 使用者可以彼此進行私密的一對一對話,與公開留言和個人檔案互動分開。

### 什麼是私人訊息?

私人訊息提供:
- 兩位使用者之間的**私密對話**
- 帶有通知的**即時訊息**
- 跨工作階段保留的**對話歷史記錄**
- **線上狀態**指示器,可查看某人何時有空
- **未讀訊息追蹤**,讓您掌握新訊息

### 開始私人訊息對話

有幾種方式可以開始 DM 對話:

**從使用者個人檔案:**
1. 造訪該使用者的個人檔案頁面
2. 點擊「Direct Messages」分頁或「Send Message」按鈕
3. 輸入您的訊息並傳送

**從留言:**
某些實作允許點擊使用者的名稱或頭像,快速存取其個人檔案和訊息選項。

**直接連結:**
如果您有對話 ID 或 DM 重新導向連結,可以直接存取對話。

### 存取您的訊息

若要查看您所有的私人訊息對話:

1. 造訪您的個人檔案頁面
2. 點擊「Direct Messages」分頁
3. 查看您所有對話的清單

每個對話會顯示:
- 對方的頭像和名稱
- 其線上/離線狀態(線上時顯示綠色指示器)
- 最後一則訊息的預覽
- 未讀訊息數量(如果有的話)
- 最後活動的時間戳記

### 對話檢視

當您開啟對話時,您會看到:

- **完整訊息歷史記錄** - 您與對方之間的所有訊息
- **即時更新** - 新訊息透過 WebSocket 立即顯示
- **線上狀態** - 查看對方目前是否在線上
- **訊息時間戳記** - 每則訊息的傳送時間
- **訊息撰寫** - 用於輸入和傳送新訊息的文字框

### 訊息通知

您會收到新私人訊息的通知:

- **應用程式內通知** - 您個人檔案上的徽章計數器
- **電子郵件通知** - 取決於您的通知設定
- **即時提醒** - 當您登入時的即時通知

請在您的[帳戶設定](https://fastcomments.com/auth/my-account/edit-notifications)中管理通知偏好。

### 隱私與封鎖

**停用私人訊息:**
如果您不想收到 DM,可以完全停用它:
1. 前往您個人檔案上的隱私設定
2. 啟用「Disable Direct Messages」
3. DM 選項將從您的個人檔案中隱藏

更多詳細資訊,請參閱[隱私設定](/guide-user-profiles.html#privacy-settings)。

**封鎖使用者:**
如果有人透過 DM 騷擾您:
1. 造訪其個人檔案
2. 封鎖該使用者
3. 他們將無法再傳送訊息給您

被封鎖的使用者無法:
- 傳送私人訊息給您
- 查看您的活動
- 在您的個人檔案上留言
- 在 FastComments 上的任何地方與您互動

### 管理對話

**隱藏對話:**
您可以隱藏不想在對話清單中看到的對話:
1. 開啟您的 Direct Messages 分頁
2. 找出要隱藏的對話
3. 選擇隱藏/封存選項

隱藏的對話不會出現在您的主清單中,但如果對方傳送新訊息,則可以再次存取。

**標記為已讀:**
當您查看訊息時,訊息會自動標記為已讀。您也可以手動將整個對話標記為已讀:
1. 開啟您的 Direct Messages 分頁
2. 選擇一個對話
3. 選擇「Mark as Read」

這會清除該對話的未讀計數器。

### 最佳實務

**何時使用私人訊息:**
- 私下詢問後續問題
- 感謝某人提供有用的建議
- 討論離題事項而不弄亂公開留言
- 與其他社群成員協調
- 提供私人的回饋或建議

**DM 禮儀:**
- 保持尊重和專業
- 不要用未經請求的訊息轟炸使用者
- 尊重他人不回覆或停用 DM 的選擇
- 保持對話相關且有建設性
- 未經許可不要分享他人的 DM

**安全提示:**
- 除非您信任對方,否則不要分享個人資訊(電話、地址等)
- 封鎖並檢舉騷擾或濫用 DM 的使用者
- 對可疑的連結或請求保持警惕
- 如果有人讓您感到不舒服,請使用封鎖功能

### 限制與注意事項

**您可以傳訊給誰:**
- 任何未停用 DM 的 FastComments 使用者
- 未封鎖您的使用者
- 所有 FastComments 社群中的使用者

**訊息內容:**
- 支援文字訊息
- 訊息遵循與留言相同的內容政策
- 不當內容可以被檢舉

**對話範圍:**
- DM 對話是兩人之間的私密對話
- 不支援群組訊息(目前僅限一對一)
- 對話歷史記錄會無限期保留

### 疑難排解

**無法傳送訊息?**
對方可能已經:
- 在其隱私設定中停用了私人訊息
- 封鎖了您
- 刪除了其帳戶

**沒有收到通知?**
請在[帳戶設定](https://fastcomments.com/auth/my-account/edit-notifications)中檢查您的通知設定,確保已啟用 DM 通知。

**訊息無法傳送?**
- 檢查您的網際網路連線
- 重新整理頁面並再試一次
- 確認您沒有被封鎖
- 如果問題持續存在,請聯絡支援團隊
