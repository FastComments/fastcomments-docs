다이렉트 메시징(DM)을 통해 FastComments 사용자는 공개 댓글 및 프로필 상호작용과 별도로, 일대일 비공개 대화를 나눌 수 있습니다.

### 다이렉트 메시징이란?

다이렉트 메시징은 다음을 제공합니다:
- 두 사용자 간의 **비공개 대화**
- 알림이 포함된 **실시간 메시징**
- 세션 간에 유지되는 **대화 기록**
- 상대방이 접속 중인지 확인할 수 있는 **온라인 상태** 표시기
- 새 메시지를 놓치지 않도록 하는 **읽지 않은 메시지 추적**

### 다이렉트 메시지 시작하기

DM 대화를 시작하는 방법은 여러 가지가 있습니다:

**사용자 프로필에서:**
1. 사용자의 프로필 페이지를 방문합니다
2. "Direct Messages" 탭 또는 "Send Message" 버튼을 클릭합니다
3. 메시지를 입력하고 전송합니다

**댓글에서:**
일부 구현에서는 사용자 이름이나 아바타를 클릭하여 해당 프로필과 메시징 옵션에 빠르게 접근할 수 있습니다.

**직접 링크:**
대화 ID 또는 DM 리디렉션 링크가 있는 경우, 대화에 직접 접근할 수 있습니다.

### 메시지 확인하기

모든 다이렉트 메시지 대화를 보려면:

1. 프로필 페이지를 방문합니다
2. "Direct Messages" 탭을 클릭합니다
3. 모든 대화 목록을 확인합니다

각 대화에는 다음이 표시됩니다:
- 상대방의 아바타와 이름
- 온라인/오프라인 상태 (온라인일 때 초록색 표시기)
- 마지막 메시지 미리보기
- 읽지 않은 메시지 수 (있는 경우)
- 마지막 활동 시간

### 대화 보기

대화를 열면 다음을 볼 수 있습니다:

- **전체 메시지 기록** - 나와 상대방 간의 모든 메시지
- **실시간 업데이트** - WebSocket을 통해 새 메시지가 즉시 표시됨
- **온라인 상태** - 상대방이 현재 온라인인지 확인 가능
- **메시지 타임스탬프** - 각 메시지가 전송된 시간
- **메시지 작성** - 새 메시지를 입력하고 전송할 수 있는 텍스트 상자

### 메시지 알림

새 다이렉트 메시지에 대한 알림을 받게 됩니다:

- **앱 내 알림** - 프로필의 배지 카운터
- **이메일 알림** - 알림 설정에 따라 다름
- **실시간 알림** - 로그인 중일 때 즉시 알림

알림 기본 설정은 [계정 설정](https://fastcomments.com/auth/my-account/edit-notifications)에서 관리할 수 있습니다.

### 개인정보 보호 및 차단

**다이렉트 메시지 비활성화:**
DM을 받고 싶지 않은 경우, 완전히 비활성화할 수 있습니다:
1. 프로필의 개인정보 보호 설정으로 이동합니다
2. "Disable Direct Messages"를 활성화합니다
3. 프로필에서 DM 옵션이 숨겨집니다

자세한 내용은 [개인정보 보호 설정](/guide-user-profiles.html#privacy-settings)을 참조하세요.

**사용자 차단:**
누군가 DM으로 괴롭히는 경우:
1. 해당 사용자의 프로필을 방문합니다
2. 사용자를 차단합니다
3. 더 이상 메시지를 보낼 수 없게 됩니다

차단된 사용자는 다음을 할 수 없습니다:
- 다이렉트 메시지 보내기
- 내 활동 보기
- 내 프로필에 댓글 달기
- FastComments 어디에서든 나와 상호작용하기

### 대화 관리

**대화 숨기기:**
대화 목록에서 더 이상 보고 싶지 않은 대화를 숨길 수 있습니다:
1. Direct Messages 탭을 엽니다
2. 숨길 대화를 찾습니다
3. 숨기기/보관 옵션을 선택합니다

숨겨진 대화는 기본 목록에 표시되지 않지만, 상대방이 새 메시지를 보내면 다시 접근할 수 있습니다.

**읽음으로 표시:**
메시지는 확인 시 자동으로 읽음으로 표시됩니다. 전체 대화를 수동으로 읽음으로 표시할 수도 있습니다:
1. Direct Messages 탭을 엽니다
2. 대화를 선택합니다
3. "Mark as Read"를 선택합니다

이렇게 하면 해당 대화의 읽지 않은 카운터가 지워집니다.

### 모범 사례

**다이렉트 메시지를 사용하는 경우:**
- 후속 질문을 비공개로 묻기
- 도움이 되는 조언에 감사 전하기
- 공개 댓글을 어지럽히지 않고 주제 외 사항 논의하기
- 다른 커뮤니티 회원과 조율하기
- 비공개 피드백이나 제안 제공하기

**DM 에티켓:**
- 존중하고 전문적으로 대하기
- 원치 않는 메시지로 사용자에게 스팸을 보내지 않기
- 상대방이 응답하지 않거나 DM을 비활성화한 경우 존중하기
- 대화를 관련성 있고 건설적으로 유지하기
- 허락 없이 다른 사람의 DM을 공유하지 않기

**안전 수칙:**
- 상대방을 신뢰할 수 없다면 개인 정보(전화번호, 주소 등)를 공유하지 않기
- DM으로 괴롭히거나 악용하는 사용자는 차단하고 신고하기
- 의심스러운 링크나 요청에 주의하기
- 누군가 불편하게 만든다면 차단 기능을 사용하기

### 제한 사항 및 참고 사항

**누구에게 메시지를 보낼 수 있나:**
- DM을 비활성화하지 않은 모든 FastComments 사용자
- 나를 차단하지 않은 사용자
- 모든 FastComments 커뮤니티의 사용자

**메시지 내용:**
- 텍스트 메시지가 지원됩니다
- 메시지는 댓글과 동일한 콘텐츠 정책을 따릅니다
- 부적절한 콘텐츠는 신고할 수 있습니다

**대화 범위:**
- DM 대화는 두 사람 간의 비공개 대화입니다
- 그룹 메시징은 없습니다 (현재 일대일만 가능)
- 대화 기록은 무기한 보존됩니다

### 문제 해결

**메시지를 보낼 수 없나요?**
상대방이 다음 상태일 수 있습니다:
- 개인정보 보호 설정에서 다이렉트 메시지를 비활성화함
- 나를 차단함
- 계정을 삭제함

**알림을 받지 못하나요?**
[계정 설정](https://fastcomments.com/auth/my-account/edit-notifications)에서 알림 설정을 확인하여 DM 알림이 활성화되어 있는지 확인하세요.

**메시지가 전송되지 않나요?**
- 인터넷 연결을 확인합니다
- 페이지를 새로고침하고 다시 시도합니다
- 차단되지 않았는지 확인합니다
- 문제가 지속되면 지원팀에 문의합니다
