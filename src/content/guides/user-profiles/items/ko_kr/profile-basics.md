FastComments의 사용자 프로필은 각 사용자가 커뮤니티 전반에서 자신의 정체성, 활동, 기여를 보여줄 수 있는 전용 공간을 제공합니다.

### 사용자 프로필이란 무엇인가요?

사용자 프로필은 각 FastComments 사용자를 위한 개인화된 페이지로, 다음을 표시합니다:

- **프로필 헤더** - 프로필을 개성화하는 사용자 지정 가능한 배경 이미지
- **아바타** - 온라인/오프라인 상태 표시기가 있는 사용자의 프로필 사진
- **표시 정보** - 사용자 이름, 표시 이름, 선택적 국기
- **소개** - 개인적인 설명 또는 자기소개
- **소셜 링크** - 사용자의 소셜 미디어 프로필 및 웹사이트 연결
- **배지** - 획득한 업적 및 표창
- **통계** - 사용자 카르마 및 총 댓글 수
- **커뮤니티** - 사용자가 활동 중인 사이트/도메인

### 사용자 프로필에 접근하는 방법

사용자의 프로필에 접근하는 방법은 여러 가지가 있습니다:

1. **아바타 클릭** - 댓글 위젯에서 아무 사용자의 아바타를 클릭하여 프로필을 확인합니다
2. **사용자 이름 클릭** - 댓글의 사용자 이름은 프로필로 연결되는 클릭 가능한 링크입니다
3. **직접 URL** - `https://fastcomments.com/auth/user-profile/[userId]` 방문

### 프로필 보기

프로필을 볼 때 자신의 프로필인지 다른 사람의 프로필인지에 따라 다른 탭이 표시됩니다:

#### 자신의 프로필
- **알림** - 나의 알림 및 멘션
- **최근 활동** - 모든 커뮤니티에 걸친 나의 댓글 기록
- **프로필 댓글** - 다른 사람이 내 프로필 페이지에 남긴 댓글
- **다이렉트 메시지** - 다른 사용자와의 개인 대화

#### 다른 사용자의 프로필
- **최근 활동** - 해당 사용자의 공개 댓글 기록 (비공개로 설정하지 않은 경우)
- **프로필 댓글** - 해당 프로필의 댓글 (비공개로 설정하지 않은 경우)
- **다이렉트 메시지** - 개인 대화 시작 또는 계속 (DM을 허용하는 경우)

### 온라인 상태

사용자 프로필은 실시간 온라인 상태를 표시합니다:
- **녹색 표시기** - 사용자가 현재 온라인 상태
- **표시기 없음** - 사용자가 오프라인 상태

이를 통해 누군가가 플랫폼을 활발히 사용 중인지 알 수 있으며, 다이렉트 메시징에 특히 유용합니다.

### 사용자 유형

FastComments는 프로필이 있는 두 가지 유형의 사용자를 지원합니다:

1. **일반 사용자** - FastComments에 직접 가입한 사용자
2. **SSO 사용자** - 사이트의 Single Sign-On 통합을 통해 인증하는 사용자

두 사용자 유형 모두 전체 프로필 시스템에 접근할 수 있지만, SSO 구성에 따라 SSO 사용자는 특정 필드(예: 아바타) 편집에 일부 제한이 있을 수 있습니다.
