사용자 노트를 사용하면 다른 FastComments 사용자에 대한 개인적이고 비공개의 메모를 남길 수 있습니다. 이 노트는 완전히 비공개이며 본인만 볼 수 있습니다.

### 사용자 노트란 무엇인가요?

사용자 노트는 다음과 같습니다:
- 다른 사용자에 대해 작성하는 **비공개 메모**
- **본인만 볼 수 있음** - 노트의 대상이 되는 사용자는 볼 수 없습니다
- **지속적** - 해당 사용자의 프로필을 볼 때마다 저장되어 접근 가능합니다
- 사용자에 대한 맥락, 상호작용 또는 중요한 세부 사항을 **기억하는 데 유용합니다**

### 사용자 노트를 사용하는 이유는?

사용자 노트는 다음과 같은 경우에 유용합니다:

**모더레이터:**
- 특정 사용자와의 상호작용 기록 추적
- 경고 패턴이나 행동 관찰 기록
- 모더레이션 결정을 위한 맥락 기억
- 특정 조치가 취해진 이유 문서화

**커뮤니티 매니저:**
- 가치 있는 기여자와 그들의 전문 분야 기억
- 특별 역할의 좋은 후보가 될 수 있는 사용자 기록
- 커뮤니티 회원과 필요한 후속 조치 추적

**일반 사용자:**
- 서로 다른 커뮤니티에서 누군가를 어떻게 알게 되었는지 기억
- 특정 사용자와 논의한 주제 기록
- 관심 분야에서 도움이 되는 기여자 추적
- 대화에서 공유된 개인적인 세부 사항 기억 (적절한 범위 내에서)

### 사용자 노트 작성하기

사용자에 대한 노트를 추가하려면:

1. 해당 사용자의 프로필 페이지를 방문하세요
2. "User Note" 또는 "Add Note" 섹션을 찾으세요
3. 클릭하여 새 노트를 만드세요
4. 노트를 입력하세요 (최대 1000자)
5. 노트를 저장하세요

노트는 저장되며 해당 사용자의 프로필을 볼 때마다 표시됩니다.

### 사용자 노트 보기

노트는 관련 사용자의 프로필을 볼 때 표시됩니다:

- **위치:** 일반적으로 프로필 페이지의 전용 섹션에 있습니다
- **가시성:** 로그인한 상태에서 본인만 볼 수 있습니다
- **맥락:** 사용자의 공개 정보와 함께 표시됩니다

이를 통해 자주 상호작용하는 사용자에 대한 중요한 맥락을 쉽게 기억할 수 있습니다.

### 사용자 노트 편집하기

기존 노트를 업데이트하려면:

1. 해당 사용자의 프로필을 방문하세요
2. 기존 노트를 찾으세요
3. "Edit"를 클릭하거나 노트 필드를 클릭하세요
4. 변경 사항을 적용하세요
5. 업데이트된 노트를 저장하세요

### 사용자 노트 삭제하기

노트를 제거하려면:

1. 해당 사용자의 프로필을 방문하세요
2. 본인의 노트를 찾으세요
3. "Delete" 또는 제거 옵션을 클릭하세요
4. 삭제를 확인하세요

한 번 삭제되면 노트는 영구적으로 제거되며 복구할 수 없습니다.

### 글자 수 제한

사용자 노트는 **1000자**로 제한됩니다. 이는 다음을 장려합니다:
- 간결하고 집중된 노트
- 긴 서술보다 핵심 요점
- 빠른 참조 정보

더 많은 공간이 필요하다면 FastComments 외부에 별도의 문서로 보관하는 것을 고려하세요.

### 개인정보 및 보안

**완전한 개인정보 보호:**
- 노트는 사용자 ID와 함께 저장됩니다
- 본인이 작성한 노트만 볼 수 있습니다
- 노트의 대상이 되는 사용자는 볼 수 없습니다
- 다른 사용자는 볼 수 없습니다
- 사이트 관리자도 개인 노트를 볼 수 없습니다 (모더레이션 로그와 별도로 저장됩니다)

**모더레이션에 관한 참고 사항:**
사용자 노트는 모더레이션 노트나 플래그와 다릅니다:
- 개인 참조용으로는 사용자 노트를 사용하세요
- 위반이나 문제는 모더레이션 신고 도구를 사용하세요
- 사용자 노트는 어떠한 조치나 알림도 트리거하지 않습니다

### 모범 사례

**포함할 내용:**
- 사용자를 어떻게 만났거나 알게 되었는지
- 사용자가 잘 아는 주제
- 이전의 도움이 된 상호작용
- 과거 대화의 맥락
- 전문 분야 또는 관심 분야
- 후속 조치를 위한 리마인더

**피해야 할 내용:**
- 노트에 민감한 개인 정보를 저장하지 마세요
- 비공개 노트라도 자극적이거나 부적절한 내용은 피하세요
- 중요한 정보를 노트에만 의존하지 마세요 (다른 곳에 백업을 보관하세요)
- 노트는 공식 기록이 아닌 본인의 참조용임을 기억하세요

**업무적 사용:**
모더레이터와 커뮤니티 매니저의 경우:
- 노트는 사실적이고 객관적으로 유지하세요
- 시간에 민감한 정보에는 날짜를 포함하세요
- 고립된 사건보다 패턴을 기록하세요
- 공식 모더레이션 로그를 보완하는 용도로 (대체하지 않고) 노트를 사용하세요

### 사용 사례

**예시 1: 커뮤니티 매니저**
> "기술 토론에 활발히 참여. 백엔드 개발자로 재직. 문서화 지원 의사 표명함. 위키 기여에 대해 후속 조치 필요."

**예시 2: 모더레이터**
> "도움이 되는 사용자이지만 가끔 뜨거운 논쟁에 휘말림. 대체로 존중하는 태도. 이전의 예의 관련 리마인더에 잘 반응함."

**예시 3: 일반 사용자**
> "게임 스레드에서 만남. 나와 같은 게임을 함. 유용한 튜토리얼 링크 공유함. 영국 시간대 거주."

### 제한 사항

**사용자 노트가 하지 않는 것:**
- 기기 간 동기화되지 않습니다 (동일한 계정에 로그인한 경우 제외)
- 댓글이나 다른 맥락에는 표시되지 않고 프로필에만 표시됩니다
- 사용자의 프로필이나 가시성에 어떠한 영향도 미치지 않습니다
- 검색할 수 없습니다 (현재)
- 알림이나 조치를 트리거하지 않습니다

**저장:**
- 노트는 삭제하지 않는 한 무기한 저장됩니다
- 노트당 최대 1000자
- 사용자당 하나의 노트 (여러 개를 만드는 대신 기존 노트를 업데이트하세요)

### 기술 세부 사항

사용자 노트는 다음과 같습니다:
- 작성자로서 본인의 사용자 ID와 함께 데이터베이스에 저장됩니다
- 대상 사용자의 ID와 연결됩니다
- 전송 중 암호화됩니다 (HTTPS)
- 표준 FastComments 데이터 보존 정책의 적용을 받습니다
- 공개 데이터 내보내기나 API 응답에 포함되지 않습니다

### 문제 해결

**노트가 저장되지 않는 경우:**
- 로그인되어 있는지 확인하세요
- 노트가 1000자 미만인지 확인하세요
- 페이지를 새로고침하고 다시 추가해 보세요
- 인터넷 연결을 확인하세요

**노트가 표시되지 않는 경우:**
- 노트를 작성한 계정으로 로그인했는지 확인하세요
- 해당 사용자의 프로필 페이지를 새로고침하세요
- 필요한 경우 브라우저 캐시를 지우세요

**실수로 노트를 삭제한 경우:**
안타깝게도 삭제된 노트는 복구할 수 없습니다. 중요한 정보는 FastComments 외부에 백업으로 보관하는 것을 고려하세요.
