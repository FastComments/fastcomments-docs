### 401 अनधिकृत त्रुटियाँ

यदि आपको प्रमाणित API का उपयोग करते समय 401 त्रुटियाँ मिल रही हैं:

1. **अपनी API कुंजी जाँचें**: सुनिश्चित करें कि आप अपने FastComments डैशबोर्ड से सही API कुंजी का उपयोग कर रहे हैं
2. **टेनेंट ID सत्यापित करें**: सुनिश्चित करें कि टेनेंट ID आपके खाते से मेल खाती है
3. **API कुंजी प्रारूप**: API कुंजी को Configuration में पास किया जाना चाहिए:

```rust
let mut config = Configuration::new();
config.api_key = Some(ApiKey {
    prefix: None,
    key: "YOUR_API_KEY".to_string(),
});
```

### SSO टोकन समस्याएँ

यदि SSO टोकन काम नहीं कर रहे हैं:

1. **प्रोडक्शन के लिए सुरक्षित मोड का उपयोग करें**: प्रोडक्शन के लिए हमेशा अपनी API कुंजी के साथ `FastCommentsSSO::new_secure()` का उपयोग करें
2. **केवल सर्वर-साइड**: SSO टोकन अपने सर्वर पर जनरेट करें, कभी भी अपनी API कुंजी क्लाइंट्स को उजागर न करें
3. **उपयोगकर्ता डेटा जाँचें**: सुनिश्चित करें कि सभी आवश्यक फ़ील्ड (id, email, username) प्रदान की गई हैं

### Async रनटाइम त्रुटियाँ

SDK async संचालन के लिए tokio का उपयोग करता है। सुनिश्चित करें कि आप:

1. tokio को अपनी निर्भरताओं में जोड़ें:
```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
```

2. tokio रनटाइम का उपयोग करें:
```rust
#[tokio::main]
async fn main() {
    // आपका async कोड यहाँ
}
```
