### ब्रॉडकास्ट IDs

आप देखेंगे कि कुछ API कॉल में `broadcastId` पास करना अपेक्षित है। जब आप इवेंट्स प्राप्त करते हैं, तो आपको यह ID वापस मिलेगी, ताकि आप उस इवेंट को अनदेखा कर सकें यदि आप क्लाइंट पर बदलावों को ऑप्टिमिस्टिक रूप से लागू करने की योजना बना रहे हैं
(जो आप शायद करना चाहेंगे क्योंकि यह सबसे अच्छा अनुभव देता है)। यहाँ एक UUID पास करें। ID इतनी अद्वितीय होनी चाहिए कि वह एक ब्राउज़र सेशन में दो बार न आए।
