#### Як відображаються коментарі у ваших курсах

Після того як інтеграцію LTI активовано та External App встановлено, FastComments працює автоматично на основі налаштованих вами placements:

#### Вигляд завдання (Assignment View)

Якщо placement **Assignment View** активовано, коментарі автоматично з'являються під кожним завданням у курсі. Студенти та викладачі бачать розділ із деревоподібними коментарями, коли переглядають завдання — жодних додаткових налаштувань для кожного завдання не потрібно.

Кожне завдання отримує власний окремий потік коментарів.

#### Кнопка Rich Content Editor

Якщо placement **Editor Button** активовано, викладачі можуть вбудувати FastComments у будь-який контент, що використовує Rich Content Editor:

1. Відредагуйте **Сторінку (Page)**, **Тест (Quiz)** або **Оголошення (Announcement)**.
2. На панелі інструментів Rich Content Editor натисніть кнопку **FastComments**.
3. FastComments автоматично вбудовується у контент.
4. Збережіть сторінку.

Коли студенти переглядають сторінку, вбудований віджет FastComments завантажується з потоком коментарів, унікальним для цієї сторінки.

#### Автоматичний SSO

В обох placements студенти автоматично авторизуються через свій обліковий запис Canvas. Імена, електронні пошти та аватари синхронізуються через LTI launch, окремий вхід не потрібен.

#### Обмеження публічного доступу (рекомендовано)

За замовчуванням дані коментарів FastComments є публічно доступними для читання. Будь-хто, хто здогадається про URL потоку або API endpoint, може переглянути його коментарі, навіть поза Canvas. Для обговорень у курсах вам майже напевно захочеться обмежити перегляд лише зарахованими студентами.

Відкрийте свою <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">сторінку налаштування віджета</a> та створіть правило з увімкненою опцією **Require SSO To View Comments**, а потім встановіть рівень безпеки **Secure SSO**, щоб потоки можна було завантажити лише через підписаний LTI launch.

Повний покроковий посібник, зокрема як обмежити правило одним доменом або сторінкою, дивіться в статті [Захист потоків коментарів за допомогою Single-Sign-On](/guide-customizations-and-configuration.html#sso-require-to-view-comments).
