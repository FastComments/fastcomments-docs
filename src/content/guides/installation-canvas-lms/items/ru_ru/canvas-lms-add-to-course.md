#### Как комментарии отображаются в ваших курсах

После включения интеграции LTI и установки внешнего приложения FastComments работает автоматически на основе настроенных вами размещений:

#### Просмотр задания

Если размещение **Assignment View** включено, комментарии автоматически появляются под каждым заданием в курсе. Студенты и преподаватели видят ветвящийся раздел комментариев при просмотре задания — дополнительная настройка для каждого задания не требуется.

Каждое задание получает собственный отдельный тред комментариев.

#### Кнопка в редакторе форматированного контента

Если размещение **Editor Button** включено, преподаватели могут встраивать FastComments в любой контент, использующий редактор форматированного контента (Rich Content Editor):

1. Отредактируйте **Страницу**, **Тест** или **Объявление**.
2. На панели инструментов редактора форматированного контента нажмите кнопку **FastComments**.
3. FastComments автоматически встраивается в контент.
4. Сохраните страницу.

Когда студенты просматривают страницу, встроенный виджет FastComments загружается с тредом комментариев, уникальным для этой страницы.

#### Автоматический SSO

В обоих размещениях студенты автоматически входят через свою учётную запись Canvas. Имена, адреса электронной почты и аватары синхронизируются через LTI-запуск, отдельный вход не требуется.

#### Ограничение публичного доступа (рекомендуется)

По умолчанию данные комментариев FastComments доступны для публичного чтения. Любой, кто угадает URL треда или API-эндпоинт, может просмотреть его комментарии даже вне Canvas. Для обсуждений в курсах вы почти наверняка захотите ограничить просмотр только зачисленными студентами.

Откройте свою <a href="https://fastcomments.com/auth/my-account/customize-widget" target="_blank">страницу настройки виджета</a> и создайте правило с включённой опцией **Require SSO To View Comments**, затем установите уровень безопасности на **Secure SSO**, чтобы треды можно было загружать только через подписанный LTI-запуск.

Полное руководство см. в разделе [Защита тредов комментариев с помощью Single-Sign-On](/guide-customizations-and-configuration.html#sso-require-to-view-comments), включая то, как ограничить действие правила одним доменом или страницей.
