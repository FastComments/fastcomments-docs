#### Перейдите к конфигурации LTI

Откройте <a href="https://fastcomments.com/auth/my-account/canvas-lti-config" target="_blank">вашу конфигурацию LTI в FastComments</a>.

Страница настройки использует пошаговый мастер, который проведёт вас через каждый этап. Вы начнёте с **Шага 1: Создание**.

#### Создайте новую конфигурацию LTI

Заполните следующие поля:

- **Название конфигурации** — необязательная метка для идентификации этой конфигурации (полезно, если вы подключаете несколько экземпляров Canvas).
- **URL платформы** — URL вашего экземпляра Canvas (например, `https://yourschool.instructure.com`). Это обязательное поле.

#### Выберите размещения

Под URL платформы вы можете выбрать, где FastComments будет отображаться в ваших курсах Canvas. Оба размещения включены по умолчанию:

- **Просмотр задания** — комментарии автоматически появляются под заданиями.
- **Кнопка в редакторе Rich Content Editor** — преподаватели могут встраивать FastComments в страницы, тесты и объявления с помощью кнопки на панели инструментов в редакторе Rich Content Editor.

Вы можете включить одно или оба. Должно быть включено хотя бы одно размещение.

Нажмите **Create Configuration**.

#### Скопируйте URL конфигурации

После создания конфигурации мастер перейдёт к **Шагу 2: Подключение**. В верхней части страницы будет отображён заметный **URL конфигурации** с кнопкой **Copy**.

Скопируйте этот URL. Он понадобится вам на следующем шаге для создания ключа разработчика в Canvas.

На странице также приведены пронумерованные инструкции о том, что нужно сделать в Canvas, а также поля для ввода **Client ID** и необязательного **Deployment ID**, когда они у вас появятся.
