Виджет комментариев можно <a href="/guide-customizations-and-configuration.html#custom-css" target="_blank">настраивается</a> по‑разному для каждого сайта.

На странице настройки виджета вы найдете выпадающий список с меткой "domain". Выбор `All` в этом поле применит правило ко всем
сайтам в вашей учетной записи, вы можете ввести конкретный домен, который ограничит настройки или пользовательский CSS, которые вы хотите применить только к этому домену.

Это позволяет вам сделать FastComments выглядеть или работать совершенно по‑разному для каждого сайта.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = 'label.domain'; alt='Выпадающий список домена на странице настройки виджета, установленный на All или конкретный сайт'; title='Домен правила настройки' app-screenshot-end]

Для одного сайта может использоваться жирный шрифт и разрешать анонимные комментарии, а для другого сайта может
быть иной стиль и требовать от пользователя указать свой email при комментировании.
