Для каждого сайта WordPress требуется отдельный аккаунт или тенант FastComments. WordPress нумерует записи независимо на каждом сайте, поэтому запись 5 на одном сайте и запись 5 на другом
использовали бы одну ветку комментариев, если бы оба были подключены к одному аккаунту. По этой причине настройка плагина отказывается подключать сайт, если к аккаунту уже подключён другой.

[Просмотреть активные интеграции можно здесь.](https://fastcomments.com/auth/my-account/manage-data/integrations)

Чтобы запустить несколько сайтов WordPress, создайте [тенант](https://fastcomments.com/auth/my-account/tenants) для каждого из них, переключитесь на него, а затем подключите сайт со страницы настройки плагина. Тенанты входят в тарифные планы с white labeling. Вы также можете создать отдельный аккаунт FastComments для каждого сайта, используя разные адреса электронной почты.

Если сайт был перемещён, например, со staging на production, деактивируйте плагин на старом сайте и удалите старый сайт из активных интеграций. Затем подключите новый. Комментарии, уже синхронизированные со старого сайта, остаются в аккаунте и отображаются на любой записи с тем же ID на новом сайте.

Вы можете использовать один аккаунт FastComments с одной установкой WordPress, которая охватывает несколько доменов и имеет одинаковое содержимое на этих доменах.
