Κάθε ιστότοπος WordPress χρειάζεται το δικό του λογαριασμό FastComments ή ενοικιαστή. Το WordPress αριθμεί τις δημοσιεύσεις ξεχωριστά σε κάθε ιστότοπο, έτσι ώστε η δημοσίευση 5 σε έναν ιστότοπο και η δημοσίευση 5 σε έναν άλλο να μοιράζονται το ίδιο νήμα σχολίων εάν και οι δύο είναι συνδεδεμένοι στον ίδιο λογαριασμό. Για αυτόν τον λόγο, η ρύθμιση του πρόσθετου αρνείται να συνδέσει έναν ιστότοπο όταν ο λογαριασμός έχει ήδη συνδεδεμένο διαφορετικό.

[Μπορείτε να δείτε τις ενεργές ενσωματώσεις σας εδώ.](https://fastcomments.com/auth/my-account/manage-data/integrations)

Για να λειτουργήσετε πολλούς ιστότοπους WordPress, δημιουργήστε έναν [ενοικιαστή](https://fastcomments.com/auth/my-account/tenants) για καθέναν, μεταβείτε σε αυτόν και, στη συνέχεια, συνδέστε τον ιστότοπο από τη σελίδα ρύθμισης του πρόσθετου. Οι ενοικιαστές περιλαμβάνονται στα πακέτα με λευκή σήμανση. Μπορείτε επίσης να δημιουργήσετε ξεχωριστό λογαριασμό FastComments για κάθε ιστότοπο, χρησιμοποιώντας διαφορετική διεύθυνση email για καθέναν.

Εάν ένας ιστότοπος έχει μετακινηθεί, για παράδειγμα από περιβάλλον δοκιμών σε παραγωγή, απενεργοποιήστε το πρόσθετο στον παλιό ιστότοπο και αφαιρέστε τον παλιό ιστότοπο από τις ενεργές ενσωματώσεις σας. Στη συνέχεια, συνδέστε τον νέο. Τα σχόλια που έχουν ήδη συγχρονιστεί από τον παλιό ιστότοπο παραμένουν στον λογαριασμό και εμφανίζονται σε οποιαδήποτε δημοσίευση με το ίδιο ID στον νέο ιστότοπο.

Μπορείτε να χρησιμοποιήσετε τον ίδιο λογαριασμό FastComments με μια μοναδική εγκατάσταση WordPress που καλύπτει πολλαπλούς τομείς και έχει το ίδιο περιεχόμενο σε αυτούς τους τομείς.
