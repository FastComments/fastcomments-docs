Cada site WordPress precisa de sua própria conta FastComments ou locatário. O WordPress numera as postagens separadamente em cada site, portanto a postagem 5 em um site e a postagem 5 em outro compartilhariam um único thread de comentários se ambos estivessem conectados à mesma conta. Por esse motivo, a configuração do plugin recusa conectar um site quando a conta já tem outro site conectado.

[Você pode ver suas integrações ativas aqui.](https://fastcomments.com/auth/my-account/manage-data/integrations)

Para operar vários sites WordPress, crie um [locatário](https://fastcomments.com/auth/my-account/tenants) para cada um, alterne para ele e então conecte o site a partir da página de configuração do plugin. Locatários estão incluídos nos planos com marca branca. Você também pode criar uma conta FastComments separada para cada site, usando um endereço de e‑mail diferente para cada um.

Se um site foi movido, por exemplo de staging para produção, desative o plugin no site antigo e remova o site antigo de suas integrações ativas. Em seguida, conecte o novo. Comentários já sincronizados do site antigo permanecem na conta e são exibidos em qualquer postagem com o mesmo ID no novo site.

Você pode usar a mesma conta FastComments com uma única instalação WordPress que abrange vários domínios e tem o mesmo conteúdo nesses domínios.
