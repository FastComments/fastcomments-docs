Jede WordPress‑Seite benötigt ihr eigenes FastComments‑Konto oder Mandanten. WordPress nummeriert Beiträge separat pro Seite, sodass Beitrag 5 auf einer Seite und Beitrag 5 auf einer anderen denselben Kommentar‑Thread teilen würden, wenn beide mit demselben Konto verbunden wären. Aus diesem Grund verweigert das Setup‑Plugin die Verbindung einer Seite, wenn das Konto bereits eine andere Seite verbunden hat.

[Sie können Ihre aktiven Integrationen hier einsehen.](https://fastcomments.com/auth/my-account/manage-data/integrations)

Um mehrere WordPress‑Seiten zu betreiben, erstellen Sie für jede einen [Mandanten](https://fastcomments.com/auth/my-account/tenants), wechseln zu ihm und verbinden dann die Seite über die Setup‑Seite des Plugins. Mandanten sind in den Plänen mit White‑Labeling enthalten. Sie können auch für jede Seite ein separates FastComments‑Konto anlegen, wobei Sie für jedes eine andere E‑Mail‑Adresse verwenden.

Wenn eine Seite beispielsweise von einer Staging‑Umgebung in die Produktionsumgebung verschoben wurde, deaktivieren Sie das Plugin auf der alten Seite und entfernen die alte Seite aus Ihren aktiven Integrationen. Anschließend verbinden Sie die neue Seite. Kommentare, die bereits von der alten Seite synchronisiert wurden, bleiben im Konto und werden bei jedem Beitrag mit derselben ID auf der neuen Seite angezeigt.

Sie können dasselbe FastComments‑Konto mit einer einzigen WordPress‑Installation verwenden, die mehrere Domains umfasst und auf diesen Domains denselben Inhalt hat.
