Das Kommentar-Widget kann <a href="/guide-customizations-and-configuration.html#custom-css" target="_blank">angepasst</a> werden, um für jede Site unterschiedlich zu sein.

Auf der Seite zur Widget-Anpassung finden Sie ein Dropdown-Menü mit der Bezeichnung "domain". Wenn Sie in diesem Feld `All` auswählen, wird die Regel auf alle Sites in Ihrem Konto angewendet; Sie können eine bestimmte Domain eingeben, die die Einstellungen oder das benutzerdefinierte CSS, das Sie nur für diese Domain anwenden möchten, einschränkt.

Damit können Sie FastComments für jede Site völlig anders aussehen oder funktionieren lassen.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = 'label.domain'; alt='Das Domain-Dropdown auf der Widget-Anpassungsseite, eingestellt auf Alle oder eine bestimmte Site'; title='Anpassungsregel Domain' app-screenshot-end]

Eine Site könnte fettgedruckten Text verwenden und anonyme Kommentare zulassen, und eine andere Site könnte
ein anderes Styling haben und verlangen, dass der Benutzer beim Kommentieren seine E‑Mail-Adresse hinterlässt.
