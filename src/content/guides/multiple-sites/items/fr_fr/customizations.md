Le widget de commentaire peut être <a href="/guide-customizations-and-configuration.html#custom-css" target="_blank">personnalisé</a> différemment pour chaque site.

Sur la page de personnalisation du widget, vous trouverez un menu déroulant intitulé « domain ». Sélectionner `All` dans ce champ appliquera la règle à tous les sites de votre compte ; vous pouvez saisir un domaine spécifique qui limitera les paramètres ou le CSS personnalisé que vous souhaitez appliquer uniquement à ce domaine.

Cela vous permet d'avoir FastComments qui a un aspect ou un fonctionnement complètement différent pour chaque site.

[app-screenshot-start url='/auth/my-account/customize-widget/new'; selector = 'label.domain'; alt='Le menu déroulant du domaine sur la page de personnalisation du widget, réglé sur All ou sur un site spécifique'; title='Domaine de la règle de personnalisation' app-screenshot-end]

Un site peut utiliser du texte en gras et autoriser les commentaires anonymes, et un autre site peut
avoir un style différent et exiger que l'utilisateur laisse son e‑mail lorsqu'il commente.
