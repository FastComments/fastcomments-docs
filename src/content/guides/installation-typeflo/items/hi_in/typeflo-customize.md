FastComments को आपके ब्लॉग के डिज़ाइन से मेल खाने के लिए अनुकूलित करने के लिए डिज़ाइन किया गया है।

यदि आप कस्टम स्टाइलिंग जोड़ना चाहते हैं, या कॉन्फ़िगरेशन में बदलाव करना चाहते हैं, तो [हमारी कस्टमाइज़ेशन दस्तावेज़ीकरण देखें](/guide-customizations-and-configuration.html) और जानें कि कैसे।

Typeflo.io ब्लॉग्स के लिए, आप उसी Custom Code सेक्शन में कस्टम CSS स्टाइल जोड़ सकते हैं जहाँ आपने FastComments स्क्रिप्ट जोड़ी थी।
