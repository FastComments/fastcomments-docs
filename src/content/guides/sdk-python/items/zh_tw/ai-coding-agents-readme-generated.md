[![skills.sh](https://skills.sh/b/fastcomments/skills)](https://skills.sh/fastcomments/skills)

為您的程式編寫代理提供 FastComments 所需的上下文 - 小工具、設定、Secure SSO、REST API 與 SDK：

```bash
npx skills add fastcomments/skills
```

支援 Claude Code、Codex、Cursor、Copilot、Gemini，以及所有其他由 [skills CLI](https://github.com/vercel-labs/skills) 支援的代理。
