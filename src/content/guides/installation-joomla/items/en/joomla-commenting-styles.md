FastComments supports several commenting styles, chosen with the plugin's **Commenting Style** setting. Each style loads on the single-article view.

### Comments

The classic threaded comment widget below the article, with replies, @mentions, voting, and a notification bell. This is the default.

### Collab Chat

Readers select any text in the article to start an inline discussion anchored to that content, with an online-presence indicator. No comment widget is shown below the article.

### Collab Chat + Comments

Both at once: inline text-selection discussions plus the threaded comment widget below the article.

### Live Chat

A real-time chat room below the article, ideal for live events and fast-moving conversations.

### Image Chat

Comment threads anchored to individual images in the article. Readers hover an image to open its discussion. Great for photo essays, galleries, and design reviews.

<sup>Note!</sup> Collab Chat and Image Chat attach to your template's article body. The plugin looks for the standard Joomla article container and falls back to the main content region, so it works across most templates.
