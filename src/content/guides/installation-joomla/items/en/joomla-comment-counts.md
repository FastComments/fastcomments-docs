Turn on **Show Comment Counts in Listings** in the plugin settings to display a comment count next to each article title in your category, blog, and featured list views.

The count appears under the article title wherever Joomla lists articles, so readers can see which posts have the most discussion before they click through.

Counts are fetched in a single batched request per page, so adding them to a busy listing does not slow the page down. The full comment widget still renders only on the single-article view.

<sup>Note!</sup> Counts use the same Tenant ID and CDN URL as the comment widget. There is nothing extra to configure beyond the toggle.
