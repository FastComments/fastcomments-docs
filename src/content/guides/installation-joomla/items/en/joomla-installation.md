The FastComments Joomla extension adds a fast, real-time commenting system to your Joomla articles. It works with Joomla 4.2 and later, including Joomla 5.

FastComments ships as a single installable package that bundles a content plugin (the comment widget) and three sidebar modules (Recent Comments, Recent Discussions, Top Pages).

## Install the package

1. Download `pkg_fastcomments.zip`.
2. In the Joomla administrator, go to `System > Install > Extensions`.
3. On the `Upload Package File` tab, drop in the ZIP and let it install.

That installs the content plugin and all three modules at once.

## Enable the plugin

Joomla installs plugins disabled by default. Go to `System > Manage > Plugins`, search for `FastComments`, and enable the `FastComments` content plugin.

<sup>Note!</sup> The extension only requires Joomla core. There are no other extensions or libraries to install.

Once the plugin is enabled, open it and head to the `Configuration` section to set your Tenant ID and API Secret.
