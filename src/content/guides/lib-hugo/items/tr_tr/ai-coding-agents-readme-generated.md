Kodlama ajanınıza FastComments bağlamını sağlayın - widget'lar, yapılandırma, Güvenli SSO, REST API ve SDK'lar:

```bash
npx skills add fastcomments/skills
```

Claude Code, Codex, Cursor, Copilot, Gemini ve [skills CLI](https://github.com/vercel-labs/skills) tarafından desteklenen diğer tüm ajanlarla çalışır.
