सार्वजनिक `demo` टेनेंट के विरुद्ध लोकल रूप से हर शॉर्टकोड और थीम पार्शियल देखने के लिए, रिपॉज़िटरी को क्लोन करें और बंडल किया गया `exampleSite` चलाएँ:

```bash
git clone https://github.com/FastComments/fastcomments-hugo.git
cd fastcomments-hugo/exampleSite
hugo server
```

प्रत्येक विजेट की `exampleSite/content/` के अंतर्गत अपना पेज होता है, जिसे आप सीधे अपनी साइट में कॉपी कर सकते हैं।
