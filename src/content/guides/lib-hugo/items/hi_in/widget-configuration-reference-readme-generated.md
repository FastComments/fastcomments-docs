पूरी विजेट विकल्पों की सूची के लिए, [FastComments कस्टमाइज़ेशन दस्तावेज़](https://docs.fastcomments.com/guide-customizations-and-configuration.html) देखें। दो विजेट एक आवश्यक विकल्प लेते हैं जिसका कोई डिफ़ॉल्ट नहीं है:

- `fastcomments-collab-chat` और `fastcomments-image-chat` को `target` की आवश्यकता होती है, जो जिस तत्व से जोड़ना है उसके लिए एक CSS सेलेक्टर है।
- `fastcomments-user-activity-feed` को `userId` की आवश्यकता होती है।
