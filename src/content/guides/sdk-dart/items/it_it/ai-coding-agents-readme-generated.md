Fornisci al tuo agente di programmazione il contesto FastComments di cui ha bisogno: widget, configurazione, Secure SSO, la REST API e gli SDK:

```bash
npx skills add fastcomments/skills
```

Funziona con Claude Code, Codex, Cursor, Copilot, Gemini e tutti gli altri agenti supportati dal [skills CLI](https://github.com/vercel-labs/skills).
