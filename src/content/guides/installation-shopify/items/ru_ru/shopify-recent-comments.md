Блок **FastComments - Recent Comments** показывает самые последние комментарии со всего вашего магазина. Используйте его, чтобы отображать свежую активность в боковой панели, подвале или на главной странице.

### Добавление блока

1. Откройте редактор темы Shopify.
2. Откройте шаблон, в который хотите добавить ленту. Хорошо подойдут боковая секция, главная страница или индекс блога.
3. Нажмите **Add block** в секции, где он должен находиться.
4. В разделе **Apps** выберите **FastComments - Recent Comments**.
5. Нажмите **Save**.

### Настройки

| Настройка | Что делает | По умолчанию |
|---|---|---|
| Tenant ID (необязательно) | Переопределяет, из какого тенанта FastComments лента читает комментарии. Оставьте пустым, чтобы использовать автоматически настроенный тенант магазина. | (пусто) |
| Number of comments | Сколько последних комментариев показывать. Диапазон от 1 до 50. | 5 |

### Советы

- Каждый комментарий ссылается на страницу, где он был оставлен, поэтому блок также служит подсказкой «о чём сейчас говорят» для навигации.
- Лента действует на весь магазин. Чтобы показать последние комментарии для отдельной страницы, используйте вместо этого блок **FastComments** на этой странице.
