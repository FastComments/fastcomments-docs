Блок **FastComments - Recent Discussions** выводит список страниц вашего магазина с самой недавней активностью комментариев — по одной записи на страницу. Используйте его, когда хотите, чтобы посетители находили активные обсуждения, а не отдельные комментарии.

### Добавление блока

1. Откройте редактор темы Shopify.
2. Откройте шаблон, в который вы хотите добавить ленту — например, боковую панель, подвал, индекс блога или секцию главной страницы.
3. Нажмите **Add block** в секции, которая должна его содержать.
4. В разделе **Apps** выберите **FastComments - Recent Discussions**.
5. Нажмите **Save**.

### Настройки

| Настройка | Что делает | По умолчанию |
|---|---|---|
| Tenant ID (необязательно) | Переопределяет, из какого тенанта FastComments лента читает данные. Оставьте пустым, чтобы использовать автоматически настроенный тенант магазина. | (пусто) |
| Number of comments | Сколько недавних обсуждений показывать. Диапазон от 1 до 50. | 20 |

### Recent Discussions и Recent Comments

Оба блока используют одни и те же данные, но показывают их по-разному:

- **Recent Comments**: плоский список последних отдельных комментариев. Лучше всего подходит для «что только что сказали».
- **Recent Discussions**: одна запись на страницу, упорядоченная по последней активности. Лучше всего подходит для «какие обсуждения активны прямо сейчас».

Можно использовать оба блока в одном магазине. Например, Recent Comments в боковой панели блога, а Recent Discussions на главной странице.
