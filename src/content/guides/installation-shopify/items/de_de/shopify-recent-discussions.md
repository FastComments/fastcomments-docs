Der Block **FastComments - Recent Discussions** listet die Seiten Ihres Shops mit der aktuellsten Kommentaraktivität auf, ein Eintrag pro Seite. Verwenden Sie ihn, wenn Besucher aktive Threads entdecken sollen statt einzelner Kommentare.

### Block hinzufügen

1. Öffnen Sie den Shopify-Theme-Editor.
2. Öffnen Sie die Vorlage, in der Sie den Feed möchten, z. B. eine Seitenleiste, den Footer, einen Blog-Index oder einen Homepage-Abschnitt.
3. Klicken Sie in dem Abschnitt, der den Block enthalten soll, auf **Block hinzufügen**.
4. Wählen Sie unter **Apps** die Option **FastComments - Recent Discussions** aus.
5. Klicken Sie auf **Speichern**.

### Einstellungen

| Einstellung | Funktion | Standardwert |
|---|---|---|
| Tenant ID (optional) | Überschreiben, welchen FastComments-Tenant der Feed ausliest. Lassen Sie das Feld leer, um den automatisch konfigurierten Tenant des Shops zu verwenden. | (leer) |
| Number of comments | Wie viele aktuelle Diskussionen angezeigt werden sollen. Bereich 1 bis 50. | 20 |

### Recent Discussions vs. Recent Comments

Beide Blöcke greifen auf dieselben Daten zu, zeigen aber unterschiedliche Ansichten:

- **Recent Comments**: eine flache Liste der neuesten einzelnen Kommentare. Am besten für „was wurde gerade gesagt".
- **Recent Discussions**: ein Eintrag pro Seite, sortiert nach der aktuellsten Aktivität. Am besten für „welche Threads gerade aktiv sind".

Sie können beide im selben Shop verwenden. Zum Beispiel Recent Comments in der Blog-Seitenleiste und Recent Discussions auf der Startseite.
