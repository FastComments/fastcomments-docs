**FastComments** 블록은 메인 댓글 위젯입니다. 블로그 포스트 템플릿, 상품 템플릿, 또는 토론 스레드나 실시간 채팅을 원하는 다른 모든 페이지에 추가하세요.

### 블록 추가하기

1. Shopify 테마 편집기를 엽니다 (**온라인 스토어 > 테마 > 사용자 지정**).
2. 댓글을 달고 싶은 템플릿을 선택합니다: **블로그 포스트**, **상품**, 또는 다른 페이지나 섹션 템플릿.
3. 댓글이 표시되길 원하는 섹션에서 **블록 추가**를 클릭합니다.
4. **앱** 아래에서 **FastComments**를 선택합니다.
5. **저장**을 클릭합니다.

블록이 즉시 나타납니다. 입력할 Tenant ID가 없습니다; 앱을 설치할 때 스토어의 테넌트가 자동으로 연결됩니다.

### 설정

| 설정 | 기능 | 기본값 |
|---|---|---|
| Tenant ID (선택 사항) | 블록이 렌더링되는 FastComments 테넌트를 재정의합니다. 스토어에 자동으로 구성된 테넌트를 사용하려면 비워 두세요. 수동 테넌트 ID는 fastcomments.com/auth/my-account/api-secret에서 찾을 수 있습니다. | (비어 있음) |
| SSO | 댓글을 달기 전에 방문자를 Shopify 고객 계정으로 자동 로그인합니다. [Shopify 고객 자동 로그인](/guide-installation-shopify.html#shopify-sso)을 참조하세요. | 켜짐 |
| 댓글 스타일 | 중첩된 답글과 투표를 위한 **Threaded**, 또는 실시간 채팅 피드를 위한 **Streaming**. | Threaded |
| Custom URL ID | 자동 감지된 페이지 식별자를 재정의합니다. 두 URL이 하나의 댓글 스레드를 공유하도록 하려는 경우 이를 사용하세요. | (자동 감지) |

### 페이지 식별자가 선택되는 방식

각 댓글 스레드는 URL ID로 구분됩니다. 블록은 자동으로 하나를 선택합니다:

- **블로그 포스트 템플릿:** `shopify-article-{article.id}`, 슬러그와 제목 변경에도 안정적입니다.
- **상품 템플릿:** `shopify-product-{product.id}`, 슬러그와 제목 변경에도 안정적입니다.
- **기타 템플릿:** 요청 경로.

**Custom URL ID**를 설정하면 해당 값이 대신 사용됩니다. 여러 블록에서 동일한 Custom URL ID를 사용하여(예: 상품 페이지의 현지화된 변형에서) 하나의 댓글 스레드를 공유하세요.

### Threaded vs Streaming

**Threaded**가 기본값입니다. 방문자가 서로 답글을 달고, 투표하며, 조정 도구가 예상대로 작동합니다. 블로그 포스트와 상품 리뷰에 가장 적합합니다.

**Streaming**은 스레딩을 제거하고 새 댓글이 게시되는 대로 실시간으로 표시하여 채팅 피드처럼 보입니다. 상품 출시, 라이브 이벤트, 커뮤니티 페이지에 가장 적합합니다.

### 같은 페이지에 여러 블록

블록은 동일한 템플릿에 두 번 이상 추가할 수 있습니다. 예를 들어, 상품 페이지 상단에 리뷰 요약을, 하단에 FastComments 블록을 배치할 수 있습니다. 블록들이 URL ID를 공유하므로 요약이 아래의 댓글을 반영합니다.

### 팁

- 블록은 테넌트를 찾지 못하면 테마 편집기 미리보기에서 노란색 알림과 함께 자신을 숨깁니다. 라이브 스토어에서 이것이 나타나면 FastComments 앱을 다시 설치하세요.
- 상품 페이지의 경우, FastComments 블록은 상품 리뷰 위젯 역할도 합니다. 페이지 상단에 별점 요약을 위해 **FastComments - Reviews Summary**와 함께 사용하세요.
