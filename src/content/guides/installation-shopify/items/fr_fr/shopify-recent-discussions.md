Le bloc **FastComments - Recent Discussions** liste les pages de votre boutique ayant l'activité de commentaires la plus récente, avec une entrée par page. Utilisez-le lorsque vous souhaitez que les visiteurs découvrent des discussions actives plutôt que des commentaires individuels.

### Ajouter le bloc

1. Ouvrez l'éditeur de thème Shopify.
2. Ouvrez le modèle où vous souhaitez afficher le flux, par exemple une barre latérale, un pied de page, un index de blog ou une section de page d'accueil.
3. Cliquez sur **Add block** dans la section qui doit le contenir.
4. Sous **Apps**, sélectionnez **FastComments - Recent Discussions**.
5. Cliquez sur **Save**.

### Paramètres

| Paramètre | Fonction | Valeur par défaut |
|---|---|---|
| Tenant ID (facultatif) | Remplace le tenant FastComments à partir duquel le flux lit les données. Laissez vide pour utiliser le tenant configuré automatiquement pour la boutique. | (vide) |
| Nombre de commentaires | Nombre de discussions récentes à afficher. Plage de 1 à 50. | 20 |

### Recent Discussions vs Recent Comments

Les deux blocs s'appuient sur les mêmes données, mais affichent des vues différentes :

- **Recent Comments** : une liste plate des derniers commentaires individuels. Idéal pour « ce qui vient d'être dit ».
- **Recent Discussions** : une entrée par page, classée par activité la plus récente. Idéal pour « quelles discussions sont actives en ce moment ».

Vous pouvez utiliser les deux sur la même boutique. Par exemple, Recent Comments dans la barre latérale du blog et Recent Discussions sur la page d'accueil.
