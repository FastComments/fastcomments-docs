Блок **FastComments - Comment Count** приказује мали број коментара за једну страницу. Користите га у листама блог постова, картицама производа или у било ком шаблону који води ка страници са коментарима, тако да посетиоци могу да виде колико је нека тема активна пре него што кликну.

### Додавање блока

1. Отворите Shopify уредник теме.
2. Отворите шаблон у ком желите да се бројач прикаже. На пример, шаблон **Blog** (листа постова) или секцију са листом производа.
3. Кликните **Add block** у секцији која приказује сваку ставку.
4. Под **Apps**, изаберите **FastComments - Comment Count**.
5. Кликните **Save**.

### Подешавања

| Подешавање | Шта ради | Подразумевано |
|---|---|---|
| Tenant ID (опционо) | Одлучује са ког FastComments тенанта бројач чита податке. Оставите празно да би се користио аутоматски конфигурисан тенант продавнице. | (празно) |
| Custom URL ID | Одлучује који идентификатор странице бројач тражи. Користите ово када се бројач налази на другачијој страници од FastComments блока који прати. | (аутоматски детектовано) |

### Како бројач проналази нит коментара

Блок Comment Count користи исту логику аутоматске детекције као и блок **FastComments**:

- Шаблон блог поста: `shopify-article-{article.id}`
- Шаблон производа: `shopify-product-{product.id}`
- Остали шаблони: путања захтева

Ако сте поставили **Custom URL ID** на **FastComments** блоку на некој страници, поставите исти Custom URL ID и на блоку Comment Count како би оба указивали на исту нит.

### Савети

- Бројачи за све ставке на страници се преузимају једним захтевом, тако да додавање блока на сваку ставку у дугој листи не изазива додатне трошкове мрежних захтева.
- Један блок Comment Count по чланку или производу у листи је очекивана употреба; блок може бити додат онолико пута колико вам је потребно.
