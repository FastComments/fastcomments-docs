Блок **FastComments - Recent Discussions** приказује странице ваше продавнице са најновијом активношћу коментара, по један унос по страници. Користите га када желите да посетиоци открију активне дискусије, а не појединачне коментаре.

### Додавање блока

1. Отворите Shopify уређивач теме.
2. Отворите шаблон у ком желите фид, нпр. бочну траку, подножје, индекс блога или секцију насловне странице.
3. Кликните **Add block** у секцији која треба да га садржи.
4. Под **Apps**, изаберите **FastComments - Recent Discussions**.
5. Кликните **Save**.

### Подешавања

| Подешавање | Шта ради | Подразумевано |
|---|---|---|
| Tenant ID (опционо) | Одређује из ког FastComments тенанта фид чита податке. Оставите празно да би се користио аутоматски конфигурисан тенант продавнице. | (празно) |
| Number of comments | Колико недавних дискусија приказати. Опсег од 1 до 50. | 20 |

### Recent Discussions у односу на Recent Comments

Оба блока вуку податке из истог извора, али приказују различите погледе:

- **Recent Comments**: равна листа најновијих појединачних коментара. Најбоље за „шта је управо речено".
- **Recent Discussions**: један унос по страници, поређан по најновијој активности. Најбоље за „које дискусије су тренутно живе".

Можете користити оба на истој продавници. На пример, Recent Comments у бочној траци блога и Recent Discussions на насловној страници.
