Блок **FastComments - Comment Count** відображає невеликий лічильник коментарів для однієї сторінки. Використовуйте його у списках постів блогу, картках товарів або будь-якому шаблоні, що посилається на сторінку з коментарями, щоб відвідувачі могли бачити, наскільки активне кожне обговорення, перед переходом.

### Додайте блок

1. Відкрийте редактор теми Shopify.
2. Відкрийте шаблон, у якому має з'явитися лічильник. Наприклад, шаблон **Blog** (список постів) або розділ зі списком товарів.
3. Натисніть **Add block** у розділі, який відображає кожен елемент.
4. У розділі **Apps** виберіть **FastComments - Comment Count**.
5. Натисніть **Save**.

### Налаштування

| Налаштування | Що воно робить | За замовчуванням |
|---|---|---|
| Tenant ID (необов'язково) | Перевизначає, з якого орендаря FastComments зчитується лічильник. Залиште порожнім, щоб використовувати автоматично налаштованого орендаря магазину. | (порожньо) |
| Custom URL ID | Перевизначає ідентифікатор сторінки, який шукає лічильник. Використовуйте це, коли лічильник розташований на іншій сторінці, ніж блок FastComments, який він відстежує. | (визначається автоматично) |

### Як лічильник зіставляється з гілкою коментарів

Блок Comment Count використовує ту саму логіку автоматичного визначення, що й блок **FastComments**:

- Шаблон посту блогу: `shopify-article-{article.id}`
- Шаблон товару: `shopify-product-{product.id}`
- Інші шаблони: шлях запиту

Якщо ви встановили **Custom URL ID** у блоці **FastComments** на сторінці, встановіть той самий Custom URL ID у блоці Comment Count, щоб вони вказували на одну гілку.

### Поради

- Лічильники для всіх елементів на сторінці завантажуються одним запитом, тому додавання блоку до кожного елемента в довгому списку не має додаткових витрат на мережеві запити.
- Один блок Comment Count на статтю або товар у списку — це очікуване використання; блок можна додавати стільки разів, скільки потрібно.
