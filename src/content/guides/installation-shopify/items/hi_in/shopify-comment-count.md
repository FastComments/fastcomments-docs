**FastComments - Comment Count** ब्लॉक एक पेज के लिए एक छोटी कमेंट गिनती दिखाता है। इसे ब्लॉग पोस्ट लिस्ट, प्रोडक्ट कार्ड, या किसी भी ऐसे टेम्पलेट में उपयोग करें जो कमेंट्स वाले पेज से लिंक करता है, ताकि विज़िटर क्लिक करने से पहले देख सकें कि कौन सी थ्रेड कितनी सक्रिय है।

### ब्लॉक जोड़ें

1. Shopify थीम एडिटर खोलें।
2. वह टेम्पलेट खोलें जहाँ आप गिनती दिखाना चाहते हैं। उदाहरण के लिए, **Blog** टेम्पलेट (पोस्ट लिस्ट) या प्रोडक्ट लिस्टिंग सेक्शन।
3. उस सेक्शन में **Add block** पर क्लिक करें जो प्रत्येक आइटम रेंडर करता है।
4. **Apps** के अंतर्गत, **FastComments - Comment Count** चुनें।
5. **Save** पर क्लिक करें।

### सेटिंग्स

| सेटिंग | यह क्या करती है | डिफ़ॉल्ट |
|---|---|---|
| Tenant ID (वैकल्पिक) | यह ओवरराइड करें कि गिनती किस FastComments टेनेंट से पढ़ी जाए। स्टोर के स्वतः-कॉन्फ़िगर किए गए टेनेंट का उपयोग करने के लिए खाली छोड़ दें। | (खाली) |
| Custom URL ID | यह ओवरराइड करें कि गिनती कौन सा पेज आइडेंटिफ़ायर देखती है। इसका उपयोग तब करें जब गिनती उस FastComments ब्लॉक से अलग पेज पर हो जिसे वह ट्रैक करती है। | (स्वतः-पहचाना गया) |

### गिनती कमेंट थ्रेड से कैसे मैच होती है

Comment Count ब्लॉक **FastComments** ब्लॉक के समान ऑटो-डिटेक्शन लॉजिक का उपयोग करता है:

- ब्लॉग पोस्ट टेम्पलेट: `shopify-article-{article.id}`
- प्रोडक्ट टेम्पलेट: `shopify-product-{product.id}`
- अन्य टेम्पलेट: रिक्वेस्ट पाथ

यदि आपने किसी पेज पर **FastComments** ब्लॉक पर **Custom URL ID** सेट किया है, तो Comment Count ब्लॉक पर भी वही Custom URL ID सेट करें ताकि दोनों एक ही थ्रेड की ओर इशारा करें।

### सुझाव

- पेज पर प्रत्येक आइटम की गिनती एक ही रिक्वेस्ट में फ़ेच की जाती है, इसलिए लंबी लिस्ट में प्रत्येक आइटम पर ब्लॉक जोड़ने का कोई अतिरिक्त राउंड-ट्रिप खर्च नहीं होता।
- लिस्टिंग में प्रत्येक आर्टिकल या प्रोडक्ट के लिए एक Comment Count ब्लॉक ही अपेक्षित उपयोग है; ब्लॉक को आवश्यकतानुसार जितनी बार चाहें जोड़ा जा सकता है।
